# 加载场景与加载动作页动作

V2 的新面板按“场景 → 分组 → 动作”组织，不再把某个程序下的二维动作页当作唯一入口。迁移后如果需要快速跳到某个场景、分组或旧动作页，可以按下面顺序处理。

## 在面板中加载场景

- 单击全局区或上下文区顶部的场景标签，可以切换当前区域显示的场景。
- 鼠标位于全局区或上下文区时，按住 `Ctrl` 滚动滚轮，可以切换该区域的场景标签。
- 右键上下文区锁定按钮，可以选择要加载并锁定的应用场景；再次点击锁定按钮可恢复自动切换。
- 需要管理场景、分组和触发规则时，双击场景标签，或从新版主窗口标题栏菜单打开 **场景与动作管理**。

详细界面说明见 [新面板窗口的使用](/v2/what's-new/new-main-win/usage)。

## 为常用分组创建入口

在开启“显示分组”后，右键具名分组可以创建一个“加载此分组”的动作。这个动作适合放在常用场景中，用来快速定位到某个分组。

“加载此分组”只是入口动作，不会复制分组里的动作内容。整理动作时仍要区分“移动/同时添加入口”和“删除动作本体”。

## 旧动作页如何处理

旧动作页会作为迁移后的可查看内容保留在 **场景与动作管理** 中。需要把旧动作页里的内容放到新面板时，优先使用新面板或场景管理中的导入、移动和分组整理入口，而不是让 1.x 与 V2 同时编辑同一批动作。

如果需要回退到 1.x，应重新安装 1.x，并使用迁移前备份或 1.x 自己的数据。不要把 V2 数据目录覆盖到旧版数据目录。
