# 鼠标手势

鼠标手势用「按住某个键并移动鼠标」画出一条轨迹；Quicker 把轨迹和已保存的手势图形比对，命中后执行绑定的动作。适合鼠标不离开当前窗口、又希望一笔画完就执行的场景。

移入下方演示区可亲自画一笔；移出后会自动演示几条常见轨迹。演示页**不会**做真实模板匹配。

## 快速开始

1. 确认已能弹出动作面板（或至少 Quicker 在后台运行）。
2. 用手势时，通常先通过 **高级鼠标触发** 进入手势会话。常见配置：按住 **右键** 并移动一段距离 → 操作选 **开始鼠标手势**（也可改为中键等，以你本机设置为准）。
3. 打开 **场景与动作管理 → 鼠标触发 → 手势**。
4. 在当前场景中为某条手势轨迹绑定动作：可双击手势磁贴编辑，或从动作面板拖入动作。
5. 保存后，在目标程序中按你配置的方式开始手势，画出对应轨迹并松开。

手势的**图形定义**在账号内共用；各场景保存的是「这条轨迹在当前上下文执行什么」。

## 画的时候你会看到什么

- **轨迹线**：默认灰色；识别成功变为青蓝色（默认 `#00BFFF`），未匹配为灰色（默认 `#808080`）。可在手势功能设置里改颜色和粗细。
- **动作名**：命中后可在轨迹附近看到将要执行的内容。
- **停顿候选**：停顿一段时间后（默认约 1.2 秒），可能在轨迹末端出现候选手势缩略图，可点选；明确点选优先于收笔时的自动识别。
- **收笔**：松开时会补入最终位置再匹配，减少「看起来画完了却少了末尾方向」的情况。

可在功能设置中关闭轨迹显示，或开启结束淡出等特效。

## 按场景覆盖与禁用

手势规则使用与面板、轮盘一致的场景识别。常见继承顺序：

- 普通程序：当前程序 → 全局
- 浏览器：当前浏览器 → 浏览器通用 → 全局
- 网址：当前网址 → 当前浏览器 → 浏览器通用 → 全局
- 子场景（路径 / 标题 / 窗口类）：子场景 → 所属程序 → 全局

同一条轨迹在更具体的场景绑定动作后，会覆盖上级同轨迹动作。

注意区分：

| 操作 | 效果 |
| --- | --- |
| 本地禁用该轨迹 | 阻止上级同轨迹规则触发 |
| 删除本地覆盖 | 恢复使用上级继承的动作 |

手势或轮盘会话开始后，本次会话会固定开始位置对应的场景与动作；即便前台窗口随后变化，延迟执行也不会改用新窗口的规则。

## 延迟执行

在手势动作编辑里可设置延迟：识别完成后先关闭轨迹窗口，再等待指定时间执行。适合截图、窗口操作等需要界面先消失的情况。直接触发动作与按键子动作共用同一条延迟设置。

## 与轮盘、扩展热键共用右键时

若右键同时用于轮盘、手势、长按面板和右键扩展热键，Quicker 会按本次操作意图协调：

- 按住右键再按字母 → 倾向扩展热键
- 按住右键并移动 → 可进入轮盘或手势
- 扩展热键一旦确定触发，同一次按住不会再误转成轮盘或手势

细节见 [扩展热键（2.x 变化）](/v2/what's-new/others/powerkeys) 与 [轮盘菜单（2.x 变化）](/v2/what's-new/others/circle-menu)。

## 运行时快速进设置

通过「按键 + 移动」等高级鼠标规则启动手势后，可在结束会话前把指针移到**当前屏幕顶部角落**（识别范围很小）：

- **左上角**：打开当前场景的手势管理
- **右上角**：打开手势功能设置

这不会替代普通的「移到屏幕角落」高级鼠标规则。

## 限制与排障

- **远程桌面 / 软件渲染 / 很长的轨迹**：显示与识别已做抽稀和平滑，但仍建议在真实环境多试几次常用手势。
- **自绘界面、游戏**：手势本身不依赖目标控件，但若与其它鼠标功能抢同一按键，可能进不了手势会话——先查高级鼠标规则与轮盘/扩展热键是否冲突。
- **总是进轮盘而不是手势**：检查同一按键上是否同时配置了「显示轮盘」与「开始鼠标手势」，以及移动距离、触发类型是否满足手势条件。
- **升级后手感变化**：匹配阈值会按兼容方式换算；若个别手势变难，可在管理页重绘该轨迹或微调功能设置。相对 1.x 的改进清单见 [鼠标手势（2.x 变化）](/v2/what's-new/others/mouse-gestures)。
