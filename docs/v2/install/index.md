# 安装与更新

Quicker V2 下载入口是 [https://getquicker.net/V2](https://getquicker.net/V2)。不要从 `/Download` 下载 1.x 安装包来体验 V2。

V2 当前是 Preview，官方 V2 页面标注为「仅专业版」；免费账号数据迁移仍在进行，当前不能登录 2.0。安装前请先阅读 [体验前必读](/important-notice)。

## 入口

- [安装 Quicker V2](/v2/install/windows)：系统要求、下载、安装和首次启动。
- [更新 Quicker V2](/v2/install/update)：应用内更新、官网版本记录和回退提醒。
- [运行平台与兼容性](/v2/what's-new/platform-and-compatibility)：.NET 10、x64、Windows 支持范围和组件位数。

## 迁移提醒

Quicker 1.x 与 V2 不建议同时安装使用。若要从 1.x 迁移，先在 1.x 中完成同步、导出和备份，再卸载 1.x、安装 V2。完整步骤见 [从 V1 迁移](/v2/migration/from-v1)。
