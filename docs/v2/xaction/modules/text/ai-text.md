# AI 文本处理

使用统一 AI 设置完成总结、改写、翻译、校对等文本任务，也可以用完整系统提示词定义自定义处理规则。

使用前，请先在 Quicker 的 **设置 → AI** 中配置服务、模型和“日常文本处理与翻译”任务场景。配置方式见[统一 AI 服务与模型设置](/v2/what's-new/ai-services-and-models)。

## 基本用法

1. 将待处理内容传给“文本”。
2. 选择“操作”，按需填写补充要求；翻译时还需填写目标语言。
3. 选择 AI 任务场景和输出方式。
4. 从“回答”输出中取得处理结果。

内置操作包括总结、改写、精简、扩写、翻译、校对、改变语气、生成标题和提取关键词。选择“自定义”时必须填写“完整系统提示词”，内置模板和“补充要求”不会再参与请求。

## 输出方式

- **直接返回**：请求结束后立即把完整回答写入输出，适合无人值守流程。
- **交互调整**：打开 Markdown 对话窗口，流式显示回答，并允许继续追问。只有点击“采用当前回答”后步骤才成功；关闭或取消窗口会按用户取消结束，不会把当前内容作为结果。

例如，将剪贴板文本传入“文本”，操作选择“总结”，补充要求填写“使用三条要点，每条不超过 30 字”，即可将“回答”交给后续的写入剪贴板或显示文本步骤。

## 注意事项

- 动作保存的是任务场景 ID，不包含服务凭据。分享动作或换电脑后，需要在目标设备重新配置 API Key，并保证存在对应任务场景。
- 当自定义任务场景不存在时，可按“任务场景缺失时”的设置回退到内置文本场景或直接失败；“实际任务场景”和“是否回退场景”可用于诊断。
- “最大输出 Token”为 0 时，本步骤不额外设置上限。“温度”留空时不会发送该参数，避免与不支持它的模型冲突。
- 输入内容会发送给实际选中的 AI 服务商，请勿处理不允许外发的敏感数据。
