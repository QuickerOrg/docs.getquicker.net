# Quicker V2

Quicker V2 目前是 Preview，官方 V2 页面标注为「仅专业版」；免费账号数据迁移仍在进行，当前不能登录 2.0。请不要把 V2 当作关键 1.x 环境的直接替换，体验前先阅读 [体验前必读](/important-notice)。
