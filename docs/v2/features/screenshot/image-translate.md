# 图片翻译

截图或贴图遇到外文界面、外文资料时，可用 **图片翻译**：把当前图像交给百度翻译或有道智云的**图片翻译**接口，得到带译文贴合的结果图（图到图），再决定复制或替换原图。

配额与计费由你在开放平台开通的账号决定，Quicker **不提供**内置翻译额度。

:::tip[与 OCR 无关]
图片翻译的 Key **不是**「组合动作模块选项 → 基础 OCR」里的百度 OCR Key。OCR 与图片翻译是两套凭证，互不通用。
:::

## 快速开始

1. 打开 Quicker **设置 → 截图 → 截图设置**。
2. 选择 **服务商**（百度翻译开放平台 / 有道智云），并设置 **目标语言**。
3. 按下文在开放平台开通**图片翻译**能力，把 APP ID / 密钥填入对应栏目。
4. 点击 **验证图片翻译**，确认成功。
5. 进入 [截图 Pro](./capture-pro.md)：确认选区后打开工具栏，点击 **图片翻译**；或在贴图右键菜单选择 **图片翻译**。
6. 在结果窗口预览译文图，可 **复制图片** 或 **替换**（贴图 / 截图选区内容）。

未配置凭证时，软件会提示到 **设置 → 截图 → 截图设置** 填写。

## 设置项说明

路径：**设置 → 截图 → 截图设置**（与「快速截图」同组）。

| 项 | 说明 |
| --- | --- |
| 服务商 | **百度翻译开放平台** 或 **有道智云**；实际调用所选服务商的图片翻译接口 |
| 目标语言 | 跟随软件界面、简体中文、繁体中文、英语、日语、韩语、法语、德语、西班牙语、俄语等 |
| 百度 APP ID / 密钥 | 百度翻译开放平台开发者中心中的 APP ID 与密钥 |
| 有道应用 ID / 应用密钥 | 有道智云应用总览中的应用 ID 与密钥 |
| 验证图片翻译 | 用一张样例图调用**图片翻译**接口，检查凭证与权限是否可用 |

### 本机保存，不同步

API Key 只保存在本机账号数据中，**不会**随 Quicker 云同步上传。换电脑或重装后需要重新填写。

## 如何使用

### 截图 Pro

1. 进入截图 Pro，框选或确认选区。
2. 按空格显示标注工具栏（若尚未显示）。
3. 点击工具栏上的 **图片翻译**。
4. 等待云端处理；结果窗口打开后预览译文贴合图。
5. **复制图片** 写入剪贴板，或 **替换** 当前选区图像后继续标注 / 结束截图。

未确认选区时无法翻译，需先完成选区。

### 贴图

在贴图窗口右键菜单中选择 **图片翻译**。成功后可 **复制图片**，或 **替换** 贴图内容。

## 配置百度翻译开放平台

官方入口：[百度翻译开放平台](https://fanyi-api.baidu.com/)  
产品说明：[图片翻译 API](https://fanyi-api.baidu.com/product/22)（含定价与接入文档）

1. 注册并登录百度翻译开放平台。
2. 开通 **图片翻译** 相关服务（不要只开通通用文本翻译）。
3. 进入开发者中心，复制 **APP ID** 与 **密钥**。
4. 在 Quicker **截图设置** 中：服务商选 **百度翻译开放平台**，填入 **APP ID**、**密钥**。
5. 点击 **验证图片翻译**。

出错时可对照百度开放平台文档中的错误码说明排查。

## 配置有道智云

官方入口：[有道智云 AI 开放平台](https://ai.youdao.com/)  
能力说明：创建应用时选择 **图片翻译**，并以 **API** 方式调用。

1. 注册并登录有道智云。
2. 创建应用：选择 **图片翻译**，调用方式为 **API**。
3. 在控制台为该应用开通 **图片翻译** 服务，确认状态为正常。
4. 在应用总览中复制 **应用 ID** 与 **密钥**。
5. 在 Quicker **截图设置** 中：服务商选 **有道智云**，填入 **应用 ID**、**应用密钥**。
6. 点击 **验证图片翻译**。

出错时可对照有道智云文档中的错误码说明排查。

:::tip[验证与正式使用]
Quicker 的「验证图片翻译」会真实调用图片翻译接口。验证成功通常表示 APP ID / 密钥正确，且已开通图片翻译权限。若只开通了**文本翻译**、未开通图片翻译，验证或实际使用都会失败。
:::

## 结果与限制

| 说明 | 详情 |
| --- | --- |
| 结果形态 | 厂商返回的贴合图（图到图），不是纯文本译文窗 |
| 网络 | 需要能访问对应开放平台接口 |
| 配额 | 按服务商套餐计费；免费额度用尽后需在开放平台续费或升级 |
| 效果 | 小字、艺术字、复杂背景、倾斜文字等可能导致识别或贴合不佳 |
| 不包含 | 不调用 Quicker 云端翻译；不做「图片到文本 / 大模型翻译」模式；不与动作里的文本翻译步骤共用 Key |
