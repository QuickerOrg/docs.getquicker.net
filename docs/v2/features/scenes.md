# 场景与分组

V2 的面板按 **场景 → 分组 → 动作** 组织。场景回答「当前在哪个上下文」，分组用来替代 1.x 里「同一程序下的多张动作页」。

## 日常怎么用

- **全局区**：不依赖当前程序、希望随时能用的动作。
- **上下文区**：随前台程序或网址变化；末尾的 **通用** 适合所有程序都要用的动作。
- 单击场景标签切换；双击打开「场景、动作与触发」管理窗口（2.2.26 起由原「场景与动作管理」更名）；右键可新建、导入或从旧动作页引入动作。
- 开启「显示分组」后，组在同一列表里连续显示；连续显示时，动作区左侧的圆点导航可跳转（悬停显示分组名）。「每次单个分组（上）」时导航在标题行。
- 动作本体和入口是分开的：从场景移除只去掉当前位置，删除才会去掉本体。

完整操作（启用新面板、置顶、拖动、批量移动、锁定上下文）见 [动作面板使用说明](/v2/features/action-panel/usage)。

## 让不同软件显示不同动作分组

要让 Quicker 随当前软件显示各自的动作分组，先为软件建立程序场景，再把动作放进该场景的分组：

1. 打开「场景、动作与触发」管理窗口，在场景列表底部选择 **添加场景**，选中目标软件并创建程序场景。也可以先切到该软件，在新面板的上下文区使用 **创建场景** 提示。
2. 在新场景下建立分组，将需要的动作添加或移动到分组中。另一个软件重复这两步，分别安排自己的分组和动作。
3. 切换到目标软件并打开新面板，检查上下文区是否切到对应程序场景。若面板被锁定在别的上下文，先解除锁定；识别不符时，从面板的「更多 → 工具 → 诊断与修复」打开 **当前场景诊断** 查看实际命中。

全局区的动作不会随着软件切换；要让同一组规则与动作在多个程序间复用，可用下文的[规则父场景](#规则父场景)。

## 网址场景：如何填写网址

网址场景适合放置某个网站专用的动作和触发规则。新建或编辑网址场景时，**网址**填写的是当前网页的匹配规则。浏览器打开符合规则的页面时，Quicker 才会识别到该网址场景。

### 常用填写方式

通常使用 `*` 通配符即可，它表示零个或多个任意字符：

| 想匹配的范围 | 填写示例 |
| --- | --- |
| 某个网站的所有页面 | `https://www.baidu.com/*` |
| 某个网站下的指定路径 | `https://github.com/QuickerOrg/*` |
| 同时匹配 HTTP 和 HTTPS | `http*://example.com/*` |

建议从浏览器地址栏复制网址，保留需要限定的域名和路径，再用 `*` 替换会变化的部分。域名前的 `www.` 也是网址的一部分：`https://example.com/*` 不匹配 `https://www.example.com/`。

匹配不区分大小写，默认只要网址中的一部分符合规则就算命中，并不要求整条网址完全一致。例如，只填 `example.com` 也可能匹配其他网站网址的路径或参数中出现的这段文字。因此，通常应填写包含协议、域名和路径边界的规则；需要严格限定范围时，使用下面的正则表达式。

### 使用正则表达式精确匹配

以小写 `regex:` 开头，后面填写正则表达式。例如，匹配 `example.com` 主域名和它的所有子域名，同时支持 HTTP 和 HTTPS：

```text
regex:^https?://([a-z0-9-]+\.)*example\.com([/?#]|$)
```

这个规则可以匹配 `https://example.com/`、`https://www.example.com/docs` 和 `https://help.example.com/`，不会匹配 `https://example.com.other.com/`。

需要整条网址完全一致时，使用 `^` 限定开头、`$` 限定结尾。例如，只匹配指定页面，不接受后面附加的查询参数：

```text
regex:^https://example\.com/docs/start$
```

普通写法使用 `*`，正则表达式中表示任意长度字符则使用 `.*`；编写正则时建议始终加上 `regex:` 前缀。

### 设置后没有生效怎么办

1. 确认浏览器扩展已连接到 Quicker；仅将程序设置为浏览器，不能代替扩展连接。
2. 在浏览器中切换到目标网页，再从面板标题栏「更多」→「工具」→「诊断与修复」打开「当前场景诊断」，查看实际识别的网址及命中的网址场景。
3. 对照实际网址检查协议、`www.`、路径、末尾斜杠和查询参数；使用 `^`、`$` 精确匹配时，这些差异也会影响结果。

## 场景和触发是同一套上下文

快捷键、轮盘、手势、文本指令等规则也按场景生效。更具体的场景可以覆盖或禁用上级规则。统一编辑入口在 **场景、动作与触发** 管理窗口。

共享场景识别不代表各功能会先显示同一个来源。例如，网页场景已匹配时，普通触发的轮盘仍默认先显示浏览器程序轮盘，向下滚轮才进入网页独立轮盘；窗口子场景则按自身的合并或独立模式显示。具体操作见[轮盘的场景来源与切换](/v2/features/triggers/circle-menu#不同场景先显示哪个轮盘)。

2.1.28 起，可在该窗口里对第三方浏览器程序的场景条目右键选择 **作为浏览器程序**，让小众浏览器使用浏览器场景和对应触发规则。

## 作为浏览器程序与父场景归属

2.2.17 起，自定义程序的浏览器归属统一纳入父场景管理，并随账号同步；此前可能出现“重启后归属失效”的情况已按此修复。把自定义程序添加到浏览器父场景下之后，需要重新设置一次归属。多设备或可能回退时，请先阅读 [2.2.17 浏览器父场景归属的多设备与回退](/v2/migration/upgrade-and-rollback#2217-浏览器父场景归属的多设备与回退)。

## 场景、动作与触发管理中的右键

2.2.9 起，左侧场景列表右键菜单补齐常用操作：

- **编辑**、**删除**（仍会检查内容并确认）
- **添加窗口子场景**
- **置顶** / 取消置顶
- **创建并复制加载场景的动作**（加载目标为右键选中的场景）
- **复制场景标识**

另有既有的 **作为浏览器程序**（适用于可归类为浏览器的程序场景）。虚拟分组不提供场景命令。2.2.12 起还可建立独立的“规则父场景”，让多个程序共用规则与面板动作，见下文。


## 规则父场景

2.2.12 起，可把多个程序加入一个规则父场景，共用触发规则和新面板动作，不必逐个复制。

1. 在场景目录底部选择“新建规则父场景”，填写名称。
2. 在父场景中配置共享规则，需要共享的动作放入它的面板。
3. 对程序场景右键选择“规则父场景…”，选择归属；新建程序场景时也可直接选择。
4. 切到成员程序，验证共享触发规则。父场景有当前设备可用的动作时，新面板会自动显示独立的共享标签。

每个程序最多选择一个规则父场景，不支持父场景嵌套。2.2.17 起，浏览器公共场景也纳入同一归属选择：程序自身规则优先，其次是选定的父场景，最后是全局规则。显式选择自定义父场景后，不再叠加浏览器公共规则；未指定归属的内置浏览器继续使用浏览器默认归属。各触发方式仍保留自己的覆盖和禁用语义。窗口子场景沿用所属程序的归属，网址场景使用当前浏览器的归属。

共享标签使用父场景自身的动作与排列，不向成员复制。空父面板不增加标签；不支持用它共享旧动作页。原有自定义场景不自动转换为规则父场景。

删除父场景前先移出所有成员；删除成员程序前，先在“规则父场景…”中选“无”。旧客户端不应用新增继承层，多设备使用时请先升级。

### 浏览器归属的升级与多设备使用

2.2.17 起，“作为浏览器程序”和父场景选择使用同一份账号归属数据，并随账号同步。选择浏览器父场景也能让第三方浏览器用于“用当前浏览器打开网址”；读取当前网址仍需要浏览器扩展实际连接，单独设置归属不能代替扩展。

旧版本的本机自定义浏览器名单**不会迁移**，请重新设置浏览器父场景归属。原文件不会删除，浏览器公共场景已有的规则、动作和布局继续保留。

使用浏览器归属前，请把同一账号的设备全部升级到 **2.2.17 或更高版本**。回退或混用旧版时，只要归属配置中包含浏览器父场景，旧客户端就会将整份归属配置视为只读，其他自定义父场景归属也会暂时失效；数据不会因此删除，重新升级后可恢复。详见[升级与回退](/v2/migration/upgrade-and-rollback#2217-浏览器父场景归属的多设备与回退)。

### 拖动设置场景归属

2.2.12 起，可把程序场景直接拖到规则父场景上，用来设置或更换归属；拖回普通场景区域可解除归属。场景列表的展开状态和显示选项会在本机记住，不改变同步数据本身。

## 删除场景与空动作页

2.2.11 起，删除场景时可在确认窗口选择一并清理符合安全条件的空动作页。只有确认列出的空页才会清理，不会因此把仍有内容的动作页或其它位置的动作一起删除；提交前请核对删除范围。

## 跨场景复制移动与未分组

2.2.10 起，动作分组的跨场景复制、移动以及「未分组」批量管理更完整：把分组或未分组动作整批挪到另一场景时，会尽量避免把同名分组混进同一组，减少整理后入口错位。具体操作仍在[动作面板使用说明](/v2/features/action-panel/usage)里用多选、整组移动或批量剪切完成。

相对 1.x 的管理方式和诊断见 [场景与触发方式](/v2/what's-new/scenes-and-triggers.md)。各入口怎么选见 [快速触发概览](./triggers/index.md)。

需要用动作切到某个场景、分组或旧动作页时，见 [加载场景与加载动作页](/v2/migration/new-main-win/load-action-page.md)。
