# 左键辅助

左键辅助是在按住鼠标左键时，再按另一个键或鼠标键来执行操作。适合在拖选文字、框选对象或持续按住左键的过程中快速调用复制、搜索、窗口操作等功能。

全局启用状态、兼容禁用应用列表和动作规则集中显示在 **全局 · 左键辅助**。2.2.11 起，可在功能设置的“适用程序”中管理黑白名单；需要按网址或具体场景区分时，再设置场景规则。

## 快速开始

1. 打开 **场景与动作管理**，进入 **全局 · 左键辅助**，确认功能已启用。
2. 需要按程序或网址区分动作时，左侧改选对应场景。
3. 添加规则，在同一编辑窗口填写按键或多键序列，设置普通操作；需要长按时再展开长按设置。
4. 也可以从动作面板把动作拖到已有规则上替换短按或长按，或拖到列表空白处创建新规则。
5. 保存后，在目标程序中按住左键，再短按或长按第二按键试一次。

绘图、拖放、按住空格平移等软件可能大量使用「左键 + 键盘」，建议只启用明确需要的第二按键。

## 短按和长按分别配置

每个「左键 + 第二按键」规则可以分别设置：

- **单击操作**：第二按键短按时执行；
- **长按操作**：第二按键保持一段时间后执行；
- 规则说明和启用状态。

单个键盘按键可以选择“追加触发”（先执行普通操作，达到长按时间后再执行长按操作）或“分别触发”（短按与长按只执行其中一种）。长按区域按需添加。多键序列不支持长按；特殊键使用窗口中的按键选择控件。

动作以引用方式保存，原动作标题、图标或内容更新后，左键辅助可以继续使用最新内容。列表支持双击编辑、添加规则、删除选择项，并独立显示每条规则的启用状态。

## 一次按住，连续执行

2.2.11 起，同一次按住左键可以连续完成多段操作。例如分别配置 `A` 为全选、`C` 为复制，按住左键后依次按 A、C，操作会按顺序执行。耗时操作会让同一会话的后续操作等待。

也可以把 `AA`、`CP` 等配置成一条多键规则。序列最多 8 个字母或数字；相同字母要先松开再按一次。完整序列不能同时配置长按操作。若同时配置 `A` 和 `AA`，短序列需要等待后续输入判定，不宜把有歧义的前缀用于要求立即执行的操作。

## 适用程序

功能设置可分别保存白名单和黑名单。白名单非空时只允许其中的程序；白名单为空时使用黑名单；两者都为空时适用所有程序。名单支持搜索、选择运行中程序、选窗口和批量粘贴，不需要先创建程序场景。

:::warning 多设备与回退
旧客户端不支持新增的多键、短长按模式和白名单，保存并同步设置可能丢失这些字段。请先备份，并升级所有维护这些规则的设备；回退后避免修改、同步相关设置。丢失后需要从备份恢复或重新配置。详见 [体验前必读](/important-notice#2211-触发设置的多设备与回退风险)。
:::

## 按场景覆盖与禁用

2.2.11 按完整按键序列匹配继承规则：`A` 和 `AA` 是不同规则，不只比较第一个按键。普通场景优先于父场景和全局：

| 操作 | 效果 |
| --- | --- |
| 当前场景没有该按键 | 使用上级规则 |
| 当前场景设置该按键 | 使用本地规则 |
| 当前场景将该序列规则禁用 | 跳过本地停用项，继续查找上级同序列规则 |
| 删除本地规则 | 恢复上级继承 |

停用本地规则不等于禁用上级规则。要在某个程序完全停用左键辅助，使用功能级适用程序名单或场景级禁用设置；不要依赖一条停用规则拦住上级。此处与动作快捷键的同键屏蔽语义不同。

## 目标窗口

会话开始时使用统一的鼠标目标和场景识别结果。对桌面、任务栏、普通资源管理器、UWP、WPS 和浏览器网址，规则选择与其它场景触发功能保持一致。

设置窗口和动作编辑窗口等普通 Quicker 窗口也可以按场景规则触发左键辅助；主面板和明确不参与全局触发的悬浮窗口仍会排除。

删除用户已配置的全局规则后，不会在下一次运行时悄悄恢复同位置的系统预置动作。只有尚未初始化过规则的账号才会使用初始默认值。

## 限制与排障

- **目标软件已经占用「左键 + 某键」**：只启用明确需要的按键；要完全禁用，请调整功能级名单或场景级设置，单独停用本地项仍可能回退上级。
- **停用本地规则后上级同序列仍触发**：这是 2.2.11 的回退行为。要完全禁用，请调整功能范围或场景级设置。
- **想恢复全局动作却没有出现**：检查是否还有启用的同序列本地规则，以及功能范围是否允许当前程序。
- **与扩展热键、高级鼠标或系统快捷键共用按键**：按真实按下顺序测试是否冲突。
- **相对 1.x 的场景化与短按/长按拆分**：见 [左键辅助（2.x 变化）](/v2/what's-new/others/left-button-plus)。
