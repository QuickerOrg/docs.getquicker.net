# 高级鼠标触发

高级鼠标触发可以组合鼠标按键、控制键、触发类型和屏幕位置执行操作。常见方式包括单击、双击、长按、划动、滚轮、移动到角落，以及 2.2.11 起的触碰屏幕边框。

它也是 [轮盘菜单](/v2/features/triggers/circle-menu)、[鼠标手势](/v2/features/triggers/mouse-gestures) 和快速截图的常见启动入口：在划动或长按规则里把操作选成对应项即可。

## 快速开始

1. 打开 **场景、动作与触发 → 鼠标触发 → 高级鼠标触发**。
2. 左侧选择要设置的场景。
3. 新增一条规则：选择鼠标按键（左键、右键、中键、X1、X2 或无按键）、触发类型，以及要执行的操作。
4. 若要打开轮盘、手势或截图：把触发类型设为 **划动** 或 **长按**，操作分别选 **显示轮盘菜单**、**开始鼠标手势** 或 **快速截图**。
5. 保存后，在目标位置按配置的方式试一次。规则很多时，用列表顶部的按键、触发类型或说明文字筛选。

只填写触发后提示而不设置具体操作也是合法配置，适合先验证规则是否命中。

## 触发类型与可执行操作

普通单击、双击和滚轮只显示适合直接执行的操作。划动或长按规则还可以选择：

- **显示轮盘菜单**
- **开始鼠标手势**
- **快速截图**

2.3.36 起，**划动** 还可配置 **屏幕选字**，按住引导键拖选文字后复制、编辑或翻译；直接使用 Win＋左键预设的方法见[屏幕拖选文字](../screenshot/screen-text-selection.md)。

切换触发方式时，编辑器会继续校验当前操作是否仍适用于新方式，避免保存「界面上存在但运行时不能执行」的组合。

需要配合键盘引导键时，可以直接选择任意普通引导键。该键尚未定义扩展热键时，保存规则会自动创建对应的引导键设置；如果引导键已存在但处于停用状态，Quicker 会明确提示并让你确认是否启用。仍然建议检查同一引导键是否已经用于面板、轮盘、手势或扩展热键，避免一个按键承担过多入口。

## 常用辅助功能与自定义规则的优先级 {/* #drag-priority-2338 */}

2.3.38 起，常用辅助功能中的 Win＋左键屏幕选字、Win＋Alt＋左键框选截图预设优先于相同手势的用户规则；两个组合也不再互相抢占。若希望相同手势执行自定义规则，请先在 **设置 → 常用辅助功能 → 其它鼠标操作** 关闭对应预设，再测试规则。2.3.36–2.3.37 中，这两类预设会让位于用户规则。

2.3.40 起，设置中的规则列表会提示与辅助功能预设的冲突。即使自定义规则已保存，相同手势仍先执行已开启的预设；请先关闭相应预设，再验证自定义行为。

## 2.3.36 · 组合修饰键与截图后处理 {/* #text-and-capture-2336 */}

在规则编辑器的 **附加修饰键** 中可勾选 `Ctrl`、`Alt`、`Shift`、`Win`，要求它们与引导键同时按住。若扩展热键动作已经执行，该次组合鼠标操作不会再触发；配置后应按真实的按下、拖动、松开顺序测试。

左键划动新增屏幕选字和快速截图的受支持组合；不同操作允许的引导键组合并不相同，以编辑器校验为准，不代表任意操作都能绑定左键划动。

2.3.40 起，左键 **屏幕选字** 允许使用普通键引导，不再限于修饰键；窗口拖动、快速截图没有同步放宽。普通键规则需要 2.3.40 或更新客户端，配置后请检查它与原程序输入、扩展热键是否冲突。

2.3.39 起，**屏幕选字** 的选字后处理增加 **显示工具栏并复制文字**：自动复制识别结果，同时保留工具栏。旧客户端不支持，回退前应改回其它受支持选项。它与下面快速截图的“截图后”选项不同，详见[屏幕选字](../screenshot/screen-text-selection.md#自定义引导键和触发规则)。

**快速截图** 操作增加 **截图后** 选项：

- 按全局设置处理；
- 复制图片；
- 识别并复制文字；
- 显示识别工具栏；
- 识别并翻译；
- 贴图（旧版名称为“钉住”）；
- 贴图并显示贴图工具栏（2.3.37 起）。

明确选择某个处理方式后，不再执行全局快速截图中的其它自动处理。需要继续校对、翻译或表格识别时，可先选择显示识别工具栏。组合动作截图步骤的显式参数仍由步骤自己控制。

选择 **贴图** 仅显示图片，不自动展开编辑工具条；选择 **贴图并显示贴图工具栏** 可在松手后立即标注，按空格可收起或展开工具条。后一个选项需要 2.3.37 或以上客户端；旧版不能执行，可改用“贴图”。内置 Win＋Alt 框选预设见[框选截图并贴图](../screenshot/capture-pro.md#win-alt-capture-2337)。

新操作、附加修饰键及后处理参数需要 2.3.36 或以上客户端。旧版保存并同步可能清除新字段，尤其会丢失附加修饰键限制；回退前请备份并停用相关规则，见[升级与回退](/v2/migration/upgrade-and-rollback#text-and-table-2336)。

## 2.3.33 · 按住滑动移动与缩放窗口 {/* #window-drag-2333 */}

高级鼠标触发可以在按住鼠标键滑动期间，连续移动或调整目标窗口大小，不必先找到标题栏或边框。

1. 新增或编辑一条规则，将触发类型设为 **划动**。
2. 在操作中选择 **按住滑动移动** 或 **按住滑动缩放**。
3. 配置鼠标键和适用场景，保存后在目标窗口内按住该键并滑动，松开鼠标键完成。

使用左键时，需同时配置 **Ctrl、Shift 或 Alt** 控制键，并选择上述窗口操作；这不代表所有操作都开放了左键划动。缩放方向由按下位置决定：靠近边缘或角落时调整对应边，位于窗口中央时调整右下方向。

按 `Esc` 取消本次窗口交互时，会恢复开始时的窗口位置或大小。窗口自身不允许调整、权限不足或目标已关闭时，操作可能无法完成；请先用普通窗口验证规则，避免与已有左键拖选或修饰键操作冲突。

2.3.33 也修复了按住滑动结束、取消或禁用时按下与抬起不配对的问题。新增的两种操作需要在 2.3.33 或更高版本运行，分享规则或回退前请核对版本。

## 触碰屏幕边框

2.2.11 起，新增规则时选择“触碰屏幕边框”，再选择整条边或其中半边、停留时间及操作。编辑窗口默认停留 200 毫秒，可设为 0～10000 毫秒；新建规则默认不在全屏程序中触发。

- 支持四条整边和八个半边，不含屏幕角落；多屏之间可以穿越的接缝不触发，错位排列时外露的边段可以触发。
- 每次进入最多执行一次。沿同一边段移动不重新计时，离开边缘至少 4 像素后才能重新触发。
- 触碰时不能按住鼠标键；可使用键盘引导键或不设引导键。离开目标半边、按下鼠标键或暂停功能会取消等待。
- 当前不提供“摩擦屏幕边界”的配置入口，不要把它与触碰边框混为一种触发方式。

旧客户端不能维护这种规则。降级前请停用或移除，重新升级后再启用。

## 规则列表筛选

2.3.37 起，列表增加 **全部、鼠标按键、滚轮、划动、屏幕边缘** 分类标签；存在历史或未分类规则时，还会显示 **其它**。分类只改变当前显示范围，不会删除隐藏规则或改变运行时优先级。在分类页新增规则时，编辑器会预选对应的触发类型，保存前仍可调整。

列表顶部可以组合筛选：

- 鼠标按键：无按键、左键、右键、中键、X1、X2；
- 触发类型：短按、按下、长按、双击、划动、四向滚轮、屏幕角落、触碰屏幕边框；
- 说明文字。

筛选期间会禁用拖动排序，避免把过滤后的局部顺序误写成完整规则顺序。清除筛选后可以继续正常排序。

只切换分类、不附加上述筛选时，可以在分类内拖动排序，只调整当前可见规则占用的位置，隐藏规则的位置不变。切换分类会清除旧选择；编辑后的规则若不属于当前分类，可按保存后的提示跳转查看。

2.2.18 起，规则支持多选删除、复制和粘贴。粘贴时先选中目标规则，新增条目会放在当前选中项之后，便于保持相关规则相邻。不再把「常用按键」做成另一套并行编辑入口。

## 按场景匹配与禁用

高级鼠标规则会按鼠标开始位置或当前前台目标解析程序、网址和子场景，并与轮盘、手势和动作面板使用同一套场景身份。

对资源管理器桌面与任务栏、UWP、WPS 内部文档、浏览器网址和 WebView 宿主，会使用统一的逻辑目标和回退规则。

| 操作 | 效果 |
| --- | --- |
| 全局、父场景和当前场景中所有启用且条件匹配的规则 | 都会参与匹配 |
| 停用一条本地规则 | 只排除该条规则，不会自动屏蔽上级其它鼠标规则 |
| 需要在某个场景完全关闭高级鼠标触发 | 使用场景级禁用开关 |

这和 [动作快捷键](/v2/features/triggers/action-hotkeys)「停用本地同键则整键不回退」不同；[左键辅助](/v2/features/triggers/left-button-plus)在 2.2.11 也会跳过停用项，但按完整序列确定覆盖关系。

## 触发目标与延迟执行

鼠标按下、移动、释放以及延迟执行可能跨越多个窗口。会话开始时会固定必要的鼠标目标和规则内容，执行时仍使用这次操作的原始目标，不会因为指针经过 Quicker 辅助窗口或前台窗口变化而改用另一场景。

设置窗口、动作编辑窗口等普通 Quicker 窗口可以按正常场景规则使用鼠标触发；主面板和明确标记为不参与触发的悬浮窗口仍会排除，避免在操作 Quicker 面板时意外递归触发。

## 轮盘和手势的角落快捷入口

如果高级鼠标规则启动了轮盘或手势，可以在结束会话前把指针移动到当前屏幕顶部角落：

- **左上角**：打开本次场景的轮盘或手势动作管理
- **右上角**：打开对应功能的全局参数设置

该入口只在已经开始的轮盘或手势会话中生效，识别范围很小。普通「移动到屏幕角落」规则仍按高级鼠标触发自己的设置运行，不会被这个入口替代。

## 限制与排障

- **总是进轮盘而不是手势（或相反）**：检查同一按键上是否同时配置了「显示轮盘菜单」与「开始鼠标手势」，以及移动距离、触发类型是否满足预期条件。
- **和扩展热键、左键辅助抢同一按键**：按真实按下顺序测试；引导键停用时保存规则会提示是否启用。
- **筛选后拖不动顺序**：先清除筛选，再排序。
- **全屏、任务栏、多显示器、WPS 或角落规则不准**：按实际使用路径各测试一次，并结合 **「更多」→「诊断与修复」→「动作运行与触发记录」→「触发记录」**、**当前场景诊断**。
- **相对 1.x 的场景解析与筛选变化**：见 [高级鼠标触发（2.x 变化）](/v2/what's-new/others/advanced-mouse-triggers)。
