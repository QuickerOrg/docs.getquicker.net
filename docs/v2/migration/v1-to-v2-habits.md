# 1.x 习惯与入口变化速查

很多 1.x 老用户升级到 2.x 后，并不是不会用动作，而是第一天找不到熟悉的界面、开关或动作页，担心整理面板时不小心把多年积累删掉。

这页把升级初期最常见的 **心智差异、入口搬家和排障捷径** 浓缩在一起。想看底层原理与完整版本演进细节，可以再展开下方「按主题深入了解 V2 变化」。

## 先吃三颗定心丸

1. **切回旧面板不等于退回 1.x 数据**：已登录云账号的用户可在旧面板右上角菜单或基础设置中临时切回旧面板（本机离线账号固定使用新面板）。新旧面板读写的是同一套 V2 数据，不会变回 1.x 的 `quicker.db`。
2. **切到新面板不会删除旧动作页**：首次建立新面板场景时，V2 只以旧动作页为种子生成分组和入口，不会删除原有二维动作页；但此后两套布局不再双向镜像。
3. **“从此场景移除”和“删除分组”都不会删除动作本身**：动作本体与显示位置已经分开，只有右键确认执行 **删除**（动作本体）时才会真正删掉动作并清理相关引用；删除分组也只是把动作移到「未分组」。详见 [动作面板常见问题](/v2/features/action-panel/faq)。

## 1.x 常用入口搬哪去了？

| 1.x 的习惯 / 入口 | 在 2.x 中去哪找 / 怎么变 | 说明与详情 |
| --- | --- | --- |
| 动作页、轮盘、手势、快捷键分散在不同设置里 | **场景、动作与触发** 管理窗口（原「场景与动作管理」） | 按场景集中编辑动作与规则，支持继承上级或明确禁用；见 [场景与触发方式变化](/v2/what's-new/scenes-and-triggers) |
| 独立「动作管理」「公共子程序管理」窗口 | **设置 → 动作 → 全部动作 / 公共子程序**（2.2.26 起） | 管动作本体与公共子程序，支持按类型筛选、查看引用与批量删除 |
| 同一程序的多个二维动作页 | 新面板中合并到同一场景的多个 **分组** | 日常优先使用场景与分组；若需切到特定场景、分组或旧动作页，见 [加载场景与加载动作页动作](/v2/migration/new-main-win/load-action-page) |
| 选字后弹出的 **文本悬浮窗** | **选中文本工具条** | 默认关闭，需在设置中手动启用并重新挑选按钮；**不再自动复制选中文字**，依赖预先复制的旧动作请改为主动读取选区。见 [选中文本工具条](/v2/features/triggers/text-selection-toolbar) |
| 新建试验动作先在动作页占一个格子 | 左侧导航 **暂存区**（收件箱图标） | 可在暂存区新建、粘贴、用 AI 写或安装分享动作，试好再「保留到场景」；注意暂存区仅保存在本机、不同步、丢弃不进回收站。见 [本机动作暂存区](/v2/features/action-panel/action-drafts) |
| 设置窗口翻大类找选项、改完点底部保存 | 左侧 **树形导航** + 左上角关键词 / 拼音首字母搜索 | 多数页面标有「修改后自动保存」，开关与下拉改动后立即生效；输入校验错误需处理提示，见 [查找和修改设置](/v2/what's-new/tools-and-experience#查找和修改设置) |
| 不知道为什么触发到了错误程序或快捷键撞车 | 新面板标题栏 **更多 → 诊断与修复 → 当前场景诊断 / 动作运行与触发记录** | 快捷键冲突也可查 **设置 → 快捷键查询 → 快捷键占用查询** |
| Ctrl+右键打开网页动作设计器 / 网页版 AI | 桌面 **AI 工作台** 与桌面动作编辑器 | 2.3.13 起网页 AI 与网页动作设计器已退役，统一留在桌面完成 |

## 常见触发方式升上来有哪些变化？

原有快捷键、手势、轮盘和大多数规则都会保留并迁入，重点差异如下：

- **扩展热键**：原先“不保留单键功能”对应 **仅作为引导键**，“保留单键功能”对应 **平衡模式**（接近 1.x 手感且保护快速打字），不会自动启用试验策略「输入优先」；建议重点测空格/标点引导键、左侧修饰键及 `Win` 引导键规则。见 [扩展热键](/v2/features/triggers/powerkeys)。
- **鼠标手势与轮盘菜单**：旧轨迹形状与阈值按兼容方式换算；右键同时挂轮盘、手势与扩展热键时协作识别更稳；轮盘支持覆盖粘贴与跨场景安全剪切（第三常驻圈、可视子动作及第二圈第 9～16 格需有效专业版授权）。见 [鼠标手势](/v2/features/triggers/mouse-gestures) 与 [轮盘菜单](/v2/features/triggers/circle-menu)。
- **左键辅助与高级鼠标触发**：左键辅助在 2.2.11 起拆出短按、长按与拖放并支持功能级黑白名单；2.3.38 起，常用辅助功能中的 **Win 拖动预设**（屏幕选字 / 框选截图）优先于同手势自定义规则，若发现原有 Win 拖动触发失效，先关闭冲突预设。见 [左键辅助](/v2/features/triggers/left-button-plus) 与 [高级鼠标触发](/v2/features/triggers/advanced-mouse-triggers)。
- **动作快捷键 / 热键联动 / 按键双击 / 文本指令**：旧程序规则进入场景继承链。如果某程序里需要屏蔽全局规则，请设为 **明确禁用**；想恢复使用上级规则，则删除这条本地禁用规则。见 [快速触发概览](/v2/features/triggers)。

## 旧动作跑不通？优先查这 4 件事

1. **表达式语法或外部引用报错**：2.3.18 起 V2 只使用自研 **QkEval** 表达式引擎，不再内置旧的 `Z.Expressions`；直接依赖其特有写法或外部程序集的复杂动作请先复制测试。见 [全新表达式引擎](/v2/what's-new/actions/new-expression-engine)。
2. **提示未注册类、找不到提供程序或 DLL 加载失败**：V2 不再提供 32 位安装包，进程内调用的 DLL、COM、ODBC / OLE DB 驱动必须与当前 Quicker 架构（x64 或 ARM64）匹配。见 [运行平台、系统要求与 64 位迁移](/v2/what's-new/platform-and-compatibility)。
3. **旧版组合动作点不开编辑**：1.x 早期旧版组合动作在 V2 中仅保留只读查看和兼容运行；继续修改需要先按步骤重写为新版组合动作（旧动作建议保留副本）。见 [不再支持或不再推荐的功能](/v2/what's-new/not-supported)。
4. **动作丢了之前的本机记录或配置状态**：可在 **设置 → 数据与维护 → 维护工具 → 从旧版迁移状态数据** 对照 1.x 与 V2 状态并按需迁入。见 [按动作迁移 1.x 状态](/v2/migration/from-v1#action-state-migration-2327)。
