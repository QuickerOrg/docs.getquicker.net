Quicker 截图（原称**截图 Pro**）是 Quicker 的渐进式选区截图：进入后先出现全屏遮罩，光标附近会给出初始选区；你可以拖拽框选，也可以直接利用**自动选区**快速锁定窗口、面板和具体控件，再标注、复制、保存或贴图。同一界面也可进入长截图或录屏。

在组合动作中，对应步骤为 **交互截图**（步骤 Key：`sys:screenCapturePro`）。

2.3.13 起，步骤可单次指定鼠标指针、确认快存文件名模板和 PNG/JPEG 格式，并输出实际结束方式。用法见[单次截图参数与结束方式](/v2/xaction/modules/screen-capture-pro#2313--单次截图参数与结束方式)。

- 文字识别、原图选字、在线表格识别、结果窗与本地 OCR 保活设置已拆至 [截图文字识别（OCR）与表格识别](./ocr.md)。
- 区域录屏、系统声音、录屏编辑与智能缩放已拆至 [桌面录屏与视频编辑](./screen-recording.md)。
- 桌面贴图交互、分组管理、窗口贴图缩放与渲染清晰度已拆至 [贴图窗口](./pin-window.md)。

## 截图速度与资源占用 {/* #capture-speed-2342 */}

2.3.42 加快了截图首屏显示和框选响应，减少进入标注编辑时的闪烁、指针短暂变回箭头，以及远程桌面下标注和切换文字框时的卡顿。实际速度仍受屏幕数量、分辨率、显卡和远程连接影响。

在 **设置 → 截图与文字识别 → Quicker 截图 → 截图内容与提示** 中，可调整 **优化截图速度**：

- 默认开启，本机与远程桌面均可使用；只对本机生效，不随账号同步。
- 开启后会准备图形加速资源，额外占用内存和显存，屏幕越多、分辨率越高，成本通常越大。**2.3.43 起在首次截图关闭后才开始准备**，仅启动 Quicker、尚未使用截图时不会提前准备这些资源。双高分屏实测约 140 MB 显存、50 MB 进程内存，仅供参考。
- 内存或显存紧张时可关闭，释放预热资源；后续截图可能变慢，系统资源计数不一定立即下降。

回退旧版并保存本机截图配置，可能清除关闭偏好，再次升级后恢复开启。需要保留时请先备份，见[2.3.42 升级与回退](/v2/migration/upgrade-and-rollback#capture-speed-2342)。

若开启此选项后，在锁屏、远程桌面重连或显示器变化后出现内存和线程持续增长，请升级到 **2.3.46 或更高版本**；该版本修复了这些场景下加速资源重建时的泄漏。暂时无法升级时可先关闭该选项。

## Win＋Alt 框选截图并贴图 {/* #win-alt-capture-2337 */}

2.3.37 起，可用一次拖动完成框选截图并进入贴图编辑：

1. 打开 **设置 → 常用辅助功能 → 其它鼠标操作**，开启 **Win+Alt+左键拖动：框选截图并贴图**，默认关闭。
2. 按住左侧或右侧 `Win` 和 `Alt`，用鼠标左键框选需要的区域。
3. 松手后，图片直接贴在桌面并展开编辑工具条，可立即标注；按空格收起或展开工具条。

开启预设会同时补齐或启用左右 Win 的扩展热键引导键，关闭此开关不会关闭引导键。2.3.38 起，该预设优先于相同手势的用户高级鼠标规则，且不再被单独的 Win＋左键拖动抢占；2.3.37 的旧行为是用户规则优先。需要自定义组合或截图后处理时，先关闭冲突预设，再使用[高级鼠标触发](../triggers/advanced-mouse-triggers.md#text-and-capture-2336)。

回退或混用旧客户端前，请查看[2.3.37 升级与回退](/v2/migration/upgrade-and-rollback#capture-and-font-2337)，避免旧设备保存并同步设置后清除新开关。

## 2.3.19 · 名称与全局快捷键 {/* #capture-name-and-hotkey-2319 */}

从 **2.3.19** 起，“截图 Pro”统一称为 **Quicker 截图**，原有截图、标注、贴图和识别能力继续保留；本文网址及动作步骤 Key 不变。旧名称仍可用于设置搜索。

打开 **设置 → 功能快捷键 → 常用功能**，设置 **打开 Quicker 截图**，即可直接用全局快捷键进入选区界面。默认未绑定，长按不会重复触发；侧栏截图按钮的提示也会显示已配置的快捷键。2.3.19 的绑定仅保存在本机；**2.3.20 起随账号同步**，升级时优先使用已同步的绑定，没有时再导入旧本机绑定。

2.3.38 修复了含 `Alt` 的热键启动截图时被菜单状态干扰的问题。仍无法进入截图时，先检查快捷键是否被其它软件占用，以及当前是否处于禁用状态。

## 2.3.20 · 复制 PNG 文件与偏好同步 {/* #capture-copy-and-sync-2320 */}

在 **设置 → 截图 → Quicker 截图** 中开启 **复制时附带 PNG 文件**，复制截图、长截图、贴图或历史图片时，剪贴板会同时提供图片和 PNG 文件，方便粘贴到支持文件附件的终端、AI 工具或文件夹。此项默认关闭；接收程序实际使用哪一种格式，由该程序决定。PNG 临时文件保存在本机，当前剪贴板正在使用的文件不会被自动清理。

按住 `Ctrl` 点击截图或贴图工具栏的**保存按钮**，可直接打开系统“另存为”窗口；普通点击仍使用原保存窗口。截图全局快捷键启动时减少了等待，标注工具栏也改为按需加载。

截图操作、复制、保存文件名与格式，以及贴图交互偏好开始随账号同步；**保存目录、HDR、标注工具样式、历史图片和录屏配置仍保留在本机**。首次升级优先采用账号已有偏好；没有时从本机旧设置导入一次，随后切换到其他新账号不会重复继承这份旧设置。“运行动作”若只能按旧名称查找且出现重名或找不到，需重新选择目标动作。

回退和混用旧客户端前，请阅读[2.3.20 升级与回退](/v2/migration/upgrade-and-rollback#capture-sync-and-icons-2320)，尤其留意旧版保存通用设置后对截图快捷键的影响。

## 2.3.22 · 自定义工具栏布局 {/* #toolbar-layout-2322 */}

打开 **设置 → 截图 → Quicker 截图 → 工具栏 → 自定义工具栏…**，可以整理截图和贴图共用的标注工具栏：

- 调整工具和工具组的顺序，将低频工具移到更多菜单。
- 合并或拆分工具组，调整组内顺序。2.3.23 起，命令组使用组内第一项作为默认项，绘图组记住最近使用项；打开旧布局时仍保留原默认项，编辑并保存后按新规则生效。
- 需要重新开始时恢复默认布局；完成与取消按钮固定保留。

保存后，布局随账号同步。**2.3.23 起，当前普通截图的工具栏会立即刷新**，保留选区、标注、所选工具和撤销记录；已打开的贴图与脚本自定义工具栏会话仍使用原快照，新开会话再应用。取消编辑或保存失败不会应用修改。2.3.22 只在新开会话时应用。

### 2.3.23 · 更多菜单与即时刷新 {/* #toolbar-layout-2323 */}

编辑器把“更多”中的成员集中显示，可排序、移回主栏，或把整组和单项移入更多；拖放位置会显示放置标记。运行时更多菜单平铺工具，默认布局和录屏控制栏不受影响。“恢复默认”可正确保存，并立即更新当前普通截图工具栏。

这里管理的是账号布局，不是动作里的自定义命令。需要添加动作或子程序，继续在 **交互截图** 步骤中编排工具栏；步骤显式替换整栏时仍使用自己的布局。新旧客户端混用及离线冲突处理见[升级与回退](/v2/migration/upgrade-and-rollback#toolbar-and-mcp-2322)。

:::note 预览有复制，实际截图时却没有？

当确认按钮已经负责复制图片时，截图工具栏会自动隐藏独立的 **复制到剪贴板** 入口，包括分组或“更多”菜单中的复制项。例如，“保存＋复制”组会只剩保存按钮，下拉箭头也会消失；这不会删除已保存的布局配置。

直接打开 Quicker 截图时，检查 **设置 → 截图 → Quicker 截图 → 截图确认后执行 → 复制到剪贴板**；通过动作步骤启动时，检查该 **交互截图** 步骤的 **确认后复制图片**。两处分别配置，只取消全局设置不会取消步骤参数。若希望保留独立复制入口，请取消对应的复制选项，再重新启动截图。详见[交互截图参数说明](/v2/xaction/modules/screen-capture-pro#参数说明)。

:::

:::note 预览有二维码 / 条形码识别，实际截图时却没有？

工具栏布局编辑器同时列出截图和贴图可用的功能，因此「文字识别」组中可以看到 **二维码 / 条形码识别**。实际截图时不会显示这个手动入口：框选并进入选区调整阶段后，Quicker 会自动识别选区内的码，识别成功后把光标悬停到码上即可查看、复制内容或打开链接。

自动预览没有提示时，可以缩小选区或提高图片清晰度；也可以先贴图，再从贴图右键菜单的识别子菜单中执行 **识别二维码 / 条形码**，进行完整扫描。调整工具栏顺序或将该项移到主栏，不会让它出现在截图工具栏中。更多说明见[二维码与条形码](#二维码与条形码)。

:::

## 自定义截图、贴图与录屏快捷键 {/* #capture-shortcuts-2340 */}

2.3.40 起，打开 **设置 → 截图 → Quicker 截图 → 工具栏 → 自定义工具栏…**，在快捷键设置中为具体标注工具、操作区命令和录屏控制录入按键。键位绑定到具体工具，不随拖动工具栏位置改变；数字位置快捷键可单独开关。

重复按键、与保留命令冲突或无效的组合会阻止保存，请先清除冲突。保存后随账号同步；取消编辑不会应用草稿。命令是否可执行仍取决于当前截图、贴图或录屏阶段，编辑文字时不会把普通输入当作工具切换。

2.3.43 起，**快捷键** 页可修改、清除和恢复更多内置命令的默认按键，包括复制、保存、撤销、刷新底图及贴图锁定等。选择命令类别后：

- 点击输入框，再按下新组合键；新组合会替换该命令的全部默认按键。
- 点击 **清除**，或在输入框中按 `Backspace` / `Delete`，禁用该命令的快捷键。
- 点击该行的 **默认**，只恢复此命令的全部默认按键；窗口顶部的 **恢复默认** 会同时重置工具栏布局和快捷键。

改绑或清除默认键后，回退旧版可能无法使用这份配置。回退前的处理方式见[截图快捷键兼容说明](/v2/migration/upgrade-and-rollback#capture-shortcuts-2343)。

**开始／停止录制** 默认改用 `Alt+F10`，可在这里修改，也可从录屏控制栏右键进入配置。此组合在准备和录制期间全局占用：准备时开始、录制中停止。它与截图选区阶段进入录屏的 `G` 不同，不是常驻的全局录屏启动键。本文下方表格列的是默认按键，自定义后以当前工具提示为准。

## 快速开始

### 作为动作步骤

1. 在动作编辑器中添加 **交互截图** 步骤。
2. 按需设置延迟、是否写入剪贴板、是否截图后贴图、是否自动吸附等参数。
3. 运行动作。屏幕进入全屏选区界面。
4. 框选或确认高亮区域，必要时标注，然后复制、保存、贴图或确认结束。

步骤成功后可得到：

- **图片**：截取到的图像变量
- **截图区域**：屏幕坐标 `left,top,right,bottom`
- **保存路径**：若通过「保存」写入磁盘则返回文件路径，否则为空

2.2.19 起，步骤可填写物理像素坐标的 **预选截图区域**，跳过第一次手动框选，直接进入可调整和标注状态。长截图步骤也可预先指定范围，直接开始长截图流程。

### 预选截图区域与快捷出口

2.2.25 起，Quicker 截图的**所有操作**均可使用预选截图区域（不限于组合动作步骤）。「框选即出图」和快速保存也可同时勾选 **复制到剪贴板**、**截图后贴图**，在框选或快速保存结束后一并完成。具体勾选项以 **设置 → 截图 → Quicker 截图** 与当前步骤参数为准。

需要在受控 JavaScript 中打开 Quicker 截图时，2.2.19 起可使用自动化脚本的 [`capturePro.open()`](/v2/xaction/modules/automationscript#打开截图-pro)。

### 基本操作流程

1. 进入截图后，移动鼠标查看高亮区域；或按住左键拖拽框选。
2. 如果当前高亮还太大，先滚动鼠标滚轮在父 / 子控件之间切换；满意后再单击或按 `Enter` 确认。
3. 按 `Space` 显示或隐藏标注工具栏，进行画框、箭头、文字、马赛克等标注。
4. 用复制、保存、贴图或确认按钮（或对应快捷键）结束；`Esc` 或右键可取消 / 重选。

## 2.3.15 · 截图 AI 提问

选好截图区域后，点击工具栏的 **问问 AI**，或在截图画布按 `/`，可直接就这张图片提问。

1. 输入问题，例如“把表格转成 Markdown”或“解释图中的报错”。
2. 选择可用的模型，再明确发送。需要先配置 AI 服务和支持图片输入的模型，见[AI 设置](/v2/features/ai/services-and-models)。
3. 截图层关闭后，图片和问题交给 **问问 AI** 独立窗口处理，之后也可在 AI 工作台继续同一对话。若模型不可用或发送失败，检查工作台保留的草稿，再手动重试。

输入框以 `/` 开头时，会显示历史问题和预置示例；继续输入可筛选。上下键选择后按 `Enter`，或点击候选，只会填入问题，仍需再次明确发送。`Esc` 优先收起候选，输入文字或使用输入法时不会误触画布的 `/` 快捷键。

2.3.40 起，可从提示词管理入口维护图片或文本提问模板。浮窗下方的模板按钮会替换当前输入并立即发送，与上面的候选填入方式不同，点击前请确认内容。模板建立、账号同步及旧模板不自动导入的说明见[提示词库](/v2/features/ai/prompt-library-and-sessions#prompt-library-2340)。

最近 20 条明确提交的问题仅在本机按账号保存，可以清空；取消不会加入历史。历史只保存问题，不保存图片或附加的窗口背景。

:::caution[发送时附带的窗口背景]
识别到关联窗口时，问题会附带该窗口的标题、进程名及与选区的推测关系，发送给所选模型并保存在对话中。标题可能包含选区外的文件名、邮件主题或聊天对象；它不是仅从截图像素中识别出的文字，当前没有单独关闭此背景信息的开关。
:::

回退旧版可能清除本机问题历史，处理方式见[升级与回退](/v2/migration/upgrade-and-rollback#2315--会话目录与截图-ai-历史)。

## Quicker 截图设置页 {/* #截图-pro-设置页 */}

### 2.3.18 · 截图确认与外观记忆 {/* #capture-confirm-actions */}

打开 **设置 → 截图 → Quicker 截图 → 截图确认后执行**，可同时勾选 **复制、自动保存到文件、贴图、运行动作**。从侧栏或菜单打开 Quicker 截图后，点击对勾或双击确认，会执行勾选的操作；全部不选时只完成截图。自动保存的目录、文件名模板和格式在 **自动保存设置** 中配置，不弹另存为窗口；工具栏的保存按钮仍单独打开另存为窗口。

图钉按钮及直接贴图快捷操作是否同时复制，由 **贴图** 分组中的独立开关控制，不再跟随对勾的多选组合。旧配置会按原行为兼容。组合动作中的 交互截图步骤仍使用自身参数，不受这里的确认组合影响。

2.3.40 起，快速拖动截图的“贴图”和“贴图并显示贴图工具栏”也会遵循 **截图直接贴图时同时复制到剪贴板** 开关；若松手后已贴图但剪贴板没有图片，请先核对这个设置。

选区外观的 **圆角、边框、阴影、撕边** 可分别设置“下次截图沿用此效果”。取消沿用只影响后续截图，不会关闭本次效果或清除已设置的参数。回退旧版只能使用旧版可表达的操作组合，再次保存偏好会丢失新版选项，备份方法见[升级与回退](/v2/migration/upgrade-and-rollback#capture-preferences-2318)。

2.3.20 起，识字、识别及仅选取区域的流程不再沿用截图圆角、边框等外观；普通截图继续使用已记忆的效果。


### 2.3.17 · HDR 截图颜色校正（实验性）

Windows 开启 HDR 后若普通截图或 Quicker 截图的颜色过曝，可在 **设置 → 截图 → Quicker 截图** 中开启「HDR 截图颜色校正（实验性）」。此选项默认关闭；首次开启后请稍候再截图，并在自己的 HDR 屏幕上核对颜色。普通 SDR 屏幕沿用原采集方式。

校正覆盖普通截图、Quicker 截图的初始画面与刷新，以及快速截图的区域/全屏路径；输出仍是可编辑、复制和保存的普通 SDR 图片。长截图、录屏、独立取色和窗口专用捕获不在此次范围。旋转屏、采集失败或探测尚未完成时可能回落原截图方式，此时不代表 HDR 颜色已校正。若结果不理想，可关闭该开关恢复原路径。

2.2.1 起，Quicker 设置中提供 Quicker 截图的专用设置页，当前入口为 **设置 → 截图 → Quicker 截图**，用来集中管理截图工具栏、确认后执行的操作、自动保存、贴图和历史偏好。2.2.5 起，Quicker 截图和贴图菜单也可控制工具栏显示；保存图片时可选择内置日期格式与文件名模板。

2.2.14 起，文件名模板支持 `{date:格式}`（.NET DateTime，例如 `{date:yyyy_MM_dd_HH_mm_ss}`），设置页会提供实时文件名示例。原独立日期格式选项已并入文件名模板；编辑时会把旧日期格式转换并保留效果。回退旧版后需将 `{date:格式}` 改回 `{date}`、`{time}` 等旧语法，见 [升级与回退](/v2/migration/upgrade-and-rollback#2214-截图文件名模板与悬浮分组动作)。同版起，工具栏的确认与复制按钮不再重复显示。

这些设置影响手动截图和未显式指定行为的场景。通过组合动作步骤调用 Quicker 截图时，**步骤参数优先**；例如动作里已经指定了写入剪贴板、截图后贴图或工具栏配置，就按动作步骤当前参数执行。

2.2.17 起，截图设置可指定**本机 ffmpeg** 用于 MP4 实时录屏：默认关闭；需自行准备 `ffmpeg.exe`，在设置中检测通过后再启用。未启用时仍使用原有录制路径。2.2.20 起，录屏步骤还可直接填写编码方案和多行 FFmpeg 参数（支持变量），用于自定义编码器、码率或滤镜；使用自定义编码时仍以设置页检测通过的本机 ffmpeg 路径为前提。

完整发版注意见[官网版本记录](https://getquicker.net/V2/Versions)。

## 2.3.25 · 恢复截图现场与选区 {/* #capture-history-2325 */}

在截图界面按 `,`（逗号）向前、`.`（句号）向后浏览最近的截图现场，可重新移动、扩大选区，再标注、复制、保存或贴图。按 `F5` 返回本次画面；浏览历史时按 `Esc` 也可返回进入浏览前的截图。旧标注已合入底图像素，不能逐个重新编辑。

如果只想在当前桌面沿用以前的区域，按 `N` 恢复更早的选区，按 `M` 返回较新的选区。最多记忆 10 个不同区域；它只恢复位置和大小，使用当前屏幕内容，不依赖图片历史开关。恢复后仍需确认，显示器布局变化时会调整到可用范围。

:::caution[完整底图可能包含选区外的内容]
截图历史默认开启，已明确关闭的设置保持不变。2.3.25 起，最近 10 次交互截图还会在本机保存完整屏幕底图，额外最多占用 128 MB，并受截图历史总容量限制。底图可能包含没有截入成品的文件、聊天或其他敏感内容。

可在 **设置 → 截图 → Quicker 截图** 关闭 **记录交互截图历史**，停止后续记录；关闭开关不会代替删除已有历史。删除对应截图历史时，完整底图一并清理。底图、图片历史及选区记录不随账号同步。
:::

没有可恢复底图的旧记录仍可在采集历史中心查看成品。截图历史未开启或记录不可用时，当前截图会显示提示；过去未记录的完整画面不能补回。正在输入文字、拖拽、保存或执行命令时不能切换历史，当前标注需先完成或清除。恢复历史现场后不能进入长截图或录屏。

### 尺寸与比例约束 {/* #capture-size-2325 */}

点击选区旁的尺寸信息，设置宽高或比例。固定宽高后移动或调整选区会保持指定的像素尺寸；固定比例后拖动按该比例调整。恢复截图现场或选区历史时，也会恢复当时的尺寸模式。

选区历史、尺寸模式和取色格式的回退影响，见[2.3.25 升级与回退](/v2/migration/upgrade-and-rollback#capture-and-ai-2325)。

## 选择区域

### 悬停与滚轮

2.3.45 改善了自动吸附切换大范围选区时的动画流畅度。在 Quicker 设置页截图时，也可通过控件层级选择整个设置分组，减少手动框选。

进入截图后，把光标移到目标附近，选区会跟着高亮。范围偏大时，滚一下滚轮，即可在窗口、面板和具体控件之间切换；满意后单击或按 `Enter` 确认。菜单、设置页局部、按钮、输入框等标准界面元素，往往比手动拖框更省事。

把鼠标移入下方演示区可试一下：悬停会吸附到较细的控件，滚轮向上扩大到父级、向下缩小到子级。

### 悬停高亮与框选

进入截图后：

- **移动光标**：可用鼠标，也可用 `W` / `A` / `S` / `D` 微调位置。
- **框选**：按住左键拖拽画出矩形区域。
- **快速选屏**：按 `Ctrl+A` 可先选中鼠标所在显示器，再在当前显示器与全部屏幕之间切换。
- **确认高亮区域**：单击或 `Enter`。
- **取消**：`Esc` 或右键。

确认选区后进入调整阶段：

- **移动选区**：`W` / `A` / `S` / `D`
- **缩放选区**：鼠标滚轮
- **确认**：双击或 `Enter`
- **重选 / 取消**：右键或 `Esc`

### 混合文本捕获

2.2.8 起，在**自动选区**阶段可混合捕获界面文字与图片文字：按 `R` 或 `Shift+C`，会读取当前 UI 文本，并用 OCR 补充图片中的文字。2.2.11 已移除直接复制混合文本的 `Ctrl+Shift+C` 快捷键，请在识别结果窗口中复制。这些快捷键用于自动选区阶段；手动框选后请用工具栏 OCR。贴图窗口里的 `R` 仍是缩略图切换，二者场景不同。

### 选区刷新

2.2.8 起，选区侧栏支持**按住刷新**查看实时桌面，松开后重新捕获当前画面；也可按 `F5` 刷新截图，并保留当前选区、样式和标注。刷新后再用马赛克、模糊、填充、橡皮擦或撤销 / 重做时，不会带回旧画面；旧画面上的智能马赛克识别结果也会清除。

<a id="选区二维码" />

### 二维码与条形码

2.2.5 起，OCR 结果窗可以查看并复制识别到的二维码内容。2.2.6 起，截图选区阶段也会自动识别选区内的二维码：把光标悬停到码上即可看到内容，并可直接复制或打开链接，不必先打开结果窗。

选区内没有可识别的码、或码被遮挡、模糊时，不会出现悬停提示。需要进一步识别时，先确认图片中的码清晰完整，再重新框选。

<a id="开发版识别更多条码" />

#### 识别更多条码

2.3.0 起，Quicker 截图与贴图的本地识别扩展为**二维码 / 条形码**：除二维码外，还支持 Code 128、EAN / UPC、Data Matrix、Aztec、PDF417 等常见格式，并改进竖向、反色和同图多个码的识别。悬停结果可查看或复制内容；只有有效的 HTTP / HTTPS 地址才提供打开链接。

选区内先显示快速预览（自动预览优先快速显示结果）；未出现提示并不一定代表图片中没有码。可缩小选区、提高图片清晰度，或先贴图，再从右键菜单执行「识别二维码 / 条形码」进行完整扫描。完整扫描与快速预览的识别范围和耗时不同，结果仍需核对。本项说明针对截图与贴图界面，不改变「识别二维码」组合动作模块的参数定义。

### 自动吸附

步骤参数 **自动吸附**（默认关闭）决定悬停时是否主动下钻到更细的控件：

| 设置 | 行为 |
| --- | --- |
| 关闭（默认） | 悬停时优先跟随窗口范围；需要更细的控件层时，用滚轮在父 / 子控件间切换 |
| 开启 | 悬停时持续尝试吸附到更细的控件；仍可用滚轮在层级间切换 |

习惯先看大范围再自己滚轮缩到按钮时，保持默认关闭通常更好控；经常直接截标准控件，可打开 **自动吸附**。自绘界面、游戏、远程桌面等若高亮不准，改用手动框选即可。吸附窗口时，Quicker 截图、长截图和录屏会尽量排除窗口阴影，避免把阴影算进截图范围。多显示器或混合 DPI 下若略有偏差，确认后用滚轮或拖动手柄微调。


### 2.3.36 · 截图吸附与整窗边缘 {/* #capture-snap-2336 */}

截图设置增加 **自动吸附界面元素**，默认开启。关闭后仅自动选择窗口范围，仍可通过滚轮选择内部控件；组合动作的截图模块继续使用自身参数。该偏好随账号同步，旧设备保存后的影响见[升级与回退](/v2/migration/upgrade-and-rollback#text-and-table-2336)。

自动吸附完整窗口截图时会补绘浅灰轮廓，使窗口边缘更清楚；手动框选或内部控件选区不沿用整窗补线。

### 2.3.32 · 截图准备与重复取字 {/* #capture-response-2332 */}

截图准备速度和元素吸附响应已有优化；2.3.42 起，远程会话也会按图形设备能力尝试加速首屏，HDR 仍沿用原有准备方式。速度与资源取舍见[截图速度与资源占用](#capture-speed-2342)。在同一轮截图中，对相同图片再次取字可复用最近一次成功结果，减少等待；图片、识别模型或方向检测选项改变时会重新识别，点击重试也会重新识别。

从文字识别结果窗口重新截图时，会先隐藏结果窗再采集，修复结果窗口自身可能被截入图片的问题。

| 鼠标操控 | 移动、调整选区，不绘制 |

| 矩形 / 椭圆 | 形状标注 |

| 箭头 / 折线 | 指向说明；折线可单击加点，右键或 `Enter` 结束 |

### 标注阴影与形状线型 {/* #annotation-style-2311 */}

2.3.11 起，标注工具统一提供阴影开关、距离和模糊设置，各工具分别记忆；阴影默认关闭，可按需要开启。矩形与椭圆还可选择实线、虚线或点线。这里调整的是标注自身，不是整张截图的边框或阴影。

回退到 2.3.10 后再保存本机截图工具样式，可能清除这些阴影和线型偏好。需要保留时，请先按[标注样式回退说明](/v2/migration/upgrade-and-rollback#annotation-style-2311)备份；已导出的图片不受影响。

### 2.3.29 · 等宽高绘制与复制标注 {/* #annotation-copy-2329 */}

绘制矩形或椭圆时，按住 `Shift` 可保持宽高相等，画出正方形或圆形。

选中标注后按 `Ctrl+D`，可复制内容与样式，并将副本稍作偏移，便于继续拖动排列。可以连续复制，复制结果支持撤销、重做；复制序号标注时，副本使用下一个编号。

### 2.3.20 · 气泡、序号与连续标注 {/* #annotation-tools-2320 */}

在 **标注工具** 下拉菜单选择 **气泡标注**，从指向位置拖到气泡位置，再输入说明。拖动尖角手柄调整落点，拖动正文调整气泡位置；双击或按 `F2` 编辑，`Shift+Enter` 换行。

气泡参数栏可分别设置文字色、边框色和实色底；在 **气泡样式** 中切换椭圆、显示边框、正文宽高及尖角根部宽度与位置。文字默认跟随边框色，取消此项后可单独选色。序号工具增加 **方形** 和 **白色描边**；白色描边用于已开启填充的序号。

尺寸标注输入如 `50厘米` 后，当前图片中的下一条尺寸线会按上一条线的长度比例预填，并保留文字格式；前一条没有明确数值或包含多个数字时仍需手填。预填只是参考，请自行核对，不能当作经过校准的实际测量。铅笔工具按住 `Shift` 连续点击，可从上一笔末端连接直线；按 `Esc` 或右键结束本轮连接。引出线说明也增加了文字下方的横线。

这些工具样式仅在本机记忆；回退旧版后保存工具设置可能重置新增样式，见[升级与回退](/v2/migration/upgrade-and-rollback#capture-sync-and-icons-2320)。

### 序号旁的文字说明

以下标注改进从 **2.3.1** 起可用。

使用序号工具放置编号后，选中编号，点击旁边的添加说明按钮，或双击该编号，即可输入解释文字。已有说明也可双击继续编辑。

### 2.3.19 · 尺寸、角度与局部放大 {/* #annotation-tools-2319 */}

打开 **标注工具** 右侧的下拉菜单选择工具。主按钮会记住最近使用的工具；需要其他工具时再展开菜单。

| 工具 | 操作 |
|---|---|
| **引出线说明** | 从目标位置拖出指示线，输入说明；`Enter` 确认，`Shift+Enter` 换行，拖动文字调整位置 |
| **局部放大** | 框选需要突出的细节，再拖动放大框安排位置；滚轮调整倍率，可在参数栏调整外形和边框 |
| **尺寸标注** | 拖动绘制尺寸线，输入尺寸或说明，再调整位置与样式 |
| **角度标注** | 依次点击顶点和两条边，标出 0°～180° 的夹角 |

局部放大用于在图片中突出细节，与选区阶段的取色放大镜不同；录屏标注中不提供此工具。尺寸线上的文字可自行输入，不应把填写的数值当作经过物理尺寸校准的测量结果。

折线从形状组移至箭头组；原来的背景填充改为马赛克组中的独立工具。点击工具主按钮使用当前工具，点击右侧下拉按钮选择其他工具；也可在主按钮获得键盘焦点时按方向键 `↓` 展开菜单。切换工具或参数栏时，主工具栏会尽量保持原位置，整组越出屏幕工作区时才重新定位。

新增工具的样式与最近使用选择会记在本机。回退旧版并触发截图偏好保存会丢弃这些新增偏好；备份与恢复方式见[2.3.19 升级与回退](/v2/migration/upgrade-and-rollback#preferences-and-ai-2319)。

2.3.39 起，箭头工具的样式列表增加 **圆尾内凹实心箭头**，可用于截图和贴图标注。旧版不认识此样式；回退后保存箭头偏好可能改回旧样式，升级后可重新选择，已导出的图片不受影响，见[升级与回退](/v2/migration/upgrade-and-rollback#text-and-arrow-2339)。本版还修复了实心标注阴影边缘重复叠色的问题。

### 箭头圆角与折线两端样式 {/* #arrow-and-polyline-2341 */}

2.3.41 起，在箭头工具参数栏勾选 **圆角**，可为当前箭头样式启用圆角外观；不同箭头样式分别记忆圆角选择。

折线参数栏可分别选择 **起点样式** 和 **终点样式**，用 **交换两端** 调换方向；带箭头时还可调整箭头圆角和大小。这些设置可用于截图和贴图标注。

新增外观偏好保存在本机。回退旧版后使用并保存截图工具设置，可能清除箭头圆角和折线两端样式；再次升级后可重新配置，已导出图片不受影响。需保留时先按[2.3.41 兼容说明](/v2/migration/upgrade-and-rollback#screen-text-and-settings-2341)备份。

### 文字局部格式与对齐 {/* #text-format-2340 */}

2.3.40 起，编辑文字标注时可选中其中一段，单独修改字号、颜色、粗体、斜体、下划线或删除线；没有选区时作用于整框。左对齐、居中和右对齐统一作用于整框的所有段落。先进入文字编辑状态，再选择文字并调整参数，避免把移动标注与选择文字混淆。

2.3.42 起，编辑一段文字后，单击空白位置即可直接创建下一个文字框，不必先额外点击一次退出旧框。新框的首次输入与创建合并为一次撤销；清除尚未输入的空框不会增加多余的撤销步骤。

工具样式仅在本机记忆。回退旧版后保存工具设置，会丢失新增的装饰线和对齐偏好；备份方式见[2.3.40 升级与回退](/v2/migration/upgrade-and-rollback#prompts-and-ocr-2340)。

### 铅笔

2.3.37 调整了截图与贴图的铅笔平滑方式，减少转折被过度抹平的情况，收笔时保留实际落点。

### 荧光笔

2.2.12 起，铅笔工具组增加 **荧光笔**。可选择框选或拉线，并使用正片叠底或半透明效果；复制、保存和贴图时都会把荧光笔烘焙进最终图像。

选中已绘制的荧光笔后，可修改颜色、粗细和混合方式；Ctrl+Z 只撤销这次样式修改，不会误删整条标注。

图片翻译会调用你在开放平台配置的百度 / 有道**图片翻译** API，得到译文贴合图后再复制或替换；配置步骤见 [图片翻译](./image-translate.md)。

需要加入「调用子程序处理图片」或「把图交给某个动作」等按钮时，在 **交互截图** 步骤里编辑工具栏。2.2.16 起，可视化编排可直接拖动排序、添加子程序或动作，并设置整栏图标大小；普通场景优先用可视化方式，不必先写脚本。需要用脚本生成按钮或进阶重排时，再填写 **自定义工具栏脚本**（见 [JS 自定义工具栏](./toolbar-script.md)）。默认只加自定义按钮（原工具栏保留，固定位置出下拉）；只有要改内置工具顺序时才整栏重排。

### 选区阴影与边框

从 **2.3.9** 起，选区外观栏分别提供 **圆角、边框、阴影、撕边** 开关，边框和阴影的参数可以独立调整。吸附窗口时会按可见窗口边框确定范围，并自动裁切窗口圆角；仍可手动调整选区。

2.2.7 起，确认选区后可为截图添加**阴影**和**边框**；效果会随复制、保存和贴图一起输出。圆角设置会记住；阴影与边框的启用状态默认不带到下次截图，需要时再勾选记忆。2.2.10 起，选区**圆角可单独开关**：关闭圆角后仍会记住上次使用的半径，再次打开时直接恢复，不必重新调。

回退到 2.2.6 后若再保存截图工具设置，会丢弃新版阴影 / 边框配置；重新升级后需重新设置（截图文件本身不受影响）。需要保留配置时，可先备份本机 `ScreenCapture/settings/image-drawing-tool-state.json`。详见 [升级与回退](/v2/migration/upgrade-and-rollback#回退到-226-后保存截图设置会丢弃-227-的阴影与边框配置2026-09-07)。升级后首次使用本地 OCR 或抠图可能需要下载新版引擎及原生库；已有识别模型继续复用。

### 2.3.9 · 截图撕边

确认矩形选区后，在外观栏打开 **撕边**，选择上、右、下、左中的作用边，再调整 **深度**（1–32 px）与 **齿宽**（4–64 px）。默认作用于右边和下边；点击 **换一种** 可更换不规则边缘形状。

撕边可以与边框、阴影组合，效果随复制、保存和贴图一起输出。圆角同时开启时，只有相邻两边都没有撕裂的角使用圆角；套索裁切不同时应用撕边。

撕边默认关闭。**每次截图都设置（全部外观）** 会共同记住边框、阴影和撕边的开关，圆角仍独立记忆。回退到 2.3.8 后保存截图工具设置会丢弃撕边偏好；回退前可备份本机设置，详见[升级与回退](/v2/migration/upgrade-and-rollback#239--截图外观与录屏默认提示)。

### 工具栏位置

Quicker 截图工具栏可以拖动并吸附到选区附近；双击拖动手柄可恢复自动定位。进入长截图或录屏后，对应工具栏也提供六点拖动手柄，可停靠在选区四边或自由摆放，双击手柄同样恢复自动定位。2.2.8 起，跨多显示器时工具栏和选区样式栏会跟到正确屏幕，避免贴错屏或被裁切。

### 长截图编辑

#### 工具栏直接保存 {/* #long-capture-save-2326 */}

2.3.26 起，采集工具栏增加 **保存** 按钮，不必先进入编辑窗口。点击可选择保存位置；按住 `Ctrl` 点击则打开系统“另存为”窗口。保存成功后结束本次长截图；取消或保存失败会保留已拼接内容，并恢复进入保存前的暂停状态，可继续操作。

#### 编辑拼接结果

2.2.13 起，长截图完成后会先打开编辑窗口，可裁剪四周，也可选中中间一段直接删除，再保存、复制或贴图。编辑只作用于当前结果；取消不会覆盖原始拼接图。

2.2.22 起，采集工具栏提供 **重来**：丢弃本轮已拼接的内容，保留选区和滚动方向，从页面当前位置重新采集；暂停时点击也会恢复采集。它不会自动把页面滚回起点，需要从头截取时，请先把页面滚到所需位置。

同版改进了快速滚动时的采集稳定性和预览绿框显示，进入编辑或确认导出前会处理尚未拼接完的画面。遇到动画、固定悬浮层或异步加载内容时，仍建议放慢滚动并检查拼接结果。

超长图贴图时会先适合当前屏幕并居中，必要时首次缩放可低于 10%，避免窗口超出工作区。

<a id="开发版长截图自动滚动" />

#### 长截图自动滚动

2.3.0 起，选好范围并进入长截图后，点击工具栏的 **自动滚动**。纵向模式向下滚动，横向模式向右滚动；每次匹配完成后再继续下一次滚动。点击速度按钮可在 **0.5×～2×** 间调整，速度面板打开时暂停采集，关闭后继续。

点击 **停止自动滚动** 可切回手动滚动；需要暂停采集或移动选区时，使用 **暂停采集**。暂停、移动选区或进入编辑、导出会停止自动滚动。它不会替你自动滚回页面起点。

选区外的状态提示用于判断中断原因：

- **页面没有继续移动**：可能已到末尾，也可能窗口不支持自动滚动。可手动滚动后继续，或检查结果后完成截图。
- **找不到滚动窗口、窗口不可用或被遮挡**：先把鼠标放在目标内容上，并恢复页面，再开启自动滚动。
- **拼接中断**：已拼接内容会保留。回滚到上一段后缓慢滚动，匹配恢复后可继续手动采集或重新开启自动滚动；需要丢弃本轮结果时再用「重来」。

自动滚动仍依赖页面能够滚动和相邻画面能够匹配。遇到动画、固定遮挡或异步加载内容，应放慢速度并检查拼接结果。

### 马赛克与智能马赛克

2.3.37 起，智能马赛克会在识别出的文字边缘外留出遮盖余量，减少笔画露出。敏感内容处理后仍应放大检查，必要时补充手动马赛克。

马赛克工具是一个**分裂按钮**：左侧主键执行当前模式，右侧箭头在「手动马赛克 / 智能马赛克」之间切换，并记住上次选择。

**手动马赛克**：在图片上拖拽绘制打码区域。副工具条可选效果：

| 效果 | 说明 |
| --- | --- |
| 马赛克 | 像素化打码 |
| 模糊 | 高斯模糊 |
| 填充 | 按邻域取色硬填充，适合 UI 纯色块去字（非 AI 修复） |

**智能马赛克**：自动识别文字区域后再打码：

1. 进入工具后，对当前截图选区（截图界面）或整张图片（贴图）运行 OCR。
2. 悬停可高亮候选文字框；**单击**切换单个候选的打码 / 取消。
3. **拖框**可一次选中多个候选，批量应用为一个撤销步骤。
4. 仍在智能马赛克工具下时，若选区变化会防抖后自动重跑识别。

智能马赛克**不会**打开 OCR 结果窗，也**不会**写入贴图的文本选择层。


## 结束方式

确认选区（并可标注）后，常见结束方式：

| 操作 | 快捷键 / 入口 | 结果 |
| --- | --- | --- |
| 复制 | `Ctrl+C` 或工具栏「复制」 | 将当前图像（含标注）写入剪贴板，并结束截图 |
| 确认截图 | 双击、`Enter` 或工具栏确认 | 组合动作调用按步骤参数返回图片；2.3.18 起，侧栏或菜单打开的截图按「截图确认后执行」的勾选项处理 |
| 保存 | `Ctrl+S` 或工具栏「保存」 | 打开保存对话框写入文件；可按设置使用文件名模板（2.2.14 起支持 `{date:格式}`）；步骤可输出保存路径 |
| 贴图 | `Ctrl+T` 或工具栏「钉住」 | 在选区位置打开浮动贴图窗口 |
| OCR | 工具栏「文字识别」 | 2.3.1 起留在截图界面选字或编辑全文；2.3.0 及更早版本会结束截图并打开 OCR 结果窗 |
| 长截图 | `L` 或工具栏「长截图」 | 进入长截图流程 |
| 录屏 | `G` 或工具栏「录屏」 | 进入区域录屏 |
| 取消 | `Esc` / 右键 | 取消本次截图或回到重选 |


说明：

- 步骤的 **写入剪贴板** 和 **截图后贴图** 可用于默认确认出口（双击、`Enter` 或工具栏确认）；2.2.25 起也支持「框选即出图」和快速保存。
- 界面内复制、保存、工具栏直接贴图，以及自定义工具栏的 `post.confirm` / `post.pin` 都按各自出口处理，不再额外触发上述两个步骤参数。因此勾选「写入剪贴板」后用保存结束，并不会顺带写入剪贴板；勾选「截图后贴图」后用复制或保存结束，也不会再弹贴图。
- 长截图、录屏、OCR、界面内复制 / 贴图等「另类出口」会在截图界面内完成对应操作；步骤仍可能带上可用的图片、区域或路径输出。
- 成功确认、复制、保存、OCR、直接贴图等操作默认会写入本机**截图历史**（可在采集历史中心查看）；取消、仅选录屏范围、长截图过程中的中间帧不会收录。


## 动作步骤参数

2.2.17 起，组合动作里的 **交互截图** 步骤可选择框选后直接走 **截图 / 复制 / 贴图 / 保存 / 识别** 等出口，不必再在工具栏里点一次确认。2.3.24 起，“操作”可绑定变量；当前参数及显示条件见[交互截图模块说明](/v2/xaction/modules/screen-capture-pro)。

| 参数 | 默认 | 说明 |
| --- | --- | --- |
| 截图前延迟时间 | `0` | 开始截图前等待的毫秒数，便于先打开菜单或隐藏 Quicker 面板 |
| 预选截图区域 | 空 | 2.2.19 起可填 `left,top,right,bottom` 物理像素坐标，右、下边界不包含；留空时手动选区。2.2.25 起手动截图与「框选即出图」等出口也可使用预选区域 |
| 写入剪贴板 | 关 | 默认确认出口结束时写入剪贴板；2.2.25 起也支持「框选即出图」和快速保存，其他出口见[模块说明](/v2/xaction/modules/screen-capture-pro#各操作的预选区域与完成后操作) |
| 截图后贴图 | 关 | 默认确认出口结束时贴图；2.2.25 起也支持「框选即出图」和快速保存，其他出口见[模块说明](/v2/xaction/modules/screen-capture-pro#各操作的预选区域与完成后操作) |
| 贴图后显示工具栏 | 关（高级） | 贴图窗口打开后是否自动显示标注工具栏；关闭时仍可按空格显示 |
| 自动吸附 | 关 | 是否在悬停时持续吸附到细控件；关闭时滚轮再触发精细选区 |
| 自定义工具栏脚本 | 空 | 可选的 JS 脚本，默认只加自定义按钮（原工具栏保留）；写法见 [JS 自定义工具栏](./toolbar-script.md)。留空则使用默认工具栏；推荐外置为动作包内文件 |
| 失败时中止动作 | 视步骤配置 | 用户取消或失败时是否中止后续步骤 |

输出：

| 输出 | 说明 |
| --- | --- |
| 是否成功 | 步骤是否成功 |
| 图片 | 截取图像 |
| 截图区域 | `left,top,right,bottom` |
| 保存路径 | 用户保存到磁盘或快速保存成功后的路径，否则为空 |

同一时间只能进行一次 Quicker 截图；若已在截图中再次触发，会提示等待当前截图完成。

## 辅助线与工具栏

2.2.11 起，单按左或右 Alt 可切换光标十字线、选区边界延长线及中心线，方便对齐。辅助线不进入最终截图。

工具栏图标使用固定大小；鼠标操控入口合并到工具栏手柄。2.3.25 起，右键点击 **撤销** 按钮可重做，工具栏不再因撤销/重做状态变化而来回变宽；快捷键仍是 `Ctrl+Z`、`Ctrl+Y` / `Ctrl+Shift+Z`。自定义布局只保留重做按钮时，仍显示独立的重做按钮。不要再按旧截图寻找单独的鼠标操控按钮。

2.3.25 起，在截图放大镜取色时按 `C`，成功复制颜色后会结束截图；复制失败仍保留窗口。RGB / HEX 格式在本机记住，截图、贴图和独立取色共用；标注工具取色仍返回颜色并继续编辑。

手动保存图片会记住最近使用路径；2.3.25 起，手动选择的目录不再覆盖 **自动保存设置** 中的固定目录。需要调整自动保存位置时，请到设置中修改。

| 切换原始鼠标指针显示 | <kbd>`</kbd>（反引号，Esc 下方；2.2.15 起；预览与输出一致） |
| 刷新截图（保留选区与标注） | `F5` |
| 浏览较早 / 较新的截图现场（2.3.25 起） | `,` / `.` |
| 在当前画面恢复较早 / 较新的选区（2.3.25 起） | `N` / `M` |
| 长截图 / 录屏 | `L` / `G` |
| 重选 / 取消 | 右键 / `Esc` |

放大镜可见时还可使用：

| 操作 | 快捷键 |
| --- | --- |
| RGB / HEX 颜色格式切换 | `Shift` |
| 复制当前像素颜色（2.3.25 起截图中复制成功后结束） | `C` |
| 全局坐标 / 相对坐标切换 | `P` |

2.2.15 起，选区操作中的鼠标光标闪烁已修复，截图快捷键提示样式也已统一。

### 标注工具栏可见时（截图与贴图）

数字键按工具栏**从左到右**的顺序选择工具；再按同一键可取消选中并回到鼠标。

2.3.40 起可关闭数字位置快捷键，或为具体工具设置独立按键，见[自定义快捷键](#capture-shortcuts-2340)。以下是默认启用数字位置快捷键时的示例，实际工具顺序和自定义键位以当前工具栏为准。

| 键 | 典型工具 |
| --- | --- |
| `0` | 鼠标（移动 / 调整） |
| `1` | 铅笔 |

| `3` | 箭头 / 折线 |
| `4` | 标注工具（序号 / 引出线说明 / 局部放大 / 尺寸 / 角度） |

| `8` | 橡皮 |

正在编辑文本框时，数字键用于输入文字，不会切换工具。

2.2.22 起，截图、贴图和录屏标注统一用 `Ctrl+Shift+Z` 重做，不再清空全部标注；清空改用 `Shift+Delete`。首次使用旧快捷键时会显示一次变更提示。

## 常见问题

### 控件高亮不准或不出现

先确认步骤是否开启 **自动吸附**；关闭时需要滚轮才会进入更细的控件层。若你已经滚轮切换但仍没有更准确的高亮，通常说明目标程序没有提供可靠的 UI 自动化信息，这时请改用手动拖拽框选。

### 截图后剪贴板没有图片

检查是否使用了 `Ctrl+C` / 工具栏复制，或在当前操作支持时勾选了 **写入剪贴板**。2.2.25 起，「框选即出图」和快速保存也支持此选项；从工具栏保存、直接贴图或自定义出口结束时不再叠加。默认确认且未勾选时，图片只进入动作变量。

### 保存后没有自动贴图

通过工具栏复制、保存、直接贴图或自定义出口结束时，不再额外叠加 **截图后贴图**。需要同时保存和贴图时，2.2.25 起可选择「快速保存」操作并勾选「截图后贴图」，再通过确认出口完成；也可在后续步骤中处理输出图片。


### 智能马赛克识别不到文字

智能马赛克依赖 OCR 结果。若图片过小、文字过糊或背景复杂，请改用手动马赛克，或先用 OCR 结果窗确认能否识别。


### 想截下拉菜单或短暂弹出的内容

把 **截图前延迟时间** 设为几百到几千毫秒，先运行动作，再在倒计时内打开菜单，然后再框选。

### 与「屏幕截图」步骤有何不同

**Quicker 截图** 面向交互式选区：控件吸附、标注、OCR、贴图、长截图和录屏入口更完整。传统屏幕截图步骤适合更简单的截取需求。新动作优先使用 Quicker 截图。
