# 悬浮动作与分组

悬浮动作让常用动作留在桌面上，不必每次打开动作面板。把多个悬浮动作组成一组后，可以一起移动、统一调整大小，也可以让它们只在指定程序中显示，或跟随程序窗口移动。

:::note 版本说明
2.2.6 起提供悬浮分组。若当前版本中没有“管理悬浮分组”或“悬浮此分组”等入口，请先确认版本。分组模式默认关闭；启用或关闭后需要重启 Quicker 才生效。开关随账号同步，布局、名称和窗口跟随仅保存在本机。
:::

## 开始使用

1. 从 Quicker 菜单的“悬浮按钮”子菜单打开“管理悬浮分组”。
2. 点击“启用分组模式…”，按提示重启 Quicker。
3. 将动作设为悬浮，再把一个悬浮动作拖到另一个附近，看到粘连预览后松手，即可组成分组。

已有面板分组时，也可以右键点击面板上的分组，选择“悬浮此分组”。Quicker 会按照该分组当前展示的动作顺序和行列布局，创建一个新的悬浮分组，并统一按钮大小。

面板分组和悬浮分组是两套独立的布局：后续调整面板分组的成员或排列，不会自动重新排列已创建的悬浮分组。两处使用的仍是同一个动作，编辑动作内容会影响所有引用它的位置。

## 移动和整理

分组的“定位动作”是最上方一行中的最左侧动作。它既可以运行动作，也承担移动整组的作用。分组左上角外侧的小圆点是手柄，用于移动和设置分组。

| 操作 | 效果 |
| --- | --- |
| 拖动定位动作 | 移动整组 |
| 按住 Ctrl 拖动定位动作 | 调整该动作在组内的位置，或将它拖出分组 |
| 拖动其他成员 | 调整组内位置，或将它拖出分组 |
| 左键拖动圆形手柄 | 移动整组 |
| 右键点击手柄 | 打开分组菜单 |

整理时根据预览松手，动作会归入目标位置；必要时其他成员会让出位置。拖到分组外松手，则成为独立悬浮动作，并继承分组的按钮大小和进程绑定。拖出成员后，不会自动填补所有空位。

也可以将整个分组拖向另一个分组来合并。目标组原有动作的位置保持不变，拖入成员统一使用目标组的按钮大小；合并后以目标组的分组设置为准。

开启“锁定位置”后不能拖动，Ctrl 也不会绕过位置锁。分组空白区域允许鼠标穿透，不会挡住下方软件的操作。

### 快速变宽或变窄

在手柄菜单中选择“每行个数”，即可按当前动作的逐行顺序重新排列：

- 每行个数减少：分组变窄、变高。
- 每行个数增加：分组变宽、变矮。

重排保持分组左上角位置和按钮大小不变，但会整理掉原来的空位，因此适合规则的行列布局。位置锁定时不能使用此操作。

### 调整按钮大小

- 在组内任意动作上按住 Ctrl 滚动鼠标滚轮，调整整组按钮大小。
- 在手柄上直接滚动滚轮即可，不需要按 Ctrl。
- 也可以使用手柄菜单的“组内按钮大小”，或管理窗口中的“缩小”“放大”。

每次调整 2 个逻辑像素，组内成员保持相同大小。大小锁定时不能缩放。在动作上不按 Ctrl 的滚轮操作仍按该动作配置的滚轮触发行为处理。

## 关联程序与跟随窗口

这两个设置解决的问题不同：

| 设置 | 用途 |
| --- | --- |
| 分组进程绑定 | 决定使用哪些程序时显示分组 |
| 跟随绑定程序的当前窗口 | 让分组随程序窗口移动，并保持相对位置 |

### 只在指定程序中显示

创建分组时会沿用初始动作的进程绑定，之后可以修改。一个分组可以关联多个进程，匹配其中任意一个即可。

在“管理悬浮分组”中选中分组，在“关联进程”输入框填写进程名，多个名称用分号分隔，例如 `chrome;msedge`。也可以使用输入框右侧的拾取按钮选择目标窗口，添加其进程。

勾选“按关联进程自动显示”，然后点击“保存设置”。也可以直接在手柄菜单的“分组进程绑定”中调整或暂停绑定。

### 指定跟随的相对位置

1. 切换到已绑定程序的目标窗口。
2. 将悬浮分组拖到希望停留的位置，例如窗口左上角附近。
3. 在手柄菜单中启用“跟随绑定程序的当前窗口”。

跟随会以就近的窗口角点和相对偏移定位，而不是按窗口宽高的百分比定位。例如靠近左上角的分组，在只拖动窗口右边框时，不会因为窗口变宽而按比例向右移动。

启用后仍可拖动整组来修改相对位置；松手后会重新选择就近角点。这里跟随的是绑定程序的当前匹配窗口，不是永久固定某个窗口句柄。

“显示全部”会临时暂停跟随，便于找到和整理悬浮按钮；回到自动显示模式后恢复跟随，不会清除跟随设置。管理窗口中的“移到当前屏幕”则会把分组移到鼠标所在屏幕，并关闭该分组的窗口跟随。

## 自动折叠与手柄颜色

不常用但又希望随时可用的分组，可以开启“自动折叠”。鼠标离开分组片刻后，按钮收起，只留下较大的圆形手柄；鼠标移入手柄时展开。

每个分组独立设置：可以从手柄菜单切换，也可以在管理窗口中勾选“自动折叠”后保存。

多个分组折叠后容易混淆，可以通过手柄菜单的“手柄颜色”为它们设置不同颜色，或在管理窗口中调整后保存。颜色在展开和折叠状态下都会使用。

拖动悬浮动作或整个分组时，在折叠手柄附近稍作停留，目标组会展开，便于查看和选择粘连位置。因进程绑定而隐藏的分组不会因此显示。

普通单成员分组不显示手柄，动作菜单也会隐藏折叠、颜色、每行个数等分组专用入口。已开启自动折叠的分组减到一个成员时仍保留相关设置，可以从 Quicker 菜单进入管理窗口修改。

## 管理分组

从“悬浮按钮”菜单或分组手柄菜单打开“管理悬浮分组”，可以通过缩略图识别分组，选中后进行以下操作：

- 修改分组名称、进程绑定、自动折叠和手柄颜色。
- 调整按钮大小。
- 将分组移到当前屏幕。
- 删除分组。
- 备份或恢复整个悬浮布局。

名称、关联进程、折叠和颜色等编辑内容需要点击“保存设置”才会应用。直接在桌面上移动、整理或缩放产生的布局变化会自动保存。

如果打开管理窗口后又通过手柄菜单修改了同一分组的设置，保存时可能提示先刷新。这是为了避免管理窗口中的旧内容覆盖刚做的修改；请刷新后重新编辑。

### 关闭、解除与删除有什么区别？

| 操作 | 保留什么、移除什么 |
| --- | --- |
| 关闭此悬浮动作 | 仅移除该悬浮实例 |
| 解除分组（保留悬浮动作） | 解除容器，成员留在原位置成为独立悬浮动作，并继承绑定；不再按原组跟随窗口 |
| 删除分组 | 关闭整组悬浮实例，并移除保存的分组布局 |

这些操作都不会删除动作本体，也不会删除面板上的动作。

:::warning 手柄中键会删除整组
使用鼠标中键点击手柄可以快速删除分组，效果与菜单中的“删除分组”相同，不是临时折叠。重要布局建议先备份。
:::

## 保存、备份与恢复

### 哪些设置会同步？

“是否启用分组模式”随账号同步，需要重启后生效。分组布局、名称、位置等悬浮状态保存在本机，不会随账号自动同步到其他电脑。

如需启动 Quicker 时还原上次的悬浮布局，还需要在基本设置中开启“自动恢复悬浮按钮和动作页”。仅保存布局或启用分组模式，不代表一定会在启动时显示。

关闭分组模式不会直接清空已保存的分组结构；关闭模式后使用独立悬浮窗口。重新启用分组模式并恢复悬浮状态时，可以继续使用保留的分组布局。

### 备份

在管理窗口右上角点击“备份…”，选择文件保存位置。

备份包含当前完整悬浮状态，包括独立悬浮动作和分组，以及名称、位置、大小、进程绑定、跟随、折叠和手柄颜色等设置。

备份不包含动作内容、账号中的分组模式开关，也不包含管理窗口中尚未点击“保存设置”的编辑内容。它是布局备份，不是动作安装包。

### 恢复

1. 点击“恢复…”，选择之前导出的备份文件。
2. 确认用备份替换当前悬浮状态。恢复是替换，不是把两份布局合并。
3. 按提示重启 Quicker，并确保已开启启动时恢复悬浮状态。

恢复前会先校验文件并备份当前状态。成功导入后，请尽快重启：当前桌面仍可能显示旧布局，但这时对旧布局的调整不会再覆盖刚导入的状态。

在其他电脑恢复时，需要先确保被引用的动作已经存在，例如已通过账号同步。屏幕数量、分辨率不同时，可用“移到当前屏幕”找回位置不合适的分组。

## 常见问题

### 分组突然看不到了

先检查是否只是折叠成手柄，或因进程绑定而隐藏。可以在“悬浮按钮”菜单中选择“显示全部”，再从管理窗口查找。位置不合适时使用“移到当前屏幕”，注意此操作会关闭该分组的窗口跟随。

### 重启后没有恢复

检查是否开启启动时恢复悬浮状态，是否使用了同一个账号，以及当前电脑上是否有对应布局和动作。悬浮布局不会自动同步到另一台电脑，需要手动备份、恢复。

### 为什么单个动作的菜单少了一些项目？

单个动作隐藏了不适用的分组专用菜单。进程绑定、窗口跟随和动作自身的操作仍可使用，Ctrl + 滚轮也仍可调整大小。需要完整管理入口时，从 Quicker 的“悬浮按钮”菜单进入。

### 布局文件异常怎么办？

检测到无法安全读取的布局时，Quicker 会保护原文件，避免直接覆盖。优先恢复有效备份；如需重新开始，可根据管理窗口中的异常提示使用“备份原文件并重置…”。不要把布局恢复当作恢复已删除动作内容的方法。
