# 轮盘菜单（V2 变化）

:::info[完整功能说明已合并至功能目录]
轮盘菜单的圈层布局、扩展圈、子动作及外观配置请查看主文档 **[轮盘菜单](/v2/features/triggers/circle-menu)**。本页仅保留相对 1.x 的增量变化、授权边界与历史锚点。
:::

## 相对 1.x 的主要变化

- **第三个常驻圈与可视子动作**：在传统扩展圈之外新增常驻第三圈与三种可视子动作展开样式；引入「指针放大倍率」调节外圈滑动距离。
- **直接编辑与跨场景协同**：可在轮盘预览界面直接新建、拖拽编辑、绑定与切换来源；屏幕顶部左右角可快速进入当前场景轮盘管理或设置。
- **鼠标冲突判定改进**：同一右键同时用于轮盘、手势、长按或右键扩展热键时，依据鼠标移动与按键顺序协同区分意图。

## 覆盖粘贴与跨场景剪切

2.2.10 起，轮盘动作支持：

- **覆盖粘贴**：把剪贴板中的动作粘贴到已有槽位时可以直接覆盖，不必先清空。
- **跨场景剪切**：可以把轮盘槽位动作剪切到另一场景的轮盘，再粘贴到位；目标写入成功后才会从原场景移除。

## 从 1.x 升级时需要注意

- **专业版授权要求**：第三个常驻圈、可视子动作与第二圈第 9～16 格需有效专业版授权（不提供传统扩展圈 90 天试用）；受限设备暂时不显示但保留配置数据。
- 原有程序覆盖、按键子动作、传统扩展圈继续保留；「自动隐藏连续为空的外圈」不删槽位，「指针放大倍率」默认 `1` 不改变原有滑动习惯。
