# AI 指令与记忆

从 **2.3.27** 起，可在 **设置 → AI → AI 指令与记忆** 中管理提供给助手的长期信息。适合保存经常重复的回答要求、个人偏好和环境背景，减少每次重新说明。

这项功能提供长期上下文，不等于把所有历史聊天自动带入新对话，也不能保证模型每次都正确遵守。重要任务仍应写清当前要求并检查结果。

## 指令和记忆有什么区别

| 内容 | 适合保存什么 | 示例 |
| --- | --- | --- |
| 指令 | 希望助手持续遵守的处理方式，由你集中编辑 | “回答使用中文；给代码时先说明如何运行。” |
| 记忆 | 可单独查看、更正和删除的偏好或背景，既可手动添加，也可由助手记录 | “我通常用 Excel 整理订单。” |

临时任务、一次性的路径和长篇资料，优先放在当前对话中。记忆可能过时；环境、偏好发生变化后，请及时更正或删除。

## 共享与本机范围

指令和记忆都分为两种范围：

| 范围 | 保存与同步 | 适用内容 |
| --- | --- | --- |
| 共享 | 登录云账号时随当前账号同步，可供同账号其他设备使用 | 通用的语言偏好、工作习惯 |
| 本机 | 仅保存在当前设备的当前账号数据中，不上传同步 | 本机软件位置、硬件和目录约定 |

本地账号不会上传共享内容；选择“共享”也不会让内容公开给其他用户。本机内容换电脑后不会自动出现，需要先导出，再在目标设备导入。

:::caution[共享内容与模型调用]
共享指令和共享记忆会以明文上传 Quicker 云端，请勿写入密码、密钥等敏感信息。

“本机”只表示不通过账号同步；用于对话时，本机指令和记忆仍会作为上下文发送给你选择的模型。使用远程模型时，这些内容也会离开本机。
:::

## 编写长期指令

1. 打开 **AI 指令与记忆**。
2. 将所有设备通用的要求写入 **共享指令（所有设备）**；只适用于当前电脑的要求写入 **本机指令（仅本设备）**。
3. 点击 **保存指令**，确认没有保存失败或冲突提示。
4. 在后续对话中检查助手是否按要求处理。

例如，共享指令可以写“说明操作步骤时使用中文菜单名”；本机指令可以写“本机项目目录是 `D:\Projects`”。尽量写短而明确的规则，避免互相矛盾。内容过长时可能无法完整带入模型，可参考页面显示的字符用量精简。

## 添加、更正和撤销记忆

在对话中可以明确要求助手记住某项长期偏好，也可在设置页点击 **添加记忆**，输入内容并选择共享或本机范围。是否记录成功应以设置页中的条目为准。

记忆列表可直接编辑内容，点击该条的 **保存** 生效；也可使用 **移到本机 / 移到共享** 或 **删除**。移动到共享后，该内容将进入云账号同步范围。

助手记录记忆时会先写入，不是每条都先弹确认窗口。请定期查看列表；不正确的记录可更正、删除，或在 **最近操作** 中撤销相应记忆变更。删除一条记忆不会删除包含它的历史聊天，已经发送给模型的内容也不会因此被收回。

## 让 AI 整理记忆

点击 **让 AI 整理记忆**，可以请已配置的模型提出合并重复、精简或更正的建议。整理会把记忆内容发送给该模型，并可能产生用量。

建议出现后，可逐条选择 **应用 / 忽略**，或使用 **全部应用 / 全部忽略**。只有应用后才修改记忆；应用前请检查是否改变原意、误删条件或混淆本机与共享范围。已应用的记忆变更可在 **最近操作** 中撤销。

## 暂停使用记忆

**启用记忆** 默认开启，开关按当前账号保存在本机，不随账号同步。

关闭后，新对话不再带入这里的指令和记忆；进行中的对话停止补送这些内容，并停止提供记忆写入工具。已保存的内容不会被删除。

**已进入当前聊天或压缩摘要的内容仍可能影响回答。** 若希望接下来的任务不受此前指令和记忆影响，请先关闭开关，再新建对话。其他设备需要分别调整自己的开关。

## 导出、导入与换机

- **导出…**：可选择全部、仅共享或仅本机内容。导出文件包含可读的指令和记忆，请按其中的隐私内容保管。
- **导入…**：选择此前导出的文件，先检查新增、更新和指令替换预览，再确认。导入中的指令可能替换对应范围的现有指令；操作前建议导出当前内容备份。
- **换电脑**：云账号的共享部分通过同步取得；本机部分需要导出、导入。检查导入后的范围，不要把旧电脑专用的路径误当成新电脑配置。

## 同步冲突与旧版使用

共享记忆同步发生冲突时可能保留两份，页面会提示重复，可检查后整理。共享指令的同一处被多台设备修改时，设置页会显示冲突草稿，供你选择本机、云端或手动合并；未解决的冲突草稿不会作为新指令发送给助手。

2.3.26 及更旧版本不提供本页功能。回退后不能在旧版管理和使用这些内容；重新升级后再检查。需要换机、重装或清理账号数据时，请先导出，尤其是不会自动同步的本机内容。一般升级与回退注意事项见[升级与回退](/v2/migration/upgrade-and-rollback)。

## 为什么助手没按记忆回答

先检查 **启用记忆** 是否开启、条目是否保存在当前账号、所选范围是否适用于当前设备，以及是否存在同步或保存错误。内容过多时精简重复条目，并在新对话中验证。

记忆是给模型的参考上下文，不会授予额外的文件、动作或系统权限，也不会代替当前任务的授权。外部 MCP 助手和普通 AI 动作步骤不能仅因使用同一套模型配置，就认定会读取这里的内容。
