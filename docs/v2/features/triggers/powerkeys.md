# 扩展热键

扩展热键把一个普通按键或鼠标键作为「引导键」，再配合另一个按键执行操作。例如：

- 按住空格再按 `E`，启动 Everything 搜索；
- 按住右键再按 `A`，执行指定动作；
- 以 `CapsLock`、`Win` 或其它不常用按键为引导键，建立一组容易记忆的快捷操作。

重点是区分「用户正在打字」和「用户有意按下扩展热键」，减少吞键、误触和与鼠标功能冲突。

## 快速开始

1. 打开 **场景与动作管理 → 扩展热键**。
2. 在上方启用引导键，并选择激活策略（见下文）。管理页分为 **按键动作** 和 **引导键设置** 两个标签页。
3. 在 **按键动作** 中添加组合：指定第二键，以及要执行的动作或操作。
4. 需要改共用时间参数时，点击右上角 **扩展热键功能设置**；只改当前引导键时，在 **引导键设置** 中覆盖全局默认值。
5. 保存后，按住引导键再按第二键试一次。若空格或字母容易误触，先做打字节奏校准，或改用「输入优先」。

## 三种激活策略

每个键盘引导键都可以单独选择激活策略。

### 仅作为引导键

该按键只用于扩展热键，不再保留原来的单键输入功能。组合键按下后可以立即识别，也不使用前序保护、抬起判定和按住确认等时间参数。

适合 `CapsLock`、不常用功能键或专用外接键，以及更重视响应速度、希望组合立即触发的场景。

### 平衡模式

该按键既能正常输入，也能作为扩展热键引导键。Quicker 会根据连续输入状态和抬起顺序区分两种意图。这是大多数空格和字母引导键的推荐选择。

以平衡模式下的 `F+A` 为例：

| 操作顺序 | 处理结果 |
| --- | --- |
| 依次按下 `F`、`A`，先松开 `F` | 恢复普通输入 `fa` |
| 依次按下 `F`、`A`，先松开 `A` | 触发扩展热键 `F+A` |

### 输入优先（试验）

只有引导键达到「按住确认」时间后，组合键才会触发；按住时间不足时优先恢复普通输入。适合打字较快、经常因为滚键误触的用户。代价是需要有意识地稍微按住引导键，触发速度会比平衡模式慢一些。

:::tip[如何选择]

- 引导键不需要输入原字符：选择「仅作为引导键」。
- 希望兼顾输入速度和组合响应：先使用「平衡模式」。
- 空格或字母仍然容易误触：尝试「输入优先」。

:::

## 全局默认与逐引导键设置

设置分成两层：

- **扩展热键功能设置**：保存所有引导键共用的默认参数；
- **引导键设置**：为当前引导键选择策略，并可覆盖全局默认值。

常用参数：

| 参数 | 作用 |
| --- | --- |
| 前序保护 | 引导键距离上一次按键太近时，认为用户仍在连续打字，按普通输入处理 |
| 抬起判定 | 平衡模式下，在这段时间内通过两个键的抬起顺序判断用户意图 |
| 按住确认 | 输入优先模式下，引导键至少按住多久后组合才允许触发 |
| 未配置组合处理 | 抬起判定结束后遇到没有设置的组合时，恢复普通输入或忽略该键 |
| 单键恢复超时 | 仅长按引导键超过此时间后，不再补发它原来的单键输入 |

「未配置组合处理」只在抬起判定时间结束后生效。判定时间内如果发现更像快速打字的未知组合，会优先恢复普通输入，避免因为「忽略未配置组合」而吞掉文字。

:::note[单键恢复超时]

该参数只决定是否恢复引导键原来的按键输入。即使超过时间，已经为「单独按下引导键」配置的动作仍可能执行。

:::

`Win` 键作为引导键时，可以保留常见的 Windows 系统快捷键兼容。该选项只会在当前引导键为左侧或右侧 `Win` 键时显示。

## 打字节奏校准

在扩展热键功能设置中点击测试区域，按平常节奏连续输入至少 6 个按键。Quicker 会根据相邻按键间隔给出前序保护、抬起判定和按住确认的建议。

校准只统计时间间隔，不记录按键内容、输入文字、当前程序或完整按键序列。建议值不会自动改变现有行为，需要点击「采用建议值」，再应用设置后才会保存。

按平时打字习惯输入一段自然、熟悉的文字即可，不必刻意追求速度。

## 右键扩展热键与轮盘、手势协作

右键扩展热键、轮盘、鼠标手势和长按动作会共同判断当前操作意图：

- 按住右键再按字母，可以触发对应的扩展热键；
- 按住右键并移动鼠标，仍可进入轮盘或手势；
- 长按右键打开面板后，只要右键仍未松开，还可以继续触发「右键+字母」；
- 一旦扩展热键已经确定触发，同一次按住过程不会再误转成轮盘或手势。

这样可以继续保留「长按右键打开面板，再使用右键组合」的操作习惯。日常配置见 [轮盘菜单](/v2/features/triggers/circle-menu) 与 [鼠标手势](/v2/features/triggers/mouse-gestures)。

## 诊断最近一次判定

引导键设置页会显示最近一次判定摘要。遇到「为什么这次恢复了普通输入」或「为什么组合没有触发」时，按实际方式重现一次，然后点击「刷新」查看原因。

常见原因包括：

- 距离上一次输入太近，进入前序保护；
- 根据抬起顺序恢复了普通输入；
- 输入优先模式下尚未达到按住确认时间；
- 组合没有配置，并按当前策略恢复或忽略；
- 引导键被长按取消；
- 组合已触发，后续自动重复被抑制。

## 限制与排障

- **输入优先仍是试验策略**：建议先为少量引导键启用并观察实际手感。
- **校准不能代替试用**：不同输入法、键盘布局和打字习惯差异较大。Quicker 目前不会把输入法已经开启等同于「正在组字」。
- **快速滚键、长按自动重复或按错第三个键**：会尽量恢复完整的普通输入，避免丢字或重复执行动作。
- **在线分享和在线安装暂时停用**，等待分享数据具备明确的 2.x 版本兼容能力；本地设置和规则使用不受影响。
- **与高级鼠标、轮盘共用同一鼠标键**：先确认引导键和高级鼠标规则没有互相抢输入。
- **相对 1.x 的识别与策略变化**：见 [扩展热键（2.x 变化）](/v2/what's-new/others/powerkeys)。
