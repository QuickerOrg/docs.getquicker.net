# 生成随机数

生成随机数

## 当前模块定义

<XActionModuleMeta moduleKey="sys:randomNum" />

生成一个随机的数字（整数）。

最小值 &lt;= 随机数 &lt; 最大值。

<ModuleParamPreview moduleKey="sys:randomNum" />

## 参数

【最小值】随机数的最小值，结果可能等于这个值。

【最大值】随机数的最大值，结果小于这个值。

## 输出

【随机数】计算生成的随机数。
