# 运行子程序模块

2.x 将主动作与子程序调用纳入统一执行会话。停止、取消和失败状态可以沿调用关系传播，非模态窗口等延后回调也会按所属窗口和调用会话处理，减少子程序结束后仍影响无关动作的情况。

结构化调试会保留主动作与子程序的父子关系。调试器还可以强制记录下级子程序，方便进入子程序断点和查看内部步骤；原有“跳过调试输出”参数仍可用于减少普通调试日志。

这些变化不会修改子程序的输入输出定义，但复杂动作升级后仍建议重点检查依赖并行、窗口回调或主动中止的调用链。

参数说明见[运行子程序](/v2/xaction/modules/subprogram)。
