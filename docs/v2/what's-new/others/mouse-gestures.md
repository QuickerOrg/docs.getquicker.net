# 鼠标手势

Quicker 2.x 保留了 1.x 的手势轨迹、候选列表、按键子动作和未识别手势重放，并重点改进了收笔识别、长轨迹性能、场景规则和编辑效率。

| 方面 | 1.x | 2.x |
| --- | --- | --- |
| 收笔识别 | 最后几个鼠标点可能尚未进入识别 | 松开时补入最终位置并完成一次确定性匹配 |
| 长轨迹 | 轨迹过长后识别数据可能停止增长 | 持续抽稀并保留整体形状，长手势仍可继续识别 |
| 轨迹显示 | 长轨迹可能增加重绘负担 | 分块增量绘制，并对曲线做平滑处理 |
| 场景 | 以全局和程序覆盖为主 | 使用统一场景链，支持程序、子场景和网址场景继承 |
| 编辑 | 主要依赖完整编辑窗口 | 支持右键快速设置、拖入动作、拖动排序和双击直达编辑 |

## 收笔识别更稳定

快速画完手势并立即松开时，1.x 的移动处理线程可能还没有消费最后一小段轨迹，导致屏幕上看起来已经画完整，实际识别却少了末梢方向。

2.x 会在收笔时补入鼠标最终位置，固定本次轨迹，再用完整点集完成最终匹配。对于“先横后竖”“末尾回勾”等依赖最后方向的手势，结果会更确定。

停顿后出现候选列表时，用户在列表中的明确选择仍然优先，不会被收笔时的自动识别覆盖。

## 长轨迹与显示性能

2.x 把轨迹记录、识别和重放收口到同一份会话数据。轨迹较长时，识别点会在保持形状的前提下自动抽稀，而不是到达固定数量后停止更新。

轨迹线改为分块增量绘制：新移动只追加当前段，不再为每一个鼠标点反复重建整条线。识别成功或失配时，颜色变化也不会重新计算所有轨迹几何。

视觉上，轨迹使用向心 Catmull–Rom 曲线做平滑处理。尖角、回勾和闭环仍会保持原来的主要形状，同时减少折线感和快速绘制时的闪烁。

这些改进主要在快速长手势、远程桌面或软件渲染环境中更明显。原有的“隐藏轨迹”和“结束特效”开关仍然可用。

## 场景继承与禁用

2.x 的手势规则使用与动作面板、轮盘等功能一致的场景识别结果。常见继承顺序包括：

- 普通程序：当前程序 → 全局；
- 浏览器：当前浏览器 → 浏览器通用场景 → 全局；
- 网址：当前网址 → 当前浏览器 → 浏览器通用场景 → 全局；
- 程序路径、窗口标题或窗口类子场景：子场景 → 所属程序 → 全局。

同一条手势轨迹在更具体的场景中设置动作后，会覆盖上级场景的同轨迹动作。将本地手势规则禁用会阻止上级同轨迹规则触发；如果希望重新使用上级动作，应移除本地覆盖或恢复继承。

轮盘或手势打开后，本次会话会固定开始位置对应的目标、场景和动作内容。即使随后前台窗口变化，延迟执行也不会误用新窗口的规则。

## 每条手势可以设置延迟

2.x 可以在手势动作编辑窗口中设置延迟时间。手势识别完成后，Quicker 会先关闭轨迹窗口，再等待指定时间执行操作。

这适合截图、窗口操作或需要等界面消失后再运行的动作。直接触发动作和按键子动作使用同一条手势规则的延迟设置。

## 管理手势更直接

在“场景与动作管理 → 鼠标触发 → 手势”中，可以：

- 双击手势磁贴直接编辑当前场景的动作；
- 从动作面板拖入动作，快速建立引用；
- 在空手势的右键菜单中直接选择常见操作类型；
- 拖动手势磁贴调整显示顺序；
- 复制、粘贴或清除当前场景的手势动作；
- 重绘或删除手势轨迹。

手势的图形定义仍是账号级共用内容；各场景保存的是这条轨迹在当前上下文中要执行的动作。

## 运行时快速进入设置

通过“按键 + 移动鼠标”或其它高级鼠标规则启动手势时，可以把鼠标移动到当前屏幕顶部角落再结束会话：

- 左上角：打开当前场景的手势管理；
- 右上角：打开手势功能设置。

角落识别范围很小，只在轮盘或手势会话结束时判断，不会替代普通的“移动到屏幕角落”高级鼠标规则。

## 从 1.x 升级时需要注意

- 原有手势图形、程序动作、按键子动作和外观设置会继续保留；
- 旧的程序覆盖会进入新的场景继承链，建议检查浏览器和网址场景的实际来源；
- 本地禁用会屏蔽上级同轨迹规则；删除本地规则才会恢复继承；
- 原有匹配阈值会按兼容方式换算，升级后不会因为内部评分公式调整而普遍变难触发；
- 使用未识别手势重放、候选列表、多显示器或远程桌面的用户，建议各画几次常用手势确认实际手感。
