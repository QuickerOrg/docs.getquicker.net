# 动作历史版本、备份与恢复

需要撤销动作定义的修改时，从动作菜单或编辑器打开历史版本。此功能可能受当前账号权益限制；没有权限时，客户端会先显示版本限制说明。

## 选择历史版本

正式动作的历史窗口提供“本地备份”“手动网络备份”“自动网络备份”页签。记录是否存在取决于此前是否保存过对应备份；不能假定每次修改都有网络副本。

1. 先保存或另行导出需要保留的当前内容。
2. 打开历史窗口，选择来源与记录，核对保存时间、类型和备注。
3. 本地备份可切换“显示自动保存的版本”，再选择“加载此版本”。
4. 返回宿主编辑器后检查内容，按该编辑器的保存流程应用。取消历史窗口不会选择恢复项。

历史版本用于恢复动作定义，不能据此恢复该动作的外部文件、数据库或运行状态；运行状态需要[单独备份](./account-and-sync.md#动作运行数据的本地备份)。

## 删除历史记录

本地备份可以删除选中记录或删除该动作的全部记录。删除后不能再从这些记录恢复；清理前请先导出重要版本。

## 导入导出动作定义

动作定义的导入、导出也可能受账号权益限制。导出的定义与动作运行数据备份用途不同：前者保存动作本身，后者保存已安装动作的运行状态。分享网页的 revision 历史是另一套记录，见[分享版本历史](./action-sharing.md#版本历史怎么看)。

## 本机暂存动作

暂存区使用独立的本机历史和手动备份。“恢复选中”会基于旧内容生成新版本；丢弃暂存项会同时删除其历史，不能从正式动作回收站找回。保留数量、手动备份及写回说明见[本机动作暂存区](./action-panel/action-drafts.md#手动备份和版本说明)。
