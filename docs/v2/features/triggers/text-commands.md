# 文本指令

文本指令可以在输入缩写词后执行操作，例如输入 `;date` 插入日期，或用正则表达式捕获内容并把匹配结果传给动作。

支持直接触发、触发字符、正则匹配、输入法清除方式、分组、导入和分享，并按场景分别配置规则。

## 快速开始

1. 打开 **场景与动作管理 → 键盘触发 → 文本指令**。
2. 左侧选择要设置的场景：全局、程序、标题子场景或网址。
3. 新增一条规则：填写缩写词（或正则），选择触发键和要执行的操作。
4. 保存后，在目标程序的输入框中输入该缩写并按下触发键。
5. 需要搜索、分组、导入导出或分享时，到全局场景的完整管理界面操作；场景列表是局部规则入口。

例如：

- 在邮件程序中输入 `;sig` 插入邮件签名；
- 在代码编辑器中输入 `;log` 插入调试模板；
- 在特定工单网址中输入 `;reply` 运行该网站专用回复动作；
- 在全局场景保留日期、地址等通用缩写。

网址场景运行时会继续经过当前浏览器程序、浏览器通用场景和全局规则查找，不需要把同一网址规则复制到 Chrome、Edge 等不同浏览器。

## 按场景覆盖与禁用

文本指令使用「缩写词 + 是否正则匹配 + 触发键」作为覆盖单位。

| 操作 | 效果 |
| --- | --- |
| 当前场景没有同规则 | 继续使用父场景或全局指令 |
| 当前场景存在同规则 | 由当前场景接管 |
| 当前场景的同规则被停用 | 上级同规则也不会触发 |
| 删除当前场景的同规则 | 恢复继承 |

这和 [动作快捷键](/v2/features/triggers/action-hotkeys) 相同：停用本地同规则会屏蔽上级，避免在某个程序中停用后全局同名指令又意外生效。要恢复继承，应删除本地同规则。

管理页默认只显示本场景规则。开启「显示继承的规则」后，可以查看来源，并把继承项复制到本场景再修改。

## 批量复制到其它场景

场景文本指令列表支持多选、`Ctrl+C` 和 `Ctrl+V`：

- 可以一次复制多条本地或继承规则；
- 粘贴后会生成当前场景自己的副本；
- 已存在相同规则键的项目会跳过，不会静默覆盖；
- 无效规则和因数量限制不能新增的项目会给出统计提示。

这适合把一组工作缩写从全局规则复制到某个程序，再做少量定制。

## 批量修改生效进程

在全局文本指令管理界面中多选规则，打开 **批量修改**，勾选 **修改生效进程**，即可一次调整所选规则的进程范围：

- 留空表示在所有进程中生效；
- 多个进程名用英文分号 `;` 分隔；
- 可以使用右侧的窗口选择按钮取得目标程序的进程名；
- 只有勾选了「修改生效进程」才会覆盖原值，未勾选时保持每条规则原来的设置。

批量窗口还可以同时修改忽略大小写和触发键。保存前会统一确认。批量修改生效进程会直接覆盖所选规则的原进程列表，提交前确认分号分隔的进程名完整无误。

## 切换窗口时的输入

程序或网址变化时，后续输入会按当时可用的场景和规则继续判断，不再仅因为物理进程发生变化就取消一段已经开始的短暂输入。

对于 WPS 内部文档识别尚未稳定的过渡状态，文本指令会保守回退到可信的 WPS 宿主和全局规则，不会继续执行上一个文档场景的指令。

## 限制与排障

- **输入后没有触发**：检查缩写、是否正则、触发键，以及当前场景最终是否有一条启用的同规则。
- **停用后全局同名指令仍不触发**：这是预期行为。删除本地同规则才会恢复继承。
- **批量粘贴没有全部出现**：会跳过重复规则；完成后留意结果提示中的新增、重复和无效数量。
- **不同浏览器同一网址表现不一致**：检查当前网址场景是否正确命中。
- **误触发或场景不对**：看 **最近触发历史**，并可配合 **当前场景诊断**。
- **相对 1.x 的场景化变化**：见 [文本指令（2.x 变化）](/v2/what's-new/others/text-commands)。正则规则、忽略大小写、触发字符和输入法清除方式沿用原有语义。
