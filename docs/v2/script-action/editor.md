脚本编辑器以源码为中心。信息栏用于修改标题、图标、说明和超时，也提供选项、关联以及历史版本入口。源码补全、悬浮说明和签名提示可以帮助你查阅当前 API。

## 日常编写流程

1. 输入或修改源码，设置动作标题和超时。
2. 点击“检查”，先处理“问题”页的语法、入口和能力识别提示。
3. 选择 Main 或菜单方法作为运行入口；按需开启“提示参数”。
4. 运行后查看“结果”和“日志”；复杂问题使用[调试与运行分析](./debugging.md)。
5. 确认内容后保存。编辑器中运行当前草稿不等于保存动作。

## 结果与日志

return 的值显示在“结果”页；void 入口没有返回值。qk.Log(...) 的信息显示在“日志”页。遇到 qk 调用错误，可记录错误码、调用名和扩展信息，详见[常见问题](./troubleshooting.md)。

检查通过不保证文件、网络或目标窗口一定存在。编辑器运行与面板运行都是真实执行。运行耗时较长或等待用户交互时，先设置合适的超时；等待对话框的时间也计入动作时限。

## 保存、关闭与恢复

保存保留编辑器当前内容；关闭时如有未保存修改，应按提示选择是否保存。只读查看时无法保存或修改受限内容。

使用[备份与恢复](./backup.md)在大幅修改前保存一个可返回的版本。AI 修改后先检查，再由你决定运行和保存。
