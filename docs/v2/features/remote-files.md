# 远程文件

2.2.18 起，组合动作可通过 **远程文件** 步骤操作 WebDAV、网盘和 NAS 中的文件。2.2.19 起支持 S3 / S3 兼容存储、账号导入导出、图片和文本内容，以及批量读取、批量下载和文件夹传输。

这个功能直接访问你配置的存储服务，不会把账号凭据放进动作、分享包或账号同步。

## 配置账号

1. 打开 **设置 → 软件连接 → 远程文件账号**。
2. 新建账号，选择 **WebDAV** 或 **S3 / S3 兼容存储**。账号保存后不能切换协议；需要另一种协议时请新建账号。
3. 填写稳定的 **引用名**。动作通过它查找账号；修改显示名不影响动作，修改引用名后则要同步修改动作。
4. 填写服务器、根路径或根前缀及凭据，保存后点击 **测试连接**。

密码、Secret Access Key 等凭据使用当前 Windows 账号加密，只保存在本机。编辑时留空表示保留原凭据。

### WebDAV

服务器地址填写 WebDAV 入口，用户名和密码分开填写。可用于支持 WebDAV 的 NAS、网盘或自建服务。不同服务对覆盖、移动和条件请求的实现存在差异；用于重要文件前，先在测试目录验证上传、下载、移动和同名文件策略。

### S3 及兼容存储

S3 账号需要 Endpoint、Region、Bucket、Access Key ID 和 Secret Access Key。Endpoint 只填协议、主机和可选端口，不要加桶名、路径、查询串或凭据。

- AWS S3 通常使用区域 Endpoint，例如 `https://s3.ap-southeast-2.amazonaws.com`，Region 填 `ap-southeast-2`，不勾选 Path-style。
- S3 兼容服务是否需要 Path-style，以服务商文档为准；OSS 不能使用 Path-style。
- 根前缀是 Quicker 的客户端路径约束，不能代替 IAM 或桶策略权限。
- 列表需要 `s3:ListBucket`，读取需要 `s3:GetObject`，上传需要 `s3:PutObject`，删除和移动源文件需要 `s3:DeleteObject`，分片清理需要 `s3:AbortMultipartUpload`。

设置页的连接测试会查询和列出账号根，再上传并删除一个小型临时文件。它不覆盖大文件分片、移动、分页或并发覆盖，正式使用前仍应按自己的服务和权限做小范围验证。

## 在动作中使用

添加 **远程文件** 步骤，选择账号后再选操作。常用操作包括：

- 上传本地文件、文本、字节数组或图片。
- 下载为本地文件，或在内存中读取为文本、字节数组或图片。
- 列目录、查询、新建目录、删除、移动/重命名和复制文件。
- 批量读取内容、批量下载、上传文件夹和下载文件夹。

对会写入或删除远端数据的操作，先用测试目录确认路径和同名文件策略。如果写入已发出后遇到断线或超时，结果可能为“未知”；先查询或下载比对远端状态，不要盲目重试。

## 导入、导出和凭据安全

2.2.19 起，账号页可导入或导出单个账号。导出文件包含明文密码、Secret Access Key 及可能存在的会话令牌：

- 只导出到可信位置，不要上传到公开网盘、聊天群、动作分享或源码仓库。
- 传输完成后删除导出文件；如果文件曾外泄，立即在服务端轮换凭据。
- 导入时会校验配置；重名引用不会静默覆盖既有账号。

## 回退旧版

保存 S3 账号后，本机的远程文件账号配置会升级。旧版 Quicker 会拒绝修改整份账号列表（包括其中的 WebDAV 账号），以避免丢失 S3 字段和密钥引用。数据不会因为打开旧版而被删除，但旧版不能继续管理这些账号。

即使后来删除全部 S3 账号，配置也不会自动降回旧格式。需要长期回退时，建议先在新版导出必要账号，再手工重建旧版可用的 WebDAV 配置。
