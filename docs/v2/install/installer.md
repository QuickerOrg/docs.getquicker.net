# Quicker 安装器与修复工具

**Quicker 安装器（QuickerInstaller）** 是独立运行的工具。它可以检测、下载和安装运行环境与 Quicker，也提供启动、显示、连接和安装状态等维护工具。即使 Quicker 本体无法打开，也可以单独运行安装器处理问题。

日常更新已安装的 Quicker，优先使用[应用内更新](./update.md)；首次安装、补齐运行环境，或需要修复问题时，再使用安装器。

## 下载与打开

从 [Quicker V2 官网](https://getquicker.net/V2)点击 **下载 2.0 安装器**，或使用[官方安装器下载入口](https://getquicker.net/Download/Installer)。下载后直接运行 `QuickerInstaller-版本号.exe`。

左侧有两个主要入口：

- **安装**：查看组件状态，安装运行环境、Quicker 和可选组件。
- **工具**：按具体问题进入维护子页，查看检测结果并执行修复。

安装器本身不需要先安装到电脑。组件安装、系统时间同步或安装状态修复等操作需要管理员权限时，会单独请求授权；取消授权不代表操作已经完成。

安装器不能绕过 Quicker 的系统要求、账号限制或组件架构要求。安装前仍需阅读[系统要求](./windows.md#系统要求)；从 1.x 升级时，先完成[备份与迁移准备](/v2/migration/from-v1)。

## 安装运行环境与 Quicker

1. 在 **安装** 页等待组件检测；需要重新检查时点击 **刷新**。网络不可用时，本机检测与获取最新版本、下载文件是两件不同的事，不能把联网失败当成“尚未安装”。
2. 需要补齐运行环境时，点击 **一键安装运行环境**；检测到需要修复时，按界面提供的 **一键修复** 操作。当前运行环境包括 .NET 10 Desktop Runtime、ASP.NET Core 10 Runtime 和 Visual C++ 运行库。
3. 在 **Quicker 2.0** 卡片上，按当前状态选择安装或更新，等待下载与校验完成，再按外部安装向导操作。保存工作，并按提示退出正在运行的 Quicker。
4. 安装进程结束后，安装器会重新检测。请检查卡片上的状态与版本，再启动 Quicker 确认；不能仅凭安装窗口关闭就认为安装成功。

安装器默认按操作系统选择 x64 或 ARM64 目标。Windows on ARM 上已有 x64 版 Quicker、或动作依赖特定架构的 DLL、COM 和驱动时，请先核对[平台与组件兼容性](/v2/what's-new/platform-and-compatibility)，不要为消除“未安装”提示而直接混装另一架构。

Everything 和 Chrome / Edge Connector 属于按需使用的组件，不必为了安装 Quicker 全部装上。浏览器扩展会引导到对应扩展商店，仍需在浏览器中完成安装或启用。软件 Bridge 请在 Quicker 的[软件连接](/v2/features/software-connections)中管理。

### 历史版本与回退

在 Quicker 组件卡片中点击 **历史版本**，查看并选择需要安装的版本。选择历史版本只决定安装的程序版本，不会把账号、动作和设置恢复到当时的数据。

需要安装 Quicker 1.x 时，使用安装页中的 **Quicker 1.x** 回退入口，并先阅读[迁移与回退说明](/v2/migration/from-v1)。两代不能同时安装；V2 小版本降级前，也应核对[升级与回退](/v2/migration/upgrade-and-rollback)中的兼容风险。

### 下载、取消与重试

- 下载期间可点击 **取消下载**。重新尝试时会重新准备和校验文件，不保证从上次中断处续传。
- 进入外部安装向导后，取消操作应在该向导或系统授权窗口中完成。取消或失败后，请刷新检测并核对实际版本。
- 点击左侧 **下载目录** 可打开普通下载文件所在位置；Quicker 分卷包及共享缓存由程序管理，不要只移动 MSI、丢弃配套 CAB 或手动拼装缓存文件。
- 下载或校验失败时，先检查网络与错误提示，再重试或使用界面提供的手动下载入口。不要跳过校验、改文件名冒充已下载成功的包。

## 按问题选择维护工具

进入左侧 **工具**，选择对应项目。先阅读检测结果和确认内容，操作完成后按提示重新检测或重启目标程序。

| 遇到的问题 | 工具 | 作用与边界 |
| --- | --- | --- |
| 更换或重装 Photoshop 后，Quicker 连不上 | Photoshop 连接修复 | 检查并修复 Windows 中的 Photoshop 连接登记；修复后重启 Photoshop，再验证连接 |
| Quicker 开机后没有自动启动 | 开启无法自动启动问题检查 | 检查并重建当前用户启动命令；Windows 已禁用启动项时，仍需到系统“启动应用”中启用 |
| 启动动作导致卡住，想先停用它们排查 | 禁用/恢复启动时自动运行动作 | 切换启动动作禁用状态，下次启动 Quicker 生效；不是删除动作 |
| 窗口显示异常，怀疑 GPU 渲染兼容性 | 禁用/恢复 GPU 渲染 | 切换渲染禁用状态，下次启动生效；需要恢复时回到此工具操作 |
| 电脑时间不准 | 系统时间 | 对比网络参考时间，按需请求 Windows Time 服务同步；不更换系统时间源或域策略 |
| 想把 Quicker 数据从 C 盘移到其他磁盘 | 数据位置迁移 | 预检、复制并切换数据位置，也可迁回；完整步骤见[数据目录与迁移](./data-location.md) |
| 旧 MSI 缓存或安装记录损坏，无法重装 | 安装状态修复 | 清理旧安装记录与旧程序目录，之后回到安装页重新安装；不是恢复动作或账号数据 |

### Photoshop 连接修复

先选择要连接的 Photoshop 版本，再检查连接登记。需要修复时，核对确认信息中的目标版本后继续；修复后保存工作，关闭并重新打开该版本 Photoshop，再点击 **验证连接**。

验证时应关闭 Photoshop 内的对话框，并确保 Photoshop 与安装器使用相同用户和权限级别。登记正常不等于实际连接成功；仍需验证并回到 Quicker 重试原动作。工具提供撤销修复；登记信息已被其他程序改动时，会停止撤销以保留这些改动。

### 安装状态修复前确认

此工具面向旧安装记录或 MSI 缓存损坏导致无法安装的情况，不是普通更新的必做步骤。

1. 保存工作并完全退出 Quicker。
2. 先备份重要动作与本机数据，再进入 **工具 → 安装状态修复**，点击 **修复**。
3. 确认将清理旧 Quicker 安装记录和 `Program Files` 中的旧程序目录；动作、配置和账号等用户数据保留。需要管理员授权时核对后继续。
4. 修复成功后，回到 **安装** 页重新安装 Quicker，再检查版本和数据。

修复不等于已经重新安装，也不等于恢复旧数据。取消或失败时按子页提示处理，不要自行删除 Windows Installer 缓存、注册表安装项或用户数据目录。

## 失败时如何反馈

保留安装器版本、目标 Quicker 版本、Windows 与处理器架构、具体组件或工具名称，以及完整错误提示。修复失败时，按工具显示的路径查找日志或备份记录。

独立安装器的提示与日志，和[Quicker 应用内更新的 MSI 日志](./update.md#2328--安装日志)不是同一个入口，请使用本次操作实际显示的路径。网络或服务不可用时可稍后重试；不要反复执行清理或迁移来解决下载失败。

反馈前请检查日志中的用户名、路径、账号及其他隐私内容，按需脱敏后提交到[Quicker 讨论区](https://getquicker.net/QA)。
