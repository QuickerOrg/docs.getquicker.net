# 高级鼠标触发（V2 变化）

:::info[完整功能说明已合并至功能目录]
高级鼠标触发的规则设置、角落入口与场景继承请查看主文档 **[高级鼠标触发](/v2/features/triggers/advanced-mouse-triggers)**。本页仅保留相对 1.x 的变化与升级核对项。
:::

## 相对 1.x 的主要变化

- **统一场景识别**：触发时与主窗口共用同一套程序与网址场景识别链。
- **管理与引导键选择简化**：支持按场景与触发类型筛选规则列表；直接点击选择键盘引导键；轮盘和手势提供屏幕角落快捷设置入口。

## 从 1.x 升级时需要注意

- 原有规则、顺序、进程范围和触发位置保留；全局规则仍在账号级列表，程序/网址规则进入对应场景。
- 停用本地单条规则不会屏蔽父场景规则；需要完全关闭请使用场景级禁用。
- 与面板、轮盘、手势、扩展热键或左键辅助共用同一按键时，请按实际路径复核冲突（尤其屏幕角落、全屏禁用、多显示器、任务栏与 WPS）。
