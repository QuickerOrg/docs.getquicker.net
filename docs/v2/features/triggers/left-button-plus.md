# 左键辅助

左键辅助是在按住鼠标左键时，再按另一个键或鼠标键来执行操作。适合在拖选文字、框选对象或持续按住左键的过程中快速调用复制、搜索、窗口操作等功能。

全局启用状态、兼容禁用应用列表和动作规则集中显示在 **全局 · 左键辅助**。旧版进程黑名单继续兼容，但新配置建议直接在对应程序或网址场景中禁用。

## 快速开始

1. 打开 **场景与动作管理**，进入 **全局 · 左键辅助**，确认功能已启用。
2. 需要按程序或网址区分动作时，左侧改选对应场景。
3. 添加一条「左键 + 第二按键」规则，分别设置单击操作和（如需）长按操作。
4. 也可以从动作面板把动作拖到已有规则上替换短按或长按，或拖到列表空白处创建新规则。
5. 保存后，在目标程序中按住左键，再短按或长按第二按键试一次。

绘图、拖放、按住空格平移等软件可能大量使用「左键 + 键盘」，建议只启用明确需要的第二按键。

## 短按和长按分别配置

每个「左键 + 第二按键」规则可以分别设置：

- **单击操作**：第二按键短按时执行；
- **长按操作**：第二按键保持一段时间后执行；
- 规则说明和启用状态。

父级规则可以被当前场景完整覆盖。编辑器会明确显示两个操作区域，未设置其中一项时不会影响另一项。

动作以引用方式保存，原动作标题、图标或内容更新后，左键辅助可以继续使用最新内容。列表支持双击编辑、添加按键、删除选择项，并独立显示每条规则的启用状态。

## 按场景覆盖与禁用

普通场景可以覆盖全局或父场景中相同第二按键的规则：

| 操作 | 效果 |
| --- | --- |
| 当前场景没有该按键 | 使用上级规则 |
| 当前场景设置该按键 | 使用本地规则 |
| 当前场景将该按键规则禁用 | 阻止上级同按键规则触发 |
| 删除本地规则 | 恢复上级继承 |

因此，「禁用本地规则」和「恢复继承」是两个不同操作。这和 [动作快捷键](/v2/features/triggers/action-hotkeys) 类似，而和 [按键双击](/v2/features/triggers/key-double-click) 的回退语义不同。

## 目标窗口

会话开始时使用统一的鼠标目标和场景识别结果。对桌面、任务栏、普通资源管理器、UWP、WPS 和浏览器网址，规则选择与其它场景触发功能保持一致。

设置窗口和动作编辑窗口等普通 Quicker 窗口也可以按场景规则触发左键辅助；主面板和明确不参与全局触发的悬浮窗口仍会排除。

删除用户已配置的全局规则后，不会在下一次运行时悄悄恢复同位置的系统预置动作。只有尚未初始化过规则的账号才会使用初始默认值。

## 限制与排障

- **目标软件已经占用「左键 + 某键」**：只启用明确需要的第二按键，或在该程序场景中禁用对应规则。
- **禁用本地规则后上级同键仍触发**：不应发生。若仍触发，确认禁用的是该第二按键的规则，而不是另一条不同按键。
- **想恢复全局动作却没有出现**：删除本地规则才会恢复继承；只停用本地规则会继续屏蔽上级。
- **与扩展热键、高级鼠标或系统快捷键共用按键**：按真实按下顺序测试是否冲突。
- **相对 1.x 的场景化与短按/长按拆分**：见 [左键辅助（2.x 变化）](/v2/what's-new/others/left-button-plus)。
