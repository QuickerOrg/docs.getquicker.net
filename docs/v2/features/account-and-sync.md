# 账号、登录与数据同步

Quicker V2 重做了账号数据目录和同步协议。当前 Preview 阶段还有账号范围限制：官方 V2 页面标注为「仅专业版」，免费账号数据迁移仍在进行，当前不能登录 2.0。

## 先读这些

- [体验前必读](/important-notice)：Preview、专业版、免费账号和回退风险。
- [数据存储与同步变化](/v2/what's-new/data-and-sync)：账号隔离、本地目录、同步项目、迁移和回退边界。
- [从 V1 迁移到 V2](/v2/migration/from-v1)：迁移前同步、备份、卸载 1.x、首次登录和验证清单。

## 日常使用要点

- V2 为每个账号建立独立的数据空间，切换账号不再共用同一份账号业务库。
- 同步以动作、动作页、程序场景设置、文本指令和公共子程序等独立项目为单位，冲突也会尽量定位到更具体的数据项。
- 本机状态、缓存、日志和临时文件不等同于账号业务数据；备份和恢复优先使用 Quicker 提供的同步、导出及恢复入口。
- API Key 等本机凭据可能不会随账号同步，换电脑或回退旧版时可能需要重新填写。

如果你正在从 1.x 迁移，不要把 V2 数据目录覆盖回 1.x。需要回退时，使用迁移前备份或重新安装 1.x。
