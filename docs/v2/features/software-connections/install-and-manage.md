Bridge 是安装在第三方软件中的连接插件。2.2.5 起，普通 Bridge 的安装与管理入口集成到 **Quicker 设置 → 软件连接**。请先查看[对应软件指南](./index.md#支持的软件)，确认你的软件版本、首次加载要求及当前可用状态。

## 打开软件连接设置

1. 打开 Quicker **设置 → 软件连接**。
2. 按名称筛选或滚动找到目标软件卡片。
3. 在卡片详情中核对检测到的宿主版本、安装位置、运行状态与可安装版本。
4. 需要查看特定软件说明时，点击卡片上的文档链接打开对应指南。

设置页的软件卡片负责普通 Bridge 的安装、更新、修复和卸载，也负责查看在线实例与打开命令工具。设置页显示“未连接”时，不等于插件尚未安装，可能只是宿主还没有启动或尚未加载插件。

旧版本文档或界面可能还保留 **Quicker组件安装器** 入口。如果当前版本仍能打开，可作为备选路径；日常说明以设置页软件卡片为主。

:::caution[WPS 是预览特例]
[WPS Office](./software/wps-office.md) 的文字、表格、演示加载项由官方网页管理，不走普通 Bridge 文件安装流程。正式管理页的安装、更新、卸载尚未完成真机闭环，不应将入口存在理解为已经正式可用。
:::

:::note[模兔云不是 Quicker Bridge 安装]
[模兔云](./software/motuyun.md) 使用它在 SketchUp 中提供的本机服务。Quicker 的软件连接页只负责发现连接、打开命令工具和文档链接；插件安装与更新仍在模兔云一侧处理。
:::

## 第一次安装

1. 保存第三方软件中未保存的工作，完全退出该软件；有多个进程时全部退出。
2. 返回 **设置 → 软件连接** 并刷新软件卡片状态。确认软件版本被识别，且有兼容 Bridge。
3. 点击 **安装**，等待下载、校验和安装结束。下载阶段可使用 **取消**；进入安装阶段后等待结果，不强行结束进程。
4. 若系统弹出管理员权限提示，核对正在管理的软件后确认。普通用户目录部署通常不需要提权，SOLIDWORKS、CorelDRAW 等机器级部署需要。
5. 重新启动第三方软件，按其插件信任或扩展批准提示完成首次启用。
6. 到 [Quicker 软件连接与命令工具](./command-tool.md)确认在线实例，运行 `bridge.ping`。

安装完成只表示插件落盘或被宿主插件管理器识别。**出现在线实例并成功调用，才证明当前进程已加载并连接 Bridge。**

## 怎样理解状态

| 看到的状态或信息 | 下一步 |
| --- | --- |
| 尚未检测、检测中 | 等待完成，必要时刷新状态 |
| 未检测到宿主 | 先安装受支持的软件，查看[排障](./troubleshooting.md#没有检测到软件) |
| 未安装 | 核对兼容版本并安装 |
| 已安装 | 启动宿主，在 Quicker 确认连接 |
| 有可更新版本 | 保存工作、退出宿主，再更新 |
| 需要修复 | 退出宿主，使用重新安装恢复受管文件 |
| 宿主正在运行 | 完全退出列出的宿主进程，再刷新 |
| 无兼容版本或检查失败 | 阅读详情；不要手工套用另一年份的软件插件 |

一台电脑的多个宿主年份可能共用部署目标，也可能分别部署。操作前看详情中的目标路径与宿主列表；更新共享目标可能影响多个年份，不能仅关闭当前前台窗口。

## 更新与修复

更新前保存工作并退出宿主，刷新后选择 **更新**。若版本相同但文件损坏、缺失或安装状态异常，使用 **重新安装**；按钮会随当前状态显示版本信息。

完成后重启宿主，通过命令工具核对运行中的 Bridge 版本。文件版本已更新，但未退出的宿主仍可能加载旧代码。

修复面向 Quicker 管理的插件文件。不要以清空整个插件目录的方式排障，以免删除其他扩展或用户文件。

## 卸载

保存工作、退出宿主，打开对应软件详情并选择 **卸载**，按提示确认。卸载后刷新安装状态；再启动宿主时不应出现该 Bridge 的新连接。

卸载移除受管插件，不删除你的模型、工程或设计文件。目录中非本 Bridge 管理的额外文件可能保留；不要因为目录仍存在就断定卸载失败。Adobe 等由厂商工具管理的插件，以软件卡片刷新后的检测结果为准。

## 网络或版本检查失败

设置页需要联网获取可安装版本和下载包。网络不可用时，本机检测仍有意义，但不能把“已安装”理解为已获取最新版本。缓存可用性由软件卡片判断；过期或无法验证的版本信息不能用来开始安装。

检查网络、代理和系统时间后重试。仍失败时记录详情错误、宿主版本和 Quicker 版本，参阅[通用排障](./troubleshooting.md)。不要绕过校验手工安装来源不明的包。
