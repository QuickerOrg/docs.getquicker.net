# 轮盘菜单

轮盘菜单适合把一组常用操作放在鼠标周围，通过方向和距离快速选择。Quicker 2.x 保留了 1.x 的滑动触发、点击触发、按键子动作和传统扩展圈，同时重新整理了轮盘的容量、层级、场景来源和编辑方式。

主要改进如下：

| 方面 | 1.x | 2.x |
| --- | --- | --- |
| 常驻圈层 | 第一圈、第二圈 | 可增加第三个常驻圈，并分别设置圈层容量 |
| 子动作 | 主要通过按键触发，不直接显示 | 可在父项外侧展开可见、可直接选择的子动作 |
| 程序与场景 | 以全局动作和程序覆盖为主 | 可选择合并上级轮盘或使用独立轮盘版式，网址场景也有稳定归属 |
| 来源切换 | 来源模式不够直观 | 可用滚轮切换当前场景、程序和全局来源，中心位置点提示当前来源 |
| 编辑 | 通常先进入设置页再找到对应位置 | 轮盘打开时可用 `Ctrl+Shift` 直接添加、编辑或删除槽位动作 |
| 滑动手感 | 圈层越多，够到外圈所需移动越长 | 可用“指针放大倍率”缩短实际鼠标移动距离 |
| 外观与反馈 | 基础配色和指示线 | 增加跟随主题、扇区光泽、悬浮边框、弹出动效和更清楚的选中反馈 |

## 第三个常驻圈与独立版式

1.x 已有第一圈、第二圈，以及位于常驻圈外侧的 8 个方向扩展位置。2.x 在保留这些位置和原有配置的基础上，增加了真正的第三个常驻圈。

版式可以设置为：

- 第二圈：`0`、`8` 或 `16` 格；
- 第三圈：`0`、`8`、`16` 或 `24` 格。

第三圈与传统扩展圈不是同一个功能：

- **第三圈**是始终参与正常布局和指向选择的常驻圈；
- **扩展圈**仍是常驻圈外侧的 8 个方向位置，继续保留 1.x 的使用方式和数据。

启用“自动隐藏连续为空的外圈”后，轮盘会根据当前来源中实际存在的动作收起最外侧空圈。它只隐藏连续为空的尾部圈，不会改变每圈格子数，也不会把中间的空圈压缩掉。因此，同一个动作的方向和位置不会因为临时空了几个槽位而改变。

在轮盘编辑器中，“查看全部位置”可以临时显示第二圈 16 格和第三圈 24 格，方便检查暂时超出当前版式的动作。它只改变编辑器显示，不会修改版式或删除动作。缩小版式可能影响已有动作时，Quicker 会先统计影响范围并要求确认。

## 可视子动作

2.x 可以给一个轮盘项添加一组“可视子动作”。鼠标指向父项后，子动作会在轮盘外侧展开，继续移动鼠标即可选择，不需要记住额外按键。

可视子动作适合：

- 把“复制、粘贴、剪切”等相关命令收在一个父项下；
- 为同一个动作提供几种常用参数；
- 把应用的常用右键菜单命令转换成更容易指向的入口；
- 在不长期占用主轮盘槽位的情况下扩充一组低频操作。

可以在轮盘项编辑窗口的“可视子动作”标签页中添加、编辑、复制、删除和拖动排序，也可以从父动作的自定义右键菜单导入。每个子动作都可以单独设置标题、图标、说明、延迟时间和临时禁用状态。

可选择三种展开样式：

| 样式 | 特点 |
| --- | --- |
| 扇环式 | 子动作沿轮盘外缘排成一段扇环，适合保持传统轮盘的方向感 |
| 串珠式 | 子动作沿父项方向排成一串圆形按钮，适合直线移动选择 |
| 折扇式 | 子动作在父扇区范围内分层展开，适合项目较多的情况 |

目前只支持一层可视子动作。数量不限制为 8 项，但项目过多时会自动缩小，实际使用时仍建议把一组控制在容易辨认和命中的范围内。

:::note[父项可以只作为分组]

父项可以不设置直接触发动作，只保留可视子动作。此时在父项上释放会取消并关闭轮盘，不会自动执行第一个子动作。

:::

## 更清楚的场景关系与来源切换

2.x 把“当前显示哪些动作”和“使用哪一种轮盘版式”分开处理。普通程序或子场景可以选择：

- **合并并复用上级轮盘**：保留上级动作，在当前场景中覆盖或增加少量专用动作，并沿用上级版式；
- **独立轮盘模式**：使用当前场景自己的动作和圈层容量，不在初始视图中混入上级动作。

这使同一套使用习惯可以逐级细化。例如，全局轮盘放通用操作，浏览器程序轮盘增加浏览器命令，某个网址再使用自己的独立轮盘。网址轮盘的版式不依赖当前使用 Chrome 还是 Edge，切换浏览器后仍保持相同的动作方向。

轮盘打开后，可以使用滚轮在当前场景、宿主程序和全局轮盘等可用来源之间切换。轮盘中心的位置点会显示有多少个可切换来源以及当前所在位置；没有有效动作的来源会自动跳过。

切换来源时，轮盘会使用对应来源的版式重新显示，但保持鼠标的屏幕位置不变。一次轮盘操作开始后，目标程序、场景和动作内容也会保持稳定，不会因为轮盘显示期间前台窗口变化而误用另一个程序的配置。

## 在轮盘中直接添加和编辑

2.x 缩短了从“发现这里需要一个动作”到完成配置的路径。轮盘打开后，保持 `Ctrl+Shift`：

- 指向空槽并提交，可以直接打开创建窗口；
- 指向已有动作并提交，可以编辑当前实际显示的动作；
- 编辑已有动作时，可以使用“删除此位置动作”移除该槽位内容。

“提交”在滑动模式下是松开触发鼠标键，在点击模式下是点击目标槽位。组合键生效时，空槽会显示“＋”，已有动作会显示编辑提示，轮盘中心同时说明将要修改的场景，例如“添加到当前网址”或“编辑全局轮盘”。

新动作会保存到当前正在查看的来源：当前场景、网址、宿主程序或全局轮盘。编辑继承而来的动作时，则会修改该动作真正所属的来源，不会悄悄复制一份到当前场景。

:::tip[避免误进入编辑]

普通方式在空槽上松手仍然只是取消。只有在本次轮盘操作中明确按下 `Ctrl+Shift`，并在提交时继续按住，才会进入槽位管理。

:::

快速编辑适用于当前可见的常驻圈槽位。轮盘中心、圈间空白、传统扩展圈的空位置和可视子动作区域不会通过此方式创建动作。

## 用更短的移动距离够到外圈

第三圈和可视子动作增加了可用空间，也可能让滑动距离变长。2.x 新增“指针放大倍率”，只在按住鼠标键滑动触发时生效。

例如设置为 `2` 倍时，鼠标从轮盘中心实际移动一段距离，Quicker 会按两倍距离计算轮盘上的指向位置。这样可以用更短的手部移动到达外圈，同时保持原来的方向判断。

可在轮盘功能设置中把倍率设为 `1` 到 `4` 倍：

- `1` 倍以及 `1.1` 倍以内视为关闭；
- 倍率越大，够到外圈需要的移动越短；
- 放大后，真实鼠标位置和计算出的指向位置不再重合，轮盘会用小圆点标出当前指向位置；
- 点击方式显示轮盘时不使用指针放大。

建议从较小倍率开始逐步调整。倍率过大虽然移动更短，但也会放大手部的细小偏移。

## 外观与交互反馈

2.x 的轮盘外观会更自然地配合当前主题，并增加了几项可选效果：

- 未单独指定的轮盘颜色可以使用浅色或深色主题默认值；
- 矢量图标颜色可以“跟随全局”；
- “扇区光泽”可以在扇区底色上叠加由主题决定的明暗渐变；
- 可以为当前指向的扇区设置独立的悬浮边框色；
- 轮盘弹出使用淡入和轻微缩放，可视子动作展开使用淡入；不喜欢动效时可以统一关闭；
- 轮盘主体、中心提示和来源位置点使用一致的透明度与显示状态。

扇区光泽和悬浮边框默认不会强制改变已有配色。升级后可以先继续使用原外观，再按需要逐项开启。

## 运行时快速进入设置

通过“按键 + 移动鼠标”或其它高级鼠标规则启动轮盘时，可以在结束会话前把鼠标移动到当前屏幕顶部角落：

- 左上角：打开本次场景的轮盘动作管理；
- 右上角：打开轮盘功能设置。

角落识别范围很小，只在已经开始的轮盘会话结束时判断，不会替代普通的“移动到屏幕角落”高级鼠标规则。

## 与右键扩展热键和手势协作

如果轮盘、鼠标手势、右键长按和右键扩展热键使用同一个鼠标键，2.x 会共同判断这次操作更像按键组合还是鼠标滑动：

- 按住右键再按字母，可以触发右键扩展热键；
- 按住右键并移动鼠标，仍可进入轮盘或手势；
- 长按右键打开面板后，只要右键仍未松开，还可以继续使用右键组合；
- 一旦某个扩展热键已确定触发，同一次按住过程不会再误转成轮盘或手势。

这项协调减少了 1.x 中多个右键功能争抢同一次输入的情况。具体的扩展热键判定方式可参阅[扩展热键](./powerkeys.md)。

## 从 1.x 升级时需要注意

- 原有轮盘动作、程序覆盖、按键子动作和传统扩展圈会继续保留；
- 第三个常驻圈与可视子动作是新增能力，需要当前有效的专业版授权，不提供传统扩展圈的 90 天试用；
- 第二圈使用第 9～16 格同样需要当前有效的专业版授权；
- 当前设备暂时不能使用某个圈层时，配置和动作仍会保留；以后在具备能力的设备上会重新显示；
- “自动隐藏连续为空的外圈”只影响显示，不删除槽位数据；
- “指针放大倍率”默认是 `1`，升级后不会自动改变原来的滑动距离；
- 缩小圈层容量前请留意影响提示；暂时越界的动作可以通过“查看全部位置”检查和调整。

建议升级后依次检查：

1. 全局轮盘与常用程序轮盘的合并关系；
2. 第二圈、第三圈的格子数以及是否需要自动隐藏空外圈；
3. 同时使用右键轮盘、手势、长按和扩展热键的规则；
4. 屏幕边缘、多显示器或高 DPI 下的滑动距离，按需要调整指针放大倍率；
5. 新增可视子动作后，三种展开样式中哪一种更符合自己的移动习惯。
