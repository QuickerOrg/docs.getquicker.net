组合动作中的“运行 C# 脚本”步骤和新版脚本动作使用不同宿主。旧脚本不是复制到新编辑器就一定能执行，也无需为了使用 V2 而把所有已有脚本重写。

## 建议迁移顺序

1. 复制旧动作，保留可运行的版本。
2. 先迁移纯计算部分，整理为 Main 输入和 return 输出。
3. 对照[语言限制](./language.md)，去掉类声明、异步线程和不支持的类型。
4. 把文件、网络、进程、窗口和界面操作改成对应 qk API。
5. 加上空值、用户取消和错误处理，在测试数据上验证。
6. 如仍依赖某个组合动作模块，把它封装为公共子程序，再从脚本调用；或保留原组合动作。

旧脚本中的宿主变量、context 对象、程序集引用和 .NET 库不能原样沿用。Main 参数、qk.Context 与 qk.State 分别承担输入、运行上下文和跨运行存储。

文件写入默认不覆盖、进程启动的权限行为、网络超时和对话框取消，都需要重新核对。API 方法名相似不代表默认值和失败处理相同。

完整调用例子见[动作互调](./tutorials/action-call.md)，基础 API 对照见[语言与脚本结构](./language.md)。
