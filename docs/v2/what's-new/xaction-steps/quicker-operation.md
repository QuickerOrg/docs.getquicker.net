# Quicker操作模块

2.x 的“Quicker操作”继续集中提供显示面板、搜索框、轮盘、暂停和停止动作等程序内功能，并增加“显示选中文本工具条”操作。

动作可以主动让新版选中文本工具条针对当前选区显示候选操作，用它替代 1.x 的文本悬浮窗流程。工具条会按当前场景和规则提供动作，不需要在组合动作中自行重建菜单。

原有操作 Key 保持兼容；旧版已经移除或更换界面的功能会转到 2.x 对应入口。

参数说明见[Quicker操作](/v2/xaction/modules/quickeroperations)。
