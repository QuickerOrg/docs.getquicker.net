# 贴图

在屏幕指定位置浮动贴图（与截图 Pro 贴图窗口一致）。按来源自动识别图片、HTML、公式、OCR 原始结果或文本。

## 当前模块定义

下方参数与 **2.3.7 发布快照**中的纯文本、主题选项一致；版本是否开放下载以[官网版本记录](https://getquicker.net/V2/Versions)为准。使用 2.3.6 时，请按下方旧版参数说明操作。

## 使用说明

选择内容来源并填入对应内容，再设置屏幕位置。处理从剪贴板复制的图片或网页内容时可选「剪贴板（自动）」；只想显示文字时选择「纯文本」，避免把文字误识别为 HTML 或公式。

从图片变量贴回截图原位置时，选择「自定义坐标」，并将截图步骤输出的区域坐标传入位置参数。「截图原位置」读取的是剪贴板携带的位置数据，不会从图片变量取得位置；没有位置数据时会落到当前光标。

2.1.27 起，HTML、公式或剪贴板贴图窗口已经显示后，不再因后续未生成位图提示而误弹“未产生位图”。

2.1.28 起，贴图右键菜单「图像处理」可用 **抠出主体（透明背景）**；2.1.29 起可手动选择 **通用抠图** 或 **人像抠图**，在本机完成抠图后继续保存或贴图。首次使用需要已登录 Quicker，并下载约 4.4 MB 的独立本地模型；它和 OCR 文字模型分开管理，不会重复下载已有 OCR 模型。

2.2.17 起，贴图支持**鼠标穿透**，并可通过独立工具条调节不透明度、恢复操作或关闭贴图。交互细节见 [截图 Pro · 贴图窗口](/v2/features/screenshot/capture-pro#贴图窗口截图后)。

2.2.19 起，步骤成功创建贴图后会输出 **窗口句柄**。可将它传给[窗口操作](/v2/xaction/modules/windowoperations)等后续步骤，精确操作本次新建的贴图，不必依赖窗口标题。贴图关闭后句柄失效，不要持久化后在下次运行中复用。

2.2.23 起，贴图的系统窗口标题固定为 `QuickerPin`。按 `F2` 或右键选择「设置标题…」编辑的是**图片下方的显示标题**：`Enter` 保存，`Esc` 取消，清空后保存可移除显示标题。设置显示标题不会改变系统窗口标题；已有按图片标题查找窗口的动作，应改用本步骤输出的窗口句柄。

2.2.20 起，贴图窗口可按 `Y` 切换窗口阴影，右键菜单也把常用窗口状态操作提升到一级菜单；文字编辑时不会拦截 `Y`，`Ctrl+Y` 仍用于重做。详情见 [截图 Pro · 贴图窗口](/v2/features/screenshot/capture-pro#贴图窗口截图后)。

## 2.3.5 · 文字与 HTML 贴图

以下参数说明适用于 **2.3.5–2.3.6**；2.3.7 的主题与参数变化见[下方说明](#237--纯文本与主题)。

文字贴图的生成速度已改善。从网页复制 HTML 后，贴图会优先保留内容自身的字体、字号、文字颜色和背景样式，改善深色网页内容的配色。

- 「纯文本字体名称」「字号」「纯文本文字颜色」用于纯文本，自动识别为 OCR 内容时沿用相应设置；HTML 使用内容自身样式。
- 「文本/公式背景颜色」用于纯文本、公式及自动识别的 OCR 内容，不影响自动识别的 HTML。
- 「HTML/公式默认背景」用于无背景 HTML 的画布；默认白色会匹配文字明暗，也可设置自定义颜色或带透明通道的颜色。内容自身的背景优先。旧显式 HTML 动作未设置此项或保持默认白色时，仍兼容已保存的背景颜色。

## 2.3.7 · 纯文本与主题

以下说明依据 **2.3.7 发布快照**。

- **内容来源 → 纯文本**：把「文本」中的文字原样贴出，即使包含 HTML 标签或公式符号，也不自动识别为 HTML、LaTeX 或 OCR。需要控制文字字体和字号时，选择此模式并设置「纯文本字体名称」「纯文本字号」。
- **变量（自动） / 剪贴板（自动）**：继续按内容自动识别，主要提供统一主题与宽度设置；它们不再使用旧的纯文本字体、字号或 OCR 字体来覆盖识别结果。需要特定字体时，改用对应的显式来源模式。
- **主题**：默认「自动」，HTML 保留来源主题，文本、公式和 OCR 跟随 Quicker 主题；也可以选择「浅色」或「深色」。HTML 的主题调整会尽量处理背景、文字和行内样式，但复杂网页内容仍需检查实际结果。

旧的「纯文本文字颜色」「文本/公式背景颜色」「HTML/公式默认背景」「OCR 文字颜色」「OCR 画布背景」不再作为当前参数，也不再读取或求值。旧动作里保存的颜色仍可能存在，但新代码不会用它们恢复原配色，依赖这些颜色或颜色表达式的动作应改为主题选项并重新试运行。

旧显式「文本」模式仍兼容自动识别公式；「纯文本」用于明确避免识别。回退 2.3.6 时，主题选项不会生效，旧版会继续使用原有颜色参数；详情见[升级与回退](/v2/migration/upgrade-and-rollback#237--贴图主题与-ai-保存)。

:::caution[HTML 仅静态离线渲染]
无论直接输入 HTML，还是从变量、文本或剪贴板自动识别，贴图均不执行来源脚本、不加载网络资源。保留内联样式，公式使用本地 KaTeX。依赖在线图片、外部样式或脚本的内容，需先转换为静态内容；图片无法加载时会显示回退提示，不能当作已完整渲染。
:::
