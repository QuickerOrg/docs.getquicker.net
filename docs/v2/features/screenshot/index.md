# 截图与贴图概览

Quicker 提供一套完整的屏幕截取与后续处理能力，可在动作中作为步骤使用，也可配合快捷键随时唤起。

| 功能 | 说明 |
| --- | --- |
| [截图 Pro](./capture-pro.md) | 全屏选区、控件吸附、标注、复制 / 保存 / 贴图，并可进入长截图或录屏 |
| 贴图 | 将图片浮在屏幕上，支持缩放、透明度、缩略图、图像处理与标注 |
| 长截图 | 在选区内滚动或移动选区，自动拼接成长图 |
| 录屏 | 选定区域后录制为视频或 GIF |

组合动作中的相关步骤包括：`截图 Pro`、`长截图`、`贴图`、`录屏` 等。动作链中已能完成的后处理（例如单独的 OCR、图片处理），不必全部塞进截图界面。

建议先阅读 [截图 Pro](./capture-pro.md)，了解选区、标注与常用结束方式。
