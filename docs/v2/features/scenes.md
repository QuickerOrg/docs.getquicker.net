# 场景与分组

V2 用“场景”统一组织面板、动作分组和触发规则。它不再等同于 1.x 的某张动作页；同一个动作可以出现在多个场景或触发入口中。

## 推荐阅读顺序

1. [新面板窗口的使用](/v2/what's-new/new-main-win/usage)：认识全局区、上下文区、场景标签、分组、暂存区和动作整理方式。
2. [场景与触发方式](/v2/what's-new/scenes-and-triggers)：了解程序场景、网址场景、自定义场景，以及触发规则如何继承和禁用。
3. [快速触发概览](/v2/features/triggers)：按鼠标、键盘、划词等使用习惯选择合适入口。

## 操作要点

- 场景决定当前上下文下显示哪些动作和启用哪些触发规则。
- 分组只负责整理一个场景内的动作列表；删除分组不等同于删除动作本体。
- 从场景移除动作只删除当前位置；删除动作本体会影响其它场景、旧动作页和触发规则中的引用。
- 需要跨场景整理时，优先使用新版主窗口的“场景与动作管理”。

如果只是想把 1.x 的动作页迁到新面板，先按 [从 V1 迁移](/v2/migration/from-v1) 完成备份和首次验证，再逐步整理场景与分组。
