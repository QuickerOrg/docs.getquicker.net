本页说明桌面 **AI 工作台**、**问问 AI**、**动作设计器/窗口助手** 的日常用法、保存与审批机制及当前功能边界。

- 管理提示词模板、会话历史、独立工作目录和界面操作，见[AI 提示词库、会话历史与工作区](/v2/features/ai/prompt-library-and-sessions)。
- 配置外部助手（Cursor / Claude 等）与 MCP 权限，见[连接外部助手与 MCP](/v2/features/ai/mcp-and-external-agents)。
- 配置 API 服务与模型分配，见[统一 AI 服务与模型设置](/v2/what's-new/ai-services-and-models)；管理长期偏好，见[AI 指令与记忆](./memory.md)。

## 入口与整体能力

- **桌面 AI 工作台**：2.3.10 起直接开放（旧网页版与手机 AI 已退役），可从托盘、面板菜单的 **AI 工作台**、侧栏快捷按钮或功能快捷键打开；暂存区的 **用 AI 写** 同样使用桌面工作台。
- **问问 AI**：可从搜索框输入 `??` / `？？`、选中文本工具条、图片与文件右键菜单或动作中的 **问问AI** 步骤打开独立提问窗口，关闭后可在工作台继续同一对话。
- **窗口内嵌助手**：在组合动作／C# 脚本／公共子程序设计器，以及「设置」「场景、动作与触发管理」窗口标题栏点击 **AI** 或按 `Ctrl+J` 打开。
- **组合动作 AI 模块**：共用 **设置 → AI → AI 服务 / 模型分配** 中的全局连接配置，包括 [AI 文本处理](/v2/xaction/modules/ai-text)、[AI 图片理解](/v2/xaction/modules/ai-vision)、[AI 文本分类](/v2/xaction/modules/ai-classify)、[AI 结构化提取](/v2/xaction/modules/ai-extract)、[AI 交互对话](/v2/xaction/modules/ai-chat) 与 [问问AI](/v2/xaction/modules/askai)。

### 长期指令与记忆 {/* #memory-2327 */}

可在 **设置 → AI → AI 指令与记忆** 中管理长期偏好与背景。共享部分随云账号同步，本机部分仅保存在当前设备；支持手动编辑、记忆操作撤销、AI 整理与导入导出。默认启用，隐私、暂停使用及换机方法见专页[AI 指令与记忆](./memory.md)。

助手处理动作时，只在你要求打开编辑器时才主动打开，避免编辑窗口打断当前任务。模型请求可分别设置首次响应和响应间隔超时，持续输出的流式回复不再受固定总时长限制，见[响应超时](/v2/what's-new/ai-services-and-models#response-timeout-2327)。

首次使用前需在「配置 API」添加服务商、模型与 API Key。API Key 默认仅在本机加密保存，不随动作分享或普通设置同步；2.3.1 起可按需开启[设备间凭据同步](/v2/what's-new/ai-services-and-models#在设备间同步-api-密钥)（默认关闭）。

## 问问 AI 与从动作打开问问 AI {/* #2317--问问-ai-入口与文件操作 */}

### 从搜索、选区与菜单提问

在搜索框输入 `??` 或 `？？` 开始提问：按 `Enter` 会尝试附上当前选中文字，按 `Ctrl+Enter` 则只发送问题；选区获取失败时保留草稿并提示手动发送。也可使用功能快捷键，或从选中文本工具条（需在场景中自行添加）、图片和文件右键菜单打开。

问问 AI 使用独立小窗；关闭后同一会话保留在 AI 工作台，点小窗中的「工作台」可立即切换。选中文字成为“选中内容”附件；图片菜单附上当前图片；文件菜单只附上**路径清单**，不会因打开窗口就自动读取或上传文件内容，发送前请核对附件。

### 从动作打开问问 AI {/* #ask-ai-2345 */}

2.3.45 起，组合动作可通过 **问问AI** 步骤预填问题并附带图片、文件、文本或窗口背景交给问问 AI 窗口（脚本动作可使用 [qk.Ai.OpenAssistant](/v2/script-action/api/ai#aiopenassistant)）。

- 默认由用户检查后发送；选择 **自动发送** 会直接交付配置的模型，不再另行确认，可能产生服务费用。后续工具调用仍遵循助手审批设置。
- 该步骤只负责打开窗口和交付材料，**不等待回答，也不返回回答正文**。需要在动作中取得回答，请改用[AI 文本处理](/v2/xaction/modules/ai-text)或[AI 交互对话](/v2/xaction/modules/ai-chat)；材料大小、重试与结果说明见[问问AI模块](/v2/xaction/modules/askai)。

### 窗口背景关联方式 {/* #window-context-2330 */}

从其他程序唤起 **AI 工作台** 或 **问问 AI** 时，输入区标签会显示来源窗口，默认先显示虚线备选标签「点击添加背景窗口信息」，**点击确认后才读取窗口背景**。可在窗口标签菜单或工作台侧栏的 **窗口背景** 中切换模式：

| 模式 | 行为 |
| --- | --- |
| 不关联窗口 | 不自动附带来源窗口背景；仍可手动选择需要的窗口 |
| 点击后关联（默认） | 先显示备选窗口，点击确认后读取背景 |
| 自动关联窗口 | 自动读取来源窗口背景并在发送时提供给 AI |

此偏好仅保存在当前账号的本机，不随账号同步；回退到 2.3.29 会清除新版模式偏好并恢复旧版自动关联，兼容详情见[升级与回退](/v2/migration/upgrade-and-rollback#window-context-2330)与[2.3.19 偏好说明](/v2/migration/upgrade-and-rollback#preferences-and-ai-2319)。

#### 窗口背景内容与欢迎示例 {/* #window-context-2319 */}

背景信息按目标程序支持情况读取窗口标题、程序名、当前文件夹、选中文件路径、网页地址、活动文档与选中文字（自绘界面或高权限程序可能不完整），核对时注意：

- **切换目标或取消**：可在目标窗口菜单重新读取或取消；从外部窗口再次唤起会更新来源并保留已输入草稿，旧窗口迟到结果不会覆盖当前草稿。
- **选中文件路径**：仅附带路径清单不等于已读取文件正文，后续读取文件仍受权限与审批约束。
- **欢迎示例**：工作台欢迎页结合已有动作和剪贴板内容提供按能力分组的示例，选中后请检查填入的问题和附件再发送。

## 用 AI 编写、修改和保存动作 {/* #用-ai-编写和修改动作 */}

### 新建动作与覆盖范围 {/* #239--编写搜索与管理动作 */}

在暂存区点击 **用 AI 写** 或在工作台直接描述需求，AI 工作台（与 MCP）支持生成和编辑**组合动作**、**Quicker 脚本动作**及常用基础动作（打开网址/文件、运行程序、等待、发送文本与按键等）。

- 新建动作先保存在本机[暂存区](/v2/features/action-panel/action-drafts)，试运行和检查后再 **保留到场景**。
- 可让助手按最近编辑、最近使用或最近安装搜索动作，或查询引用与恢复历史版本。注意引用查询不能穷尽其他动作正文或动态脚本里的调用，空结果不代表没有依赖；历史恢复只恢复动作定义，不会撤回已执行的外部操作。
- 工作台动作卡片提供 **运行、最小化后运行、编辑** 等入口，运行的是**最近保存版本**，不会自动保存编辑器未提交改动。试跑会真实操作文件或窗口，停止不代表回滚外部副作用。

### 修改与保存已有正式动作 {/* #237--保存已有动作 */}

#### 动作保存与对话入口 {/* #动作保存与对话入口 */}

在独立 AI 对话中通过 `@` 搜索并引用已有正式动作即可说明修改要求（2.3.7 起不再为无旧暂存副本的动作额外建同名草稿，同一项目聊天共用该动作工作内容；2.3.6 及更早版本流程为先建暂存编辑副本再写回原动作）。

- **保存与权限**：「保存」按当前审批权限直接校验并提交到原动作；开启 **完全控制** 时可直接提交，其它审批方式仍需弹窗确认。**仅保存到暂存区** 不代表已应用到原动作，保存也不等于已运行验证。
- **冲突保护**：2.3.34 起保存遇到目标版本冲突时，会单独确认是否覆盖最新动作（**完全控制模式也需要确认**）；打开动作遇到旧编辑冲突时会先备份再加载最新版本，详见[编辑副本恢复](/v2/features/action-panel/action-drafts#234--外部助手恢复编辑副本)。
- **旧暂存写回**：如仍有历史留存的暂存编辑副本，写回时会尝试合并不冲突修改，有冲突则保留两份内容并可让 AI 协助合并（见[暂存副本冲突处理](/v2/features/action-panel/action-drafts#原动作已变化时处理冲突)）。
- **步骤引用与撤销**：在右侧设计器中可将步骤拖到对话或「加入对话」引用（仅提供定位上下文，不会运行步骤）；独立对话的聚合变更卡片支持点击 **撤销** 回退该轮第一次保存之前的动作内容（仅回退动作定义，不删除新建动作或撤回外部副作用，亦与设计器「撤销本轮」相互独立）。

### 在动作设计器内修改与调试 {/* #在设计器内修改 */}

#### 在线图库与编辑器助手调试 {/* #icons-and-editing-2325 */}

在组合动作或脚本编辑窗口点击标题栏 **AI** 按钮（或按 `Ctrl+J`）打开内嵌助手，修改的是**当前编辑窗口内容**（尚未与独立 AI 工作台实时共享内存草稿），可通过改动标记检查并由你亲自点击编辑器保存：

- **运行并分析**：可让设计器助手查看最近结构化运行记录、定位失败步骤并分析报错。
- **配置与图标**：设计器助手还可修改右键菜单、运行选项与关联配置（见[设计器内的 AI 助手](/v2/xaction/concepts/xaction-editor#designer-configuration-2325)）；在线账号可搜索并导入在线图库图标（本地离线账号不开放），图标导入成功不等于已保存应用到动作。
- **保存冲突**：助手写回与编辑器手工修改冲突时可选择 **覆盖** 或 **放弃**，覆盖前先备份需要保留的修改。

### 查看执行详情、图标与用量统计 {/* #icons-and-tool-details-2320 */}

#### 工具结果与草稿确认 {/* #tool-results-2323 */}

- **结果反馈**：助手执行检查、保存和设置跳转时会给出明确状态（如“静态检查通过”“已保存 · 完整检查未完成”“等待点击链接”），保存成功不等于通过完整校验。在普通工作台仅修改草稿标题、说明与图标时不再额外弹窗询问。
- **导入图标**：在「场景、动作与触发管理」或工作台可从本机 PNG、JPEG、SVG 导入或生成图标；在线账号会上传至图标服务，离线导入仅本机可用，SVG 兼容约束见[升级与回退](/v2/migration/upgrade-and-rollback#capture-sync-and-icons-2320)。
- **工具调用详情**：按 **结果、输入、调用记录** 分组支持搜索与复制；看到命令输出不等于执行完成或修改已保存。

#### 来源动作与用量统计 {/* #source-and-usage-2322 */}

- **来源动作权限边界**：AI 助手可按当前权限读取和编辑来源组合动作。先打开或引用目标动作，再说明要改什么；**作者只读、权限撤销或来源发生变化时，不能用强制保存绕过检查**。保存前核对候选内容，保存不等于已运行验证。
- **用量统计**：包含 **对话、动作、诊断** 等来源（纳入动作内 AI 调用与模型测试）。供应商未返回用量时记为“未知”，不代表免费，实际以服务商账单为准。

### 对话中的输入草稿、保存撤销与分享协助 {/* #对话中的保存撤销与输入草稿 */}

- 未发送的文本与会话引用草稿保存在本机；新对话在输入区附近可显示至多六个 **最近修改** 动作（含暂存项）便于快速引用。
- 2.2.23 起可让助手为正式动作准备分享说明、图标和更新摘要并打开分享窗口供核对提交，步骤见[分享动作与公共子程序](/v2/features/action-sharing#让-ai-协助分享动作)。

## 一次性桌面任务、设置与场景窗口助手 {/* #desktop-tasks-2318 */}

### 让工作台直接帮忙做事

除编写动作外，在工作台可直接描述一次性任务（如查找并打开本机文件、启动已安装程序、操作当前目标窗口）。执行一次性任务**不会自动创建一个新动作**；文件、程序和窗口操作会真实影响本机环境，切换或关闭目标窗口后请及时在输入区重选目标。

### 设置与场景窗口中的 AI 助手 {/* #设置与场景窗口中的-ai-助手 */}

在 **设置** 或 **场景、动作与触发管理** 窗口点击标题栏 AI 按钮（或按 `Ctrl+J`），可用自然语言查找设置、调整支持的设置项或为已有动作配置触发规则：

#### 统一设置入口与助手范围 {/* #236--统一设置入口与助手范围 */}

- **可改范围与限制**：支持桌面已开放的设置项，暂不支持或只读项目需点击回复卡片中的链接手动操作；手势绘制、轮盘布局及动作程序编写仍需到对应编辑器完成。

#### 批量修改设置与触发规则 {/* #234--批量修改设置与触发规则 */}

- **批量修改与部分失败**：批准前若配置已被外部或同步修改，整批提交会拒绝写入；提交途中某项失败会停止后续项，**已保存的前序修改不会自动回滚**，需逐项核对结果。
- **密码与密钥类设置隐私提醒**：已支持的密码或密钥类设置会向助手提供实际值，批准卡和回执也可能显示这些值；修改此类项目后，**分享对话前请检查内容**。

#### 窗口助手附件与历史 {/* #232--窗口助手 */}

- **设置窗口助手附件与历史**：同样支持添加附件和截图，且与独立工作区会话、动作设计器历史分开按窗口类型保存在本机（载入历史仅恢复上下文，**不会回退动作源码或设置内容**）。

## 模型选择、附件与问答交互 {/* #模型附件与提问 */}

### 为对话选择模型与思考档位

在输入区模型菜单选择模型及其思考档位，切换从下一轮请求生效，并按会话独立保存；更多新旧会话模型继承与压缩规则见[会话模型与恢复](/v2/features/ai/prompt-library-and-sessions#234--会话模型与恢复)。

### 添加附件、截图与选窗口 {/* #给设计器助手添加附件 */}

工作台、问问 AI、组合动作/脚本设计器及设置/场景助手均支持选择文件、粘贴图片/文本、拖放文件或从附件菜单 **截图 / 选择窗口**：

- **容量限制**：2.3.45 起，每轮最多添加 **20 个内容附件**（此前为 8 个），单个文件最大 **8 MiB**，每轮图片总量最多 **20 MiB**。不支持的文件类型会转为路径文本，不能认为助手已读入文件正文。
- **截图与选窗口**：选窗口会短暂隐藏助手窗口并采集窗口信息文本和截图两个附件（按 `Esc` 取消）；窗口含隐私时可在发送前先删截图只留文本。
- **图片理解**：直接看图需选用支持视觉输入的模型；本地 OCR 文字只补充文本，不能代替图像理解。

### 回答助手提问与提交反馈 {/* #回答助手的问题 */}

- **澄清提问作答**：助手需澄清时输入框上方会出现作答区。2.3.3 起，单选题点击选项立即前进并在末题提交全部答案；多选题可先勾选再确认；自由输入按 `Enter` 确认、`Shift+Enter` 换行（输入法确认候选词不提交）。提交前可使用上一题检查修改。
- **反馈未完成任务**：窗口助手回合结束后可通过「反馈给我们」提交脱敏摘要与信号（需要登录 Quicker 账号，离线可导出反馈包），**提交会上传到 Quicker 服务器**，请先核查是否包含隐私信息。

## 权限审批、完全控制与功能边界 {/* #235--完全控制与工具恢复 */}

- **审批模式**：包括「请求批准」「替我审批」「完全控制」。在「完全控制」下，助手可直接执行已启用的普通工具（包括运行动作、写回修改、删除文件、执行命令及桌面操作），不再逐次弹窗；但 **2.3.34 起保存时的动作版本冲突覆盖、以及 2.3.28 起的外部 MCP 首次接入同意，均仍需单独确认，不可由完全控制代替**。
- **普通文件删除与覆盖**：内置助手删除文件会移入回收站，覆盖前会备份原文件；在「请求批准」和「替我审批」下需逐次确认，确认前请核对路径。
- **命令「批准同类」**：仅在本次命令支持归纳范围时显示；多行脚本等仍逐次确认，批准前会标明行数。

### 当前功能边界

- Agent 与 MCP 入口已开放，但部分开发中能力（如“选网页元素”或特定后台操控）仍受当前软件界面实际支持范围限制。
- 1.x 的手机 App 遥控与 Android 局域网遥控在 V2 中已移除，暂无替代方案，见[不再支持的功能](/v2/what's-new/not-supported.md)。
- 2.3.4 起普通设置已隐藏 Computer Use 开关，不能仅凭打开「完全控制」就认定桌面操作或外部磁盘权限已全部开放。
