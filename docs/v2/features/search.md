# 搜索功能与设置定位

Quicker 搜索可以按插件提供动作、设置和其它类型的结果。搜索框与新版面板内的筛选入口并非同一个界面；调整插件设置时，请确认正在使用哪个入口。

## 查找与运行

打开搜索框后输入名称，检查结果的标题、说明和类型，再选择需要的项目。动作结果用于运行相应动作；设置结果用于打开对应页面。搜索插件是否启用、触发词和全局搜索选项会影响结果来源。

## 搜索设置项

可以直接搜索功能名称或页面关键词。设置结果的右键菜单提供“复制URI”“复制为动作”和“打开帮助文档网页”。帮助链接与设置页按钮使用同一功能文档。

需要定位页面内某个选项时，也可在设置窗口搜索。按路径组合搜索词的方法见[搜索并定位设置](./tools.md#搜索并定位设置)。

## 配置搜索

打开 **设置 → 面板、搜索与悬浮 → 搜索**：

- 在“搜索插件”中调整开关、触发词和全局搜索等选项；各插件的配置不同。
- 在“动作直达词”中管理直接运行指定动作的入口，核对目标动作是否仍存在。
- 在“默认处理”和“基础设置”中选择无结果时的处理及搜索框行为。
- “重置搜索框位置”会清除记忆的位置和宽度，下次打开回到默认位置。
- “还原默认设置”会还原搜索插件配置，使用前先确认是否需要保留自定义内容。

## 排障

找不到结果时，先检查插件开关、触发词、全局搜索选项和目标动作是否仍存在。找到设置但看不到预期内容时，检查是否已被合并到新的页面。新版面板场景与动作整理见[动作面板](./action-panel/)。
