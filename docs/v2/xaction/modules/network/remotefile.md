# 远程文件

通过本机保存的 WebDAV 或 S3 账号，在组合动作中上传、下载、列出、查询、复制、移动或删除远程文件，也可批量读取内容和传输文件夹。

## 路径与批处理结果

以下用法说明核对了 **2026-10-07 的开发代码与导出定义**，用于澄清已有操作的参数含义，不代表新增了一种远程存储操作。

远程路径从所选账号的根目录计算，**填写路径，不填写完整网址**。例如账号根目录下的 `资料/示例.txt` 填写为 `/资料/示例.txt`，根目录填写 `/`。

- 单文件上传需要写出目标文件名。上传 `C:\资料\示例.txt` 到 `/备份/示例.txt`，不能只填写 `/备份/` 并期待自动补上原文件名。复制、移动的目标路径也需要包含文件名。
- 文件夹传输会保留源目录内部层级，不再额外套一层源文件夹名称。先在小目录中验证路径和同名文件策略，再扩大范围。
- 使用图片内容上传时，让远程文件扩展名与所选图片格式一致，例如 PNG 使用 `.png`，JPEG 使用 `.jpg` 或 `.jpeg`。

批处理后先检查整体状态和汇总，再处理逐项结果。**跳过** 不等于失败；**结果未知** 需要先查远端状态；**未执行** 表示该项没有继续处理。超出批量内容读取的总大小上限会停止，不会因为勾选“失败后继续”而忽略总量限制。

目录列表返回的是账号根目录下的远程路径；批量下载和文件夹下载返回的成功路径是本机路径，不要混用。列表中类型未知的条目不能仅凭 `isDirectory` 为 `false` 就判定为文件，还需检查 `typeKnown`。字段名称、大小上限和各操作的具体输出以[当前模块定义](#当前模块定义)为准。

:::caution

删除、覆盖和移动会直接改变远端数据。先在测试目录验证账号、路径、权限和同名文件策略；返回“结果未知”时先查询远端状态，不要立即重试。

:::
