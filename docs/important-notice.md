# 安装前准备

第一次体验 Quicker V2，先确认账号和安装环境，再选择下方的安装或迁移步骤。

## 适用范围

V2 当前是 **Preview 体验版，仅面向专业版用户**。功能仍在快速迭代，已有动作也可能需要调整，适合尝鲜和反馈。

免费版数据迁移仍在开发，**免费账号目前无法登录 2.0**。

## 安装与迁移

- **保留可回退的环境。** 如果 1.x 承担着不能中断的日常工作，建议另找一台电脑体验 V2。
- **先备份，再安装。** 1.x 与 V2 不能同时安装，浏览器扩展会冲突。迁移前先同步并备份，再卸载 1.x、安装 V2。
- **确认数据独立。** 首次登录会迁移一份 1.x 数据，之后两代数据各自独立，不是双向同步。回到 1.x 时，不要用 V2 数据目录覆盖旧版。

已经在使用 V2，准备降级或混用不同版本？请看 [升级与回退](/v2/migration/upgrade-and-rollback)，按功能查找兼容注意项。
