# 截图与贴图概览

Quicker 提供一套完整的屏幕截取与后续处理能力，可在动作中作为步骤使用，也可配合快捷键随时唤起。

| 功能 | 说明 |
| --- | --- |
| [截图 Pro](./capture-pro.md) | 全屏选区、控件吸附、标注、OCR、复制 / 保存 / 贴图，并可进入长截图或录屏 |
| [图片翻译](./image-translate.md) | 截图 / 贴图图到图翻译；配置百度或有道图片翻译 API（本机 Key） |
| [JS 自定义工具栏](./toolbar-script.md) | 用脚本定制标注工具栏布局，并增加调用子程序或启动动作的按钮 |
| 贴图 | 将图片浮在屏幕上，支持自动 OCR 选字、缩放、透明度、缩略图、图像处理与标注 |
| 长截图 | 在选区内滚动或移动选区，自动拼接成长图 |
| 录屏 | 选定区域后录制为视频或 GIF |
| 采集历史 | 截图历史、已关闭贴图与录屏成品可在采集历史中心统一查看与管理 |

组合动作中的相关步骤包括：`截图 Pro`、`长截图`、`贴图`、`录屏`、`基础 OCR` 等。截图界面内已集成 OCR、[图片翻译](./image-translate.md)、智能马赛克等常用后处理；更复杂的自动化仍可在动作链中用独立步骤完成，也可通过 [JS 自定义工具栏](./toolbar-script.md) 在截图界面内直接调用。

建议先阅读 [截图 Pro](./capture-pro.md)，了解选区、标注与常用结束方式。
