# 热键联动

热键联动用于监听一个快捷键，或依次按下的两段快捷键，再执行指定操作。例如先按 `Ctrl+K`，再按 `C` 执行一个动作。

和 [动作快捷键](/v2/features/triggers/action-hotkeys) 不同：热键联动按「第一段 + 可选第二段」监听按键序列，并保留延迟时间和设备限制。

## 快速开始

1. 打开 **场景与动作管理 → 键盘触发 → 热键联动**。
2. 左侧选择要设置的场景：全局、程序、标题子场景或网址。
3. 新增一条规则：填写第一段快捷键，如需两段序列再填写可选第二段，并选择要执行的操作。
4. 按需要设置说明、延迟和限定主机。
5. 保存后，在目标程序中按第一段（以及第二段）试一次。

普通程序按「当前程序 → 全局」查找；浏览器和网址还会经过浏览器通用场景。这样可以在不同应用中复用同一段前缀键，而不必把所有规则堆在一个带进程过滤条件的全局列表中。

原有全局规则仍保留进程白名单、黑名单、限定主机和延迟时间。普通场景由场景本身限定范围，编辑时不再要求重复填写进程名。

## 按场景覆盖与禁用

热键联动使用「第一段快捷键 + 可选第二段快捷键」作为规则键。

| 操作 | 效果 |
| --- | --- |
| 当前场景没有同序列规则 | 继续使用上级规则 |
| 当前场景存在同序列规则 | 使用当前场景规则 |
| 当前场景的同序列规则被停用 | 不再回退上级同序列 |
| 删除本地同序列规则 | 恢复继承 |

这和 [动作快捷键](/v2/features/triggers/action-hotkeys) 相同：停用本地同序列会屏蔽上级，不会继续尝试继承规则。要恢复继承，应删除本地同序列规则。

管理页默认只显示本地规则。勾选「显示继承的规则」后，可以看到按键序列、来源、操作类型、摘要和状态，并把继承规则复制到本场景再编辑。

## 两段输入中途切窗口

两段热键属于短暂键盘输入。开始输入时的物理进程不会被长期固定为整个序列的唯一依据，也不会因为窗口、标题或网址变化就机械取消已经按下的第一段。

后续按键会读取当时的当前场景和规则。这使需要切换窗口后完成第二段的操作更自然，同时避免继续使用已经过期的规则对象。

## 管理界面

列表支持：

- 新增、编辑、启停和删除；
- `Ctrl` / `Shift` 多选及批量删除；
- 显示继承规则及真实来源；
- 复制继承规则到当前场景；
- 统一显示操作类型、摘要、延迟和失效状态。

编辑窗口可以设置第一段、可选第二段、说明、延迟和限定主机。已有数据能够读取但当前版本不能编辑的操作，会保留原内容并显示状态提示。

## 限制与排障

- **两段序列没有走完**：检查第一段和第二段是否与动作快捷键、扩展热键或其它程序的系统快捷键冲突。
- **停用后上级同序列仍不触发**：这是预期行为。删除本地同序列规则才会恢复继承。
- **浏览器里来源不对**：在网址场景中实际切换几个标签页，确认规则来源符合「网址 → 当前浏览器 → 浏览器通用 → 全局」。
- **误触发或场景不对**：看 **最近触发历史**，并可配合 **当前场景诊断**。
- **相对 1.x 的场景化变化**：见 [热键联动（2.x 变化）](/v2/what's-new/others/hotkey-watchers)。
