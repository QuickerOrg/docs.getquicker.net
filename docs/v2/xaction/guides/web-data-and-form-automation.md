# 网页列表提取与表单填写

Quicker Connector 1.2.0 增加了可视化的网页工具。你可以在浏览器侧边栏中识别列表或表单、调整字段并复制模板，再由 Quicker 动作在实际运行时提取数据或填写表单。

这套功能把配置分为两部分：

- **模板**描述网页结构、字段定位和翻页方式，通常由扩展生成。
- **数据**是每次运行时要填写的内容，通过 Quicker 参数、变量或表达式传入。

模板不保存本次填写值，因此同一份模板可以反复使用，也更适合分享动作。

:::tip 使用条件
请安装 Quicker Connector 1.2.0 或更高版本，并使用包含“提取网页列表数据”和“填写网页表单”操作的 Quicker V2 版本。旧版扩展不能执行这些新操作。
:::

## 打开网页工具

1. 打开要处理的网页。
2. 点击浏览器工具栏中的 Quicker Connector 图标。
3. 点击弹窗右下角的“Quicker 网页工具”按钮。
4. 在侧边栏顶部选择“列表提取”或“表单填写”。

若按钮没有出现或 Quicker 显示未连接，请先参考[设置浏览器扩展](/v2/xaction/guides/chrome-ext-settings)和[浏览器控制的连接排查](/v2/xaction/modules/chromecontrol#扩展连接问题排查)。

## 提取网页列表

### 1. 发现列表

优先点击“扫描页面”。扩展会列出页面中的重复结构候选，并自动选择排名最高的一项。候选排名只是建议，请同时检查行数、示例内容和网页中的高亮范围。

识别不准时，可以改用：

- **点击一条记录**：在网页中点击一条完整记录，适合结构明确的列表。
- **选择父元素**：先指定列表所在区域，再在较小范围内扫描。

同一批记录中若夹有置顶项、广告或特殊样式，扩展可能同时给出完整候选和若干子候选。通常应选择覆盖业务数据最完整的一项，再通过字段预览确认结果。

### 2. 编辑模板

切换到“编辑模板”，检查下列内容：

- 每个字段的 **key** 应简短、稳定；Quicker 输出表格使用 key 作为列名。
- 字段标题只影响显示，可以使用更容易理解的中文名称。
- 不需要的字段可以隐藏；低置信度字段应通过网页高亮和结果预览确认。
- 需要扩大或缩小范围时，可重新选择父元素或记录。

模板定义固定的输出列。某一行缺少可选字段时，Quicker 会保留该列并使用空值，不会因为个别行结构不同而改变表格结构。

### 3. 预览并复制模板

在“结果预览”中先测试提取，确认列、行数和内容都符合预期，然后点击“复制提取模板”。

回到 Quicker 动作编辑器：

1. 添加“浏览器控制”步骤。
2. 操作类型选择“提取网页列表数据”。
3. 把模板粘贴到“列表模板”。
4. 采集范围选择“当前页”。
5. 将“列表数据表”输出到一个表格变量。

常用输出包括：

- **列表数据表**：按模板固定列生成的 DataTable。
- **提取行数**：本次实际返回的行数。
- **网页匹配总行数**：网页中匹配到、尚未受返回上限裁剪的行数。
- **结果是否截断 / 提取警告**：用于判断是否因行数限制、缺列等原因需要检查结果。

“允许空结果”仅用于页面确实没有匹配行的情况。模板无效、页面不匹配或通信失败仍会报错，不会被静默转换为空表。

## 连续采集多页

需要合并“下一页”或“加载更多”后的数据时，先在扩展中配置翻页：

1. 在“编辑模板”中展开“多页采集”。
2. 点击“选择继续采集按钮”，再到网页中点击“下一页”或“加载更多”。
3. 设置最多采集页数并保存模板。
4. 在“结果预览”中点击“采集多页”，先验证翻页和停止条件。
5. 重新点击“复制提取模板”，粘贴到 Quicker。
6. 在 Quicker 中把“采集范围”改为“连续翻页”。

连续采集会在同一个标签页中翻页、汇总并去除重复记录，网页最终会停留在采集结束时所在的页面。建议同时设置合理的“最大行数”和超时，避免页面异常时持续运行。

可通过这些输出判断采集是否完整：

- **采集页数**：实际成功提取的页面轮次。
- **结果是否完整**：是否正常到达末页。
- **停止原因**：可能是正常末页、页数或行数限制、页面无变化、中途错误等。

扩展设有保护上限：最多 100 页、2000 行，单次采集约 5 分钟。当前方案要求页面上存在可点击的“下一页”或“加载更多”按钮，暂不支持纯滚动触底式无限列表，也不会自行推算下一页网址。

## 填写网页表单

### 1. 扫描并配置字段

在侧边栏选择“表单填写”，然后扫描整个页面或先选择表单区域。对于准备写入的字段：

- 勾选要加入模板的字段。
- 为字段设置稳定且唯一的 key。
- 只有业务上确实不可缺少的字段才勾选“必填”。
- 可使用“定位”“读取”和“试填”逐项验证字段。

“必填”是自动化执行规则，不等同于网页上的红色星号：必填字段缺少数据或定位失败时，整批填写会停止；可选字段失败时会跳过并继续。

先点击“检查定位（不填写）”验证所有字段；测试值准备好后，也可使用“试填到网页”做一次整体测试。

### 2. 复制模板和数据示例

扩展提供两类内容：

- **复制 Quicker 模板**：粘贴到 Quicker 的“表单模板”。
- **复制数据 JSON / 复制数据表达式**：作为“表单数据”的起点，按实际业务替换值。

数据 key 必须与模板字段 key 精确对应。Quicker 支持以下输入方式。

逐行输入：

```text
customerName: 张三
city: 北京
subscribe: true
```

JSON：

```json
{
  "customerName": "张三",
  "city": "北京",
  "subscribe": true
}
```

表达式：

```csharp
$=new { customerName = "张三", city = "北京", subscribe = true }
```

也可以直接选择词典变量。空字符串表示清空字段，`null` 表示没有提供该字段的数据。

### 3. 在 Quicker 中执行

1. 添加“浏览器控制”步骤。
2. 操作类型选择“填写网页表单”。
3. 粘贴表单模板，并填写或选择表单数据。
4. 第一次运行时建议开启“仅检查，不填写”。
5. 检查逐字段结果后，再关闭该选项正式填写。

默认失败策略是“必填字段失败时失败”。如需更严格的检查，可改为“任一字段失败时失败”；“始终返回结果”适合由后续步骤自行分析逐字段结果的场景。

## 更新已有模板

网页改版后，不必从头制作：

1. 从 Quicker 中复制完整模板。
2. 在扩展中选择“从剪贴板导入 Quicker 模板”。
3. 重新扫描或调整字段，并检查 key 是否仍与后续步骤一致。
4. 再次复制模板并替换 Quicker 中的旧模板。

更新时重点关注已删除、新增或无法稳定匹配的字段。修改字段标题通常不会影响数据引用；修改 key 会影响表单数据和后续表格处理。

## 限制与排查

- 浏览器内置页面、扩展商店等受保护页面不能被普通扩展控制。
- iframe、虚拟滚动列表和高度定制的网页控件可能需要缩小扫描范围或改用脚本。
- 表单扫描不会包含文件上传控件。请使用“浏览器控制”中的“上传文件到网页”或“向网页拖放文件”操作。
- 扩展显示已连接、Quicker 仍未连接时，可在扩展弹窗中执行修复连接，并确认 Quicker 没有以管理员身份运行。

复杂页面建议先在扩展侧完成单页测试，再接入 Quicker；不要直接把底层 `page.extract`、`page.list.collect` 或 `page.fillForm` 后台命令作为普通动作入口。专用操作会统一处理能力检查、超时、翻页停止条件和结果整合。
