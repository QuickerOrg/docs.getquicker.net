# 新增：PDF 文件处理模块

1.x 没有内置的综合 PDF 处理步骤，相关动作通常需要脚本、命令行工具或第三方组件。2.x 新增“PDF 文件处理”模块，可以直接在组合动作中完成常见 PDF 任务。

主要能力包括：创建空白 PDF、图片转 PDF、合并和按页拆分，以及按页码表达式提取、复制、重排、删除或旋转页面。模块还可以读取或修改文档信息、设置或移除密码，并在页面前景或背景叠加文字、水印、页码、图片、线条和图形。

页面范围使用从 1 开始的表达式，例如 `1,3-5,odd,last`。处理受密码保护的文件或生成未加密副本时，需要显式提供相应密码和安全选项。
