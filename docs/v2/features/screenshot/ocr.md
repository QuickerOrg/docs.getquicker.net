# 截图文字识别（OCR）与表格识别

本页说明 **Quicker 截图** 与 **贴图窗口** 中的本地 OCR 识字、截图内选字编辑、在线表格识别、OCR 结果窗与译文校对；选区、标注与快捷键见 [Quicker 截图](./capture-pro.md)，贴图交互见 [贴图窗口](./pin-window.md)，历史图片管理见 [图片、贴图与录屏历史管理](./media-history.md)，桌面录屏见 [桌面录屏与视频编辑](./screen-recording.md)。

### 从识字浮层打开 OCR 窗口 {/* #open-full-ocr */}

截图识字完成后，点击浮层工具栏的 **打开OCR窗口**，会结束截图并进入完整 OCR 窗口，带入当前图片、识别位置和已编辑的文字，不会再次调用识别服务。之后主动重新识别或再次截图，仍会正常发起识别。截图工具栏按识字、翻译、AI 排列；图片翻译在翻译菜单中，选择后不会改变主按钮的文本翻译功能。

## 文字识别（OCR）

Quicker 截图与贴图共用本地 OCR 能力。截图可直接在原图上选字，也可按设置打开结果窗口；贴图可在移动模式下选字复制。不同入口的处理方式如下。

| 场景 | 行为 |
| --- | --- |
| 截图工具栏点 OCR | 按设置在原图选字、打开结果窗或复制全文，见[默认模式](#ocr-result-mode-2333) |
| 贴图工具栏 / 右键「识别文字」 | 打开同一结果窗；成功后还会把文字写入贴图的不可见文本选择层 |
| 新建贴图后（自动） | 后台静默识别，不弹结果窗、默认不显示区域边框 |

使用 Quicker 截图的斜铺文字水印时，水印会作为标注效果叠加到最终图片中；之后把它贴成贴图再做 OCR，不会把水印文字当成原图内容写入贴图文本层。

普通识别入口打开文字结果窗口时，**历史列表默认收起**；从历史入口打开时则展开，方便查找记录。进入窗口后仍可自行展开或收起；复用已有窗口打开新的普通识别结果时，也会先收起历史列表。

### 识别引擎

- **优先本地 OCR**：首次使用需登录 Quicker，并按需下载识别程序、原生推理库和模型。OCR 结果窗使用标准（small）文字模型；截图和动作步骤的其它识别入口以各自选项为准。ARM64 客户端会选择 ARM64 程序和推理库。
- **本地失败时**：若你在设置中配置了自有百度 OCR Key，会尝试在线识别。
- **不会**使用 Quicker 云端 OCR，也**不会**回退到 Windows 内置 OCR。

### 中文引擎与逐字选字 {/* #ocr-selection-2322 */}

本地文字识别需要 **文字识别 Agent 0.3.8 或更新版本**，缺少或版本过低时，请按客户端提示更新组件。

本地识别默认优先使用已安装的中文识别引擎，减少因缺少默认引擎而无法识别的情况；各识别入口的模型选项以当前界面为准。截图、贴图和 OCR 结果窗中的逐字选字也作了调整，便于只复制一段文字中的几个字。

本地识别失败而改用已配置的百度 OCR 时，结果会提示本地失败原因；两端均失败时保留两种失败说明，便于分别检查本地依赖和百度配置。升级不会自动配置或启用新的百度账号。

普通本地文字识别与表格识别使用不同的处理流程。**表格使用本地 small 识字＋在线表格处理，需要联网**，详见[在线表格识别](#hybrid-table-2336)。普通本地文字识别仍在本机完成。

### 在线表格识别 {/* #hybrid-table-2336 */}

表格识别先在本机读取文字，再将 **原图和本地识字结果上传**，由在线服务处理行列、合并单元格等结构。需要登录有效会员并联网，首版仅支持 **x64**；ARM64 安装包和普通文字识别可用，不代表 ARM64 表格服务已开放。

首次使用时，先在识别结果窗的表格入口阅读并确认上传说明。拒绝后不上传图片；组合动作和脚本不会自行弹出这个确认，未同意时会明确失败。升级后会重新准备一次识别代码组件，文字模型等已有资源按实际安装状态复用。

服务不可用、限流、未登录、会员无效或本地组件不可用时，请按错误提示处理；表格失败不会自动退回本地表格算法。涉及敏感内容时，确认可以上传后再使用。

#### 模式、长表恢复与校对

- **模式** 提供自动、网格、混合、模型等选择，切换后重新识别当前图片。网格模式适合有完整网格的表格；无法使用时可查看原因，再改用其它模式。
- **长表恢复（实验）** 用于尝试恢复被截断的长表。可在 **原结果／恢复结果（实验）** 间切换对照，恢复不保证所有行列和单元格都正确，重要内容仍需校对。
- 复制或使用 Excel 打开时，以当前显示、编辑后的表格为准。重新识别、切换模式或恢复可能替换表格；已有人工改动时先检查确认提示。
- 可拖动列头边界调整列宽，双击边界恢复自动列宽。列宽只影响当前结果显示，不改变复制或导出数据；重新载入表格恢复自动布局。
- 可停止正在等待的识别。取消、换图或关闭后，迟到结果不会覆盖当前表格；停止等待不保证服务器已开始的计算立即中断。

联网、会员及上传同意要求同样适用于[基础 OCR 步骤](/v2/xaction/modules/basic-ocr#hybrid-table-step-2336)和脚本 `qk.Vision.OcrTable`。升级及回退前请看[兼容说明](/v2/migration/upgrade-and-rollback#text-and-table-2336)。

### 窗口复用与人工译文 {/* #ocr-window-and-translation-2336 */}

在 **设置 → 截图 → Quicker 截图 → 文字识别** 中，可开启 **复用已有的 OCR 结果窗口**，默认关闭。开启后，截图识别、屏幕选字的编辑和翻译等入口会在已有结果窗载入新结果；已有编辑内容时先确认，避免连续取字堆叠多个窗口。该偏好随账号同步。

翻译页在原文或翻译选项变化后自动更新。手动编辑译文，包括清空译文后，会暂停自动覆盖，后续原文变化也保留校对稿；主动点击翻译且成功后恢复自动更新。失败或取消时保留人工稿，不会对同一状态无限自动重试。

### 结果窗

从截图或贴图打开文字识别结果窗时，默认进入 **文字** 页。简版与完整结果窗共用原始／智能排版和段间空行偏好；首次使用默认原始排版，已有明确保存的选择继续保留。

在 **排版** 中选择智能模式后，可按需开启 **段间空行**。本地 OCR 与“基础 OCR”步骤的 **智能合并结果** 使用一致的文字整理方式，并改善旋转文字的阅读顺序及图文选择联动；原有步骤输出继续保持兼容。打开历史记录会沿用保存时的文字，不会因为升级或换模型而批量重新排版。旧版重存的风险见[回退说明](/v2/migration/upgrade-and-rollback#prompts-and-ocr-2340)。

结果窗口提供文字识别历史入口，可选择并恢复此前记录。图片右键菜单提供 **复制图片、复制文件、复制完整路径**；复制文件与复制图片供接收程序使用的内容不同，请按粘贴目标选择。历史保存在本机，文件已缺失时不能只凭历史项恢复原图。

结果窗顶部提供 **原图、文字、翻译、表格、公式** 页面；原图校对独立成页。识别结果就绪后可切换查看、编辑和复制：

- 切换到 **原图** 页缩放查看图片、对照文字校对；切换到 **文字** 页编辑和复制全文。原图校对副本与文字页结果分别保存，回退旧版前请先备份，见[回退说明](/v2/migration/upgrade-and-rollback#ocr-and-arm64-2331)。
- 切换到 **表格** 结果后，可用「用 Excel 打开」把当前已编辑表格保存为临时 `.xlsx`，并用系统关联程序打开；合并单元格、表头和文本会一并保留。
- 切换到 **翻译** 页签，选择源语言、目标语言和服务商；可自动翻译，也可手动重新翻译并复制译文。原文与译文列表可按行同步滚动，行数不一致时会按高度对齐。
- 本地文字识别固定使用标准模型；缺少组件或模型时按提示下载。如有漏行，可调整原图或识别选项后点击 **重新识别** 检查结果。
- 按图片情况调整 **方向检测**。切换只保存设置，不会立即重跑；需要更新结果时再点击 **重新识别**。
- 在 **排版** 菜单中选择「智能排版」整理段落，或切回「原始排版」。
- 还可使用去除空行、全角转半角、大小写、中英文标点转换等文本工具；常用的去空格、合并段落换行仍可直接使用。
- 点「复制并关闭」一次性复制并关闭窗口。

普通本地文字识别不会自动发起收费 AI 识别；使用公式等收费识别服务前，仍应核对界面提示和服务配置。窗口偏好与识别历史保存在本机，备份与回退边界见[升级与回退](/v2/migration/upgrade-and-rollback#ocr-and-arm64-2331)。

### 贴图上的选字复制

贴图在移动模式下，可直接在图片上拖选或双击选字，用 `Ctrl+C` 复制。文字层默认不可见；若需要对照识别区域，可在移动模式右键菜单中打开「显示文本区域边框」。

如果想**先把截图贴在桌面，再从贴图上选字**，在 Quicker 截图选好范围后用 `Ctrl+T` 或工具栏「钉住」贴图。新贴图会在后台自动 OCR；识别完成后按上面的方式选字复制。若只是要立即复制截图中的文字，可直接在截图界面点 **文字识别**，无需先贴图。

自动 OCR 在后台运行时，若你正在使用铅笔等标注工具，**不会**强制切回移动工具或抢占键盘焦点。关闭贴图会取消尚未完成的识别；从上次会话恢复的旧贴图不会批量重跑 OCR。

### 截图内选字与全文编辑

以下操作对应默认的 **原图选字** 模式。也可改成直接打开结果窗口或复制全文，见[截图 OCR 默认模式](#ocr-result-mode-2333)。

普通文字识别可以直接留在截图界面完成：

1. 框选范围后，点击工具栏的 **文字识别**，或按 `R`。识别状态与结果显示在当前截图上，保留原图供对照。
2. 识别完成后，在原图文字上拖选或双击选字，用 `Ctrl+C` 或 **复制选中** 复制。
3. 需要校正识别结果时，点击 **编辑全文**，修改文字后使用 **复制全文**。原图上的选字仍取原识别文字，全文编辑不会改写原图的文字选择层。
4. 默认 **复制后关闭** 开启；复制成功才结束截图。需要连续复制多段文字时，先关闭此选项。复制失败会留在当前界面，可以重试。
5. 需要重新框选时，点击 **返回截图** 或按 `Esc`；需要保留结果结束截图时，点击 **完成**。

内嵌工具栏可切换 **标准 / 快速** 和 **方向检测**；更改识别参数会重新识别当前选区。这些选项与 **复制后关闭** 会记住。识别失败可用 **重新识别** 重试，或返回截图调整范围。

### 截图 OCR 默认模式 {/* #ocr-result-mode-2333 */}

打开 **设置 → 截图 → Quicker 截图 → 文字识别 → 点击 OCR 文字识别按钮时**，选择普通截图文字识别的结果呈现方式：

| 模式 | 操作结果 |
| --- | --- |
| 原图选字（默认） | 留在截图界面，对照原图选字或编辑全文。 |
| 打开结果窗口 | 结束截图并直接打开完整 OCR 结果窗口，在窗口中识别。 |
| 识别后复制全文 | 识别后复制全文，复制成功才结束截图；失败或没有文字时留在原图界面。 |

也可右键点击截图工具栏的 OCR 按钮，修改同一默认值。按住 `Ctrl` 点击 OCR 按钮，仅本次打开完整结果窗口，不改变已保存的偏好。

该偏好随账号同步，影响普通截图的 OCR 按钮、`R`、侧栏及“截图 + 文本识别”快捷入口。组合动作或脚本显式指定的 OCR 配方仍按原图选字流程执行，不会因为个人偏好而自动复制或提前开窗；混合文本捕获与显式“识别并复制”操作也保留各自语义。

混用旧客户端前，请查看[OCR 模式的兼容说明](/v2/migration/upgrade-and-rollback#recording-and-account-2333)。

## 常见问题

### OCR 提示需要登录或下载

本地 OCR 依赖按需下载的识别组件，需先登录 Quicker 账号。首次识别或切换更大模型时可能短暂下载；下载完成后同一模型不会重复下载。

### 本地 OCR 空闲退出 {/* #local-ocr-keepalive-2320 */}

在 **设置 → 截图 → 识别与翻译 → 本地 OCR** 中调整 **本地 OCR 空闲保活时间**。未配置时默认 **300 秒（5 分钟）**，空闲超时后退出识别进程并释放模型内存；再次使用时需重新加载模型，可能稍慢，但不会因此重新下载模型。设为 **0** 表示常驻。

已有配置值会保留，包括旧配置中的 0。修改在下一次本地 OCR、表格识别或抠图请求时应用，不会在保存设置时中断当前识别；此设置只保存在本机当前账号，不参与同步。

### 翻译页签没有译文或想换服务

在 OCR 结果窗切到 **翻译** 页签，先确认源语言、目标语言和服务商，再重新翻译。识别文本变化后可重新翻译；只需要译文时，用页签里的复制按钮复制翻译结果。

### 贴图上看不到文字框，但似乎能选中

这是预期行为：自动 OCR 默认只填充不可见的文本选择层，不显示边框。需要对照区域时，在移动模式右键菜单打开「显示文本区域边框」；也可点 OCR 按钮打开结果窗查看全文。

### 图片翻译提示未配置或验证失败

图片翻译需要自备百度或有道的**图片翻译**凭证。百度图片翻译 V2.0 需在 **设置 → 截图 → 识别与翻译** 同时填写 **APP ID** 与 **API Key**；仅有 API Key 时请补填 APP ID。仅开通文本翻译、未开通图片翻译时会失败。详见 [图片翻译](./image-translate.md)。
