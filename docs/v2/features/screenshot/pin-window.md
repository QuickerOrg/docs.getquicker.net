# 贴图窗口

本页说明截图后或通过贴图步骤生成的桌面贴图窗口交互、分组切换、窗口贴图缩放与渲染清晰度；选区与标注见 [Quicker 截图](./capture-pro.md)，文字识别见 [截图文字识别（OCR）与表格识别](./ocr.md)，查看和整理历史图片与贴图组见 [图片、贴图与录屏历史管理](./media-history.md)。

## 贴图窗口（截图后）

贴图会把图片浮在屏幕上，方便对照、标注或临时展示。新建贴图后通常会在后台自动 OCR，可直接在图上选字复制（见 [截图文字识别（OCR）与表格识别](./ocr.md)）。

贴图窗口的系统标题栏不再随图片内容变化；图片标题改在窗口内、图片下方显示，便于在任务栏和窗口列表中辨认贴图窗口。

重启 Quicker 后恢复贴图时，如果原显示器仍存在，会尽量保留上次所在屏幕和位置；原显示器已移除时，才会移回主屏可见区域。

通过贴图步骤生成的 HTML 或公式贴图会先在隔离环境中渲染，再以普通图片窗口显示；未信任内容不会执行页面脚本或加载嵌入页面。作为普通图片窗口后，可以正常拖移、显示阴影，并可在自动 OCR 完成后直接选中文字复制。剪贴板图片携带的位置也会随复制保留，便于后续贴回原处。HTML 贴图会按内容自动换行；固定宽度或超长内容按需缩小。

自动识别和剪贴板来源的 HTML 贴图会隔离页面脚本，防止其执行。包括显式 HTML 模式在内，贴图仅渲染静态 HTML 与内联样式，不执行来源脚本或加载网络资源；需要在线内容时，请先转换成静态图片。

### 移动模式

- **右键短按**：打开菜单（识别文字、图片翻译、复制 / 另存为、图像处理、显示、锁定、历史记录、关闭等）
- **右键拖框**：进入非破坏性局部显示视口
- **`R`**：切换局部显示模式（旧称“缩略图模式”）
- **`Shift + 左键双击`**：以双击点为中心进入正方形缩略视口
- **`Ctrl + 滚轮`**：调节窗口透明度
- **`Ctrl + 左键拖动`**：把当前合成图拖到其它程序
- **空格**：显示 / 隐藏标注工具栏
- **`L`**：锁定 / 解锁窗口
- **`T`**：切换置顶
- **`Y`**：切换窗口阴影
- **`Ctrl+W` / `Esc`**：关闭贴图

贴图支持**鼠标穿透**：开启后鼠标可点到贴图后方的窗口；可用独立工具条调节不透明度、恢复操作，或关闭贴图。需要临时对照文档又不想挡住点击时，打开穿透即可。穿透模式下也可通过这条工具栏拖动贴图。

贴图窗口按 `Y` 可直接切换窗口阴影；正在编辑文字时不会抢走输入，`Ctrl+Y` 仍按重做处理。常用窗口状态操作在右键菜单一级显示，二维码操作在识别子菜单中。

### 多张贴图一起操作 {/* #pin-multi-select-2331 */}

在桌面贴图的 **移动模式** 下，按住 `Ctrl` 点选多张贴图；`Ctrl+A` 全选当前组的可见贴图。选中后可一起移动、缩放和关闭。此处的选择对象是桌面贴图，不是标注图形，也不会选中其它组或已隐藏的贴图；批量关闭前先核对选中范围。

### 图像处理与工具栏

贴图编辑工具条提供 **关闭贴图** 按钮；它会关闭当前贴图，区别于只结束编辑、收起工具条的确认按钮。

贴图编辑工具条增加 **表格识别** 入口，可直接将当前图片交给识别结果窗口处理。它沿用[在线表格识别](./ocr.md#hybrid-table-2336)的联网、会员、上传同意和平台限制，不等同于普通本地选字。

- 右键菜单「图像处理」中可用 **抠出主体（透明背景）**；可手动选择 **通用抠图** 或 **人像抠图**，在本机完成抠图后继续保存或贴图。
- Quicker 截图和贴图菜单可控制标注工具栏显示；需要临时隐藏或恢复工具栏时，不必进入设置页。
- **工具栏隐藏时**：数字键 `1`–`8` 可快速旋转、翻转、灰度、反色、亮度等；`0` 重置滤镜、方向与不透明度。
- **工具栏显示时**：数字键优先选择标注工具（见 [快捷键一览](./capture-pro.md#快捷键一览)），不再触发图像处理。

首次使用主体抠图需要已登录 Quicker，并下载约 4.4 MB 的独立本地模型；它和 OCR 文字模型分开管理，不会重复下载已有 OCR 模型。

### 自动折叠、复制与缩放 {/* #pin-interaction-2324 */}

在贴图右键菜单中勾选 **自动折叠**，贴图失去焦点且鼠标移出约 300 毫秒后，会缩成带边框的小预览；悬停约 200 毫秒或点击即可展开。此项默认关闭，按每张贴图记住，只保存在本机。窗口仍有焦点、正在编辑或处理图片时不会折叠；取消勾选会恢复展开。

自动折叠只临时缩小窗口，不裁切图片，也不等同于下面的 **局部显示模式**。折叠时会隐藏标注工具栏，展开后恢复正常操作。

- 工具栏的复制按钮：单击复制；双击在复制成功后关闭贴图，失败时保留窗口。
- `C` / `Ctrl+C`：优先复制选中的文字，没有选中文字时复制图片；提示会区分复制类型。
- `Shift+滚轮`：以鼠标所在位置为中心缩放；中键按最近的缩放中心恢复。

回退旧版后保存贴图或截图历史，可能清除自动折叠偏好，图片不因此丢失。备份范围见[2.3.24 升级与回退](/v2/migration/upgrade-and-rollback#pin-and-step-inputs-2324)。

### 拖动右下角缩放 {/* #pin-corner-zoom-2330 */}

在普通贴图的移动模式下，将鼠标移到图片右下角，出现斜向缩放光标后按住左键拖动，可等比放大或缩小贴图。松开提交；拖动期间按 `Esc` 取消本次缩放。

局部显示、自动折叠、锁定、鼠标穿透、取色或图片处理期间，此入口不可用；正在编辑标注文字时也不会开始角落缩放。缩放改变显示大小，不裁切原图。窗口贴图是另一种功能，操作见[窗口贴图缩放](#窗口贴图缩放)。

隐藏贴图时，编辑工具栏也会同步收起，不再因残留焦点继续响应工具栏按键。

### 右键拖框与鼠标手势 {/* #pin-right-button-2332 */}

在 **设置 → 截图 → Quicker 截图** 中可关闭 **右键拖动仅显示框选区域（局部显示）**。开关默认开启，保持右键拖框的原有操作；关闭后，可在贴图的 **移动模式** 下使用右键触发操作，例如鼠标手势。中键等其它鼠标按键不受这个开关影响。

关闭右键拖框后，仍可通过贴图右键菜单或 `R` 键切换局部显示。此设置随账号同步，修改后也会应用到已打开的贴图。

### 显示与局部显示

- 右键菜单可直接处理常用窗口状态；「显示」中仍可调缩放（25%–200%）、不透明度预设、窗口阴影、置顶等。
- 局部显示模式下，复制和另存为只输出当前可见部分；完整内容在退出局部显示后仍保留。
- 局部显示视口内可平移、拖拽边缘调整窗口大小；菜单中可用「重置局部显示范围」恢复，或用 **裁剪** 永久裁成当前视口。

### 锁定与历史

锁定窗口后，不能移动、缩放、改透明度或继续标注，但仍可复制、保存、OCR，以及开关置顶 / 阴影等。

右键菜单中的 **历史记录…** 可打开[采集历史中心](./media-history.md#图片与录屏历史管理)，查看当前贴图、已关闭贴图、截图历史与录屏历史，并做筛选、多选与批量操作。

贴图支持分组。可在贴图菜单中切换桌面贴图组；采集历史中心可把多张历史图片批量贴图到指定组、在组之间移动贴图，并管理分组。

截图侧栏可连续贴出之前关闭的贴图。使用 **恢复贴图** 可连续恢复最近关闭的贴图，无需先打开采集历史中心。

常用功能和步骤中的“从剪贴板贴图”支持富文本 HTML、公式、纯文本和图片文件。

### 快捷切换贴图组 {/* #pin-groups-2322 */}

可使用 **上一个贴图组、下一个贴图组、选择贴图组** 切换桌面贴图；从截图按钮右键菜单也可选择组。打开 **设置 → 截图 → Quicker 截图 → 管理贴图组**，可新建、编辑和排序分组。

在采集历史中心的组列表中，可上移、下移或拖动调整顺序；循环切组按保存的顺序进行。组菜单的 **创建切换动作** 可生成固定目标组的动作，再为该动作配置快捷键等触发方式。动作绑定组身份，重命名不影响绑定；目标组删除或换电脑后不存在时会提示，不能靠动作同步复制图片和分组。

“切换到指定贴图组”会显示该组全部未关闭的贴图；即使已经位于该组，也会重新显示。

可从 **创建动作 → 常用功能 → 截图功能** 创建 **切换指定贴图组显示状态** 动作：不在目标组时切入并显示，已在目标组时切换显示或隐藏。采集历史中心的组菜单可复制组 ID；组重命名后绑定仍有效。这里的显示/隐藏不等于关闭或删除贴图。

浏览历史中的某个组只筛选列表，**不会切换桌面组**；切组也不会删除、关闭或迁移图片。图片预览栏可拖动调整宽度并在本机记住。贴图组、图片及预览宽度仍保存在本机，不随账号同步。

从贴图按住 `Ctrl` 拖出统一提供 PNG 文件，便于置入 Photoshop 图层。

### 窗口贴图缩放

**窗口贴图** 是持续显示来源窗口画面的贴图，与前面的静态图片贴图不同。支持以下缩放操作：

- 普通滚轮以指针附近的图像位置为中心缩放；中键单击恢复 100%。
- `Ctrl+滚轮` 调整透明度。
- `Esc` 或 `Ctrl+W` 关闭窗口贴图；这不会关闭来源窗口。

还可双击关闭窗口贴图；右键菜单提供放大、缩小、恢复原始大小和关闭操作。关闭的是贴图，不会关闭来源窗口。

缩放只改变贴图显示大小，不调整来源窗口的尺寸。来源窗口最小化或暂时无法取景时，按窗口提示恢复、前置或刷新画面。

操作提示遵循设置中的快捷键提示开关。

## 贴图渲染与清晰度

贴图右键“显示 → 渲染方式”可在“位图”和“矢量（实验）”间切换。矢量模式可改善支持的文字、箭头等标注放大效果，但不承诺更快。截图标注默认仍为位图；已有纯文本贴图保持原有矢量默认。

不支持的效果、圆角或套索裁切等内容会使用位图。实验矢量源只保留在当前贴图窗口：隐藏再显示可复用，关闭后从历史恢复仍使用 PNG；像素处理或替换原图会清除矢量源。

HTML、公式贴图缩放时先显示预览，停稳后按倍率重绘；复制、另存为会等待清晰结果。HTML 文字选择与荧光笔高亮按视觉行处理，跨行选择不再把整段空白也连成一个高亮框。的自动换行、按比例缩小与屏幕内定位见上文[贴图窗口](#贴图窗口截图后)。
