默认输出（或输入）设备的音量。

## 构造

```csharp
VolumeInfo(int Level, bool Muted)
```

## 属性

| 属性 | 类型 | 说明 |
|---|---|---|
| `Level` | `int` | 音量 0–100。 |
| `Muted` | `bool` | 是否静音。 |
