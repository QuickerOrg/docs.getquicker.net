# 输出日志

记录动作运行中的信息，供后续查看和排查问题。通常只需填写内容，时间、动作和步骤信息由 Quicker 自动补充并统一管理。

## 使用说明

在需要观察的位置插入“输出日志”，填写“内容”。可以直接写一段文字，也可以绑定变量、表达式或插值文本。时间、动作和步骤信息由 Quicker 自动补充，不需要自己拼接。

例如，在文件处理开始前记录“开始处理文件”，处理结束后再记录结果变量；出现问题时可根据时间和调用链判断动作走到了哪里。

“级别”默认为“信息”。“警告”和“错误”只改变日志分类，不会停止动作；需要中止执行时，应另外使用流程控制步骤。“调试”级别仅在调试运行时记录，普通运行时连内容表达式也不会计算。

2.2.17 起，从 **工具 → 运行记录 → 动作日志** 查看输出，按动作、调用链、级别或关键字筛选，也可翻页和导出。详见[动作运行与触发记录](/v2/features/tools#动作运行与触发记录)。日志可能包含变量中的路径、地址或私密内容，分享前请检查。
