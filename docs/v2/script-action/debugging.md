先用“检查”处理静态错误；对执行过程中的问题，再选择日志、断点或运行分析。调试同样会产生真实副作用，建议先复制动作或使用专门测试文件。

## 用日志缩小范围

在关键分支前后调用 qk.Log(...)，输出输入、计算结果与执行到的位置。日志适合运行完毕后排查；不要把密钥、密码或私人数据写进日志。

## 断点与单步

在行号或左侧断点栏单击，或按 F9，设置断点。有断点时按 F5 或点击“运行”进入调试；命中断点后暂停，并显示当前执行行、变量和调用栈。断点右键菜单可以设置条件或日志消息。

| 操作 | 快捷键 |
|---|---|
| 设置/移除断点 | F9 |
| 运行；暂停时继续 | F5 |
| 停止调试 | Shift+F5 |
| 步过 | F10 |
| 步入 | F11 |
| 步出 | Shift+F11 |
| 运行到光标 | Ctrl+F10 |

断点会随文本编辑移动，但只在本次打开编辑器期间有效。暂停后可以查看变量快照和调用栈；这不代表可以任意求值或修改正在执行的变量。暂停时，继续和单步按钮按当前状态启用。

## 桌面自动化的前台窗口

暂停时编辑器会显示出来。按 F5 继续时，Quicker 尝试恢复暂停前的目标窗口，再放行脚本。激活失败时会提示处理方式，脚本不会直接悄悄继续。

单步与运行到光标时，编辑器保持在前台；执行依赖前台窗口的调用前，调试器会按需切回目标窗口。先用“查找并激活窗口”的例子理解这点，再调试键盘输入、选中文本和粘贴操作。

## 运行并分析

“运行并分析”收集更详细的运行轨迹，用于事后检查执行过程、调用和失败现场。它不进入断点调试；不要把详细观测的开销当作普通运行性能。

调试时当前变量属于那一次运行的快照；修改源码后重新运行，才能验证新逻辑。停止脚本不会撤回已经写入的文件或发出的请求。取消与 finally 行为见[运行上下文与生命周期](./runtime.md)。
