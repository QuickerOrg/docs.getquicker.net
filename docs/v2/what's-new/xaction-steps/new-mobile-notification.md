# 新增：发送手机通知模块

1.x 没有对应的组合动作模块。2.x 可以向 Remote 设置中已授权且在线的 Android 设备发送通知，并在手机上用按钮或文字回复，把结果送回组合动作。

下面是手机通知栏里的样子（系统通知，不是电脑上的提示消息）。可以点 **确认** / **取消**、点通知主体，或点 **回复** 输入文字，看动作会收到哪些输出。

<MobileNotificationPreview />

## 四种操作

| 操作 | 做什么 |
| --- | --- |
| **发送并等待响应** | 发出通知后停在这一步，直到手机点了按钮、点了通知、超时、被撤销，或动作被取消。 |
| **异步发送** | 发出通知后立刻继续后面的步骤。需要稍后等待或撤销时，先保存返回的通知 ID。 |
| **等待已有通知** | 用之前保存的通知 ID 继续等同一条通知。 |
| **撤销已有通知** | 撤回手机上尚未结束的同一条通知。 |

设备 ID 填 Remote 设置页里那台 Android 设备的 ID。发送时通知 ID 可以留空（会自动生成）；**等待** 和 **撤销** 必须填写。

## 按钮与回复

最多三个操作按钮。某个按钮的标题留空，这一项就不会出现在通知上。

勾选「接受文本回复」后，Android 会为该按钮加上系统内联输入框（RemoteInput），用户填的文字会写入 **回复文本**。

点击通知主体、而不是下面的按钮时，**点击按钮 ID** 为 `__notification_tap`。

默认过期时间为 300 秒，可在 1～86400 秒之间调整。过期、设备离线或授权失效时不会无限等待。

## 动作输出

| 输出 | 含义 |
| --- | --- |
| **通知 ID** | 发送时返回的幂等标识，供稍后等待或撤销。 |
| **状态** | 如 `delivered`（已送达）、`clicked`（点了按钮或通知）、`replied`（带文字回复）、`cancelled`、`expired`。 |
| **点击按钮 ID** | 用户点的按钮 ID，或通知主体的 `__notification_tap`。 |
| **回复文本** | 仅在该按钮允许文本回复且用户提交了文字时有值。 |

## 限制

- 只发到已授权且当前在线的 Android 设备。
- 通知最多三个按钮；标题为空的按钮不会显示。
- 需要稍后等待或撤销同一条通知时，应保存发送时返回的通知 ID。
- 设备离线、授权失效或通知过期时，等待会结束，不会一直卡住动作。
