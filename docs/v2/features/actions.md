# 动作与动作面板

动作是 Quicker 中可重复运行的功能单元，动作面板、场景、快捷键和触发规则则负责决定动作显示在哪里、何时运行。

Quicker 2.0 将动作内容与使用位置分开。同一个动作可以出现在多个位置；编辑动作会影响所有引用它的位置，而从面板移除按钮并不等同于删除动作本体。

## 组合动作

组合动作通过多个步骤完成较复杂的工作，例如读取剪贴板、处理文本、调用网络接口、控制窗口，再把结果发送到目标软件。

- 第一次创建组合动作，请从[怎样学会组合动作](/v2/xaction/guides/how-to-learn)开始，三条动手课之后再读[组合动作基础](/v2/xaction/concepts/xaction-intro)。
- 需要查找步骤参数时，进入[组合动作模块参考](/v2/xaction/modules)。
- 需要了解变量、表达式和子程序时，查看[基础与进阶概念](/v2/xaction/concepts)。
- 需要参考完整场景时，查看[教程与实践](/v2/xaction/guides)。

## 运行与整理动作

- 单击面板中的动作按钮即可运行动作；动作执行中显示的状态取决于动作类型和运行方式。
- 编辑动作本体前，应先确认它是否被多个面板、场景或触发规则引用。
- 只想整理面板时，应移动或移除当前位置，不要误删动作本体。
- 复杂动作升级或迁移后，建议先创建副本测试，再替换经常使用的版本。

## 分享与安装动作

2.2.1 起，动作库开始使用统一动作分享的初步方案。同一个分享动作可能同时包含 V1 和 V2 制品；若动作使用了 1.x 不支持的能力，则只能提供 V2 制品，1.x 客户端无法安装。

当前兼容判断还可能有误差：有些动作可能在 1.x 中能安装但运行不了；审核中的动作不会影响已发布版本；客户端和服务端也可能继续调整。2.1.19–2.2.0 期间使用旧 V2 分享机制发布的动作需要重新分享。更多限制见 [动作与公共子程序分享](/v2/what's-new/actions#动作与公共子程序分享) 和[官网版本记录](https://getquicker.net/V2/Versions)。

## 了解 2.0 的变化

2.0 对动作存储、操作参数、组合动作执行和调试基础结构进行了调整。旧动作兼容范围、只读边界和新版调试能力见[动作存储、执行与调试](/v2/what's-new/actions)。
