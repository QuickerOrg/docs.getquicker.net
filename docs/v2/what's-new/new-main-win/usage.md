# 新面板窗口的使用（V2 变化）

:::info[完整使用说明已合并至功能目录]
日常弹出方式、视图选项、分组排序、快捷按钮与多场景整理，请查看主文档 **[动作面板使用说明](/v2/features/action-panel/usage)**。本页仅保留 1.x → V2 变化、跨版本回退风险与历史直达锚点。
:::

## 相对 1.x 的核心变化

- **动作本体与显示位置分离**：不再绑定在固定二维动作页，改为「全局区 / 上下文区 → 场景 → 分组 → 动作」，同一动作可在多个场景、轮盘、手势与快捷键中复用。
- **已登录账号可切换，离线账号固定新面板**：已登录账号可在旧面板右上角菜单或基础设置中临时切回旧面板；本机离线账号固定使用新面板。
- **虚拟「置顶」与适用主机**：支持跨分组置顶、按「适用主机」仅在指定电脑显示某分组，以及「暂存区」「动作运行与触发记录」等新入口。
- **1.x/2.0 JSON 导入兼容**：导入本地 JSON 时自动为已存在 ID 生成新副本 ID；2.3.44 起支持整场景搜索树移动。

:::caution[跨版本回退与侧边栏快捷按钮风险]
- **2.1.21 迁移**：回退到 2.1.19–2.1.20 仅宜紧急查看，切勿编辑或同步面板配置，以免丢失新版分组身份与适用主机信息。
- **2.1.29 侧边栏快捷按钮**：若在 2.1.28 及更早版本修改并同步动作面板偏好，旧客户端可能清除快捷按钮配置。多设备同账号请先全部升级再调整。
:::

## 双击导航栏

2.2.10 起：

- 双击**面板内容空白处**，可显示或隐藏导航栏（给动作区域腾地方）。
- 双击**导航栏空白处**，可在标准导航与紧凑导航之间切换。

请点在空白区域；点到场景标签、动作磁贴或按钮上仍按原有单击 / 双击行为处理。
