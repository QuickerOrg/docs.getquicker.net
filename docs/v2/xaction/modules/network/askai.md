# 问问AI

2.3.45 起，可在组合动作中使用 **问问AI** 步骤，把问题和材料交给问问 AI 小窗。使用前先在[AI 服务与模型设置](/v2/what's-new/ai-services-and-models)中配置可用模型。

## 默认手动发送

1. 填写 **提示词**，例如“根据附带日志解释失败原因”。这是本轮问题，不是系统提示词。
2. 按需填写 **附带图片**、**附带文件**，或在高级参数中填写 **附带文本**、**窗口上下文**。
3. 保持 **发送方式 → 用户确认后发送**，运行后检查问问 AI 窗口中的问题与附件，再自行发送。

手动模式的成功表示材料已经准备好，**不表示已发送，也不表示回答完成**。这个步骤不输出回答正文。需要自动处理并取得文本结果时，使用 [AI 文本处理](/v2/xaction/modules/ai-text)；需要用户采用交互回答时，使用 [AI 交互对话](/v2/xaction/modules/ai-chat)。

## 自动发送与结果不明

选择 **自动发送** 后，材料准备完成即提交给配置的模型，不再另行确认，可能上传文件内容并产生服务费用。后续助手工具调用仍遵循现有审批设置；工具审批不等于对首次发送材料再作确认。

自动模式的成功只表示助手已经接受本轮，步骤不会等待生成答案。如果提示 **提交结果不明**，先检查问问 AI 会话，再决定是否重试，避免重复发送或计费。准备失败、取消或会话忙时，请按具体结果处理，不要把窗口已经打开当作成功。

## 材料范围

- 每轮最多 **20 个内容附件**，图片和文本合计；单张图片最多 **8 MiB**。
- **附带图片** 使用图片变量，PNG 编码后超限时需先缩小；多张图片文件可放入附带文件列表。
- **附带文件** 接受本地文件、目录路径列表。图片和不超过 **512 KiB** 的受支持文本会导入内容，其它文件或目录附带路径；路径不表示文件正文已经读取，后续读取受工具权限限制。
- **附带文本** 用于日志、JSON、正文等，最多 UTF-8 **512 KiB**，作为附件交付。
- **窗口上下文** 默认 `-1`，不附带；`0` 为执行本步骤时的前台窗口，其它有效句柄指定窗口。仅附带背景，不单独获取选区，并遵守已有采集确认设置。

发送前确认材料中没有不应上传的隐私、密钥或工作数据。分享动作时注明需要 **2.3.45 或更高版本**；回退前先备份，见[升级与回退](/v2/migration/upgrade-and-rollback#ai-images-2345)。
