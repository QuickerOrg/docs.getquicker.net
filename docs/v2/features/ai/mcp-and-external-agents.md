# 连接外部助手与 MCP

通过 MCP（Model Context Protocol），你可以让外部桌面 AI 客户端或编辑器助手连接并辅助编写、查询本机 Quicker 中的动作与配置。桌面工作台写动作见[AI 助手与动作编写](/v2/features/ai-and-agent)，提示词与会话管理见[提示词库与会话管理](/v2/features/ai/prompt-library-and-sessions)。

## 启用与连接步骤 {/* #2313--桌面入口与-mcp-接入 */}

在桌面打开外部助手的 MCP 设置页并完成连接：

1. 启用 MCP（功能默认关闭）。
2. 在外部助手设置中按客户端能力选择一种连接方式（见下表）。
3. **接入同意**：2.3.28 起，所有审批方式下首次接入都需在 Quicker 中明确同意该客户端；**完全控制** 只免除接入后的工具执行批准。
4. **写入权限**：需要编写或修改动作时，另行开启 **允许 MCP 写入**；仅连接不等于获得写入权限。
5. **撤销与升级**：可在「已同意的 MCP 客户端」列表查看程序路径并删除授权记录。同一安装位置下，仅版本号目录变化的客户端升级可沿用已有同意（如 Claude 桌面内置 Claude Code 保持安装布局）；更换其它目录或程序文件名时需重新检查。删除授权后下次接入需重新同意，完全控制也不例外。无人值守任务请先手动连接并确认，详见[升级注意](/v2/migration/upgrade-and-rollback#mcp-client-consent-2328)。

### 选择连接方式

| 页签 | 用法与说明 |
| --- | --- |
| **AI 自动配置** | 复制提示词给目标助手，让它检查自己的运行环境和配置格式，再完成连接。提示词含本机访问密钥，请勿公开分享 |
| **HTTP 连接** | 优先用于支持本机 Streamable HTTP 的客户端。复制设置页的 URL 与 Token，认证使用 `Authorization: Bearer <Token>`；只填 URL 不足以连接。2.3.19 起可显示完整密钥，截图或分享配置时应遮盖完整 Token |
| **stdio 连接** | 不支持本机 HTTP 时使用。将程序随附的 `quicker.mcp.exe` 完整路径填入 `command`，参数留空；桥接工具自动读取本机 Quicker 设置，无需另填 Token 或安装脚本 |

一个客户端选择 HTTP 或 stdio 其中一种，避免重复添加；Quicker 需要保持运行，云端或容器等隔离环境中的助手需先确认能访问本机。Token 应保存在客户端用户级配置中；主动重新生成 Token 后，直接 HTTP 客户端需更新 Token 并重新加载，stdio 桥接会自动读取新密钥。配置完成后建议先做一次只读查询确认工具可用。

## 文件访问与写入权限边界

**外部 MCP 的文件访问范围与内置桌面 Agent 不同。**

- **内置桌面 Agent（AI 工作台、问问 AI）**：普通文件工具可以按请求访问工作区外的磁盘路径，受当前 Windows 用户权限和操作审批约束。
- **外部 MCP**：文件工具只能访问 **Quicker 工作区、本会话已打开的动作槽位，以及已注册的只读逻辑挂载**。即使开启「允许 MCP 写入」或选择「完全控制」，**也不会放开任意外部磁盘路径**，也不会把外部助手自己的项目目录自动绑定为 Quicker 工作区。

例如，通过 MCP 将临时目录中的 PNG 移入动作槽位时，若源文件在允许范围外，`move_file` 会拒绝访问；导入图标应使用专用图标导入工具（参见[图标导入入口](/v2/features/ai-and-agent#icons-and-tool-details-2320)）并按权限确认，而非用文件移动代替。

通过 MCP 新建的动作仍先保存在暂存区，检查后再保留到场景；修改已有正式动作沿用[保存已有动作](/v2/features/ai-and-agent#237--保存已有动作)的提交与批准规则。允许 MCP 写入不等于新建动作自动成为正式动作，完成后请在 Quicker 中检查实际保存位置与内容。

## 每轮工具额度与 MCP 附加功能 {/* #tool-budget-and-mcp-2331 */}

### 当前对话的工具调用额度

当前对话可选择每轮工具调用额度 **96、192 或 384 次**（默认 **192 次**）。额度控制一轮任务可继续调用工具的次数，不是模型上下文长度，也不是免费用量。较高额度可能增加运行时间和服务用量；简单任务可选较低档位。对话输入区也提供上下文窗口快捷设置入口（与模型菜单一致）。

### 向 MCP 开放附加功能

在设置的 MCP 区域按需开启附加功能，两个开关均 **默认关闭**：

| 功能 | 开放范围 |
| --- | --- |
| **浏览器控制** | 已连接浏览器所支持的页面操作、脚本、Cookie、历史、下载及调试能力；具体以实际工具列表为准 |
| **本机搜索与打开** | 搜索文件和应用；开启「允许 MCP 写入」后还可打开文件、启动或激活应用 |

开启功能不代替客户端接入同意；写操作仍需「允许 MCP 写入」。浏览器功能可接触登录状态和浏览内容，请只向自己信任的外部助手开放。调整后请在外部客户端 **刷新工具列表或重新连接** 再核对可用工具。

这些附加功能开关仅保存在本机，不随账号同步。回退到 2.3.30 及更早版本并保存设置会清除新开关，重新升级需再次配置，见[升级与回退](/v2/migration/upgrade-and-rollback#ocr-and-arm64-2331)。

## API 配置边界与桌面统一设置 {/* #237--api-配置与外部助手授权 */}

<a id="开发中api-配置与外部助手授权" />

对话内的「配置 API」弹窗用于本人直接编辑服务与模型（细节见[统一 AI 服务与模型设置](/v2/what's-new/ai-services-and-models#237--api-配置弹窗)）。若模型不可用，模型菜单会具体区分「待确认工具调用」「不支持工具调用」、连接停用、模型停用和缺少密钥；Agent 需要支持工具调用的模型，能力未知时请先测试或核实，不要仅凭已保存 Key 就认定可用于 Agent。

AI 服务连接与远程文件账号列表仅支持助手查询，**助手不能新增、改写或删除账号与密钥**；未向桌面设置开放的内部项目，也不会因为换到外部 MCP 助手就变为可写。

## 自定义 MCP 集成的工具迁移 {/* #自定义-mcp-集成的写入方式 */}

- `quicker_eval` 已彻底移除（2.3.18 起不再用于写入，2.3.22 起移除）。请刷新客户端工具清单并改用专用工具，例如查找/读取设置用 `quicker_settings_search`、`quicker_settings_getvalues`，读取表格用 `quicker_tables_listrows`。
- 停止运行使用 `quicker_run_stop`（勿再向 `quicker_run_output` 传 `stop=true`）；合并预览使用 `quicker_merge_draft_preview`，`quicker_merge_draft` 只提交合并候选。
- 以客户端获取到的实际工具列表与参数说明为准，浏览器写入工具不会因工具调整而自动向 MCP 开放；已有写入授权、客户端同意和运行批准继续独立生效。
