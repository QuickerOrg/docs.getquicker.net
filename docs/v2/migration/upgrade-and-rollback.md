# 升级与回退

准备降级、混用不同版本，或把动作分享给旧版用户时，按下方功能查找对应注意项。首次安装请先看 [安装前准备](/important-notice)。

## 操作前确认

1. **先备份。** 按相关条目备份数据或本机配置，再更换版本。
2. **核对所有设备。** 新版设置在旧版保存或同步后，可能被清除；把会维护这些设置的设备一并升级。
3. **确认动作的最低版本。** 新增步骤和操作类型可能无法在旧客户端运行，分享时请注明版本要求。

回到 1.x 的安装步骤见 [从 V1 迁移](/v2/migration/from-v1)；各版本原始说明见 [官网版本记录](https://getquicker.net/v2/versions)。

## 数据与多设备

### 2.1.0 · 数据结构 {/* #从-210-降级会清掉-20x-没有的数据2026-07-28 */}

2.1.0 相对 2.0.x 增加了大量功能和对应的底层存储。2.0.x 里没有这些数据结构。如果在 2.1.0 里用过新功能并保存了新配置，再降回 2.0.x，这些数据可能被覆盖清除。

### 2.1.29 · 侧边栏按钮 {/* #2129-侧边栏快捷按钮的回退注意 */}

2.1.29 起可配置新版主窗口侧边栏快捷按钮。配置后若再用 2.1.28 或更早版本修改并同步动作面板偏好，旧客户端可能清除快捷按钮配置，恢复为仅默认「截图 Pro」。多设备使用同一账号时，建议先升级所有设备；回退旧版后也避免修改该项。

### 2.2.11 · 触发规则 {/* #2211-触发设置的多设备与回退风险 */}

新增的功能级黑白名单、左键辅助多键及短长按模式不受旧客户端支持。旧客户端可能按旧的适用范围触发；再次保存并同步设置，还可能清除新增字段，影响同账号其它设备。

请先备份配置，并把所有编辑这些设置的设备升级到 2.2.11 或更高版本。必须回退时，避免在旧版修改和同步这些设置。已经丢失的字段需要从备份恢复或重新配置。

触碰屏幕边框规则请在新版维护，降级前停用或移除。

“指定类型”变量不能生成 V1 分享制品，旧版 V2 也不能保证按指定类型正常执行；不要把含此类变量的动作交给旧客户端运行。

### 2.2.12 / 2.2.13 · 场景与布局 {/* #2212-规则父场景与-2213-面板自由布局 */}

2.2.13 起，新面板可保存动作的格子坐标、空位和分组高度。这些数据会随账号同步，但 2.2.12 及更旧客户端不识别新字段。如果回退后又在旧版编辑或同步同一场景，可能清除自由布局；再次升级后需重新摆放。

规则父场景的归属也从 2.2.12 开始保存。旧版客户端不会应用这层共享规则或它的面板动作。

多设备使用同一账号时，规则父场景需要所有设备至少升级到 2.2.12；要编辑自由格子布局，则建议全部升级到 2.2.13 或更高版本。必须回退时，不要在旧版修改或同步这些场景。

### 2.2.17 · 浏览器归属 {/* #2217-浏览器父场景归属的多设备与回退 */}

2.2.17 起，自定义程序的浏览器归属统一纳入父场景管理，并随账号同步。将自定义程序添加到浏览器父场景下后，需要重新设置一次归属。

使用浏览器父场景归属前，请将同一账号的所有设备升级到 2.2.17 或更高版本。回退到旧版本或新旧客户端混用时，包含浏览器归属的整份父场景归属配置会暂时失效并变为只读；数据不会因此删除，全部设备重新升级后可恢复。

### 2.2.26 · 轮盘 F2 开关 {/* #2226-轮盘-f2-编辑指向的动作 */}

2.2.26 起，轮盘显示时可按 `F2` 编辑鼠标指向的动作。该选项**默认开启**，可在轮盘设置中关闭。已有 F2 子动作，以及 F2 重复触发相关设置优先于本开关。

回退到旧版后，若再保存或同步轮盘设置，可能丢弃此开关；再次升级会恢复为默认开启。建议各设备升级后再调整，必要时在升级后重新关闭。操作说明见 [轮盘菜单](/v2/features/triggers/circle-menu#按-f2-编辑指向的动作)。

## 截图与悬浮布局

### 2.3.2 · 键盘黑名单与悬浮分组 {/* #232-键盘黑名单与悬浮分组 */}

悬浮分组从 2.3.2 起始终启用，移除模式开关。开启自动恢复时，旧独立项分别恢复为单成员组，已有布局和关闭状态保留；悬浮动作页沿用原窗口。布局仍只保存在本机。升级或回退前请先导出布局备份；新版不再使用旧模式开关，回退后的显示方式可能不同。

离线或状态未确认时，无法恢复的悬浮记录先保留待重试；联网确认后仍缺失、超额或不支持悬浮的记录会移除，需要重新创建悬浮项，动作本体不会因此删除。异常或不兼容布局首次被替换前会备份旧文件，读取或备份失败不覆盖原件，见 [悬浮布局异常处理](/v2/features/floating-actions#布局文件异常怎么办)。

动作快捷键、按键双击、热键联动的三个新黑名单选项默认关闭。旧客户端保存并同步设置可能清除这些字段，重新升级后需重新开启。建议所有维护同一账号设置的设备升级到 2.3.2 后再配置；回退前备份设置，避免在旧版编辑并同步这些选项。

### 2.2.5 · 保存日期 {/* #回退到-224-后保存截图设置会清除-225-的保存日期格式2026-09-04 */}

2.2.5 起截图保存设置增加了日期格式选项。若回退到 2.2.4 后又保存截图设置，旧客户端会清除新版的保存日期格式选择；再次升级后需重新选择。此设置只保存在本机，不影响已经保存的图片，也不影响云端数据。

### 2.2.7 · 阴影与边框 {/* #回退到-226-后保存截图设置会丢弃-227-的阴影与边框配置2026-09-07 */}

2.2.7 起截图 Pro 可为选区添加阴影和边框。若回退到 2.2.6 后又保存截图工具设置，旧客户端会丢弃新版阴影 / 边框配置；再次升级后需重新设置。截图文件本身不受影响。需要保留配置时，请先备份本机 `ScreenCapture/settings/image-drawing-tool-state.json`。

### 2.2.14 · 文件名与悬浮分组 {/* #2214-截图文件名模板与悬浮分组动作 */}

2.2.14 起，截图保存的独立日期格式选项已并入文件名模板，支持 `{date:格式}`（.NET DateTime）。编辑时会把旧日期格式转换并保留效果。若回退到更旧版本，需将模板中的 `{date:格式}` 改回 `{date}`、`{time}` 等旧语法，才能正常使用文件名模板。

「悬浮分组」动作（按名称打开、关闭或切换）需要 2.2.14 或更高版本客户端；旧版无法识别此动作类型。创建前建议升级所有同步设备；必须回退时，请先备份悬浮布局，并避免在旧版编辑或同步依赖该动作的内容。

## 账号与 AI

### 2.1.17 · AI 密钥 {/* #回退到-2117-之前可能要重填-api-密钥 */}

2.1.17 起，AI 设置可以同步（API Key 仍只在本机加密保存）。官网版本记录写明：若回退到 2.1.15，请在旧版中重新填写 AI API 密钥；新版保存后的凭据格式，旧版不能正确读取。使用新 AI 模块的动作也无法在 2.1.15 及更旧版本运行。

更早的回退也有类似情况，例如回退到 2.1.12 可能清除图片翻译凭证。逐版本注意以 [官网版本记录](https://getquicker.net/v2/versions) 为准。

### 2.2.18 · 远程账号与工作区 {/* #2218-远程文件账号与-ai-助手工作区 */}

2.2.18 起，组合动作可通过远程文件步骤访问 WebDAV 网盘或 NAS。远程文件账号在 **设置 → 软件连接 → 远程文件账号** 中配置，只保存在本机；它不会随账号云同步、状态备份或动作导出迁移。换电脑、重装或分享动作给别人时，需要在目标电脑重新配置相同的账号引用名。旧版客户端不能运行包含远程文件步骤的动作，升级前不要把这类动作交给仍停留在旧版的设备执行。

AI 助手正式版支持选择本地工作区。选择本地文件夹后，AI 对普通文件的修改会直接保存到该文件夹；请先确认目录、备份和版本管理方式。打开历史对话时会恢复对应目录，但切换工作区会开启新对话，不会把原对话、未提交草稿或上下文迁移过去。

如果回退到不支持自选工作区的旧正式版，已经选择工作区的项目对话不能继续按原目录工作。请升级到支持该功能的版本后，再继续对应项目对话。

### 2.2.19 · S3 与账号导出 {/* #2219-s3-账号与凭据导出 */}

2.2.19 起，保存 S3 账号会升级本机的远程文件账号配置。旧版会拒绝修改整份账号列表（包括其中的 WebDAV 账号），以避免丢失 S3 字段和密钥引用。数据不会因打开旧版而删除，但删除全部 S3 账号也不会自动降回旧格式。回退前先在新版导出必要账号，详见[远程文件](/v2/features/remote-files#回退旧版)。

远程文件账号的导出 JSON 包含明文密码或密钥。不要上传到公开网盘、聊天群、动作分享或源码仓库；传输完成后及时删除，外泄后立即在服务端轮换凭据。

### 2.2.21 · 代码补全 {/* #2221-代码补全服务 */}

2.2.21 起，组合动作与表达式等编辑器的代码补全默认走在线服务，以减小安装包并节约本机内存。需要离线或不希望上传代码时，可在 **设置 → 动作设计 → 代码补全服务** 中单独安装本地补全组件，并勾选 **使用本地补全服务** 后保存。该选项默认关闭。

使用在线补全时，Quicker 会向服务器发送正在编辑的代码、变量类型和默认 using。本地模式下，组件不可用时不会自动改用在线服务。操作入口见 [代码补全服务](/v2/xaction/concepts/xaction-editor#代码补全服务)。

### 2.3.1 · AI 数据按账号存放与密钥同步 {/* #231-ai-数据按账号存放与密钥同步 */}

2.3.1 首次启动时，会把加密保存在本机的 AI 设置等内容，以及 AI 会话、动作日志和运行历史，迁移到当前账号目录。**升级后首个启动的账号接收旧数据副本，其他账号从独立数据开始。** 同一台电脑登录过多个账号时，请先切换到需要保留旧数据的账号再升级。旧文件会保留，但部分日志、运行历史和附件迁移失败后不会自动重试。说明见 [AI 本机数据按账号存放](/v2/features/account-and-sync#ai-本机数据按账号存放)。

回退旧版会读取升级前的 AI 会话和日志，看不到升级后新增的内容；再次升级也不会自动补迁回退期间产生的数据。回退前请备份本机数据，避免在新旧版本之间交替编辑同一会话。

2.3.1 起可选同步 API 密钥和自定义请求头凭据，默认关闭。旧客户端修改并同步 AI 设置，会清除凭据同步开关和云端的密钥字段；新版设备保留本机凭据，但需要重新开启同步。建议所有设备升级后再启用，详见 [在设备间同步 API 密钥](/v2/what's-new/ai-services-and-models#在设备间同步-api-密钥)。

2.3.1 的暂存动作手动备份可能被旧版历史清理删除，回退前请导出重要动作。运行时编辑操作窗定义和按定义显示操作窗也要求 2.3.1 或更高版本；分享前确认目标设备版本。

2.3.2 的窗口助手历史可以跨重启续聊，但载入历史不会回退源码或设置。永久删除会同时清理消息、上下文和对应附件，不能恢复；需要保留代码时先使用动作保存版本或导出，而不是只保留 AI 对话。

### 2.3.4–2.3.5 · AI 与贴图行为

2.3.4 起，脚本助手的「提示词加载方式」只保存在本机；回退旧版后保存本机状态，可能清除这个新偏好，重新升级后可重新选择。它不修改脚本源码或动作定义。对话模型的独立保存规则也需要 2.3.4 或更高版本；不要期待旧版沿用新版的新对话初始模型规则。

2.3.5 扩大了「完全控制」的直接执行范围，MCP 也会继承全局完全控制。需要逐次确认时，升级后检查并改为「请求批准」，详见[完全控制与工具恢复](/v2/features/ai-and-agent#235--完全控制与工具恢复)。

HTML 贴图改为静态离线渲染，不加载网络资源或执行来源脚本。旧动作的背景参数仍有兼容处理，但依赖在线资源或脚本的内容需转换为静态内容；回退后渲染及批准行为会回到旧版。具体参数范围见[文字与 HTML 贴图](/v2/xaction/modules/pinimage#235--文字与-html-贴图)。

## 动作与日常操作

### 2.3.0 · 脚本动作 {/* #230-脚本动作 */}

脚本动作需使用 **2.3.0 或更高版本**。来自分享、文件导入或外部粘贴的脚本会按能力请求授权，后续能力扩大时再次确认；编辑器中的运行会真实执行操作。说明见 [脚本动作](/v2/features/script-actions/)与 [安全与授权](/v2/features/script-actions/security)。

使用脚本动作前建议导出备份，并将同步设备统一升级。回退旧版后重新保存或同步动作，可能丢弃新版的「外部导入」来源标记，影响重新升级后的授权判定；请避免在旧版编辑这类动作，必要时重新导入备份。

### 2.2.20 · 显示器与虚拟桌面 {/* #2220-显示器与虚拟桌面步骤 */}

2.2.20 起新增的显示器、虚拟桌面步骤需要新版客户端。含这些步骤的动作在旧版客户端中可能无法识别或运行；多设备同步或分享给他人前，请确认目标设备已升级到 2.2.20 或更高版本。

### 2.2.22 · 列表、提示与标注 {/* #2222-列表项自定义子程序与提示消息默认设置 */}

2.2.22 起，「管理和排序列表」可通过高级参数指定 **添加项子程序**、**编辑项子程序**，用多字段表单等方式处理复杂列表项。依赖这些子程序的动作需要 **2.2.22 或更高版本**客户端；分享给他人时请注明最低版本要求。旧版没有对应回调，不能当作退回内置编辑器的等价行为。操作说明见 [管理和排序列表](/v2/xaction/modules/managelist#用子程序自定义添加和编辑)。

同版起，可在 **设置 → 模块功能选项** 配置提示消息的默认显示位置和停留时间，并随账号同步。旧客户端不认识这两项设置；若在旧版保存设置并同步，可能把它们重置。建议先记下所选值，把所有会改设置的设备升级后再修改；若已被重置，可在新版重新设置。步骤或脚本里单独指定的位置、时长仍优先于全局默认。详见 [提示消息](/v2/xaction/modules/notify#默认位置与停留时间)。

同版起，截图、贴图和录屏标注中 `Ctrl+Shift+Z` 改为 **重做**（不再清空全部标注）；清空全部标注请用 `Shift+Delete`。首次按旧习惯的 `Ctrl+Shift+Z` 时，客户端会提示一次并执行重做。

旧「底部居中」步骤选项现在跟随全局默认位置；需要固定时，请重新选择本版的「底部居中」。

新导出的 Agent `.jsonl` 对话文件请用本版或更新版本导入；仍兼容旧版完整会话 JSON，已有对话无需迁移。导入的对话仅供查看，不能继续发送消息。见[AI 与 Agent](/v2/features/ai-and-agent)。

### 2.2.23 · 分享分类 {/* #2223-分享适用软件与浏览器通用 */}

2.2.23 起，分享动作可选择 **浏览器通用** 作为适用软件，使同一动作出现在 Chrome、Edge、Firefox 等支持的浏览器动作页中。从浏览器通用场景分享时默认选此分类。

更新已有分享时，若原「适用软件」保存的是非法值，需要重新选择有效分类，不再自动改为「通用」。已有 Chrome 等具体程序分类**不会**自动改成「浏览器通用」；需要跨浏览器展示时请手动改选。操作说明见 [分享动作与公共子程序](/v2/features/action-sharing#适用软件与浏览器通用)。

### 2.2.24 · 获取编辑中的动作 {/* #2224-获取最后打开编辑器的动作 */}

2.2.24 起，「Quicker操作」新增 **获取最后打开编辑器的动作**，可取得本次启动期间最近打开或重新激活编辑器的已安装动作 ID。含此操作类型的动作需要 **2.2.24 或更高版本**客户端；旧版无法识别该类型。多设备同步或分享给他人前，请确认目标设备已升级。说明见 [Quicker操作](/v2/xaction/modules/quickeroperations#获取最后打开编辑器的动作)。

### 2.2.25 · 设置与界面状态 {/* #2225-设置窗口改版与本机界面状态 */}

2.2.25 起，设置窗口改为树形导航，支持搜索并跳转到具体设置项。分类与入口有调整；找不到原位置时，优先用设置内搜索。已改版的设置页逐项自动保存，不再提供整页「应用／撤销」；无效或尚未提交的输入会在离开当前页时提示。

回退到 **2.2.24** 后，旧版保存本机状态可能清除新版 AI 助手侧栏宽度、开关和设置导航展开记录；这些界面偏好可重新设置，不影响动作内容。需要保留时，请先备份本机 `data/app-state.json`。
