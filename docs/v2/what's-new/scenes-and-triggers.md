# 场景与触发方式

> 各触发入口的选型与使用说明入口见 [快速触发概览](/v2/features/triggers)。本文说明 V2 如何统一管理场景与规则，以及相对 1.x 需要注意的变化。

Quicker 1.x 已经支持按程序切换动作页，以及文本指令、轮盘、手势和多种键鼠触发方式。

V2 保留这些能力，并把分散的编辑入口集中到“场景与动作管理”窗口。场景不再只等同于一个程序名，而是成为面板和触发规则共同使用的上下文。

## 从“程序动作页”到“场景”

V2 的场景用于回答两个问题：当前处于什么上下文，以及在这个上下文中应该显示或启用哪些动作和规则。

常见场景包括：

- 全局场景：在任何程序中都可使用；
- 程序场景：根据当前前台应用切换；
- 网址场景：浏览器打开匹配网址时出现；
- 浏览器通用场景：供多个浏览器共享；
- 自定义场景：用于手动组织或由特定动作加载；
- 通用场景：作为程序上下文中的公共入口。

程序场景和网址场景可以同时出现。网址专用动作不会因此复制到浏览器程序场景。

## 一个窗口管理场景相关功能

V2 把以下功能逐步集中到“场景与动作管理”：

- 新面板动作和分组；
- 旧动作页；
- 动作快捷键；
- 文本指令；
- 轮盘菜单；
- 鼠标手势；
- 高级鼠标触发；
- 按键双击和长按；
- 热键联动；
- 扩展热键；
- 左键辅助；
- 选中文本工具条规则。

旧设置页中的部分入口仍会保留为导航提示，但实际编辑会打开新的管理窗口。

## 场景规则支持继承和禁用

子场景可以继承上级或全局设置，也可以增加自己的规则、替换继承内容，或明确禁用某项功能。

“没有本地规则”和“明确禁用”是两种不同状态：

- 没有本地规则：继续使用上级规则；
- 明确禁用：在当前场景阻止上级规则生效；
- 恢复继承：删除当前场景的禁用或覆盖规则，重新使用上级配置。

这一规则可避免用户为了在某个程序中关闭功能，不得不删除全局配置。

## 新面板与触发规则共享场景身份

新面板、文本指令、轮盘和手势等功能使用一致的场景识别结果。打开“当前场景”时，各功能不再分别猜测当前程序。

对资源管理器、UWP、WPS、浏览器网址及多进程应用，V2 增加了更明确的场景识别和父级回退规则。

2.1.28 起，如果某个第三方浏览器没有被自动识别为浏览器，可在“场景与动作管理”窗口中找到该程序的场景条目，右键选择 **作为浏览器程序**。设置后，小众浏览器也可以使用浏览器场景及其触发规则。

如果面板标签或触发规则匹配错误，可以从新版主窗口的工具菜单打开“当前场景诊断”，查看 Quicker 识别到的程序、网址和继承链。

2.1.23 起，切换窗口或刷新设置时，高级鼠标、手势、轮盘菜单等触发规则会更稳定地按触发当时的程序和场景执行。遇到“刚切窗口就触发到上一个程序”的情况，先确认已升级到当前版本，再结合下面的最近触发历史排查具体规则。

## 诊断触发记录和快捷键占用

新版主窗口的工具菜单提供“最近触发历史”。它记录本次 Quicker 运行中最近 30 分钟、最多 200 条自动触发记录，不写入磁盘。

记录包括触发时间、前台程序、场景、触发规则和执行内容，覆盖动作快捷键、扩展热键、文本指令、轮盘、手势、按键双击、左键辅助和高级鼠标触发等入口。2.1.23 起，规则、场景和操作摘要的归因更清楚，也减少了默认记录对鼠标、键盘触发本身的影响。

遇到误触发、重复触发或场景不符合预期时，可以复制全部记录后再清空，以便和“当前场景诊断”结果一起排查。

“设置 → 快捷键查询 → 快捷键占用查询”可以按下或搜索组合键，汇总 Quicker 中已有的功能快捷键、动作快捷键和键盘监听规则，并跳转到对应设置。

Windows 全局热键可能发生系统注册冲突；Quicker 的键盘监听规则通常可以共存。查询结果用于定位 Quicker 配置，不代表能列出其它软件占用的全部快捷键。

## 迁移后建议检查的规则

基础动作和常见规则会尽量沿用原有数据。以下内容因为依赖场景、程序路径、组件位数或旧快捷操作格式，建议人工检查：

1. 浏览器网址规则和浏览器通用规则；
2. 绑定完整程序路径的特殊场景；
3. 轮盘子动作和自定义显示内容；
4. 高级鼠标、左键辅助及按键双击规则；
5. 使用内嵌快捷操作而不是引用普通动作的规则；
6. 只在特定电脑上生效的规则。

## 与新面板的关系

场景决定新面板显示哪个上下文标签，分组则负责组织该场景内部的动作。

1.x 中同一程序的多个动作页，在首次建立新面板场景时通常会转换为同一场景下的多个分组。旧动作页不会因此自动删除。

详细操作见[新面板窗口的使用](./new-main-win/usage.md)和[新面板窗口常见问题](./new-main-win/faq.md)。
