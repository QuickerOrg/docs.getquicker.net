# 工具与使用体验

除底层架构和动作系统外，V2 还更新了多项日常可见功能。本页只列出相对于 1.x 较重要的变化。

## 截图 Pro、贴图与录屏

V2 将截图、贴图、长截图和录屏整理为更完整的工作流。

截图 Pro 支持窗口与 UI 元素选区、手动框选、标注、OCR、智能马赛克、贴图、长截图和录屏入口。动作步骤也能返回图片、截图区域和保存路径。

贴图支持缩略图视口、图像处理、标注、透明度和拖出图片。截图及录屏历史使用统一的本机目录和历史管理入口。

详情见[截图与贴图概览](../features/screenshot/index.md)和[截图 Pro](../features/screenshot/capture-pro.md)。

## 选中文本工具条

1.x 的“文本悬浮窗”会展开动作页，界面较大，也把文本选择与旧动作页结构绑定在一起。

V2 改为轻量的“选中文本工具条”。它可以在选中文字后显示少量常用操作，并把更多操作收纳到展开菜单中。

工具条支持全局默认清单和按场景追加、替换或禁用。也可以关闭自动显示，仅通过快捷键主动呼出。

详情见[选中文本工具条](../features/triggers/text-selection-toolbar.md)。

## 动作与文件搜索

动作搜索会显示动作所在的新面板场景和分组，便于从搜索结果返回实际管理位置。

文件搜索和“打开所在位置”也改进了资源管理器复用逻辑。部分第三方文件管理器可以复用已有标签页，而不是重复打开窗口。

这些改进不会改变已有动作数据，但能减少在大量动作和文件之间查找、定位和重复开窗的成本。

## 统一的窗口和提示交互

V2 对设置、动作管理、确认框和通知窗口的生命周期进行了统一处理。

多数确认窗口只阻止发起操作的窗口，不再因为一个对话框而冻结同一线程上的所有 Quicker 窗口。提示按钮、禁用状态和关闭顺序也更加一致。

新版主窗口默认采用不抢占前台焦点的面板行为。进入搜索输入状态后才允许正常输入，结束搜索后恢复面板的被动显示方式。

## 场景动作的批量整理

“场景与动作管理”支持多选、连续选择、全选、批量移动、同时添加和安全剪切。

剪切不会立即从来源移除动作。只有成功写入目标场景后，Quicker 才会清理来源位置，减少未粘贴或粘贴失败导致的数据风险。

详情见[新面板窗口的使用](./new-main-win/usage.md)。
