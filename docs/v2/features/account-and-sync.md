# 账号、登录与数据同步

:::caution[Preview · 仅专业版]
免费版数据迁移仍在开发，免费账号目前无法登录 2.0。完整限制见 [体验前必读](/important-notice)。
:::

V2 为每个账号建立独立的本地数据目录。业务数据、本机状态、缓存和日志分开；切换账号时不再共用同一份账号业务库。

## 登录之后会发生什么

- 建议登录专业版账号，便于同步；也可以先用本机离线账号（离线账号固定使用新面板）。
- 从 1.x 过来时，**首次登录会分叉数据**：迁入当前账号的一份 V2 数据，之后与 1.x 不再双向镜像。
- 同步以独立数据项为单位（动作、动作页、场景配置、文本指令、公共子程序等可以分别更新）。
- 发生冲突时，不应假定一端会静默覆盖另一端。「用服务端数据重建」会以服务器数据重做本机账号库，不会自动合并尚未上传的本地修改。

## 云端动作回收站

2.2.11 起，在设置的“动作回收站”中切换“本地 / 云端”页签。云端只展示曾同步到服务器、且仍在保留期内的已删除动作；离线账号或未上传的动作仍需依赖本地备份。

1. 登录对应账号，打开“云端”页签并刷新列表。
2. 找到需要的动作，点击“复制”。
3. 在动作页空白位置粘贴，恢复为一个新的动作副本。

复制不会撤销原删除记录，也不会恢复原动作标识、原位置、分享发布身份或已删除的公共子程序。恢复后请自行放到需要的位置，并检查子程序依赖。若读取的是历史备份，会提示内容可能早于删除前最后版本。

保留期以服务端返回为准，不要把云端回收站当作永久备份。本地页签的复制、清空仍保持原有含义。暂存区的“丢弃”不会进入正式动作回收站。

## 动作运行数据的本地备份

2.2.12 起，可在 **设置 → 数据同步** 中使用“导出运行数据”和“从备份恢复”，一次备份多个已安装动作的状态。适合在重装、换电脑或大范围调整动作前手动留存。

### 导出

1. 打开“导出运行数据”，勾选要备份的动作。
2. 可选填写备注和 ZIP 密码。填写密码后，包内文件使用 AES-256 加密；忘记密码无法恢复。
3. 选择保存位置。备份文件不会自动上传或过期删除，请自行妥善保管。

未设密码的 ZIP 可直接读取其中配置；备注会出现在明文文件名中。动作状态可能包含本机路径或账号凭据，不要把备份交给不信任的人。

### 恢复

先通过账号同步或重新安装恢复动作定义，再打开备份文件。Quicker 只会列出当前已安装且标识匹配的动作；可选择要恢复的项目，并在覆盖前查看原有数据。

:::warning[备份范围]
该 ZIP 只包含已安装动作的运行状态，不包含动作定义、全局共享状态、已卸载动作的遗留状态，也不包含动作自行写入的文件或数据库。它不能替代动作导出、账号同步或整机备份。
:::

## HTTP 与 WebSocket 的本机设置

[HTTP 与 WebSocket 服务](./http-websocket.md)的端口、安全连接、访问范围、开关与凭据按当前账号保存在本机账号目录的 `data/local-settings.json` 中，不随账号同步到其他电脑。换设备后需要重新配置；HTTP 访问令牌在本机加密保存，不能直接复制密文到另一台电脑使用。
