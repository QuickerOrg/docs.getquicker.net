# 屏幕拖选文字

使用 **屏幕选字**：按住引导键，用鼠标拖选屏幕上的文字，松手后通过工具条复制、编辑或翻译。适合提取图片、扫描文档和软件界面中无法直接选取的文字。

这是屏幕文字识别，不会修改原窗口内容。识别效果受字号、清晰度、背景和版式影响；编号、金额等重要内容应先核对。

## 开启 Win＋左键拖选

1. 打开 **设置 → 常用辅助功能 → 其它鼠标操作**。
2. 开启 **Win+左键拖动：选择屏幕文字**。该预设默认关闭。
3. 在需要取字的界面，按住左侧或右侧 `Win` 键，再按下鼠标左键并拖选文字。
4. 松开鼠标，使用结果工具条处理选中文字。

开启预设会同时补齐或启用左右 `Win` 的扩展热键引导键；关闭拖选开关不会关闭这些引导键，避免影响其它组合操作。需要调整引导键时，请检查[扩展热键](/v2/features/triggers/powerkeys)中的对应设置。

此预设优先于相同手势的用户高级鼠标规则；`Win`＋左键与 `Win`＋`Alt`＋左键分别匹配。需要让自定义规则接管相同手势时，先关闭对应的常用辅助功能预设。

## 结果工具条

| 操作 | 用途 |
| --- | --- |
| 复制 | 将识别出的文字写入剪贴板，随后粘贴到其它程序。 |
| 编辑 | 打开文字识别结果窗口，检查、修改和整理文字。 |
| 翻译 | 进入结果窗口的翻译页，按所选服务处理文字。 |
| 表格识别 | 将选区交给表格识别；联网、会员和上传同意要求见[在线表格识别](./ocr.md#hybrid-table-2336)。 |
| 问问 AI（） | 将识别文字带入问问 AI，补充问题后发送。 |
| 其它（） | 打开文本关联动作菜单，将识别文字交给所选动作处理。 |
| 重新选择 | 重新选取需要处理的范围。 |

取字尚未完成或没有可用结果时，相关操作可能暂不可用。若提示缺少识别组件，先按提示完成准备，再用清晰的少量文字重试。

退出选字只结束本次等待，已开始的组件下载、安装会继续，后续取字可复用同一安装任务。

### 使用文本关联动作 {/* #text-actions-2337 */}

识别完成后，点击工具条的 **其它**（省略号），或将鼠标悬停其上，选择要执行的动作。菜单与文本上下文菜单共用动作显隐和排序；可从 **管理文本关联动作…** 调整。没有匹配项时，先检查动作是否启用了文本关联及 **返回上下文文本**，并允许在文本上下文菜单显示。

选择动作或问问 AI 后，当前选字会话会结束，再交给对应窗口处理文字；取消关联动作菜单不会取消整次选字。问问 AI 或关联动作提示不可用时，按提示检查登录状态。

**其它** 菜单也提供文本上下文菜单中的内置操作，可直接处理识别文字；展开子菜单后仍可继续选择其中的操作。

有浮窗局部遮挡时，可选择未被遮挡的周围文字。识别准确度取决于原画面质量，重要内容请校对。

普通文字取字、翻译和表格识别是不同的处理路径。不要因为文字能识别，就认为翻译服务已配置或表格可以离线使用。

### 固定常用动作 {/* #pinned-actions-2341 */}

工具条最多可固定 **3 个已安装动作**，不要求这些动作先配置为文本关联动作：

1. 打开 **设置 → 截图与文字识别 → 屏幕选字**，或从选字工具条的 **其它 → 管理屏幕选字固定动作…** 进入。
2. 点击 **添加动作…**，选择已安装的动作；取消选择不会添加。
3. 选中固定项，用 **上移、下移** 调整顺序，或用 **删除** 移除工具条入口。修改即时保存，**下次选字时生效**；移除固定项不会删除动作本体。
4. 完成一次屏幕选字后，点击工具条中的固定动作处理文字。动作未安装或当前不可用时，按钮不可用，请先安装或重新选择。

动作可通过参数接收本次识别原文；动作内的[获取选中的文本](/v2/xaction/modules/get_selected_text#screen-text-2341)也可重复读取这份纯文本，无需重新选取来源窗口文字。HTML／RTF 仍按来源窗口读取，不会由 OCR 文字生成富文本。固定任意动作只增加快捷入口，不会自动把它改造成文本处理动作，请先确认动作如何接收和使用文字。

## 自定义引导键和触发规则

选字后处理可选 **显示工具栏并复制文字**：识别完成后自动复制文字，工具栏继续保留，方便编辑、翻译或交给其它动作处理。原来的“识别并复制文字”则在复制成功后结束选字会话。内置 Win 拖选预设的默认处理方式不变；需要新模式时，请配置自定义规则，并关闭相同手势的内置预设。

在旧设备使用或回退前，请查看[选字与箭头样式的兼容说明](/v2/migration/upgrade-and-rollback#text-and-arrow-2339)。

需要限定某个程序、使用其它引导键，或指定拖选后的处理方式时，可在 **场景、动作与触发 → 鼠标触发 → 高级鼠标触发** 配置规则：

1. 选择目标场景，新增一条 **划动** 规则。
2. 选择鼠标键和引导键，在常用功能的截图功能中选择 **屏幕选字**。
3. 按编辑器提供的选项选择后处理，例如显示工具条、复制文字、编辑或翻译。
4. 保存后在目标程序中试用，确认不会与其它拖选或扩展热键冲突。

左键划动有额外限制，请以编辑器允许保存的组合为准；可先使用上面的内置 Win 预设体验。附加修饰键与快速截图后处理见[高级鼠标触发](../triggers/advanced-mouse-triggers.md#text-and-capture-2336)。

**屏幕选字** 可直接使用普通键作为左键划动的引导键，引导键可使用普通键或 `Ctrl`、`Alt` 等修饰键。先按住配置的引导键，再按左键拖选；普通键引导只适用于屏幕选字，窗口拖动和快速截图仍按各自限制校验。旧客户端不支持这种规则，请先升级相关设备。

## 使用范围与排障

跨屏复制时，选字结果已就绪、会话仍有效时，即使鼠标移到其它屏幕，物理键盘的 `Ctrl+C` 仍可复制识别文字；识别尚未完成时请先等待。复制采用智能排版结果，减少连续正文的多余换行；从首行中间拖选到下一行时会更准确地合并文字，明显的段落边界仍会保留。重要内容仍需校对。

同次选字中调整范围会复用已有识别结果。识别错误本身仍需校对，不能靠扩大选区保证正确。

首次使用缺少 OCR 组件时，需按提示下载并完成安装；已安装的本地 OCR 会在选字会话中提前准备。

- 选取的是当前可见画面，不会自动滚动原文档，也不会一次提取整份 PDF。
- 文字跨列、背景复杂或字号过小时，可缩小范围、放大原内容后重新选择。
- 复制前先检查结果；需要校对或整理段落时使用 **编辑**。
- 新规则需使用 2.3.36 或以上客户端。旧客户端保存规则可能清除新参数，回退前请先备份并停用相关规则，见[升级与回退](/v2/migration/upgrade-and-rollback#text-and-table-2336)。

在截图或贴图中取字，仍可使用[截图内选字与全文编辑](./ocr.md#截图内选字与全文编辑)或[贴图选字](./ocr.md#贴图上的选字复制)。已有可直接选中的文字也可使用[选中文本工具条](../triggers/text-selection-toolbar.md)。
