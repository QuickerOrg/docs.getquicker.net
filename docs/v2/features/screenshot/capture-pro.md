# 截图 Pro

截图 Pro 是 Quicker 的渐进式选区截图：进入后先出现全屏遮罩，光标附近会给出初始选区；你可以拖拽框选，也可以直接利用**自动选区**快速锁定窗口、面板和具体控件，再标注、复制、保存或贴图。同一界面也可进入长截图或录屏。

在组合动作中，对应步骤为 **截图 Pro**（步骤 Key：`sys:screenCapturePro`）。

## 快速开始

### 作为动作步骤

1. 在动作编辑器中添加 **截图 Pro** 步骤。
2. 按需设置延迟、是否写入剪贴板、是否截图后贴图、是否自动吸附等参数。
3. 运行动作。屏幕进入全屏选区界面。
4. 框选或确认高亮区域，必要时标注，然后复制、保存、贴图或确认结束。

步骤成功后可得到：

- **图片**：截取到的图像变量
- **截图区域**：屏幕坐标 `left,top,right,bottom`
- **保存路径**：若通过「保存」写入磁盘则返回文件路径，否则为空

### 基本操作流程

1. 进入截图后，移动鼠标查看高亮区域；或按住左键拖拽框选。
2. 如果当前高亮还太大，先滚动鼠标滚轮在父 / 子控件之间切换；满意后再单击或按 `Enter` 确认。
3. 按 `Space` 显示或隐藏标注工具栏，进行画框、箭头、文字、马赛克等标注。
4. 用复制、保存、贴图或确认按钮（或对应快捷键）结束；`Esc` 或右键可取消 / 重选。

## 截图 Pro 设置页

2.2.1 起，Quicker 设置中提供 **截图 Pro** 页，用来集中管理截图工具栏、确认后的默认动作、快速保存、贴图和历史偏好。

这些设置影响手动截图和未显式指定行为的场景。通过组合动作步骤调用截图 Pro 时，**步骤参数优先**；例如动作里已经指定了写入剪贴板、截图后贴图或工具栏配置，就按动作步骤当前参数执行。完整发版注意见[官网版本记录](https://getquicker.net/V2/Versions)。

## 选择区域

### 悬停与滚轮

进入截图后，把光标移到目标附近，选区会跟着高亮。范围偏大时，滚一下滚轮，即可在窗口、面板和具体控件之间切换；满意后单击或按 `Enter` 确认。菜单、设置页局部、按钮、输入框等标准界面元素，往往比手动拖框更省事。

把鼠标移入下方演示区可试一下：悬停会吸附到较细的控件，滚轮向上扩大到父级、向下缩小到子级。

### 悬停高亮与框选

进入截图后：

- **移动光标**：可用鼠标，也可用 `W` / `A` / `S` / `D` 微调位置。
- **框选**：按住左键拖拽画出矩形区域。
- **快速选屏**：按 `Ctrl+A` 可先选中鼠标所在显示器，再在当前显示器与全部屏幕之间切换。
- **确认高亮区域**：单击或 `Enter`。
- **取消**：`Esc` 或右键。

确认选区后进入调整阶段：

- **移动选区**：`W` / `A` / `S` / `D`
- **缩放选区**：鼠标滚轮
- **确认**：双击或 `Enter`
- **重选 / 取消**：右键或 `Esc`

### 自动吸附

步骤参数 **自动吸附**（默认关闭）决定悬停时是否主动下钻到更细的控件：

| 设置 | 行为 |
| --- | --- |
| 关闭（默认） | 悬停时优先跟随窗口范围；需要更细的控件层时，用滚轮在父 / 子控件间切换 |
| 开启 | 悬停时持续尝试吸附到更细的控件；仍可用滚轮在层级间切换 |

习惯先看大范围再自己滚轮缩到按钮时，保持默认关闭通常更好控；经常直接截标准控件，可打开 **自动吸附**。自绘界面、游戏、远程桌面等若高亮不准，改用手动框选即可。吸附窗口时，截图 Pro、长截图和录屏会尽量排除窗口阴影，避免把阴影算进截图范围。多显示器或混合 DPI 下若略有偏差，确认后用滚轮或拖动手柄微调。

## 标注

确认选区后，按 `Space` 打开工具栏（再次按下可隐藏）。常用工具包括：

| 工具 | 说明 |
| --- | --- |
| 鼠标操控 | 移动、调整选区，不绘制 |
| 铅笔 | 自由手绘 |
| 矩形 / 椭圆 / 折线 | 形状标注；折线可单击加点，右键或 `Enter` 结束 |
| 套索裁切 | 自由圈选要保留的区域，裁切后可继续保存、复制、贴图或 OCR |
| 箭头 | 指向说明 |
| 序列号 | 步骤编号 |
| 文本 | 添加文字说明 |
| 文字水印 | 输入要显示的文字，设定颜色后斜向平铺到当前截图 |
| 马赛克 / 智能马赛克 | 手动打码，或识别文字区域后自动打码（见下文） |
| 聚光灯 | 压暗周围，突出关注区域 |
| 橡皮擦 | 擦除标注 |
| 撤销 / 重做 | `Ctrl+Z` / `Ctrl+Y` |

工具栏上还可直接进行 OCR、**图片翻译**、保存、复制、贴图，以及进入长截图或录屏。

图片翻译会调用你在开放平台配置的百度 / 有道**图片翻译** API，得到译文贴合图后再复制或替换；配置步骤见 [图片翻译](./image-translate.md)。

需要加入「调用子程序处理图片」或「把图交给某个动作」等按钮时，在 **截图 Pro** 步骤里编辑工具栏：普通场景可用可视化编排，拖放内置工具、分组和自定义命令，并设置整栏图标大小；需要用脚本生成按钮或进阶重排时，再填写 **自定义工具栏脚本**（见 [JS 自定义工具栏](./toolbar-script.md)）。默认只加自定义按钮（原工具栏保留，固定位置出下拉）；只有要改内置工具顺序时才整栏重排。

### 工具栏位置

截图 Pro 工具栏可以拖动并吸附到选区附近；双击拖动手柄可恢复自动定位。进入长截图或录屏后，对应工具栏也提供六点拖动手柄，可停靠在选区四边或自由摆放，双击手柄同样恢复自动定位。

### 马赛克与智能马赛克

马赛克工具是一个**分裂按钮**：左侧主键执行当前模式，右侧箭头在「手动马赛克 / 智能马赛克」之间切换，并记住上次选择。

**手动马赛克**：在图片上拖拽绘制打码区域。副工具条可选效果：

| 效果 | 说明 |
| --- | --- |
| 马赛克 | 像素化打码 |
| 模糊 | 高斯模糊 |
| 填充 | 按邻域取色硬填充，适合 UI 纯色块去字（非 AI 修复） |

**智能马赛克**：自动识别文字区域后再打码：

1. 进入工具后，对当前截图选区（截图界面）或整张图片（贴图）运行 OCR。
2. 悬停可高亮候选文字框；**单击**切换单个候选的打码 / 取消。
3. **拖框**可一次选中多个候选，批量应用为一个撤销步骤。
4. 仍在智能马赛克工具下时，若选区变化会防抖后自动重跑识别。

智能马赛克**不会**打开 OCR 结果窗，也**不会**写入贴图的文本选择层。

## 文字识别（OCR）

截图 Pro 与贴图共用一套本地 OCR 能力，但使用场景不同：

| 场景 | 行为 |
| --- | --- |
| 截图工具栏点 OCR | 结束当前截图会话，打开「文字识别」结果窗 |
| 贴图工具栏 / 右键「识别文字」 | 打开同一结果窗；成功后还会把文字写入贴图的不可见文本选择层 |
| 新建贴图后（自动） | 后台静默识别，不弹结果窗、默认不显示区域边框 |

使用截图 Pro 的斜铺文字水印时，水印会作为标注效果叠加到最终图片中；之后把它贴成贴图再做 OCR，不会把水印文字当成原图内容写入贴图文本层。

### 识别引擎

- **优先本地 OCR**：首次使用需登录 Quicker，并按需下载依赖包（默认快速模型约 7MB，标准模型约 31MB）。
- **本地失败时**：若你在设置中配置了自有百度 OCR Key，会尝试在线识别。
- **不会**使用 Quicker 云端 OCR，也**不会**回退到 Windows 内置 OCR。

基础 OCR 的表格识别与普通文字识别共用本地能力。2.2.3 起，表格识别固定使用准确率更高的 **small** 文字模型，界面不再显示模型选项；旧动作中保存的 **tiny** 设置会被忽略。首次识别表格时，如果 small 模型尚未下载，会先提示下载。

### 结果窗

打开后会先显示预览与进度，识别完成后再填入文字，并显示本次识别耗时。你可以：

- 在左侧缩放查看原图（可隐藏预览区）。
- 在右侧编辑、复制识别文本。
- 切换到 **翻译** 页签，选择源语言、目标语言和服务商；可自动翻译，也可手动重新翻译并复制译文。原文与译文列表可按行同步滚动，行数不一致时会按高度对齐。
- 切换 **快速 / 标准** 模型后重新识别（若该档模型尚未安装，会提示下载）。这个切换只影响普通文字识别；表格识别会按上文固定使用 small 模型。
- 按图片情况开启或关闭 **方向检测**；常见横向图片关闭后可加快识别，旋转图片建议保持开启。
- 使用「自动排版 / 恢复原始排版」整理段落。
- 点「复制并关闭」一次性复制并关闭窗口。

2.1.26 起，OCR 结果窗会减少初始占用并加快首屏显示；切到需要付费识别的公式页签前，Quicker 会先确认，避免误点后直接发起付费识别。2.1.27 起，冷启动时会先显示截图预览，减少等待 Web 内容初始化时的空白和卡顿。若回退到 2.1.27 后修改并保存 OCR 结果窗口偏好，方向检测开关可能被旧版清除；再次升级后会恢复为默认开启，可重新选择。

### 贴图上的选字复制

贴图在移动模式下，可直接在图片上拖选或双击选字，用 `Ctrl+C` 复制。文字层默认不可见；若需要对照识别区域，可在移动模式右键菜单中打开「显示文本区域边框」。

自动 OCR 在后台运行时，若你正在使用铅笔等标注工具，**不会**强制切回移动工具或抢占键盘焦点。关闭贴图会取消尚未完成的识别；从上次会话恢复的旧贴图不会批量重跑 OCR。

## 结束方式

确认选区（并可标注）后，常见结束方式：

| 操作 | 快捷键 / 入口 | 结果 |
| --- | --- | --- |
| 复制 | `Ctrl+C` 或工具栏「复制」 | 将当前图像（含标注）写入剪贴板，并结束截图 |
| 确认截图 | 双击、`Enter` 或工具栏确认 | 把图片返回给动作步骤，不强制写剪贴板 |
| 保存 | `Ctrl+S` 或工具栏「保存」 | 打开保存对话框写入文件；步骤可输出保存路径 |
| 贴图 | `Ctrl+T` 或工具栏「钉住」 | 在选区位置打开浮动贴图窗口 |
| OCR | 工具栏「文字识别」 | 结束截图并打开 OCR 结果窗（仍可能输出图片变量） |
| 长截图 | `L` 或工具栏「长截图」 | 进入长截图流程 |
| 录屏 | `G` 或工具栏「录屏」 | 进入区域录屏 |
| 取消 | `Esc` / 右键 | 取消本次截图或回到重选 |

2.2.1 起，进入可视化录屏时可以预选 **主屏幕**、**所有屏幕** 或 **固定区域**。预选后会跳过手动框选，直接打开录屏工具栏；仍需临时调整范围时，继续使用手动选区方式。对应组合动作步骤见 [屏幕录制](/v2/xaction/modules/screen-recording-ui)。

说明：

- 步骤的 **写入剪贴板** 和 **截图后贴图** 只叠加到默认确认出口（双击、`Enter` 或工具栏确认）。
- 界面内复制、保存、工具栏直接贴图，以及自定义工具栏的 `post.confirm` / `post.pin` 都按各自出口处理，不再额外触发上述两个步骤参数。因此勾选「写入剪贴板」后用保存结束，并不会顺带写入剪贴板；勾选「截图后贴图」后用复制或保存结束，也不会再弹贴图。
- 长截图、录屏、OCR、界面内复制 / 贴图等「另类出口」会在截图界面内完成对应操作；步骤仍可能带上可用的图片、区域或路径输出。
- 成功确认、复制、保存、OCR、直接贴图等操作默认会写入本机**截图历史**（可在采集历史中心查看）；取消、仅选录屏范围、长截图过程中的中间帧不会收录。

## 贴图窗口（截图后）

贴图会把图片浮在屏幕上，方便对照、标注或临时展示。新建贴图后通常会在后台自动 OCR，可直接在图上选字复制（见上文）。

重启 Quicker 后恢复贴图时，如果原显示器仍存在，会尽量保留上次所在屏幕和位置；原显示器已移除时，才会移回主屏可见区域。

通过贴图步骤生成的 HTML 或公式贴图会先在隔离环境中渲染，再以普通图片窗口显示；未信任内容不会执行页面脚本或加载嵌入页面。作为普通图片窗口后，可以正常拖移、显示阴影，并可在自动 OCR 完成后直接选中文字复制。2.1.27 起，HTML、公式或剪贴板贴图窗口已经显示后，不再因后续未生成位图提示而误弹“未产生位图”。剪贴板图片携带的位置也会随复制保留，便于后续贴回原处。

### 移动模式

- **右键短按**：打开菜单（识别文字、图片翻译、复制 / 另存为、图像处理、显示、锁定、历史记录、关闭等）
- **右键拖框**：进入非破坏性缩略图视口
- **`R`**：切换缩略图模式
- **`Shift + 左键双击`**：以双击点为中心进入正方形缩略视口
- **`Ctrl + 滚轮`**：调节窗口透明度
- **`Ctrl + 左键拖动`**：把当前合成图拖到其它程序
- **空格**：显示 / 隐藏标注工具栏
- **`L`**：锁定 / 解锁窗口
- **`T`**：切换置顶
- **`Ctrl+W` / `Esc`**：关闭贴图

### 图像处理与工具栏

- 右键菜单「图像处理」中可用 **抠出主体（透明背景）**；2.1.29 起可手动选择 **通用抠图** 或 **人像抠图**，在本机完成抠图后继续保存或贴图。
- **工具栏隐藏时**：数字键 `1`–`8` 可快速旋转、翻转、灰度、反色、亮度等；`0` 重置滤镜、方向与不透明度。
- **工具栏显示时**：数字键优先选择标注工具（见「快捷键一览」），不再触发图像处理。

首次使用主体抠图需要已登录 Quicker，并下载约 4.4 MB 的独立本地模型；它和 OCR 文字模型分开管理，不会重复下载已有 OCR 模型。

### 显示与缩略图

- 右键菜单「显示」可调缩放（25%–200%）、不透明度预设、窗口阴影、置顶等。
- 缩略图模式下，复制和另存为只输出当前可见部分；完整内容在退出缩略图后仍保留。
- 缩略图视口内可平移、拖拽边缘调整窗口大小；菜单中可用「重置缩略图范围」恢复，或用 **裁剪** 永久裁成当前视口。

### 锁定与历史

锁定窗口后，不能移动、缩放、改透明度或继续标注，但仍可复制、保存、OCR，以及开关置顶 / 阴影等。

右键菜单中的 **历史记录…** 可打开采集历史中心，查看当前贴图、已关闭贴图、截图历史与录屏历史，并做筛选、多选与批量操作。2.1.23 起，采集历史中心还可以管理进行中的录屏，并在页内预览录屏成品、复制、另存或切换播放速度。

## 动作步骤参数

| 参数 | 默认 | 说明 |
| --- | --- | --- |
| 截图前延迟时间 | `0` | 开始截图前等待的毫秒数，便于先打开菜单或隐藏 Quicker 面板 |
| 写入剪贴板 | 关 | 仅默认确认出口结束时把图片写入剪贴板；复制、保存、直接贴图和自定义出口不叠加 |
| 截图后贴图 | 关 | 仅默认确认出口结束时自动贴图；复制、保存、直接贴图和自定义出口不叠加 |
| 贴图后显示工具栏 | 关（高级） | 贴图窗口打开后是否自动显示标注工具栏；关闭时仍可按空格显示 |
| 自动吸附 | 关 | 是否在悬停时持续吸附到细控件；关闭时滚轮再触发精细选区 |
| 自定义工具栏脚本 | 空 | 可选的 JS 脚本，默认只加自定义按钮（原工具栏保留）；写法见 [JS 自定义工具栏](./toolbar-script.md)。留空则使用默认工具栏；推荐外置为动作包内文件 |
| 失败时中止动作 | 视步骤配置 | 用户取消或失败时是否中止后续步骤 |

输出：

| 输出 | 说明 |
| --- | --- |
| 是否成功 | 步骤是否成功 |
| 图片 | 截取图像 |
| 截图区域 | `left,top,right,bottom` |

## 常见问题

### 控件高亮不准或不出现

先确认步骤是否开启 **自动吸附**；关闭时需要滚轮才会进入更细的控件层。若你已经滚轮切换但仍没有更准确的高亮，通常说明目标程序没有提供可靠的 UI 自动化信息，这时请改用手动拖拽框选。

### 截图后剪贴板没有图片

检查是否在截图界面内使用了 `Ctrl+C` / 工具栏复制，或是否通过默认确认出口结束且步骤勾选了 **写入剪贴板**。保存、直接贴图和自定义出口不会叠加该参数；仅默认确认且未勾选时，图片只进入动作变量。

### 保存后没有自动贴图

这是预期行为：只有默认确认出口会叠加步骤侧的 **截图后贴图**。通过复制、保存、直接贴图或自定义出口结束时不会再打开第二个贴图窗口。需要同时保存和贴图时，可先用界面工具完成其中一项，或在后续步骤中处理输出图片。

### OCR 提示需要登录或下载

本地 OCR 依赖按需下载的识别组件，需先登录 Quicker 账号。首次识别或切换更大模型时可能短暂下载；下载完成后同一模型不会重复下载。

### 翻译页签没有译文或想换服务

在 OCR 结果窗切到 **翻译** 页签，先确认源语言、目标语言和服务商，再重新翻译。识别文本变化后可重新翻译；只需要译文时，用页签里的复制按钮复制翻译结果。

### 贴图上看不到文字框，但似乎能选中

这是预期行为：自动 OCR 默认只填充不可见的文本选择层，不显示边框。需要对照区域时，在移动模式右键菜单打开「显示文本区域边框」；也可点 OCR 按钮打开结果窗查看全文。

### 智能马赛克识别不到文字

智能马赛克依赖 OCR 结果。若图片过小、文字过糊或背景复杂，请改用手动马赛克，或先用 OCR 结果窗确认能否识别。

### 图片翻译提示未配置或验证失败

图片翻译需要自备百度或有道的**图片翻译**凭证。2.2.1 起，百度图片翻译 V1 与 V2.0 分开配置；2.2.3 起，百度 V2.0 需要同时填写 **APP ID** 和 **API Key**。V1 APP ID 会自动复用到 V2.0；若此前只填了 V2.0 API Key，请在 **设置 → 识别与翻译** 补填 APP ID。仅开通文本翻译、未开通图片翻译时会失败。详见 [图片翻译](./image-translate.md)。

### 想截下拉菜单或短暂弹出的内容

把 **截图前延迟时间** 设为几百到几千毫秒，先运行动作，再在倒计时内打开菜单，然后再框选。

### 与「屏幕截图」步骤有何不同

**截图 Pro** 面向交互式选区：控件吸附、标注、OCR、贴图、长截图和录屏入口更完整。传统屏幕截图步骤适合更简单的截取需求。新动作优先使用截图 Pro。
