# 桌面录屏、贴图窗口与采集历史

本页说明 **Quicker 截图** 进入后的区域录屏、录屏剪辑与智能缩放、桌面贴图窗口交互、贴图分组以及统一的 **图片、贴图与录屏** 历史管理；截图选区、标注与快捷键见 [Quicker 截图](./capture-pro.md)，文字识别与表格识别见 [截图文字识别（OCR）与表格识别](./ocr.md)。

## 桌面录屏与采集设置

2.2.1 起，进入可视化录屏时可以预选 **主屏幕**、**所有屏幕** 或 **固定区域**。预选后会跳过手动框选，直接打开录屏工具栏；仍需临时调整范围时，继续使用手动选区方式。对应组合动作步骤见 [屏幕录制](/v2/xaction/modules/screen-recording-ui)。

2.2.12 起，本机 Windows 10 2004 或更高版本上，可视化录屏默认不把录屏工具栏录入成品。远程桌面或系统不支持排除时，Quicker 会自动回退到可用的录制方式；开录后请先做一次短录制确认效果。

2.2.17 起，录屏结束后预览会自动获得焦点，可用空格暂停或继续；预览工具条支持调整播放速度。需要边录边生成 MP4 时，可在截图设置中启用本机 ffmpeg（见上文[Quicker 截图设置页](./capture-pro.md#截图-pro-设置页)）。

2.2.26 起，录屏时的鼠标点击提示改为中空圆环，减少对画面内容的遮挡。

2.2.20 起，[屏幕录制](/v2/xaction/modules/screen-recording-ui)和[后台屏幕录制](/v2/xaction/modules/screen-recording)步骤可直接填写 FFmpeg 编码参数。参数会随同一次录制会话固定下来，并用于实时编码、延后转码、预览保存和音频合成；不要在自定义参数里再添加额外输出文件。


## 2.3.31 · 桌面录屏与系统声音 {/* #recording-2331 */}

桌面录屏默认优先使用 DXGI 采集，失败时回退 GDI。2.3.31 同时修复预热、暂停和不同采样率混音时的音画错位；升级后仍建议用实际设备做一次短录制，检查范围和声音。

:::caution[系统音量不再决定录制音量]
支持新采集方式的系统优先在主音量调节前采集系统声音，范围包含 **所有输出设备上其它应用的声音**，排除 Quicker 及其子进程。调低主音量不等于停止录音；不需要系统声音时，请关闭录屏中的 **系统声音** 选项。系统不支持时会回退原采集方式并提示。
:::

这一变化同时影响可视化录屏与[后台屏幕录制](/v2/xaction/modules/screen-recording)中的系统声音采集；不要仅凭当前耳机或扬声器听到的音量判断成品。

## 2.3.33 · 编辑录屏与智能缩放 {/* #recording-edit-2333 */}

录制结束后，可在预览工具栏点击铅笔图标（提示为 **编辑录屏：裁切、截取和智能缩放**）；也可从采集历史中心的 **录屏** 页打开历史项的编辑入口，进入 **编辑录屏**。本次录制未保留到历史时，不能从预览打开历史编辑器。

1. 设置 **开始（秒）** 和 **结束（秒）**，保留一个连续时间范围；也可定位播放位置后点击 **设为起点 / 设为终点**。
2. 在原片画面拖框，或填写左、上、宽、高的百分比，裁切固定画面范围。
3. 有可用点击轨迹时，可勾选 **智能缩放**，按录制时的点击生成镜头；最高倍率可选 1.25×、1.5× 或 1.8×，初始为 1.5×。智能缩放默认关闭；没有点击轨迹、轨迹不完整或自定义参数的坐标未映射时，该项不可用，仍可手动截取、裁切。
4. 点击 **预览效果** 按当前方案生成预览，整段生成完成后播放；可用 **查看原片** 对照。长视频可能需要等待，生成期间可取消，原片不受影响。
5. 点击 **保存编辑**（2.3.33 中名为“保存编辑方案”）保留参数，之后可重新打开继续修改；点击 **导出 MP4** 另外生成成品。只预览或导出不等于已保存方案，需要以后继续编辑时请明确保存。

编辑从保留的原片生成，不会覆盖原片，也不是继续加工上次导出的成品。首尾截取时声音使用相同时间范围；当前不提供多片段拼接、删除中间段或独立音轨编辑。导出格式为 MP4，普通导出文件不包含可编辑工程。

:::caution[编辑源、存储与回退]
新录制可保留鼠标位置、点击等编辑所需数据，原片和方案随本机录屏历史留存，不随账号同步；关闭历史或明确不保留历史的录制不会因此永久留源。编辑资产会增加磁盘占用，并计入历史清理。

重要录屏请在历史中保护并另行备份。删除或自动清理历史可能同时删除源文件和编辑数据；回退旧版前，先导出需要的成品并备份完整录屏历史，详见[2.3.33 升级与回退](/v2/migration/upgrade-and-rollback#recording-and-account-2333)。
:::

### 2.3.36 · 实时按键提示与敏感输入 {/* #recording-key-privacy-2336 */}

**实时按键提示不再自动检测密码框并隐藏。** 输入密码、验证码或其它敏感内容前，请暂停录屏或关闭按键提示，不要依赖密码框识别保护录制内容。已经录入原片的提示不能仅靠关闭后期显示移除。

录前智能缩放所使用的后期按键提示仍按其既有规则过滤普通打字；这与普通录制中的实时提示不同，开始录制前应检查实际使用的模式。

### 2.3.34 · 录前智能缩放与历史成品 {/* #recording-auto-zoom-2334 */}

在录制工具栏打开 **智能缩放**，勾选 **启用智能缩放**，可在停录后自动生成缩放成品。首次默认关闭，之后记住选择；可设置最大倍率。需要先开启录屏历史，并选择 **原生边录边编码 MP4**，不满足条件时界面会说明原因。此处是交互式录制选项，不代表后台录屏步骤已开放同名参数。

开启后，现场不显示按键提示，也不把提示录入原片；开启键盘提示时，在预览和成品输出中叠加，并固定过滤普通打字。关闭键盘提示则不记录提示标签。普通录制仍使用原有现场提示和打字过滤设置。

2.3.34 调整了智能缩放的进出、跟随和连续操作间的镜头衔接。编辑器还提供：

- **允许裁掉原片中的按键提示**：默认关闭。对已经录入原片的提示，勾选后可优先放大操作区域，提示可能落在画面外。
- **显示按键提示**：控制新录制所记录提示的预览和输出；不能删除已经录入普通原片的提示。
- **更新历史成品**：保存当前编辑设置、生成视频，并替换录屏历史中的成品；保留原片。与只保存参数的 **保存编辑**、另外生成文件的 **导出 MP4** 分开使用。
- **另存原片**：复制未应用当前编辑的源视频。导出或另存成功后，会在资源管理器中选中文件。

自动生成期间可取消，草稿会保留，可从录屏历史继续编辑。历史项显示 **有未生成的编辑** 时，上次成品与当前草稿不同，不能把已有成品当作新编辑已完成。重新预览或生成旧项目也会使用新版缩放算法，已导出的视频不会自动改写。

回退旧版前，请先导出所需成品并备份完整录屏历史。旧版重新生成不能合成本版的后期按键提示，保存方案也会丢弃新增偏好，详见[2.3.34 升级与回退](/v2/migration/upgrade-and-rollback#recording-and-fullscreen-2334)。


## 贴图窗口（截图后）

贴图会把图片浮在屏幕上，方便对照、标注或临时展示。新建贴图后通常会在后台自动 OCR，可直接在图上选字复制（见上文）。

2.2.23 起，贴图窗口的系统标题栏不再随图片内容变化；图片标题改在窗口内、图片下方显示，便于在任务栏和窗口列表中辨认贴图窗口。

重启 Quicker 后恢复贴图时，如果原显示器仍存在，会尽量保留上次所在屏幕和位置；原显示器已移除时，才会移回主屏可见区域。

通过贴图步骤生成的 HTML 或公式贴图会先在隔离环境中渲染，再以普通图片窗口显示；未信任内容不会执行页面脚本或加载嵌入页面。作为普通图片窗口后，可以正常拖移、显示阴影，并可在自动 OCR 完成后直接选中文字复制。2.1.27 起，HTML、公式或剪贴板贴图窗口已经显示后，不再因后续未生成位图提示而误弹“未产生位图”。剪贴板图片携带的位置也会随复制保留，便于后续贴回原处。2.2.15 起，HTML 贴图会按最大宽度自动换行；固定布局或超长内容按比例缩小，并改进贴图在屏幕内的定位（[#489](https://github.com/QuickerOrg/Quicker2-issues/issues/489)）。

2.2.25 起，进一步加强自动识别、剪贴板等来源的 HTML 贴图隔离，阻止其中的页面脚本执行。动作作者在步骤中**明确选择 HTML 模式**时，仍可保留脚本能力；不要把剪贴板或自动识别得到的未信任 HTML 当作可执行内容。

### 移动模式

- **右键短按**：打开菜单（识别文字、图片翻译、复制 / 另存为、图像处理、显示、锁定、历史记录、关闭等）
- **右键拖框**：进入非破坏性局部显示视口
- **`R`**：切换局部显示模式（旧称“缩略图模式”）
- **`Shift + 左键双击`**：以双击点为中心进入正方形缩略视口
- **`Ctrl + 滚轮`**：调节窗口透明度
- **`Ctrl + 左键拖动`**：把当前合成图拖到其它程序
- **空格**：显示 / 隐藏标注工具栏
- **`L`**：锁定 / 解锁窗口
- **`T`**：切换置顶
- **`Y`**：切换窗口阴影
- **`Ctrl+W` / `Esc`**：关闭贴图

2.2.17 起，贴图支持**鼠标穿透**：开启后鼠标可点到贴图后方的窗口；可用独立工具条调节不透明度、恢复操作，或关闭贴图。需要临时对照文档又不想挡住点击时，打开穿透即可。2.2.18 起，穿透模式下也可通过这条工具栏拖动贴图，工具栏定位更准确；同时修复了空格显示工具栏和右键菜单遮挡相关问题。

2.2.20 起，贴图窗口按 `Y` 可直接切换窗口阴影；正在编辑文字时不会抢走输入，`Ctrl+Y` 仍按重做处理。同版起，右键菜单中的常用窗口状态操作提升到一级菜单，二维码相关操作移到识别子菜单中。

### 2.3.31 · 多张贴图一起操作 {/* #pin-multi-select-2331 */}

在桌面贴图的 **移动模式** 下，按住 `Ctrl` 点选多张贴图；`Ctrl+A` 全选当前组的可见贴图。选中后可一起移动、缩放和关闭。此处的选择对象是桌面贴图，不是标注图形，也不会选中其它组或已隐藏的贴图；批量关闭前先核对选中范围。

隐藏后恢复贴图时，2.3.31 也修复了前后层级改变的问题。

### 图像处理与工具栏

2.3.37 起，贴图编辑工具条提供 **关闭贴图** 按钮；它会关闭当前贴图，区别于只结束编辑、收起工具条的确认按钮。

2.3.39 起，贴图编辑工具条增加 **表格识别** 入口，可直接将当前图片交给识别结果窗口处理。它沿用[在线表格识别](./ocr.md#hybrid-table-2336)的联网、会员、上传同意和平台限制，不等同于普通本地选字。

- 右键菜单「图像处理」中可用 **抠出主体（透明背景）**；2.1.29 起可手动选择 **通用抠图** 或 **人像抠图**，在本机完成抠图后继续保存或贴图。
- Quicker 截图和贴图菜单可控制标注工具栏显示；需要临时隐藏或恢复工具栏时，不必进入设置页。
- **工具栏隐藏时**：数字键 `1`–`8` 可快速旋转、翻转、灰度、反色、亮度等；`0` 重置滤镜、方向与不透明度。
- **工具栏显示时**：数字键优先选择标注工具（见「快捷键一览」），不再触发图像处理。

首次使用主体抠图需要已登录 Quicker，并下载约 4.4 MB 的独立本地模型；它和 OCR 文字模型分开管理，不会重复下载已有 OCR 模型。

### 2.3.24 · 自动折叠、复制与缩放 {/* #pin-interaction-2324 */}

在贴图右键菜单中勾选 **自动折叠**，贴图失去焦点且鼠标移出约 300 毫秒后，会缩成带边框的小预览；悬停约 200 毫秒或点击即可展开。此项默认关闭，按每张贴图记住，只保存在本机。窗口仍有焦点、正在编辑或处理图片时不会折叠；取消勾选会恢复展开。

自动折叠只临时缩小窗口，不裁切图片，也不等同于下面的 **局部显示模式**。折叠时会隐藏标注工具栏，展开后恢复正常操作。

- 工具栏的复制按钮：单击复制；双击在复制成功后关闭贴图，失败时保留窗口。
- `C` / `Ctrl+C`：优先复制选中的文字，没有选中文字时复制图片；提示会区分复制类型。
- `Shift+滚轮`：以鼠标所在位置为中心缩放；中键按最近的缩放中心恢复。

回退旧版后保存贴图或截图历史，可能清除自动折叠偏好，图片不因此丢失。备份范围见[2.3.24 升级与回退](/v2/migration/upgrade-and-rollback#pin-and-step-inputs-2324)。

### 2.3.30 · 拖动右下角缩放 {/* #pin-corner-zoom-2330 */}

在普通贴图的移动模式下，将鼠标移到图片右下角，出现斜向缩放光标后按住左键拖动，可等比放大或缩小贴图。松开提交；拖动期间按 `Esc` 取消本次缩放。

局部显示、自动折叠、锁定、鼠标穿透、取色或图片处理期间，此入口不可用；正在编辑标注文字时也不会开始角落缩放。缩放改变显示大小，不裁切原图。窗口贴图是另一种功能，操作见[窗口贴图缩放](#窗口贴图缩放)。

隐藏贴图时，编辑工具栏也会同步收起，不再因残留焦点继续响应工具栏按键。

### 右键拖框与鼠标手势 {/* #pin-right-button-2332 */}

2.3.32 起，在 **设置 → 截图 → Quicker 截图** 中可关闭 **右键拖动仅显示框选区域（局部显示）**。开关默认开启，保持右键拖框的原有操作；关闭后，可在贴图的 **移动模式** 下使用右键触发操作，例如鼠标手势。中键等其它鼠标按键不受这个开关影响。

关闭右键拖框后，仍可通过贴图右键菜单或 `R` 键切换局部显示。此设置随账号同步，修改后也会应用到已打开的贴图。

### 显示与局部显示

- 右键菜单可直接处理常用窗口状态；「显示」中仍可调缩放（25%–200%）、不透明度预设、窗口阴影、置顶等。
- 局部显示模式下，复制和另存为只输出当前可见部分；完整内容在退出局部显示后仍保留。
- 局部显示视口内可平移、拖拽边缘调整窗口大小；菜单中可用「重置局部显示范围」恢复，或用 **裁剪** 永久裁成当前视口。2.3.23 及以前的菜单名称为“缩略图模式”和“重置缩略图范围”。

### 锁定与历史

锁定窗口后，不能移动、缩放、改透明度或继续标注，但仍可复制、保存、OCR，以及开关置顶 / 阴影等。

右键菜单中的 **历史记录…** 可打开采集历史中心，查看当前贴图、已关闭贴图、截图历史与录屏历史，并做筛选、多选与批量操作。2.1.23 起，采集历史中心还可以管理进行中的录屏，并在页内预览录屏成品、复制、另存或切换播放速度。

2.2.5 起，贴图支持分组。可在贴图菜单中切换桌面贴图组；采集历史中心可把多张历史图片批量贴图到指定组、在组之间移动贴图，并管理分组。

2.2.7 起，截图侧栏可连续贴出之前关闭的贴图。2.2.8 起，「贴出上一个关闭的贴图」更名为「恢复贴图」，可连续恢复最近关闭的贴图，不必先打开采集历史中心。

常用功能和侧栏中的「剪贴板贴图」在 2.2.8 起支持富文本 HTML、公式、纯文本和图片文件，不再仅限于位图。


### 2.3.22 · 快捷切换贴图组 {/* #pin-groups-2322 */}

可使用 **上一个贴图组、下一个贴图组、选择贴图组** 切换桌面贴图；从截图按钮右键菜单也可选择组。打开 **设置 → 截图 → Quicker 截图 → 管理贴图组**，可新建、编辑和排序分组。

在采集历史中心的组列表中，可上移、下移或拖动调整顺序；循环切组按保存的顺序进行。组菜单的 **创建切换动作** 可生成固定目标组的动作，再为该动作配置快捷键等触发方式。动作绑定组身份，重命名不影响绑定；目标组删除或换电脑后不存在时会提示，不能靠动作同步复制图片和分组。

2.3.23 起，“切换到指定贴图组”会显示该组全部未关闭的贴图；即使已经位于该组，也会重新显示。

2.3.25 起，可从 **创建动作 → 常用功能 → 截图功能** 创建 **切换指定贴图组显示状态** 动作：不在目标组时切入并显示，已在目标组时切换显示或隐藏。采集历史中心的组菜单可复制组 ID；组重命名后绑定仍有效。这里的显示/隐藏不等于关闭或删除贴图。

浏览历史中的某个组只筛选列表，**不会切换桌面组**；切组也不会删除、关闭或迁移图片。图片预览栏可拖动调整宽度并在本机记住。贴图组、图片及预览宽度仍保存在本机，不随账号同步。

2.3.22 起，从贴图按住 `Ctrl` 拖出统一提供 PNG 文件，便于置入 Photoshop 图层。


<a id="开发版图片与录屏历史管理" />

### 图片与录屏历史管理

从贴图右键菜单的 **历史记录…** 等原有采集历史入口打开。

**2.3.29** 的窗口名称为 **图片、贴图与录屏**，左侧主导航分为 **图片** 和 **录屏**；图片页继续管理图片与桌面贴图。

在图片页左侧选择 **全部图片、截图历史、未打标签**，或浏览全部贴图、具体贴图组和图片标签。图片集合按原图去重；贴图组按桌面实例展示，同一张原图的多个贴图可以分别出现。浏览组只筛选列表，不切换桌面；需要切换时使用组菜单中的明确切换命令。

可结合搜索、来源程序及当前集合提供的筛选条件查找图片。搜索包括标题、日期、已保存的 OCR 文字、标签、来源程序和来源窗口标题；OCR 搜索不会重新识别所有图片。普通交互截图可记录来源程序与窗口标题，旧图片或无法确定来源的记录不会补识别。来源信息仅保存在本机。

#### 图片标签与新截图

标签从 **2.3.29** 起提供，与贴图组独立：标签用于整理原图，贴图组用于组织桌面上的贴图实例。

1. 选中一张或多张图片，在详情区点击 **标签…**，添加或移除标签；多选时只修改你操作过的标签，保留其它标签。
2. 也可把单张或多选图片拖到左侧标签上，追加该标签，不移除其它标签、不移动贴图。
3. 通过 **管理图片标签** 的省略号入口创建、重命名或删除标签。删除标签只解除关联，不删除图片和贴图。
4. 在左侧选中具体标签后点击 **新截图**，成功保存的截图会追加该标签。未打标签集合和顶部标签筛选不自动继承；取消截图或未保存历史时不创建标签关系。

同一原图的多个贴图共享标签。编辑贴图产生另一张原图时会复制原有标签与来源，后续标签修改各自独立。标签与来源只保存在本机，不随账号同步。

#### 查看、识别与桌面操作

选中图片后可复制、另存为或新建 / 恢复贴图；右键提供重命名、贴到指定分组、移动贴图到分组等操作。部分操作支持多选，按钮是否可用取决于选中项的类型和文件是否存在。**关闭贴图（可恢复）** 只关闭桌面窗口；永久删除前应检查选中范围。

2.3.29 在管理窗口增加 **识别文字** 和 **使用系统默认应用打开** 入口，均要求只选一张且文件可用；也可双击右侧图片预览查看大图。查看大图不会激活或恢复桌面贴图。这些是管理窗口的操作入口，不需要先把图片重新贴到桌面上。

需要整理桌面时，可从 **桌面贴图操作** 隐藏或显示当前分组的全部贴图、恢复最近关闭的贴图，或找回屏幕外的贴图。分组菜单可修改名称和颜色；删除分组时按提示迁移其中的贴图。

点击左侧 **录屏** 切换到录屏页。进行中的录屏与已结束的历史分开显示，可对进行中的录屏暂停、继续或结束；历史项可播放、复制文件、另存为、打开所在目录、重命名或移到回收站。2.3.33 起还可从历史项[编辑录屏](#recording-edit-2333)，截取、裁切或按需添加智能缩放。文件缺失的项需先检查所在目录，不能仅凭历史记录认为文件仍可播放。

两页均提供 **保留设置**。重要截图或录屏可标为已保护，避免参与自动清理；保护不等于额外备份，也不参与云同步。调整保留规则后，点击 **保存保留设置**；执行立即整理、清空未保护历史或删除前，先核对保护状态和确认提示。

#### 存储位置与空间占用

截图历史与贴图图片保存在 `%LOCALAPPDATA%\Quicker\ScreenCapture`，通常位于 C 盘，与软件安装位置无关。原图在 `assets` 子目录，缩略图在 `thumbnails` 子目录。按 `Win+R` 输入上述路径即可打开。

标签与来源信息使用独立的本机文件保存。回退 2.3.28 后不会显示这些信息，旧版保存图片目录不会覆盖这份文件；旧版编辑后产生的新原图不会自动继承新版标签。备份与兼容范围见[2.3.29 升级与回退](/v2/migration/upgrade-and-rollback#step-and-image-library-2329)。

可在 **保留设置** 中调整截图历史的条数、天数和容量。已保护的截图不参与自动清理，贴图仍引用的图片也会保留，因此历史容量上限不等于整个目录的硬性容量上限。

目前不能在截图设置中单独更改这个目录；需要转移到其他磁盘时，可使用 **Quicker 安装器 → 工具与诊断 → 迁移 Quicker 数据位置**，整体迁移本机数据。操作步骤、原备份清理和迁回方式见[数据目录与迁移](/v2/install/data-location)。自行另存的图片和保存在自定义文件夹中的录屏成品仍使用各自选择的位置。

<a id="开发版窗口贴图缩放" />

### 窗口贴图缩放

**窗口贴图** 是持续显示来源窗口画面的贴图，与前面的静态图片贴图不同。2.3.1 起支持以下缩放操作：

- 普通滚轮以指针附近的图像位置为中心缩放；中键单击恢复 100%。
- `Ctrl+滚轮` 调整透明度。
- `Esc` 或 `Ctrl+W` 关闭窗口贴图；这不会关闭来源窗口。

从 **2.3.27** 起，还可双击关闭窗口贴图；右键菜单提供放大、缩小、恢复原始大小和关闭操作。关闭的是贴图，不会关闭来源窗口。

缩放只改变贴图显示大小，不调整来源窗口的尺寸。来源窗口最小化或暂时无法取景时，按窗口提示恢复、前置或刷新画面。

2.3.27 也补充了截图、贴图与录屏工具栏的操作提示；通过组合动作“屏幕截图”步骤启动时，同样遵循设置中的快捷键提示开关。


## 贴图渲染与清晰度

2.2.11 起，贴图右键“显示 → 渲染方式”可在“位图”和“矢量（实验）”间切换。矢量模式可改善支持的文字、箭头等标注放大效果，但不承诺更快。截图标注默认仍为位图；已有纯文本贴图保持原有矢量默认。

不支持的效果、圆角或套索裁切等内容会使用位图。实验矢量源只保留在当前贴图窗口：隐藏再显示可复用，关闭后从历史恢复仍使用 PNG；像素处理或替换原图会清除矢量源。

HTML、公式贴图缩放时先显示预览，停稳后按倍率重绘；复制、另存为会等待清晰结果。HTML 文字选择与荧光笔高亮按视觉行处理，跨行选择不再把整段空白也连成一个高亮框。2.2.15 起的自动换行、按比例缩小与屏幕内定位见上文[贴图窗口](#贴图窗口截图后)。
