# 热键联动（V2 变化）

:::info[完整功能说明已合并至功能目录]
热键联动的按键序列配置与场景查找规则请查看主文档 **[热键联动](/v2/features/triggers/hotkey-watchers)**。本页仅保留相对 1.x 的变化与升级注意点。
:::

## 相对 1.x 的主要变化

- **按场景组织序列**：可在程序、网址等场景下配置两段按键序列；同序列本地规则直接覆盖上级，禁用同序列可屏蔽上级。
- **窗口切换时连续识别**：输入第一段按键时前台切换不会简单整段丢弃，后续按键按当前可用场景链继续判断。

## 从 1.x 升级时需要注意

- 原有全局规则与进程过滤条件保留，不会自动拆分为程序或网址场景。
- 本地禁用同序列规则会屏蔽上级规则；恢复继承需删除本地规则。
- 在浏览器网址场景使用联动规则时，建议实测标签页切换确认来源符合预期，并避免与动作快捷键或扩展热键冲突。
