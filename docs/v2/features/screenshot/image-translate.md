# 图片翻译

截图或贴图遇到外文界面、外文资料时，可用 **图片翻译**：把当前图像交给百度或有道的**图片翻译**接口，得到带译文贴合的结果图（图到图），再决定复制或替换原图。

配额与计费由你在开放平台开通的账号决定，Quicker **不提供**内置翻译额度。

:::tip[与 OCR 无关]
图片翻译的 Key **不是**「组合动作模块选项 → 基础 OCR」里的百度 OCR Key。OCR 与图片翻译是两套凭证，互不通用。
:::

## 快速开始

1. 打开 Quicker **设置 → 截图 → 截图设置**。
2. 在 **当前服务** 中选择 **百度翻译开放平台** 或 **有道智云**，并设置 **目标语言**。
3. 按下文申请对应服务，把凭证填进该服务栏目。
4. 点击 **验证图片翻译**，确认成功。
5. 进入 [截图 Pro](./capture-pro.md)：确认选区后打开工具栏，点击 **图片翻译**；或在贴图右键菜单选择 **图片翻译**。

未配置时，软件会提示到 **设置 → 截图 → 截图设置** 填写。设置页右侧和各服务栏目里也有 **配置说明**、**开通** 链接，可直接跳到申请页。

## 选择服务

两家凭证可以同时保存在本机。**当前服务** 决定优先用哪一家。

| 情况 | 实际调用 |
| --- | --- |
| 选中的服务已填齐 | 使用该服务 |
| 选中的服务未填齐，另一家已填齐 | 自动改用已配置的一家 |
| 两家都未填齐 | 提示未配置 |

百度侧推荐填写 **API Key**（图片翻译 V2.0）。有道侧填写 **应用 ID** 和 **应用密钥**。

## 设置项说明

路径：**设置 → 截图 → 截图设置**。

| 项 | 说明 |
| --- | --- |
| 当前服务 | **百度翻译开放平台** 或 **有道智云** |
| 目标语言 | 跟随软件界面、简体中文、繁体中文、英语、日语、韩语、法语、德语、西班牙语、俄语 |
| 百度 APP ID | 百度翻译开放平台控制台中的 APP ID |
| 百度密钥 | 可选。没有 API Key 时作为兼容签名 |
| 百度 API Key | **推荐**。在「API Key管理」创建，用于图片翻译 V2.0 |
| 百度擦除模式 | **高精擦除（推荐）** 或 通用擦除。高精版式更好，耗时可能略长 |
| 有道应用 ID / 应用密钥 | 有道智云应用总览中的应用 ID 与密钥 |
| 验证图片翻译 | 用一张样例图真实调用当前服务，检查凭证和权限 |

### 本机保存，不同步

凭证只保存在本机账号数据中，**不会**随 Quicker 云同步上传。换电脑或重装后需要重新填写。

## 如何使用

### 截图 Pro

1. 进入截图 Pro，框选或确认选区。
2. 按空格显示标注工具栏（若尚未显示）。
3. 点击工具栏上的 **图片翻译**。
4. 等待云端处理；结果窗口打开后预览译文贴合图。
5. **复制图片** 写入剪贴板，或 **替换** 当前选区图像后继续标注 / 结束截图。

未确认选区时无法翻译，需先完成选区。

### 贴图

在贴图窗口右键菜单中选择 **图片翻译**。成功后可 **复制图片**，或 **替换** 贴图内容。

## 申请并配置百度翻译

官方入口：[百度翻译开放平台](https://api.fanyi.baidu.com/)  
产品页：[图片翻译 V2.0](https://api.fanyi.baidu.com/product/233)  
创建 Key：[API Key 管理](https://api.fanyi.baidu.com/manage/apiKey)

这是 **百度翻译开放平台**，不是百度智能云那套图片翻译，也不是旧版「图片翻译」接口。

1. 用百度账号登录 [翻译开放平台](https://api.fanyi.baidu.com/)。
2. 若尚未认证，先在控制台完成开发者认证（个人即可）。
3. 打开 [图片翻译 V2.0](https://api.fanyi.baidu.com/product/233)，点击 **立即使用** 开通。  
   不要只开通旧版「图片翻译」，也不要只开通通用文本翻译。
4. 在控制台记下 **APP ID**。
5. 打开 [API Key 管理](https://api.fanyi.baidu.com/manage/apiKey)，点击 **创建 API Key**。
6. 回到 Quicker **截图设置**：
   - **当前服务** 选 **百度翻译开放平台**
   - 填写 **APP ID**、**API Key**（密钥可留空）
   - **擦除模式** 建议选 **高精擦除（推荐）**
7. 点击 **验证图片翻译**。

:::tip[只填了密钥？]
仅有 APP ID + 密钥、没有 API Key 时，百度 V2.0 往往会返回「token is empty」。请补填 API Key。
:::

选 **繁体中文** 时，百度 V2.0 仍按「中文」发送（开放平台语种表没有独立繁体码）。

## 申请并配置有道智云

官方入口：[有道智云 AI 开放平台](https://ai.youdao.com/)  
接口说明：[图片翻译 API](https://ai.youdao.com/DOCSIRMA/html/trans/api/tpfy/index.html)

1. 注册并登录有道智云。
2. 创建应用：选择 **图片翻译**，调用方式为 **API**。
3. 在控制台为该应用开通 **图片翻译** 服务，确认状态为正常。
4. 在应用总览中复制 **应用 ID** 与 **密钥**。
5. 在 Quicker **截图设置** 中：
   - **当前服务** 选 **有道智云**
   - 填入 **应用 ID**、**应用密钥**
6. 点击 **验证图片翻译**。

## 验证与排障

「验证图片翻译」会真实调用接口，可能消耗开放平台额度。

| 现象 | 可能原因 | 处理 |
| --- | --- | --- |
| 提示未配置 | 当前服务和备用服务都没填齐 | 按上面步骤填写后验证 |
| 百度提示 token 为空 / 签名错误 | 未填 API Key，或 Key 不正确 | 在 [API Key 管理](https://api.fanyi.baidu.com/manage/apiKey) 创建并填入 |
| 百度提示未开通图片翻译 V2.0 | 只开了文本翻译或旧版图片翻译 | 到 [产品页](https://api.fanyi.baidu.com/product/233) 单独开通 V2.0 |
| 验证失败但文本翻译正常 | 开错了产品 | 图片翻译与文本翻译、OCR 不是同一套权限 |
| 换电脑后不能用 | 凭证不同步 | 在新电脑重新填写 |

:::tip[验证与正式使用]
验证成功通常表示 APP ID / API Key（或有道应用 ID / 密钥）正确，且已开通**图片翻译**权限。
:::

## 结果与限制

| 说明 | 详情 |
| --- | --- |
| 结果形态 | 厂商返回的贴合图（图到图），不是纯文本译文窗 |
| 网络 | 需要能访问对应开放平台接口 |
| 配额 | 按服务商套餐计费；免费额度用尽后需在开放平台续费或升级 |
| 效果 | 小字、艺术字、复杂背景、倾斜文字等可能导致识别或贴合不佳 |
| 不包含 | 不调用 Quicker 云端翻译；不做「图片到文本 / 大模型翻译」模式；不与动作里的文本翻译步骤共用 Key |
