# 专业版权益与版本限制

部分功能会在使用前检查当前账号权益，例如动作历史版本、动作回收站以及导入导出动作定义。若客户端显示版本限制提示，先确认当前登录账号及权益状态；取消提示不会执行被限制的操作。

V2 的开放范围与普通功能额度是两件事。安装和登录前请先阅读[当前开放限制](/important-notice)，不要只依据 1.x 手册判断 V2 是否可用。

## 购买与续费

当前价格、套餐、有效期及可用权益以[官网价格与权益页面](https://getquicker.net/pricing)和购买时的说明为准。购买前核对登录账号；续费后如客户端状态未更新，请先检查联网和账号信息。

购买支持 Quicker 的持续开发与维护。实际需要哪些付费能力，应按当前功能说明和自己的使用需求决定；此页不承诺尚未开放的能力。
