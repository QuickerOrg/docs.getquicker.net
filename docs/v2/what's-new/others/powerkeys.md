# 扩展热键

扩展热键可以把一个普通按键或鼠标键作为“引导键”，再配合另一个按键执行操作。例如：

- 按住空格再按 `E`，启动 Everything 搜索；
- 按住右键再按 `A`，执行指定动作；
- 以 `CapsLock`、`Win` 或其它不常用按键为引导键，建立一组容易记忆的快捷操作。

Quicker 2.x 重新整理了扩展热键的识别机制和设置界面。重点不是增加更多组合，而是让 Quicker 更准确地区分“用户正在打字”和“用户有意按下扩展热键”，同时减少吞键、误触和与鼠标功能冲突的情况。

## 更准确地识别按键意图

当空格、字母等普通输入键同时作为引导键时，单看按键按下的先后顺序并不能确定用户意图。快速输入 `fa` 和按下扩展热键 `F+A`，开始时都会产生 `F` 按下、`A` 按下两个事件。

2.x 会综合参考最近是否仍在连续输入、第二键出现的时间、两个键的抬起顺序以及引导键按住的时长，再决定恢复普通输入还是触发扩展热键。

以平衡模式下的 `F+A` 为例：

| 操作顺序 | 处理结果 |
| --- | --- |
| 依次按下 `F`、`A`，先松开 `F` | 恢复普通输入 `fa` |
| 依次按下 `F`、`A`，先松开 `A` | 触发扩展热键 `F+A` |

这项改进尤其适合把空格、字母或标点作为引导键的用户。快速滚键、长按自动重复、按错第三个键或组合动作失效时，Quicker 也会尽量恢复完整的普通输入，避免丢字或重复执行动作。

## 三种激活策略

每个键盘引导键都可以单独选择激活策略。

### 仅作为引导键

该按键只用于扩展热键，不再保留原来的单键输入功能。

这种模式不需要猜测用户是不是在打字，组合键按下后可以立即识别，也不使用前序保护、抬起判定和按住确认等时间参数。

适合：

- `CapsLock`、不常用功能键或专用外接键；
- 不需要保留单键功能的按键；
- 更重视响应速度、希望组合立即触发的场景。

### 平衡模式

该按键既能正常输入，也能作为扩展热键引导键。Quicker 会根据连续输入状态和抬起顺序区分两种意图。

这是大多数空格和字母引导键的推荐选择，也最接近 1.x 的使用习惯，但对快速打字的保护更加完整。

### 输入优先（试验）

只有引导键达到“按住确认”时间后，组合键才会触发；按住时间不足时优先恢复普通输入。

适合打字速度较快、经常因为滚键误触扩展热键的用户。代价是需要有意识地稍微按住引导键，触发速度会比平衡模式慢一些。

:::tip[如何选择]

- 引导键不需要输入原字符：选择“仅作为引导键”。
- 希望兼顾输入速度和组合响应：先使用“平衡模式”。
- 空格或字母仍然容易误触：尝试“输入优先”。

:::

## 全局默认与逐引导键设置

2.x 把扩展热键的设置分成两层：

- **扩展热键功能设置**：保存所有引导键共用的默认参数；
- **引导键设置**：为当前引导键选择策略，并可覆盖全局默认值。

在“场景与动作管理 → 扩展热键”中，可以通过右上角的“扩展热键功能设置”按钮打开全局设置。管理页本身分为“按键动作”和“引导键设置”两个标签页，启用状态、激活策略和添加动作入口始终显示在上方。

常用参数的含义如下：

| 参数 | 作用 |
| --- | --- |
| 前序保护 | 引导键距离上一次按键太近时，认为用户仍在连续打字，按普通输入处理 |
| 抬起判定 | 平衡模式下，在这段时间内通过两个键的抬起顺序判断用户意图 |
| 按住确认 | 输入优先模式下，引导键至少按住多久后组合才允许触发 |
| 未配置组合处理 | 抬起判定结束后遇到没有设置的组合时，恢复普通输入或忽略该键 |
| 单键恢复超时 | 仅长按引导键超过此时间后，不再补发它原来的单键输入 |

“未配置组合处理”只在抬起判定时间结束后生效。判定时间内如果发现更像快速打字的未知组合，Quicker 会优先恢复普通输入，避免因为“忽略未配置组合”而吞掉文字。

:::note[单键恢复超时]

该参数只决定是否恢复引导键原来的按键输入。即使超过时间，已经为“单独按下引导键”配置的动作仍可能执行。

:::

## 打字节奏校准

扩展热键功能设置中提供打字节奏校准。点击测试区域后，按平常节奏连续输入至少 6 个按键，Quicker 会根据相邻按键间隔给出以下建议：

- 前序保护；
- 抬起判定；
- 按住确认。

校准只统计时间间隔，不记录按键内容、输入文字、当前程序或完整按键序列。建议值不会自动改变现有行为，需要点击“采用建议值”，再应用设置后才会保存。

如果只想估算日常打字节奏，可以输入一段自然、熟悉的文字，例如：

> 今天天气不错，我正在测试 Quicker 扩展热键的输入节奏。

不需要刻意追求速度，按平时打字习惯输入更有参考价值。

## 右键扩展热键与轮盘、手势协作

2.x 改进了鼠标功能之间的冲突处理。启用右键轮盘后，即使没有移动鼠标，1.x 中某些情况下也可能导致“右键+字母”无法触发。

现在，右键扩展热键、轮盘、鼠标手势和长按动作会共同判断当前操作意图：

- 按住右键再按字母，可以触发对应的扩展热键；
- 按住右键并移动鼠标，仍可进入轮盘或手势；
- 长按右键打开面板后，只要右键仍未松开，还可以继续触发“右键+字母”；
- 一旦扩展热键已经确定触发，同一次按住过程不会再误转成轮盘或手势。

这样可以继续保留 1.x 中“长按右键打开面板，再使用右键组合”的操作习惯，同时减少多个鼠标功能争抢同一次输入的问题。

## 诊断最近一次判定

引导键设置页会显示最近一次判定摘要。遇到“为什么这次恢复了普通输入”或“为什么组合没有触发”时，可以按实际方式重现一次，然后点击“刷新”查看原因。

常见原因包括：

- 距离上一次输入太近，进入前序保护；
- 根据抬起顺序恢复了普通输入；
- 输入优先模式下尚未达到按住确认时间；
- 组合没有配置，并按当前策略恢复或忽略；
- 引导键被长按取消；
- 组合已触发，后续自动重复被抑制。

## 从 1.x 升级时需要注意

已有引导键会尽量保留原来的单键行为：

- 原来不保留按键功能的引导键，会映射为“仅作为引导键”；
- 原来保留按键功能的引导键，会映射为“平衡模式”；
- 不会自动把已有引导键切换到“输入优先”。

升级后建议重点检查：

1. 以空格、字母或标点为引导键的组合；
2. 使用左侧 `Ctrl`、`Alt`、`Shift` 或 `Win` 作为引导键的规则；
3. 同时启用了右键轮盘、手势、长按和右键扩展热键的规则；
4. 依赖“未配置组合忽略”行为的配置；
5. 单独按下或长按引导键时需要执行的动作。

`Win` 键作为引导键时，可以保留常见的 Windows 系统快捷键兼容。该选项只会在当前引导键为左侧或右侧 `Win` 键时显示。

## 当前限制

- “输入优先”仍属于试验策略，建议先为少量引导键启用并观察实际手感；
- 不同输入法、键盘布局和打字习惯差异较大，校准建议不能代替实际试用；
- Quicker 目前不会把输入法已经开启等同于“正在组字”，以免在不同应用和输入法中产生不可靠判断；
- 扩展热键的在线分享和在线安装暂时停用，等待分享数据具备明确的 2.x 版本兼容能力；本地设置和规则使用不受影响。
