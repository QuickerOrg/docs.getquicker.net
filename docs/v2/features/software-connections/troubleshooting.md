先判断问题发生在哪一层：**安装器是否识别并安装 → 宿主是否加载 → Quicker 是否显示在线 → 命令是否适合当前文档**。从最早失败的一步检查，不必反复重装所有软件。

## 没有检测到软件

在安装器中刷新状态，核对[软件指南](./index.md#支持的软件)列出的版本与架构。能运行宿主不一定意味着它的安装信息完整；便携版、注册表残留、未初始化的用户配置可能影响检测。

Cinema 4D、InDesign 等需要先启动并退出一次以生成用户配置。仍未识别时记录软件版本、真实安装位置与安装器错误。不要把另一个年份的 DLL 或插件目录强行复制过来。

## 已安装，但没有连接

确认 Quicker 正在运行，完全退出并重新启动宿主。在 Quicker **设置 → 软件连接**刷新状态。安装器的已安装状态只检查落盘或厂商插件清单，不保证运行中的进程加载了插件。

查看宿主插件管理器或首次信任提示。Adobe UXP 软件需按[各软件指南](./index.md#支持的软件)打开状态面板；Revit、SketchUp 可能需要批准加载。WPS 还需要发行版支持 JSA；其正式分发流程目前仍处于预览。

## 提示宿主正在运行，按钮不可用

保存所有文档，退出列出的全部宿主实例。关闭文档窗口不一定结束进程；多个年份也可能共用插件目标。等待进程退出后刷新，不要强制结束仍有未保存工作的进程。

## 插件被阻止、禁用或未批准

核对插件来自统一安装器及对应软件的加载提示。只批准确认来源的插件。正式 Illustrator、After Effects CEP 包不要求开启 `PlayerDebugMode`；不要通过全局降低插件或宏安全设置来试错。

遇到企业策略限制，向管理员提供软件、插件和具体提示。宿主许可、可信路径及宏安全约束仍然有效。

## 命令工具没有实例，或 ping 失败

先刷新实例，再刷新命令，确认没有选择已经退出的旧会话。查看软件连接页的本机服务和连接诊断；若服务启动失败，记录错误后尝试正常重启 Quicker。

连接反复断开时，检查宿主是否正在退出、重复加载插件或被安全软件拦截。不要固定修改本机端口。关闭阻塞宿主的对话框后，用 `bridge.ping` 再试；它成功后才继续测试业务命令。

## 命令为空、不支持或参数无效

清除筛选条件，在正确实例上刷新命令。目录来自该实例的 `command.list`；旧 Bridge 可能没有新命令。完成更新并重启宿主后再确认。

参数按模板填写合法 JSON 对象。检查双引号、逗号、数字与字符串类型，以及 Windows 路径转义，参阅[参数填写](./command-tool.md#选择命令与填写参数)。部分命令还要求打开文档、选中对象或处于特定编辑模式。

## 目标不明确或前台软件不正确

查看[目标路由表](./command-tool.md#动作怎样选择目标)。精确路由的软件必须在触发时位于前台，且该进程已连接；其他在线进程不能替它接收动作。

Photoshop、Premiere Pro、After Effects 还要求唯一在线会话；Illustrator、InDesign 仅以唯一会话选择目标。多会话时先在命令工具核对，保存工作并关闭多余会话后再运行动作。

WPS 同一窗口可能对应文字、表格、演示多个会话。对 `bridge.ping` 等通用命令明确选择目标组件；不要用“自动”猜测应操作哪个组件。

## 安装完整性提示需要修复

退出宿主，在安装器详情中重新安装，完成后刷新检测并重启宿主。若修复失败，检查磁盘、文件占用及权限提示。不要删除整个宿主插件目录，也不要用旧开发脚本覆盖正式安装。

## 代理或安全软件影响本机连接

Bridge 连接本机 Quicker。企业代理、安全软件或宿主网络策略可能阻止它访问本机服务；记录具体拦截提示，再向管理员申请针对性的允许。不要关闭全部安全软件或把本机服务开放到公网。

## 反馈时提供什么

提供 Quicker、安装器、宿主和 Bridge 版本，复现步骤，出错阶段，完整错误，以及软件连接页复制的诊断信息。涉及命令时附命令名与可复现参数；先移除私人文件路径、设计内容和凭据。说明是否多实例、是否有模态对话框及最近是否更新插件。
