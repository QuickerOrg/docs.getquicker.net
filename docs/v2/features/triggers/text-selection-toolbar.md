# 选中文本工具条

选中文本工具条可以在鼠标附近显示一组常用操作，让你在选中文字后快速复制、搜索、翻译，或运行自己的 Quicker 动作。

此功能需要 Quicker 专业版，并且默认关闭。

## 快速开始

1. 打开 Quicker 设置，进入 **功能 → 选中文本工具条**。
2. 勾选 **启用文本选择候选动作工具条**。
3. 至少选择一种显示方式：
   - 勾选 **抬起鼠标后自动显示**；
   - 设置一个 **主动显示快捷键**。
4. 点击 **设置默认动作清单…**。
5. 在打开的“场景与动作管理”窗口中点击 **添加…**，选择要执行的操作，然后保存。
6. 回到设置窗口保存设置。

现在可以在其它程序中选中一段文字：

- 开启自动显示后，用鼠标拖选、按住 Shift 扩展选区或双击选词，工具条会尝试显示在鼠标附近。
- 使用主动快捷键时，先选中文字，再按下设置的快捷键。

点击工具条中的项目即可执行对应操作。

## 设置显示方式

### 自动显示

开启 **抬起鼠标后自动显示** 后，Quicker 会根据鼠标操作和光标形态判断是否刚刚选择了文本。

自动显示适合经常对选中文字进行处理的场景。如果工具条影响了连续选择或编辑文字，可以关闭自动显示，只保留主动快捷键。

自动检测依赖目标程序提供的鼠标光标和窗口信息，因此不同软件中的触发效果可能不同。

### 主动显示快捷键

设置快捷键后，可以在需要时主动显示当前场景的候选操作。主动快捷键可以单独使用，不需要开启自动显示。

快捷键只负责显示工具条，不会预先读取选中文字，也不会额外复制或改写剪贴板。需要使用选中文字时，应由所配置的操作或动作读取当前选区。

### 悬浮圆点与选区定位

2.2.1 起，选中文本工具条可以先显示一个悬浮圆点，也可以尝试按文本选区位置定位工具条。这两个选项默认关闭，需要在 **设置 → 功能 → 选中文本工具条** 手动开启。

按选区定位依赖目标程序能提供可靠的选区位置。自绘编辑器、远程桌面、浏览器内复杂页面等场景可能定位不准；遇到偏移或遮挡时，可关闭该选项，改回鼠标附近显示或主动快捷键呼出。完整发版说明见[官网版本记录](https://getquicker.net/V2/Versions)。

## 配置候选操作

**默认动作清单** 是所有场景的基础清单。可以直接配置复制、粘贴等简单操作，也可以选择“运行动作”，复用已有的 Quicker 动作。

在动作清单中可以：

- 点击 **添加…** 新增操作；
- 选中项目后点击 **编辑…**，或双击项目进行编辑；
- 使用 **上移**、**下移** 调整顺序；
- 直接拖动项目调整顺序；
- 从动作面板拖入一个动作；
- 点击 **移除** 删除不再需要的项目。

编辑项目时，标题、说明和图标都可以留空，Quicker 会根据所选操作自动生成显示信息。列表中的顺序就是工具条中的顺序。

如果删除了工具条引用的 Quicker 动作，该项目会在管理界面中标记为“动作不存在”，运行时也不会显示。

## 调整工具条外观

在功能设置中可以调整：

- **在动作图标旁显示动作标题**：关闭后，已设置图标的项目优先只显示图标；项目标题仍可通过悬停提示查看。
- **最多直接显示动作数量**：可设置为 1～20，默认是 5。

超出直接显示数量的操作会收纳到末尾的 **+数量** 按钮中。点击或将鼠标移到该按钮上可以打开“更多”菜单；也可以在工具条上滚动鼠标滚轮，切换当前直接显示的操作。

鼠标离开工具条后，工具条会稍后自动隐藏。切换场景或继续进行其它键盘、鼠标操作时，工具条也会隐藏。

## 为不同场景设置不同操作

除了全局默认清单，还可以为不同程序或场景设置专用规则：

1. 打开 **场景与动作管理**。
2. 在左侧选择要设置的程序或场景。
3. 打开 **选中文本** 标签页。
4. 选择规则模式并配置操作。

也可以从工具条末尾的 **更多 → 设置** 直接进入 **全局规则** 或 **当前场景规则**。

非全局场景支持以下模式：

| 模式 | 效果 |
| --- | --- |
| 继承上级 | 直接使用上级场景和全局默认清单 |
| 禁用 | 在当前场景中不显示工具条 |
| 追加动作 | 保留继承的操作，并在后面增加当前场景的操作 |
| 替换动作 | 不使用继承的操作，只显示当前场景的操作 |

选择 **追加动作** 或 **替换动作** 后，需要至少添加一个操作才能生效。

## 临时或永久禁用

打开工具条末尾的 **更多** 菜单，可以选择：

- **临时对当前程序禁用**：本次运行期间不再在当前程序中显示，重启 Quicker 后恢复。
- **永久对当前程序禁用**：把当前程序的场景规则设为“禁用”，重启后仍然有效。
- **临时禁用本功能**：本次运行期间在所有程序中禁用，重启 Quicker 后恢复。

如果之后忘记了在哪里禁用，可打开 **设置 → 功能 → 选中文本工具条**，在 **禁用状态诊断** 中点击 **刷新**。这里会列出全局开关、临时禁用状态和场景禁用规则，并提供 **前往设置** 或 **移除禁用** 操作。

## 常见问题

### 选中文字后没有显示工具条

依次检查：

1. 当前账号是否具有专业版权益。
2. 功能总开关是否已开启。
3. 是否开启了自动显示，或设置了主动显示快捷键。
4. 默认清单或当前场景最终是否至少有一个有效操作。
5. 当前程序、当前场景或整个功能是否被临时或永久禁用。
6. 当前程序是否在 Quicker 黑名单中，或受全屏禁用设置影响。

可以使用设置页中的 **禁用状态诊断** 快速检查禁用来源。

### 自动显示在某些软件中不稳定

自动检测需要结合文本光标、鼠标移动和目标窗口信息。部分自绘文本控件、远程桌面、游戏或特殊编辑器可能无法提供足够的信息。

可以关闭自动显示，改用主动快捷键；也可以保留自动显示，并在不适合的程序中通过 **更多 → 临时对当前程序禁用** 或场景规则单独禁用。

### 点击操作后没有取得选中文字

工具条本身不会先把选中文字放入剪贴板。请检查所配置的操作或动作是否会读取当前选区，例如先执行复制，或在组合动作中使用获取选中文本的步骤。

### 候选操作太多

可以在功能设置中增加 **最多直接显示动作数量**，也可以：

- 使用末尾的 **+数量** 按钮打开完整列表；
- 在工具条上滚动鼠标滚轮切换操作；
- 按程序或场景拆分操作清单，只在需要的场景中追加或替换。
