# 更新 Quicker V2

Quicker V2 的逐版本更新记录在官网维护，文档站只整理与安装、更新流程有关的长期说明。

## 查看版本更新

- 逐版本更新记录：[https://getquicker.net/v2/versions](https://getquicker.net/v2/versions)
- 文档站入口：[更新记录](/release-notes)

## 应用内更新

V2 的更新窗口可以直接选择“下载并静默更新”，也可以跳过当前版本或暂不更新。自动安装会校验 HTTPS 下载地址、SHA-256 哈希、安装包签名和发布者；确认更新后，Windows 可能请求一次管理员权限。

详细说明见 [工具与使用体验：应用更新](/v2/what's-new/tools-and-experience#应用更新)。

## 更新前提醒

- V2 当前仍是 Preview，体验前先读 [体验前必读](/important-notice)。
- 如果需要从新版回退到旧版，先确认是否存在数据结构或 AI 凭据格式变化。
- 不要通过安装 1.x 与 V2 并存的方式“回退”；需要回到 1.x 时，重新安装 1.x，并使用迁移前备份。
