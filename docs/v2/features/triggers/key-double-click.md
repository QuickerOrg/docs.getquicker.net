# 按键双击

按键双击可以在不拦截按键原有功能的情况下，监听同一个键连续按下两次并执行操作。例如双击 `Ctrl` 打开搜索，或双击 `Win` 运行一个常用动作。

按键本身不会被 Quicker 拦截。设置字母、方向键或其它常用输入键时，应先确认双击动作不会干扰目标软件。

## 快速开始

1. 打开 **场景与动作管理 → 键盘触发 → 按键双击**。
2. 左侧选择要设置的场景：全局、程序、标题子场景或网址。
3. 新增一条规则，选择要监听的按键，并指定要执行的操作。
4. 保存后，在目标程序中连续按下该键两次（间隔保持在设定范围内）。
5. 需要查看上级规则时，勾选「显示继承的规则」，确认来源后再决定是复制到本场景还是继续继承。

例如，双击 `F2` 可以在文件管理器中批量重命名，在编辑器中运行格式化动作，在其它程序中继续使用全局规则。

## 按场景覆盖与禁用

按键双击沿用「候选回退」习惯，**和动作快捷键、文本指令的禁用语义不同**：

| 操作 | 效果 |
| --- | --- |
| 本地规则启用且条件匹配 | 使用本地规则 |
| 本地规则停用或进程条件不匹配 | 继续查找父场景和全局规则 |
| 删除本地规则 | 同样会继续使用继承规则 |
| 需要完全避免触发继承规则 | 不能只停用本地候选；应调整或移除相应上级规则 |

停用当前候选后，仍会继续尝试其它适用规则。这和 [动作快捷键](/v2/features/triggers/action-hotkeys)「本地同键全部停用则不回退上级」相反。

管理页默认只显示当前场景规则。开启「显示继承的规则」后，可以查看上级规则的真实来源，并将其复制到本场景再修改。浏览器网址场景按当前网址、浏览器程序和全局链路查找规则。

## Windows 键双击

双击左侧 `Win` 时，第一次按下通常会打开开始菜单并改变前台窗口。第一次按下时会保存当时匹配到的双击操作。只要第二次按下的是同一个键且仍在设定间隔内，就执行这次已选中的操作，不会因为按键自身打开开始菜单而丢失。

其它按键在两次按下之间引入新的受监视输入时，仍会重置待完成的双击，避免把不连续操作误判为双击。

使用左侧或右侧 `Win`、任务栏和开始菜单相关规则时，建议按真实路径各试一次。

## 管理和状态

列表会显示：

- 按键和用途说明；
- 操作类型与摘要；
- 规则来源；
- 引用动作失效或操作不可编辑等状态。

支持新增、双击编辑、启停、复制到本场景、多选和批量删除。场景管理首要展示和编辑的是双击操作；旧数据中未在当前界面编辑的其它按键行为会保留。

## 限制与排障

- **双击没有执行**：确认间隔内没有插入其它受监视输入，并检查当前场景最终匹配到的是哪一条规则（含继承）。
- **停用本地规则后全局双击仍触发**：这是预期的回退行为，不是故障。需要完全避免时，应调整或移除上级规则。
- **双击 Win 丢失**：第一次按下打开开始菜单属于正常系统行为；只要第二次仍是同一键且在间隔内，应执行已选中的操作。若仍失败，结合 **最近触发历史** 和 **当前场景诊断** 查看。
- **干扰打字或目标软件**：按键不会被拦截，字母和方向键更适合只在明确需要的场景启用。
- **相对 1.x 的场景化与 Win 键改进**：见 [按键双击（2.x 变化）](/v2/what's-new/others/key-double-click)。
