# 选中文本工具条

Quicker 1.x 的“文本悬浮窗”会在选择文字后展开旧动作页，窗口较大，动作内容也与旧动作页结构绑定。

2.x 使用轻量的“选中文本工具条”替代旧悬浮窗。它只显示当前场景真正需要的候选操作，并把更多项目收纳起来，减少遮挡和误操作。

## 更轻量的显示方式

工具条可以：

- 在鼠标选择文字并抬起后自动显示；
- 关闭自动检测，只通过主动快捷键显示；
- 同时保留自动显示和主动快捷键；
- 选择是否在图标旁显示动作标题；
- 设置直接显示 `1`～`20` 个操作，默认显示 `5` 个。

超出直接显示数量的项目会进入末尾的“+数量”菜单。可以点击或悬停打开完整列表，也可以在工具条上滚动鼠标滚轮切换当前直接显示的操作。

主动快捷键只负责显示当前场景的候选操作，不会预先读取选区、模拟复制或改写剪贴板。需要取得文字时，由所选操作或动作自行读取。

## 按场景追加、替换或禁用

每个非全局场景可以选择：

| 模式 | 效果 |
| --- | --- |
| 继承上级 | 直接使用父场景或全局清单 |
| 追加动作 | 保留继承项目，再加入本场景操作 |
| 替换动作 | 只显示本场景清单 |
| 禁用 | 在当前场景完全不显示工具条 |

这比 1.x 依赖一个文本悬浮动作页更灵活。例如，浏览器保留全局“复制、搜索”，在开发文档网址追加“翻译术语”，在密码管理器中则完全禁用。

## 根据选中文字过滤操作

2.x 可以为每个候选操作设置正则显示条件。Quicker 读取到的完整选中文字只有匹配条件时才显示该项。

例如：

- 只在选中网址时显示“打开链接”；
- 只在选中邮箱地址时显示“写邮件”；
- 只在选中纯数字时显示计算或查询动作；
- 为英文单词显示词典，为中文内容显示翻译。

读取不到文字或正则不匹配时，有条件的项目会隐藏；没有设置条件的项目不受影响。正则支持选择是否忽略大小写，并在保存前检查语法。

## 位置可以按程序记忆

工具条默认显示在本次选择位置附近。也可以直接拖动工具条调整位置，2.x 会按程序记住相对偏移。

不同程序可以有不同位置，例如在编辑器中放到选区上方，在浏览器中放到下方。位置属于当前设备的本地使用习惯，不参与账号同步。通过工具条菜单可以“重置当前程序位置”。

## 动作清单更容易维护

在“场景与动作管理 → 鼠标触发 → 选中文本”中，可以：

- 添加、编辑、删除候选操作；
- 上移、下移或直接拖动排序；
- 从动作面板拖入一个动作；
- 为标题、图标和说明设置工具条专用显示内容；
- 查看引用动作是否已经删除。

展示信息留空时，工具条会根据操作或被引用动作自动生成，不需要重复维护标题和图标。

## 临时禁用与诊断

工具条的“更多”菜单可以：

- 临时对当前程序禁用，重启 Quicker 后恢复；
- 永久对当前程序禁用，写入场景规则；
- 本次运行期间临时禁用整个功能；
- 直接进入全局规则或当前场景规则设置。

如果之后忘记了禁用位置，可以在功能设置中的“禁用状态诊断”查看全局开关、临时禁用状态和场景禁用规则，并直接前往设置或移除禁用。

详细设置步骤和故障排查见[选中文本工具条使用说明](../../features/triggers/text-selection-toolbar.md)。

## 从 1.x 升级时需要注意

- 旧“文本悬浮窗”已停用，不会继续作为 2.x 的规则编辑或运行入口；
- 新工具条默认关闭，需要在“设置 → 功能 → 选中文本工具条”中启用；
- 功能需要当前有效的专业版授权，配置在权益暂时不可用时仍会保留；
- 自动显示依赖目标程序的光标和窗口信息，特殊自绘控件或远程桌面中可以改用主动快捷键；
- 工具条不会自动复制选中文字，旧动作如果依赖悬浮窗预先提供内容，需要改为在动作中主动获取选区；
- 建议先配置少量全局候选，再按程序使用追加、替换或禁用。
