# 加载场景与加载动作页动作

1.x 里常用「加载动作页」把面板切到某一张二维页。V2 新面板改成 **场景 → 分组**；旧动作页仍然可以加载，但日常整理应优先用场景和分组。

## 在面板上切换

- 单击场景标签：切到该场景。
- 上下文区右上角的锁定：停住自动切换；右键可选择要加载并锁定的应用场景。
- 开启「显示分组」后，用右侧导航或「每次显示单个分组」在组之间跳转。
- 右键具名分组，可创建一个「加载此分组」的动作，以后一键回到这个组。

界面细节见 [新面板窗口的使用](/v2/what's-new/new-main-win/usage.md)。

## 用组合动作加载

在组合动作里加入 [Quicker 操作](/v2/xaction/modules/quickeroperations)，按 **类型** 选择：

| 类型 | 做什么 |
| --- | --- |
| **加载动作页** | 把指定旧动作页加载到当前面板。动作页 ID 在「场景与动作管理」里复制。 |
| **加载场景动作（锁定切换）** | 切到某个程序或自定义场景，加载它的动作，并锁定（等同按下锁定按钮）。可填 **切换到分组**。 |
| **加载场景动作（不锁定切换）** | 同样加载场景，但不锁定，之后仍可随前台程序自动切走。 |
| **锁定/解锁 动作页自动切换** | 只切换锁定状态，不指定目标场景。 |

**场景标识**一般填该场景关联的 exe 文件名。**切换到分组**留空则用场景默认；填「未分组」切到未分组。

要让面板跟着鼠标出现：先 **显示面板**（可打开 **跟随鼠标位置**），稍等，再加载动作页或场景。参数表和示例见该模块页。

## 和 1.x 的差别

- 「加载动作页」仍然针对旧的二维动作页，不会自动变成新面板里的分组。
- 新面板里更常见的是加载场景，必要时再切分组。
- 从某个场景或分组移除入口，不会删除动作本体。
