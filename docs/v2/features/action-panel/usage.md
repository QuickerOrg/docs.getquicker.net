# 动作面板使用说明

新面板窗口是 Quicker 2.0 的主要动作入口（默认通过**鼠标中键**弹出动作面板，也可在 **设置 → 基础设置 → 弹出面板** 更改触发方式）。面板按“场景 → 分组 → 动作”组织；同一个动作也可以出现在多个场景或其它触发入口中。

> **先了解一个重要区别**
>
> 在新面板中，**动作本体**和**动作的显示位置**是两回事。
>
> - “从此场景移除”只移除当前场景中的入口，不会删除动作本体。
> - “删除”会删除动作本体，并在确认后清理动作页、场景和触发规则等引用。
>
> 如果只是整理面板，请优先使用移动、分组或“从此场景移除”。

## 如何弹出动作面板与启用新面板 {/* #启用新面板窗口 */}

默认通过**鼠标中键**在屏幕任意位置弹出动作面板，也可在 **设置 → 基础设置 → 弹出面板** 自定义其它鼠标键或快捷键触发。已登录账号启用或切换新面板的方法：

1. 打开旧面板右上角菜单，选择“切换至新版主窗口”；或
2. 打开“设置 → 面板 → 面板窗口”，开启“使用新面板窗口（推荐）”。切换时会直接保存；如果首次整理面板数据尚未就绪，界面会说明原因并恢复开关。

此后，原来用于弹出动作面板的鼠标、快捷键等触发方式会打开新面板窗口。关闭上述设置即可临时切回旧面板；切换窗口不会删除动作或动作页。

本机离线账号固定使用新面板窗口，不能切回旧面板。

### 减少面板弹出闪烁

“面板窗口”设置页提供 **减少面板弹出闪烁（软隐藏，仅新版面板）**，当前入口为“设置 → 面板 → 面板窗口”。默认关闭，且仅本机生效，不会随账号同步。

个别电脑弹出新面板时若出现闪烁或延迟，可尝试开启。软隐藏会让面板在任务切换列表里短暂可见：若发现面板进入 Alt+Tab 或 Win+Tab，请关闭此项。

多设备使用时，建议先统一升级再整理面板；混用旧客户端或降级前，请查看[升级与回退注意](/v2/migration/upgrade-and-rollback)。

## 认识面板结构

分区示意与配置入口见[概览：面板上的设置在哪](/v2/features/action-panel#面板上的设置在哪)（可点击布局图查看）。

### 打开场景、动作与触发 {/* #scene-button-2338 */}

通过面板上的 **场景、动作与触发** 按钮打开管理窗口：

- 单击：打开全局管理入口。
- 按住 `Ctrl` 单击：打开当前程序场景的动作页。

新面板已将该入口固定到侧栏时，顶部不再重复显示，请检查侧栏同名入口。也可以从程序图标或托盘打开。

如果使用旧面板，窗口较窄时，顶栏的更新、场景管理和设置按钮会依次收进右上角菜单，优先保留设置入口；找不到按钮时请展开菜单。更新入口仅在有更新时显示。

### 全局区

全局区用于放置不依赖当前程序、希望随时使用的动作。你可以在这里添加全局场景、通用场景或自定义场景标签。

### 上下文区

上下文区随当前前台程序或网址变化。例如，在资源管理器中弹出面板时，会优先显示资源管理器场景；切换到浏览器后，可以同时出现浏览器程序场景和匹配的网址场景。

“通用”标签默认保留在上下文区末尾，适合放置所有程序都要使用的动作。

#### 通用场景标签显示 {/* #common-scene-tab-2326 */}

在 **面板设置 → 布局与交互 → 显示内容 → 总是显示通用场景标签页** 中，可关闭通用标签的常驻显示。该项默认开启，随账号同步。

关闭后，只有当前自动匹配的上下文没有可用动作，或你主动加载通用场景时，才显示通用标签。手动加载其它场景不会取消当前程序的通用兜底；隐藏标签也不会删除通用动作，仍可主动加载通用场景。

此设置仅控制新版桌面面板的上下文区，不改变全局区中自行添加的标签。

如果不希望上下文继续自动切换，点击上下文区右上角的锁定按钮。再次点击可恢复自动切换；右键该按钮还可以选择要加载并锁定的应用场景。

当前程序还没有配置场景时，面板会直接显示 **创建场景**、**禁止弹出** 和 **关闭提示** 等按钮。只是临时不想为这个程序建动作时，可关闭提示；不希望以后在该程序里弹出面板时，选择禁止弹出。

### 面板主菜单 {/* #工具菜单 */}

从标题栏“更多”打开主菜单后，按用途查找入口：

- **更新与组件**：检查软件更新、检查动作更新、Quicker 组件安装器、安装 WebView2 组件。
- **同步与数据**：同步及数据管理入口，包括应用数据文件夹、用户数据文件夹、动作回收站、整理数据文件碎片。
- **诊断与修复**：[动作运行与触发记录](/v2/features/tools#动作运行与触发记录)、当前场景诊断、键盘状态、[收集并上传诊断报告](/v2/features/tools#收集诊断报告)、修复浏览器扩展连接。
- **开发与导出**：导出动作列表（CSV）、生成模块文档。

**触发规则** 按键盘、鼠标和自动分类，可直达全局场景的对应规则或自动运行、事件触发设置。要编辑特定程序的规则，请从“场景、动作与触发”选择该程序场景；不要把面板菜单打开的全局规则当作当前程序规则。

窗口尺寸入口置于菜单靠前位置。软件列表、动作库和当前软件的桥接工具仍可从面板菜单访问；桥接工具依赖[软件连接](/v2/features/software-connections)，目标软件未安装 Bridge、未运行或没有在线实例时，先检查连接状态。

### 场景标签和分组

全局区和上下文区都可以包含多个场景标签。一个场景内还可以建立多个分组，便于按用途整理动作。

- 单击场景标签：切换场景。
- 双击场景标签：在「场景、动作与触发」管理窗口中打开该场景。
- 右键场景标签：新建或导入动作、重新从旧动作页引入动作，以及打开场景管理。
- 拖动全局区的场景标签：调整标签顺序；“全局”标签也可以移动。松开后顺序会自动保存到当前账号的本机状态。
- **连续显示** 时，各组在同一滚动列表中展示；**单个分组** 时只展示当前组。导航可独立选择上方圆点、左侧圆点或左侧文字分组，详见[面板设置](#视图选项)。存在置顶动作时，还会显示虚拟“置顶”分组。

上下文区的标签由当前程序、网址和场景规则动态生成，不支持拖动排序。

#### 隐藏内容区分组标题 {/* #hide-group-titles-2340 */}

在 **面板设置 → 布局与交互 → 分组 → 隐藏内容区分组标题** 中，可隐去动作内容区的分组标题，减少占用；默认不隐藏，选择随账号同步。分组导航仍按所选模式显示，不会因此删除分组或动作。

### 暂存区

新版主窗口左侧导航栏里，「动作」和「暂存区」是两个图标按钮（不是带文字的侧栏）。点「暂存区」后，右侧内容换成暂存列表。暂存区顶部可直接 **新建动作** 或 **用 AI 写**；暂存动作可以先在本机编辑、试运行和调试，确认后再放入正式场景。详细说明见[本机动作暂存区](./action-drafts.md)。

## 查找和运行动作

- 单击动作磁贴即可运行。
- 正在运行的动作会在磁贴上显示状态小点；旧面板和悬浮动作也使用同样的提示。
- 面板保持悬停显示时，可以直接键入名称或拼音，筛选当前动作区域中的动作；输入过程不会要求面板先取得前台焦点。
- 筛选时用 `↑`、`↓` 选择结果，按 `Enter` 运行，按 `Esc` 清除筛选。
- 点击标题栏的搜索入口，会打开全局搜索窗口；它适合跨场景和其它搜索来源查找。
- 鼠标位于全局区或上下文区时，按住 `Ctrl` 滚动滚轮，可以切换该区域的场景标签；横向滚轮也可以切换标签。
- 需要数字快捷切页时，在面板设置中开启[数字键切换场景标签](#digit-scene-tabs)；默认关闭，与动作的格子触发键不同。
- 底部「最新动作」条可快速再次运行近期用过的动作；这一行只有图标，没有标题。本次启动期间在编辑器中打开查看过的动作也会进入该列表；这不会增加运行次数，也不会改写运行历史。

## 新建、粘贴和导入动作

先切换到目标场景或分组，然后使用以下入口之一：

- 点击「创建动作」磁贴，或使用分组旁的 + 按钮；使用上方分组导航时，可从导航行的 + 创建分组。自由格子单组通过空槽创建动作，不额外显示创建动作磁贴；
- 在动作区域空白处右键，选择动作类型；
- 复制动作、文件或分享动作链接后，在空白处右键粘贴；
- 把文件或文件夹从资源管理器拖到目标场景或分组，直接创建“打开文件”或“打开文件夹”动作；
- 右键场景标签，选择“导入动作到此场景”，从本地 JSON 文件导入动作。

从本地文件导入时可识别 Quicker 1.x 和 2.0 动作 JSON。若导入动作的 ID 已存在，Quicker 会为导入副本生成新的 ID，避免覆盖现有动作。

<a id="开发中在空白处创建和粘贴" />

### 在空白处创建和粘贴 {/* #234--在空白处创建和粘贴 */}

连续显示多个分组时，在某个分组的空白处右键创建或粘贴动作，会使用该位置所属的分组。新面板和「场景、动作与触发管理」中的动作页使用相同规则。

置顶区不能用来创建或粘贴新动作；连续分组布局中无法确定归属的位置，也不会悄悄改用当前选中分组。菜单没有提供创建入口时，先切换或定位到目标普通分组，再在其内容区操作。

<a id="开发版外部文件拖放" />

### 拖入文件或文件夹 {/* #232--外部文件拖放 */}

新版主面板以及「场景、动作与触发」管理窗口的面板动作区域，支持从资源管理器或能提供标准 Windows 文件投放的程序拖入文件、文件夹。

先选好可写的目标场景，再将文件拖到动作区域，根据插入线或空格边框松手：

- **流式布局**：可一次拖入多个文件或文件夹，按来源顺序创建动作。
- **自由格子布局**：只接收单个文件或文件夹，必须落在空格中；不会覆盖或挤走已有动作。格子间隙、分组标题或已有动作不作为文件落点。

投放到场景树、场景标签、标题栏等动作区域之外的位置，不会用这条通道创建动作；仅存在于来源程序中的虚拟文件也不在支持范围内。拖入文件创建的是打开目标的动作，不是导入 Quicker 动作 JSON。

多文件创建不是整体撤销式的批处理：中途失败时，已经创建成功的动作会保留，后续项可能停止。请查看成功或警告提示，核对目标场景中的实际动作，再补充遗漏项。

### 复制后同时添加与删除关联

在面板中 **复制** 某个动作后，可到另一场景或分组的空白处右键，选择 **同时添加到这里**：目标位置会增加一个入口，并与来源共用同一个动作本体（不会生成内容互相独立的副本）。这和按住 `Ctrl` 拖动、「场景、动作与触发」里的「同时添加到…」一样，都是增加入口而不是复制内容。

删除动作本体时，确认框会列出它在各场景中的关联位置，便于核对后再确认。若只想整理面板而不删本体，请继续使用「从此场景移除」、移动或「同时添加」。

## 整理动作和分组

### 自由格子布局

在 **面板设置 → 布局与交互 → 动作布局** 中选择 **自由格子布局**，再打开下方的 **自由格子布局设置…** 调整格子。每个真实分组都使用固定格位：

- 直接把动作拖到空格，可移动或交换位置；删除动作后，其他动作不会自动前移。把动作拖到格子边缘可在该位置插队，后续动作会自动顺移；想保留空位时仍拖到格子中间。
- 可分别设置全局区和上下文区的列数与最小行数；窗口较窄时可横向滚动，按住 Shift 滚轮可横滚。
- 分组菜单的“摆放动作 / 增减行”可在草稿中整理；取消、Esc 或关闭窗口不会写入。
- 搜索结果、置顶动作和最近动作仍紧凑排列，不占用独立格位。

从旧动作页导入时，自由格子布局会尽量按原固定四列保留行列和空隙。

自由格子布局随账号同步。混用旧客户端前，请阅读[自由布局的兼容注意](/v2/migration/upgrade-and-rollback#2212-规则父场景与-2213-面板自由布局)。

#### 触发键

自由格子布局可启用原有「触发键」（默认关闭；在触发键相关设置中启用）。启用期间会暂停悬停输入搜索，仍可主动进入搜索。

触发键复用已有的格子按键配置：按当前场景、当前分组的固定行列定位，并保留空位。「全部」使用第一个真实格子组；置顶投影不参与映射。

合并标签模式下，全局键位和上下文键位都在**当前标签页**按各自对应位置执行，不自动切到另一来源。启用动作触发键期间，其优先级高于数字键切换标签；不要把数字切页开关当作动作触发键设置。

### 置顶常用动作

右键动作并选择“置顶”，可以把不同分组中的常用动作集中到列表顶部。再次右键并选择“取消置顶”即可移除置顶状态。

开启“显示分组”且当前场景存在置顶动作时，会出现一个带图钉标记的虚拟“置顶”分组。需要注意：

- 置顶动作会在“置顶”分组和原来的真实分组中各显示一次，但它们是同一个动作，不是两个副本；
- 置顶或取消置顶不会改变动作原来的分组；最后一个动作取消置顶后，“置顶”分组会自动消失；
- 排序方式为“手动”时，可以在“置顶”分组内向前或向后拖动动作，调整置顶动作的相对顺序；
- “置顶”分组不能重命名、合并或删除，也不能在其中新建动作或拖入未置顶动作；从该分组向外拖动也不会改变动作的真实分组。

关闭“显示分组”后不会显示虚拟分组，但置顶动作仍会优先排列。自动排序模式下也会优先显示置顶动作，但不能通过拖动调整顺序。

### 调整动作顺序

点击面板右上角的滑块图标打开 **面板设置**，在 **布局与交互 → 动作 → 动作排序** 中选择 **手动**，即可在同一场景中拖动动作调整顺序。其它排序方式包括最后使用、最多使用、综合、最近创建、最近编辑和 **按标题排序**；这些自动排序模式下不能手动重排。

**按标题排序** 时英文在前、中文在后，各自升序，中文按拼音排序并忽略大小写；置顶动作仍优先显示。它只调整动作的显示顺序，不改变动作标题。需要恢复拖动排列时，切回 **手动**。

按时间排列的动作搜索结果保持时间顺序。

### 移动或复制动作

右键动作并选择“移动到其它场景…”，可以选择目标场景和分组。目标分组既可从已有分组中选择，也可直接输入一个新名称；留空表示放入“未分组”。

移动动作、移动分组和保留暂存动作时，目标场景使用可搜索的树形列表，按场景层级查找。浏览器父场景固定显示为 **浏览器**，即使还没有配置或动作，也可以作为目标；当前来源场景不会出现在自己的移动目标中。

也可以直接拖动动作：

- 拖到同一场景的其它位置或分组：调整顺序或分组；
- 拖到其它场景：移动动作的场景位置；
- 按住 `Ctrl` 拖到其它场景：在目标场景增加一个位置，并保留来源场景的位置。

这些操作移动或复制的是动作入口，不会创建动作内容的独立副本。编辑动作后，引用同一动作的其它入口也会显示更新后的内容。

把动作拖出面板并放到悬浮目标区域，可以建立悬浮动作入口。悬浮入口仍引用同一个动作本体，不会复制动作内容。

需要一次处理多个动作时，打开「场景、动作与触发」管理窗口并选择来源场景：

1. 单击动作可选择一个动作；按住 `Ctrl` 单击可逐个增减选择，按住 `Shift` 单击可连续选择；
2. 按 `Ctrl+A` 可选择当前场景中可见的全部动作；
3. 选择后，窗口底部会显示已选数量以及“移动到…”“同时添加到…”“剪切”等批量命令；在任一选中动作上右键也可打开批量菜单；
4. “移动到…”会在成功加入目标场景后移除来源场景中的入口；“同时添加到…”会保留来源入口；
5. 目标位置可以选择已有分组，也可以直接输入新的分组名称；留空表示放入“未分组”。

连续选择和全选都以当前界面可见的动作及显示顺序为准。搜索或筛选后，可以只处理筛选结果。

<a id="开发版拖动动作时切换场景" />

#### 拖动动作时切换场景

可以在拖动动作过程中，把鼠标停在主面板的另一个场景标签上约半秒，自动切换到该场景。保持拖动，再移入目标动作区域或分组后松开，才会按现有拖放规则完成移动或添加。

场景标签只用于切换，不能直接作为动作的放置位置；在标签上松开不会把动作放入该场景。离开标签或取消拖动会取消待执行的切换。此入口针对动作拖放，不用于把文件、普通文字或分组直接放到场景标签上。

### 创建和管理分组

使用单个分组或连续显示模式时，可从分组导航的创建入口新建分组，也可把动作拖到“创建分组”入口，在新建分组的同时移入该动作。

右键具名分组可执行以下常用操作：

- 修改分组名称；
- 合并到另一个分组；
- 移动整个分组到其它场景；
- 同时把整个分组添加到其它场景，并保留来源分组；
- 设置 **适用主机**，让同一账号下的某个分组只在指定电脑显示；
- 单独设置该分组导航圆点的颜色；
- 删除分组；
- 创建一个“加载此分组”的动作。

删除分组不会删除其中的动作，组内动作会转入“未分组”。合并分组会把来源分组的动作移到目标分组，然后删除来源分组。

整组移动会保留组内动作的相对顺序，不会自动并入目标中的同名分组；需要新建目标分组时，同名分组会自动加序号。目标场景已有的相同动作保留原位置。移动完成且来源分组已空时，来源分组会被删除。“同时添加分组到其它场景”复用原动作，不会创建动作内容的独立副本。

适用主机适合把公司电脑、家用电脑或专用设备的动作分组分开显示。它只影响该分组在当前设备上的面板呈现，不会把组内动作复制成不同版本；编辑动作本体仍会影响所有引用位置。

### 移动全部分组和动作 {/* #move-scene-2344 */}

需要把某个程序场景的面板内容整体整理到父场景或其它场景时，无需逐组移动：

1. 打开 **场景、动作与触发管理**，在左侧选中来源场景；
2. 右键管理窗口中的 **面板动作** 导航项，选择 **移动全部分组和动作到其它场景…**；
3. 在树形列表中选择目标场景。有可用的父场景时会默认选中它，也可以搜索后选择其它场景；
4. 核对来源、目标以及分组和动作数量，再确认移动。

整场景移动包含 **空分组、其它电脑适用的分组和全部动作入口**，不受当前搜索、分组筛选或已选动作范围限制。分组顺序、颜色、适用主机和布局会一同保留；目标已有同名分组时自动加序号，相同动作保留目标已有的位置。

成功后，来源场景的面板分组和动作入口会清空；场景本身、触发规则、旧动作页和动作本体保留。整理结果参与账号同步。移到父场景后，其它继承该父场景的程序也可能显示这些动作，请先确认它们是否适用。

如果提示 **已复制到目标，但清空来源失败**，说明目标已有副本，来源内容也保留了。检查两边后可以重试移动，已迁入的目标分组会被复用。若确认期间来源内容发生变化，或来源、目标只读，操作会被拒绝；请按提示刷新或检查配置后再试。

### 按旧动作页重新迁移新面板 {/* #rebuild-from-legacy-2343 */}

如果希望放弃迁移后对新面板的整理，按旧动作页重新建立布局，可使用全量重新迁移工具。它与移动单个场景不同，也不会因为升级自动执行。

1. 打开 **设置 → 常规 → 维护工具**，点击 **将旧动作页全部重新迁移到新面板**。
2. 先检查预览中的场景、分组、动作入口及风险提示。此工具按全部旧动作页生成计划，不提供逐个场景选择或合并保留新布局。
3. 确认后点击 **备份并开始迁移**；必须先成功备份才会开始修改。账号数据未加载完成、存在未处理同步冲突或场景只读时，先处理提示的问题。
4. 如需撤销，从同一窗口的 **更多操作 → 从备份恢复…** 选择迁移备份；可用 **打开备份目录** 查找文件。完成后检查结果，出现失败提示时先核对当前状态再决定下一步。

:::caution[会覆盖新面板整理结果并同步]
有旧动作页的场景会按旧页重建，覆盖对应新面板的分组、排列、格子位置、置顶、颜色和适用电脑设置；仅在新面板添加的入口可能被移除，曾删除的场景可能重新创建。动作本体及旧动作页保留，但入口需要从备份恢复或重新整理。

整个新面板还会切换为经典 4×4 样式，结果参与账号同步。请先查看预览并保留备份；重建后再修改相关场景或显示样式，可能阻止整次恢复，避免用恢复操作覆盖后续修改。详见[重新迁移与回退注意](/v2/migration/upgrade-and-rollback#panel-rebuild-2343)。
:::

## 管理多个场景和大量动作

### 定位最近动作与引用到助手 {/* #2328--定位最近动作与引用到助手 */}

在新版面板的最近动作列表中，右键动作可打开其所在分组，便于从最近使用记录回到原位置整理。

在 **场景、动作与触发** 的场景动作列表中，选中一个或多个动作后，右键选择 **复制动作ID**，可复制逗号分隔的动作 ID；选择 **在AI助手中引用**，可把选中动作加入该窗口侧边助手的输入框。引用只加入提问材料，不会立即运行或修改动作，发送前可继续补充要求。

### 隐藏不常用动作 {/* #238--隐藏不常用动作 */}

在最近使用 / 最近活动或动作搜索列表中，右键动作打开 **管理**，可分别设置 **不在最近使用与最近活动中显示**、**不在动作搜索中显示**。两个范围相互独立，设置随账号同步。

隐藏只影响对应列表，不会删除动作；快捷键、直达词和其他动作调用仍可使用。需要恢复时，打开 **设置 → 动作 → 全部动作** 并勾选 **已隐藏**，找到目标动作后取消相应隐藏设置。

### 跨场景整理

需要跨场景整理时，点击顶栏或侧栏的 **场景、动作与触发** 按钮。在「场景、动作与触发」管理窗口中，可以：

- 从左侧场景树选择全局、程序、网址或自定义场景；
- 管理新面板中的动作和分组；
- 查看及管理旧动作页；
- 在场景之间拖动动作；
- 管理该场景的快捷键、轮盘、手势和其它触发规则。

如果已经知道动作所在的来源场景，直接在这里使用多选、整组移动或批量剪切最方便。批量剪切后，切换到目标场景和分组，按 `Ctrl+V`；也可以在目标动作区域空白处右键，选择“粘贴已剪切的多个动作”。剪切时不会立即移除来源入口，只有目标写入成功后才会完成移动。

如果还不知道动作位于哪些旧动作页或场景，可打开 **设置 → 动作 → 全部动作**，按程序、动作页等条件筛选后再批量处理。详细操作和剪切安全边界见[常见问题](./faq.md)。

在 **设置 → 动作 → 全部动作** 中，也可访问 **动作回收站** 和 **批量更新动作**。从动作管理列表拖到新面板目标场景或分组时，会建立该动作的面板入口；这和“移动到…”一样处理的是动作位置，不会复制动作内容本体。

排查最近运行失败的动作时，从标题栏「更多」→「诊断与修复」→「动作运行与触发记录」打开窗口，在「动作执行」中筛选「失败」。详细说明见[内置工具](/v2/features/tools#动作运行与触发记录)。

## 设置侧栏与快捷入口

### 侧边栏快捷按钮

左侧导航**底部**的快捷按钮可以自定义。默认入口包括 **Quicker 截图** 和 **AI 工作台**；还可放入 **设置**、**场景、动作与触发管理** 等入口，也可以添加常用动作并调整顺序。入口在标题栏「更多」→「面板外观与布局」→「快捷按钮设置…」。常用动作本身的整理方式见[动作与入口](/v2/features/actions)。

侧边栏会根据可用高度尽量显示更多快捷按钮；放不下的按钮收进「更多」。

缩小窗口后按钮看似少了，可以先打开「…」菜单，无需重新添加；原有配置和顺序不会因此删除。拉高窗口后会显示更多按钮，并为场景列表保留浏览空间。

浏览全部动作或公共子程序时，打开 **设置 → 动作 → 全部动作**、**设置 → 动作 → 公共子程序**。

快捷按钮随账号同步。混用旧客户端前，请阅读[侧栏快捷按钮的回退注意](/v2/migration/upgrade-and-rollback#2129-侧边栏快捷按钮的回退注意)。

### 双击导航栏

导航栏在窗口**最左侧**：上端是 Quicker 标志，中间是「动作」「暂存区」，底部是快捷按钮。也可以打开标题栏「更多」→「面板外观与布局」→「左侧导航栏」，在标准、紧凑和关闭之间选择。

- 双击**面板内容空白处**，可显示或隐藏导航栏（给动作区域腾地方）。
- 双击**导航栏空白处**，可在标准导航与紧凑导航之间切换。

请点在空白区域；点到场景标签、动作磁贴或按钮上仍按原有单击 / 双击行为处理。

### 拖动添加与排序 {/* #sidebar-shortcut-drag */}

面板侧栏的快捷入口可直接拖动排序。把动作拖到侧栏，按插入标记松手，可在指定位置添加入口；动作原有的面板位置和内容保持不变。若侧栏已有该动作但入口被禁用，拖入会恢复已有入口；已有启用入口则可移动到落点，不会重复添加。

## 调整显示方式

### 合并显示父子场景动作 {/* #2317--合并显示父子场景动作 */}

打开 **面板设置 → 布局与交互 → 上下文场景**，勾选 **合并显示相关上下文场景动作**，可在当前程序的上下文区连续查看已加载的网页、窗口子场景、程序、规则父场景和浏览器公共场景动作。也可**右键**面板的滑块图标，在 **合并显示父子场景动作** 中勾选 **合并显示**。

需要改变父场景相对位置时，勾选 **父场景在前（不勾选则在后）**；它不改变网页与窗口子场景的相对顺序。两项设置默认均不勾选，随账号同步，并对各程序的上下文区统一生效。分组标题先显示分组名称，再以浅色标注来源场景。

合并只改变显示：动作仍保存在原场景，原有分组、顺序和自由格子位置不会搬迁。搜索可查找这些来源的动作；点击分组导航会定位到对应来源，自由格子的触发键跟随当前显示分组。合并显示时，分组导航仅用于定位，不能在导航条上拖动排序、改名或新增分组；关闭合并后恢复原来的独立场景标签和分组显示。

需要混用旧客户端或回退时，请先看[相关场景显示的兼容注意](/v2/migration/upgrade-and-rollback#2317--相关场景显示与文字图标)。

### 面板设置 {/* #视图选项 */}

点击面板右上角的**滑块图标**，打开独立的 **面板设置** 窗口。窗口分为 **布局与交互**、**外观** 两个标签；调整时可同时查看真实面板，修改生效并保存后，关闭设置窗口仍会保留。首次打开时设置窗口会尽量与面板等高，并受显示器可用空间限制。

双区显示时，按钮通常在上下文区右上角；仅全局、仅上下文和合并标签模式下，在当前显示区域的工具条中查找。**右键**滑块图标仍可添加全局场景、设置合并显示父子场景动作等场景操作。

#### 布局与显示区域 {/* #panel-layout */}

先在顶部选择 **流式布局** 或 **自由格子布局**，再选择显示区域：

| 显示区域 | 用法 |
| --- | --- |
| 全局 + 上下文 | 上下同时显示两区，可调整两区高度 |
| 仅全局区 / 仅上下文区 | 只显示指定来源 |
| 标签合并 · 全局优先 | 全局与上下文标签放在同一排，弹出时优先显示全局来源 |
| 标签合并 · 上下文优先 | 共用同一排标签，弹出时优先显示当前程序的上下文来源 |

合并模式仍可手动切换其它标签，动作不会因为标签合并而移动或复制。面板内的动作筛选只作用于当前标签；**合并标签**与上面的**合并显示父子场景动作**是两种不同设置，后者决定一个上下文标签里是否同时展示相关场景的内容。

动作样式、排序、标题换行、底部最新动作和创建动作磁贴等选项按功能分组显示。自由格子布局只显示适用选项：动作使用磁贴，不提供紧凑列表和不分组；排序只影响未定位动作，已定位动作仍按格子位置排列。自由格子单组通过空槽创建动作，不提供 **显示创建动作磁贴** 选项。切回流式布局后可恢复选择相应选项。

#### 分组显示与导航 {/* #group-navigation */}

**分组显示**决定内容如何排列：**单个分组**适合较小窗口，**连续显示**适合滚动浏览多个分组，**不分组**则平铺动作。

**分组导航**独立决定如何选组：

| 导航方式 | 用法与限制 |
| --- | --- |
| 上方圆点 | 在内容区上方选择分组，单组和连续显示均可使用；导航行不重复显示当前分组名，悬停圆点可查看名称 |
| 左侧圆点 | 沿用窄圆点导航，悬停可查看分组名 |
| 左侧文字分组 | 分组名从顶部排列；长名称省略，悬停可看全名，可拖动右边界调整宽度 |
| 隐藏 | 连续显示时可隐藏导航，通过内容滚动浏览；单个分组模式下禁用 |

不分组时导航暂不显示，但会保留所选导航偏好。切换到单个分组时，若原偏好为隐藏，会同时改为左侧圆点，保证可以切组。

**鼠标悬浮自动切换分组**默认开启。进入分组导航区域停留 **500ms** 后启用悬停切换，此后在区域内划过其它分组立即切换；离开区域后重新计时。关闭后可单击切换分组，拖放动作时的悬停切组仍保留。500ms 是固定延迟，不能单独调整。

**快速滚动区域**控制动作区中滚轮切组的范围，可选 **上方、左侧、关闭**，并可调整区域范围；它与分组导航的位置是独立选项。

#### 数字键切换场景标签 {/* #digit-scene-tabs */}

在 **布局与交互 → 交互** 开启 **数字键切换场景标签**，即可在鼠标所在动作区域按 `1`–`9`、`0` 切换前十个场景标签（`0` 对应第十个）；主键盘和数字小键盘均可。双区模式按鼠标所在的全局区或上下文区分别编号，合并模式按同一排标签从左到右编号。

此项**默认关闭**。没有对应序号时不切换，也不会因此开始数字筛选。已开始筛选或主动进入搜索输入时，数字仍作为搜索字符；动作触发键生效时优先按动作触发键执行。需要按数字查找动作时，请先主动进入搜索输入。

#### 外观与保存范围 {/* #panel-preferences-sync */}

**外观**标签复用原有面板外观设置，可调整主题、配色、按钮大小等；**选中标签页或分组文字**可独立设置颜色，未设置时沿用主题主色，不改变选中指示线。颜色在关闭调色板时保存，其它设置按页面提示提交。

布局、显示区域及优先来源、分组导航、数字切页和悬停切组开关均随账号同步；外观也沿用原有账号设置同步，不是每台电脑各存一份。**文字分组栏拖动后的宽度只在当前面板实例中保留**，不持久化、不参与同步，重新启动后按名称自动计算；双区显示时两区宽度保持一致。

旧客户端保存设置的影响，见[面板显示与配色的回退注意](/v2/migration/upgrade-and-rollback#panel-settings-2347)。

### 窗口尺寸

窗口支持拖动和缩放。标题栏「更多」→「面板外观与布局」→「窗口尺寸」可以保存和切换多个尺寸预设；双击标题栏也可以恢复或切换尺寸。

同时显示全局区和上下文区时，按住 `Ctrl` 拖动顶部或底部边框（两区之间的分界），可以分别调整某一侧的高度，而不是按比例一起变化。未按住 `Ctrl` 时，拖动边框仍会按比例调整两区。

动作磁贴会按当前可用宽度自动排列；动作名称会根据按钮空间自动缩小。面板外观仍使用 Quicker 的面板字体、磁贴尺寸、背景图片和透明度等设置。

背景可以选择普通透明、毛玻璃或亚克力，并调整背景色叠加浓度。亚克力需要 Windows 11 且开启系统“透明效果”；条件不满足时，Quicker 会按毛玻璃效果显示。

## 历史版本相关变化

以下仅列出与本页使用方式相关的重要变化，当前操作以正文为准。

- [2.3.49](/release-notes#2349--面板上下文设置与扩展热键分组)：将相关场景合并显示选项纳入面板设置，并精简顶部圆点导航和分组来源标注。
- [2.3.47](/release-notes#2347--面板设置合并标签与分组导航)：提供独立面板设置窗口，扩展标签合并、分组导航和数字键切换场景标签。
- [2.3.44](/release-notes#2344--整场景移动与树形场景选择)：支持整体移动场景的全部分组与动作，目标场景改用可搜索的树形列表。
- [2.3.43](/release-notes#2343--截图快捷键面板重新迁移与菜单编辑)：提供按旧动作页重新迁移新面板的预览、备份与恢复工具。
- [2.3.38–2.3.39](/release-notes#2339--选字自动复制设置导航与面板菜单)：调整场景管理入口和面板主菜单，已固定到侧栏的入口不再在顶部重复显示。
- [2.3.18](/release-notes#2318--截图多选工作台做事与表达式兼容)：支持将动作拖入侧栏快捷入口，并拖动排序。
- [2.3.17](/release-notes#2317--问问-ai场景合并与截图)：支持在上下文区合并显示相关父子场景的动作。

更早的自由格子布局、跨场景拖放等变化见[2.1–2.2 历史更新记录](/release-notes/archive-2-1-2-2)；旧客户端混用与降级风险见[升级与回退注意](/v2/migration/upgrade-and-rollback)。
