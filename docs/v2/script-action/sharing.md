脚本动作可以发布到分享平台，多操作动作中内嵌脚本也适用。发布前先检查源码、运行关键路径，并在说明中写清用途、外部依赖、输入输出和实际修改的数据。

## 分享前检查

2.3.23 起，脚本动作开放 .NET 类型环境，不再用原有的 `qk` 能力识别结果决定是否允许分享。源码仍需满足入口与语法要求；“可以分享”不代表代码安全或一定能在其他电脑运行。

涉及删除、覆盖、上传、启动程序或操作其他窗口时，请明确说明对象和后果。接收方运行安装或导入的脚本时不再逐项确认能力，详见[安全与授权](./security.md)。

## 版本要求

分享时记录作者使用的 Quicker 版本。比该版本旧的客户端打开动作会提示升级。不要据此认为每个 API 都有独立的最低版本标记，也不要手改动作数据绕过版本提示。

使用 2.3.23 新开放的 .NET 能力后，脚本可能无法在旧版检查或运行。需要兼容旧客户端时，请保留兼容副本，并在对应版本实际验证；仅修改版本提示不能使新代码兼容。

`qk` API 会随产品演进，旧写法需要按编辑器“检查”的提示修复。运行脚本前仍应核对代码及来源，安装和更新都不会自动撤销此前已执行的外部操作。
