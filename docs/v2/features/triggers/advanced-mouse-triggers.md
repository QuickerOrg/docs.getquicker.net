# 高级鼠标触发

高级鼠标触发可以组合鼠标按键、控制键、触发类型和屏幕位置执行操作。常见方式包括单击、双击、长按、划动、滚轮、移动到角落和摩擦屏幕边界。

它也是 [轮盘菜单](/v2/features/triggers/circle-menu)、[鼠标手势](/v2/features/triggers/mouse-gestures) 和快速截图的常见启动入口：在划动或长按规则里把操作选成对应项即可。

## 快速开始

1. 打开 **场景与动作管理 → 鼠标触发 → 高级鼠标触发**。
2. 左侧选择要设置的场景。
3. 新增一条规则：选择鼠标按键（左键、右键、中键、X1、X2 或无按键）、触发类型，以及要执行的操作。
4. 若要打开轮盘、手势或截图：把触发类型设为 **划动** 或 **长按**，操作分别选 **显示轮盘菜单**、**开始鼠标手势** 或 **快速截图**。
5. 保存后，在目标位置按配置的方式试一次。规则很多时，用列表顶部的按键、触发类型或说明文字筛选。

只填写触发后提示而不设置具体操作也是合法配置，适合先验证规则是否命中。

## 触发类型与可执行操作

普通单击、双击和滚轮只显示适合直接执行的操作。划动或长按规则还可以选择：

- **显示轮盘菜单**
- **开始鼠标手势**
- **快速截图**

切换触发方式时，编辑器会继续校验当前操作是否仍适用于新方式，避免保存「界面上存在但运行时不能执行」的组合。

需要配合键盘引导键时，可以直接选择任意普通引导键。该键尚未定义扩展热键时，保存规则会自动创建对应的引导键设置；如果引导键已存在但处于停用状态，Quicker 会明确提示并让你确认是否启用。仍然建议检查同一引导键是否已经用于面板、轮盘、手势或扩展热键，避免一个按键承担过多入口。

## 规则列表筛选

列表顶部可以组合筛选：

- 鼠标按键：无按键、左键、右键、中键、X1、X2；
- 触发类型：短按、按下、长按、双击、划动、四向滚轮、屏幕角落、摩擦边界；
- 说明文字。

筛选期间会禁用拖动排序，避免把过滤后的局部顺序误写成完整规则顺序。清除筛选后可以继续正常排序。

规则支持多选删除、复制和粘贴。新增或粘贴的条目会放在当前选中项之后，便于保持相关规则相邻。不再把「常用按键」做成另一套并行编辑入口。

## 按场景匹配与禁用

高级鼠标规则会按鼠标开始位置或当前前台目标解析程序、网址和子场景，并与轮盘、手势和动作面板使用同一套场景身份。

对资源管理器桌面与任务栏、UWP、WPS 内部文档、浏览器网址和 WebView 宿主，会使用统一的逻辑目标和回退规则。

| 操作 | 效果 |
| --- | --- |
| 全局、父场景和当前场景中所有启用且条件匹配的规则 | 都会参与匹配 |
| 停用一条本地规则 | 只排除该条规则，不会自动屏蔽上级其它鼠标规则 |
| 需要在某个场景完全关闭高级鼠标触发 | 使用场景级禁用开关 |

这和 [动作快捷键](/v2/features/triggers/action-hotkeys)「停用本地同键则整键不回退」不同，也和 [左键辅助](/v2/features/triggers/left-button-plus)「禁用本地按键会屏蔽上级同按键」不同。

## 触发目标与延迟执行

鼠标按下、移动、释放以及延迟执行可能跨越多个窗口。会话开始时会固定必要的鼠标目标和规则内容，执行时仍使用这次操作的原始目标，不会因为指针经过 Quicker 辅助窗口或前台窗口变化而改用另一场景。

设置窗口、动作编辑窗口等普通 Quicker 窗口可以按正常场景规则使用鼠标触发；主面板和明确标记为不参与触发的悬浮窗口仍会排除，避免在操作 Quicker 面板时意外递归触发。

## 轮盘和手势的角落快捷入口

如果高级鼠标规则启动了轮盘或手势，可以在结束会话前把指针移动到当前屏幕顶部角落：

- **左上角**：打开本次场景的轮盘或手势动作管理
- **右上角**：打开对应功能的全局参数设置

该入口只在已经开始的轮盘或手势会话中生效，识别范围很小。普通「移动到屏幕角落」规则仍按高级鼠标触发自己的设置运行，不会被这个入口替代。

## 限制与排障

- **总是进轮盘而不是手势（或相反）**：检查同一按键上是否同时配置了「显示轮盘菜单」与「开始鼠标手势」，以及移动距离、触发类型是否满足预期条件。
- **和扩展热键、左键辅助抢同一按键**：按真实按下顺序测试；引导键停用时保存规则会提示是否启用。
- **筛选后拖不动顺序**：先清除筛选，再排序。
- **全屏、任务栏、多显示器、WPS 或角落规则不准**：按实际使用路径各测试一次，并结合 **最近触发历史**、**当前场景诊断**。
- **相对 1.x 的场景解析与筛选变化**：见 [高级鼠标触发（2.x 变化）](/v2/what's-new/others/advanced-mouse-triggers)。
