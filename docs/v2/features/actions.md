# 动作与动作面板

动作是 Quicker 中可重复运行的功能单元，动作面板、场景、快捷键和触发规则则负责决定动作显示在哪里、何时运行。

Quicker 2.0 将动作内容与使用位置分开。同一个动作可以出现在多个位置；编辑动作会影响所有引用它的位置，而从面板移除按钮并不等同于删除动作本体。

## 组合动作

组合动作通过多个步骤完成较复杂的工作，例如读取剪贴板、处理文本、调用网络接口、控制窗口，再把结果发送到目标软件。

- 第一次创建组合动作，请从[怎样学会组合动作](/v2/xaction/guides/how-to-learn)开始，三条动手课之后再读[组合动作基础](/v2/xaction/concepts/xaction-intro)。
- 需要查找步骤参数时，进入[组合动作模块参考](/v2/xaction/modules)。
- 需要了解变量、表达式和子程序时，查看[基础与进阶概念](/v2/xaction/concepts)。
- 需要参考完整场景时，查看[教程与实践](/v2/xaction/guides)。


## 脚本动作

2.3.0 起，可新建 **Quicker脚本动作**，用 C# 语法编写动作逻辑，通过 `qk` 调用文本、文件、网络、窗口与键鼠等能力，并调用其他动作或公共子程序。入门、安全与 API 见 [脚本动作](/v2/features/script-actions/)。

## 动作面板（新面板）

日常如何启用、查找、整理分组与显示方式，见 [动作面板（新面板）](/v2/features/action-panel/)。相对 1.x / 迁移说明仍在 [新面板窗口（更新说明）](/v2/what's-new/new-main-win/usage)。

## 运行与整理动作

- 单击面板中的动作按钮即可运行动作；动作执行中显示的状态取决于动作类型和运行方式。
- 编辑动作本体前，应先确认它是否被多个面板、场景或触发规则引用。
- 只想整理面板时，应移动或移除当前位置，不要误删动作本体。
- 复杂动作升级或迁移后，建议先创建副本测试，再替换经常使用的版本。

## 2.3.36 · 触发与引用 {/* #trigger-and-reference-2336 */}

动作右键菜单的 **触发与引用** 集中提供触发设置与引用管理。原有的 **动作引用位置** 窗口扩展为 **触发与引用**，按以下页面查看当前动作的使用方式：

- **直接触发**：查看并编辑快捷键、按键双击、文本指令、扩展热键和热键联动等绑定；也可从这里添加触发。
- **位置与编排**：查看已发现的面板位置和规则编排引用，定位到原设置管理。
- **自动执行**：查看关联的自动执行任务，打开任务设置调整事件、时间和条件。

修改或删除触发规则、从某个位置移出动作，都不等于删除动作本体。删除前应分清是在移除绑定、移除位置，还是删除动作本身。来源已变化或无法唯一定位时，请刷新列表并回到原设置核对，避免修改错误规则。

2.3.37 起，**直接触发** 页可按触发类型筛选，列表紧凑展示场景、按键及引用位置。快捷键编辑窗口还可修改动作参数或删除当前规则，详见[动作快捷键](./triggers/action-hotkeys.md#从动作入口编辑已有规则)。

## 分享、安装与更新

Quicker 2.2.1 起，动作和公共子程序使用统一的分享与版本体系。同一次分享可以包含 Quicker 1.x 兼容内容、Quicker 2.0 原生内容或两者；使用了 1.x 不支持能力的动作也可以只发布 V2。

当前兼容判断仍可能有误差：有些动作可能在 1.x 中能安装但运行不了；审核中的动作不会影响已发布版本；客户端和服务端也可能继续调整。2.1.19–2.2.0 期间使用旧 V2 分享机制发布的内容需要重新分享。完整规则见[分享动作与公共子程序](/v2/features/action-sharing)和[官网版本记录](https://getquicker.net/V2/Versions)。

## 了解 2.0 的变化

2.0 对动作存储、操作参数、组合动作执行和调试基础结构进行了调整。旧动作兼容范围、只读边界和新版调试能力见[动作存储、执行与调试](/v2/what's-new/actions)。
