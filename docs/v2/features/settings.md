# 设置页面与功能入口

打开设置后，可按左侧分组浏览，也可搜索选项名称。页面名称和位置可能与 1.x 不同；旧入口会按功能定位到合并后的页面。需要排查某个开关时，先记录原值，每次只调整相关选项。

设置左侧提供分类栏和页面列表。先选择分类，再单击组内页面；也可在顶部搜索框输入选项名称定位。

在分类栏或页面列表区域滚动鼠标滚轮，可切换分类。**搜索、数据同步、维护工具** 位于 **常规**，面板相关设置位于 **面板**，**悬浮动作** 位于 **手动触发**。

## 面板设置

调整动作面板时，也可直接点击面板上的滑块图标，打开独立的 **面板设置** 窗口。在 **布局与交互**、**外观** 两个标签中调整并查看真实面板效果；外观与全局设置共用同一份配置，不是另外建立一套配色。详细说明见[面板设置](./action-panel/usage.md#视图选项)。

## 分类标题与直达链接 {/* #navigation-2341 */}

点击搜索框左侧的 **显示分类标题／隐藏分类标题** 按钮，可在图标导航与带标题的分类导航之间切换。显示方式只记在本机；滚轮切换分组的提示可单独关闭，关闭提示不影响滚轮操作。

本版统一了设置直达链接。打开受支持的 Quicker 导航链接，可定位到对应设置页、场景规则或动作预览，不必手动逐层查找；这类链接只负责打开和定位，不会因点击就运行动作或修改设置。链接目标无效或资源已不存在时，请按客户端提示处理。

回退旧版并保存本机状态，可能重置分类标题显示偏好；再次升级后可重新选择，详见[2.3.41 升级与回退](/v2/migration/upgrade-and-rollback#screen-text-and-settings-2341)。

### 把常用设置页放入轮盘 {/* #navigation-actions-2342 */}

右键点击设置页的帮助按钮，选择 **复制动作**，可把打开当前设置页的动作粘贴到轮盘等位置；**复制命令** 则复制对应的直达链接。

在 **场景、动作与触发** 管理窗口中，先选好目标场景，再右键点击功能页导航按钮，选择 **复制为动作**，可保留该场景和功能页作为打开目标。也可将导航按钮直接拖入轮盘；拖动不会切换当前正在编辑的功能页。它只是创建导航入口，不会自动修改目标场景的规则。

<a id="BasicInfo" />

## 常规

管理启动、托盘、提示消息、性能、网络和更新等基础选项。网络代理修改后应保存；只在输入框编辑并不代表代理已经生效。鼠标与键盘触发的共用参数也在这里，修改时会影响多个触发功能，不宜为了单条规则随意缩短时间阈值。

<a id="FunctionHotkeys" />

## 功能快捷键

配置打开面板、搜索等 Quicker 功能的快捷键。动作快捷键、热键联动、按键双击及快捷键占用查询从页面相关入口打开，规则本身仍由各自管理器编辑。功能快捷键与[超级键](./triggers/powerkeys.md)不同。

<a id="BlackListSettings" />

## 黑名单

指定需要限制触发的程序，并核对具体禁用项。全屏禁用、单击 Ctrl 弹出面板和各功能独立黑名单的范围不同，不应把其中一个开关当作暂停所有动作。见[触发方式与黑名单](./triggers/index.md#程序黑名单与全屏禁用)。

<a id="PanelPopupSettings" />

## 弹出方式

选择鼠标或键盘弹出面板的方式，并检查长按、双击等时间参数。与其它软件冲突时，先停用可疑触发方式，再单独试用。新版面板的隐藏与位置选项见[面板使用](./action-panel/usage.md)。

<a id="PanelTriggerKeySettings" />

## 触发按键

配置键盘方式弹出面板后，如何用按键触发面板动作。这与直接运行某个动作的快捷键不同；测试时应先按所配置的方式弹出面板，再输入触发键。

<a id="ActionDesignerSettingsPage" />

## 动作设计

调整动作设计器相关选项。学习编辑步骤、变量和外观请阅读[动作编辑器](/v2/xaction/concepts/xaction-editor/)；简单触发操作则见[快速操作](./quick-operations.md)。

<a id="BlockOptions" />

## 模块选项

管理组合动作模块使用的公共选项。修改后应针对使用该模块的动作试运行，不要将全局模块配置与单个步骤的参数混为一谈。模块具体参数见[组合动作模块](/v2/xaction/)。

<a id="ActionManagementPage" />

## 全部动作

按名称和筛选条件查找当前账号的动作，查看使用位置并整理入口。把动作拖到面板会建立入口，不等于复制动作本体；隐藏动作与删除动作也不同。见[管理多个场景和大量动作](./action-panel/usage.md#管理多个场景和大量动作)。

<a id="PublicSubProgramsPage" />

## 公共子程序

管理当前账号可复用的公共子程序、分组和分享。子程序并非一个普通面板动作；修改前先检查被哪些动作引用。定义与引用方式见[子程序](/v2/xaction/concepts/subprogram/)，对外发布见[分享公共子程序](./action-sharing.md#分享公共子程序)。

<a id="AutoRunActions" />

## 自动运行动作

管理启动后或定时执行的规则。新增或编辑规则时，确认启用状态、时间条件、目标动作和限定主机；只需要在一台电脑执行的任务，应核对主机限制，避免多台设备重复运行。规则支持复制、粘贴和删除；粘贴后仍应逐项检查参数。

<a id="EventTriggerSettingsPage" />

## 事件触发

选择事件类型、事件参数和目标动作，并确认规则启用状态。不同事件的参数不同，不能只改事件名称后沿用原参数。列表中可查看说明、动作和限定主机，编辑后用真实事件试验，避免高频事件反复启动有副作用的动作。

编辑并保存事件类型后，请核对列表中的描述和提示是否符合预期。

### 蓝牙设备断开与断开原因 {/* #bluetooth-disconnect-2348 */}

关闭 Windows 蓝牙也会为原本已连接的设备触发 **蓝牙设备断开**，每个连接周期只触发一次。可按设备名称筛选，多个名称用分号隔开，也可使用 `regex:正则表达式`；目标动作除设备名称 `DeviceName` 外，还可读取断开原因 `DisconnectReason`：

| 值 | 含义 |
| --- | --- |
| `BluetoothOff` | 已确认电脑的蓝牙无线电全部关闭或禁用 |
| `Unknown` | 无法确定原因，不能据此区分外设关机、没电或超出范围 |

启动 Quicker 或修改规则后的前 5 秒仍会忽略事件。依赖断开原因分支的动作，请在运行设备使用 2.3.48 或更高版本；旧版不提供该输出，不应将缺少值直接当作某一种断开原因。

<a id="HelperFunctionsSettingPage" />

## 常用辅助功能

这里集中提供辅助功能开关和管理入口，包括[高级鼠标触发](./triggers/advanced-mouse-triggers.md)等。打开管理器后仍需为目标场景配置规则。

**其它鼠标操作** 增加 **Win+左键拖动：选择屏幕文字**，默认关闭；开启时补齐或启用左右 Win 引导键，关闭本项不会关闭引导键。使用方法及冲突排查见[屏幕拖选文字](./screenshot/screen-text-selection.md)。

<a id="QuickCaptureSettings" />

## 快速截图

配置快速截图功能。它与“Quicker 截图”页面的选区、完成动作、保存及历史选项不同；先确认使用的是哪种截图入口。截图、贴图及新截图工具的区别见[截图功能](./screenshot/index.md)。

## 屏幕选字

**截图与文字识别 → 屏幕选字** 可添加、排序或移除结果工具条的固定动作，最多 3 个，修改后下次选字生效。它与启用 Win＋左键拖选的开关不同，完整用法见[固定常用动作](./screenshot/screen-text-selection.md#pinned-actions-2341)。

<a id="ScreenCaptureRecognitionSettings" />

## 识别与翻译

配置基础 OCR、图片翻译服务和本机凭据。先选择服务，再按服务要求填写凭据；旧版和新版图片翻译的开通流程不同，不能混用。详细开通与配置见[图片翻译](./screenshot/image-translate.md)。

<a id="AiAgentTools" />

## Agent 工具

配置联网搜索等 Agent 工具及其服务连接。工具连接与模型服务是两套配置；配置模型可用并不代表搜索工具已经可用。选择工具提供方并补齐其连接后，使用不含敏感信息的问题验证调用。见[AI 与 Agent](/v2/features/ai-and-agent)。

<a id="BasicToolsSettingPage" />

## 维护工具

此页位于 **常规** 分组。

提供维护和排障入口。诊断时先看当前状态、日志和报告，再按工具提示操作；不要在没有备份的情况下直接重建或清理数据。诊断报告和动作运行记录见[内置工具](./tools.md)。

**将旧动作页全部重新迁移到新面板** 会主动覆盖对应场景的新面板布局，并调整整套面板样式；不是补齐遗漏动作的普通同步操作。使用前请先阅读[重新迁移步骤与备份恢复](./action-panel/usage.md#rebuild-from-legacy-2343)。

## AI 提示词库与会话历史

在 **设置 → AI → 提示词库** 中按图片提问、文本提问、通用提问和 AI 工作台管理常用模板；云账号的模板随账号同步。旧本机模板不会自动导入，请先阅读[提示词库的建立与同步](/v2/features/ai/prompt-library-and-sessions#prompt-library-2340)。

**设置 → AI → 会话历史** 可集中筛选、预览和管理工作台及编辑助手的本机历史，归档、恢复或永久删除所选会话，也可回到原助手继续处理。会话内容不会因为这个页面而上传或跨设备同步，具体范围见[集中管理会话历史](/v2/features/ai/prompt-library-and-sessions#conversation-history-2340)。

<a id="AboutSettingPage" />

## 关于 Quicker

查看账号、版本、隐私声明与用量统计。反馈问题时附上实际版本和相关功能，不要把日志中的账号凭据公开发布。

<a id="HotkeyUsageLookupPage" />

## 快捷键占用查询

从功能快捷键或超级键页面的相关操作中打开，输入组合键，检查功能快捷键、动作快捷键和键盘监听规则的匹配结果。查询的是 Quicker 能识别的规则，不能保证其它应用没有占用该组合键。

<a id="PrivacyPolicy" />

## 隐私声明

在“关于 Quicker”中打开客户端当前的隐私声明。需要了解数据存放与同步边界时，另见[账号与同步](./account-and-sync.md)。

<a id="UsageStatisticsInfoPage" />

## 用量统计

在“关于 Quicker”中打开用量统计入口。用量信息不等于动作历史备份，也不能据此恢复动作内容。

## 历史版本相关变化

以下为与本页相关的重要变化，当前用法以正文为准。

- [2.3.48](/release-notes#2348--蓝牙断开原因与模型名称)：蓝牙设备断开事件支持关闭系统蓝牙的情况，并提供断开原因。
- [2.3.42](/release-notes#2342--截图速度与设置直达动作)：设置页帮助按钮可复制打开当前页的动作或直达命令。
- [2.3.41](/release-notes#2341--选字固定动作标注样式与设置导航)：分类导航可显示标题，并提供屏幕选字固定动作设置。
- [2.3.40](/release-notes#2340--提示词库会话管理与截图文字编辑)：调整分类与单击切页交互，增加提示词库入口。
- [2.3.39](/release-notes#2339--选字自动复制设置导航与面板菜单)：设置采用分类栏与页面列表。

更早记录与完整修复列表见[更新记录](/release-notes)。
