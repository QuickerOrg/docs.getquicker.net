# 迁移

从 Quicker 1.x 体验 V2 前，先确认 Preview、专业版、免费账号和回退风险。不要把 V2 直接替换为唯一可用的关键 1.x 环境。

## 必读顺序

1. [体验前必读](/important-notice)：Preview、专业版、免费账号、并存限制和降级风险。
2. [从 V1 迁移到 V2](/v2/migration/from-v1)：同步、导出、备份、卸载 1.x、安装 V2、首次登录和验证清单。
3. [数据存储与同步变化](/v2/what's-new/data-and-sync)：V2 数据空间、同步项目、数据分支和回退边界。
4. [新面板窗口迁移](/v2/migration/new-main-win/load-action-page)：在新面板中加载场景、分组和旧动作页入口。

## 核心原则

- 1.x 与 V2 不建议同时安装使用；浏览器扩展等组件会冲突。
- 首次登录 V2 会建立新的数据空间，不是与 1.x 长期双向镜像。
- 回退到 1.x 时重新安装 1.x，并使用迁移前备份或 1.x 自己的数据。
