# 文本指令（V2 变化）

:::info[完整功能说明已合并至功能目录]
文本指令的正文规则、正则匹配、批量复制到其它场景与移动到父场景请查看主文档 **[文本指令](/v2/features/triggers/text-commands)**。本页仅保留相对 1.x 的变化与升级注意点。
:::

## 相对 1.x 的主要变化

- **原生程序/网址场景规则**：除账号级全局列表外，可直接为程序、标题子场景或网址场景配置，并支持在场景与全局之间批量复制/移动。
- **切换窗口不简单丢弃已输入前缀**：仅当 WPS 内部文档处于不稳定过渡态时保守回退到宿主与全局规则。

## 从 1.x 升级时需要注意

- 原有全局指令、分组、分享与进程过滤保留；正则、触发字符、大小写及输入法清除沿用原语义。
- 本地禁用同规则会屏蔽上级；在批量粘贴到全局或覆盖进程列表前请核对分号分隔的进程名。
