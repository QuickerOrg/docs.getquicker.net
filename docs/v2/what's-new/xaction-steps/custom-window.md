# 自定义窗口模块

2.x 优化了自定义操作窗的创建和事件处理。相同辅助 C# 代码的回调会复用编译与方法查找结果，复杂窗口重复打开时可以减少准备时间；字段变化和按钮事件的映射也会在窗口初始化时整理，不再每次从头扫描。

窗口上下文会保存创建它的动作 ID、标题和触发来源，并提供读取、写入该动作状态的能力。即使非模态窗口晚于原动作关闭，回调仍可按创建窗口时的动作身份工作。

窗口回调和其中运行的子程序也会关联到结构化调试会话；停止时按窗口所有权处理，减少一个窗口关闭时误停其它窗口子程序的情况。

参数说明见[自定义操作窗](/v2/xaction/modules/customwindow)。
