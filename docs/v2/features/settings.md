# 设置页面与功能入口

打开设置后，可按左侧分组浏览，也可搜索选项名称。页面名称和位置可能与 1.x 不同；旧入口会按功能定位到合并后的页面。需要排查某个开关时，先记录原值，每次只调整相关选项。

<a id="BasicInfo" />

## 常规

管理启动、托盘、提示消息、性能、网络和更新等基础选项。网络代理修改后应保存；只在输入框编辑并不代表代理已经生效。鼠标与键盘触发的共用参数也在这里，修改时会影响多个触发功能，不宜为了单条规则随意缩短时间阈值。

<a id="FunctionHotkeys" />

## 功能快捷键

配置打开面板、搜索等 Quicker 功能的快捷键。动作快捷键、热键联动、按键双击及快捷键占用查询从页面相关入口打开，规则本身仍由各自管理器编辑。功能快捷键与[超级键](./triggers/powerkeys.md)不同。

<a id="BlackListSettings" />

## 黑名单

指定需要限制触发的程序，并核对具体禁用项。全屏禁用、单击 Ctrl 弹出面板和各功能独立黑名单的范围不同，不应把其中一个开关当作暂停所有动作。见[触发方式与黑名单](./triggers/index.md#程序黑名单与全屏禁用)。

<a id="PanelPopupSettings" />

## 弹出方式

选择鼠标或键盘弹出面板的方式，并检查长按、双击等时间参数。与其它软件冲突时，先停用可疑触发方式，再单独试用。新版面板的隐藏与位置选项见[面板使用](./action-panel/usage.md)。

<a id="PanelTriggerKeySettings" />

## 触发按键

配置键盘方式弹出面板后，如何用按键触发面板动作。这与直接运行某个动作的快捷键不同；测试时应先按所配置的方式弹出面板，再输入触发键。

<a id="ActionDesignerSettingsPage" />

## 动作设计

调整动作设计器相关选项。学习编辑步骤、变量和外观请阅读[动作编辑器](/v2/xaction/concepts/xaction-editor/)；简单触发操作则见[快速操作](./quick-operations.md)。

<a id="BlockOptions" />

## 模块选项

管理组合动作模块使用的公共选项。修改后应针对使用该模块的动作试运行，不要将全局模块配置与单个步骤的参数混为一谈。模块具体参数见[组合动作模块](/v2/xaction/)。

<a id="ActionManagementPage" />

## 全部动作

按名称和筛选条件查找当前账号的动作，查看使用位置并整理入口。把动作拖到面板会建立入口，不等于复制动作本体；隐藏动作与删除动作也不同。见[管理多个场景和大量动作](./action-panel/usage.md#管理多个场景和大量动作)。

<a id="PublicSubProgramsPage" />

## 公共子程序

管理当前账号可复用的公共子程序、分组和分享。子程序并非一个普通面板动作；修改前先检查被哪些动作引用。定义与引用方式见[子程序](/v2/xaction/concepts/subprogram/)，对外发布见[分享公共子程序](./action-sharing.md#分享公共子程序)。

<a id="AutoRunActions" />

## 自动运行动作

管理启动后或定时执行的规则。新增或编辑规则时，确认启用状态、时间条件、目标动作和限定主机；只需要在一台电脑执行的任务，应核对主机限制，避免多台设备重复运行。规则支持复制、粘贴和删除；粘贴后仍应逐项检查参数。

<a id="EventTriggerSettingsPage" />

## 事件触发

选择事件类型、事件参数和目标动作，并确认规则启用状态。不同事件的参数不同，不能只改事件名称后沿用原参数。列表中可查看说明、动作和限定主机，编辑后用真实事件试验，避免高频事件反复启动有副作用的动作。

<a id="HelperFunctionsSettingPage" />

## 常用辅助功能

这里集中提供辅助功能开关和管理入口，包括[高级鼠标触发](./triggers/advanced-mouse-triggers.md)等。打开管理器后仍需为目标场景配置规则；开启开关本身不会自动创建动作。

<a id="QuickCaptureSettings" />

## 快速截图

配置快速截图功能。它与“Quicker 截图”页面的选区、完成动作、保存及历史选项不同；先确认使用的是哪种截图入口。截图、贴图及新截图工具的区别见[截图功能](./screenshot/index.md)。

<a id="ScreenCaptureRecognitionSettings" />

## 识别与翻译

配置基础 OCR、图片翻译服务和本机凭据。先选择服务，再按服务要求填写凭据；旧版和新版图片翻译的开通流程不同，不能混用。详细开通与配置见[图片翻译](./screenshot/image-translate.md)。

<a id="AiAgentTools" />

## Agent 工具

配置联网搜索等 Agent 工具及其服务连接。工具连接与模型服务是两套配置；配置模型可用并不代表搜索工具已经可用。选择工具提供方并补齐其连接后，使用不含敏感信息的问题验证调用。见[AI 与 Agent](./ai-and-agent.md)。

<a id="BasicToolsSettingPage" />

## 维护工具

提供维护和排障入口。诊断时先看当前状态、日志和报告，再按工具提示操作；不要在没有备份的情况下直接重建或清理数据。诊断报告和动作运行记录见[内置工具](./tools.md)。

<a id="AboutSettingPage" />

## 关于 Quicker

查看账号、版本、隐私声明与用量统计。反馈问题时附上实际版本和相关功能，不要把日志中的账号凭据公开发布。

<a id="HotkeyUsageLookupPage" />

## 快捷键占用查询

从功能快捷键或超级键页面的相关操作中打开，输入组合键，检查功能快捷键、动作快捷键和键盘监听规则的匹配结果。查询的是 Quicker 能识别的规则，不能保证其它应用没有占用该组合键。

<a id="PrivacyPolicy" />

## 隐私声明

在“关于 Quicker”中打开客户端当前的隐私声明。需要了解数据存放与同步边界时，另见[账号与同步](./account-and-sync.md)。

<a id="UsageStatisticsInfoPage" />

## 用量统计

在“关于 Quicker”中打开用量统计入口。用量信息不等于动作历史备份，也不能据此恢复动作内容。
