# 快速操作与操作类型

在轮盘位置、文本指令、超级键、鼠标手势等规则中，可以直接选择要执行的操作。操作编辑器顶部的类型按钮用于选择类型，下方参数随类型变化；不必为每个简单任务都另建组合动作。

## 选择操作

1. 在相应功能的管理界面中新增或编辑一个位置、指令或规则。
2. 点击操作类型按钮，选择“运行其它动作”、输入、打开文件或其它操作。
3. 填写该类型的必填参数，并核对要操作的程序、文件或目标动作。
4. 在宿主编辑器中保存；取消编辑不会应用本次修改。

“继承全局设置”只在支持场景覆盖的编辑器中出现，表示沿用全局规则，不是清空该位置。“无操作”与继承不同；是否提供这些选项取决于所在功能。

## 常用类型

| 类型 | 用途 |
| --- | --- |
| 运行其它动作、链接动作 | 运行已经存在的动作；需要传参时填写动作参数 |
| 发送快捷键、模拟按键B、发送文本、粘贴内容 | 向目标窗口输入；不同类型的语法和粘贴方式不同 |
| 多步骤模拟输入 | 按顺序安排输入步骤与等待 |
| 启动程序、打开文件、打开文件夹、打开网址、运行命令 | 直接打开目标或运行命令，见[基础操作](./basic-actions.md) |
| 内置功能 | 执行所选 Quicker 功能 |
| 加载指定场景的动作、打开动作页 | 切换动作入口，先确认场景或动作页 |
| 悬浮分组 | 按名称显示、关闭或切换分组；同名分组会一起操作 |
| 启动轮盘菜单、启动鼠标手势、快速截图 | 调用相应功能 |
| Quicker脚本动作 | 使用 C# 和 qk API，见[脚本动作](/v2/script-action/) |

## 触发提示与运行环境

触发提示用于说明这个操作，不会代替操作参数。键盘、鼠标或文本触发可能改变焦点；配置输入操作时，先用无敏感内容的窗口验证焦点、输入法及等待时间。

编辑器显示不支持的操作类型时，会保留原始数据。不要为了消除提示而随意换成其它类型；切换类型后应重新检查参数。

复杂流程、条件判断和重复执行适合使用[组合动作](/v2/xaction/)，再从触发规则运行该动作。
