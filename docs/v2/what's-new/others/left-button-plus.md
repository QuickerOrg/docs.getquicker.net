# 左键辅助

左键辅助是在按住鼠标左键时，再按另一个键或鼠标键来执行操作。它适合在拖选文字、框选对象或持续按住左键的过程中快速调用复制、搜索、窗口操作等功能。

2.x 保留了 1.x 的短按、长按和进程兼容配置，并把动作规则集中到场景与动作管理窗口。

## 全局开关与场景动作分开

左键辅助的全局启用状态、兼容禁用应用列表和动作规则现在集中显示在“全局 · 左键辅助”中。旧版进程黑名单继续兼容，但新配置建议直接在对应程序或网址场景中禁用。

普通场景可以覆盖全局或父场景中相同第二按键的规则：

- 当前场景没有该按键：使用上级规则；
- 当前场景设置该按键：使用本地规则；
- 当前场景将该按键规则禁用：阻止上级同按键规则触发；
- 删除本地规则：恢复上级继承。

因此，“禁用本地规则”和“恢复继承”是两个不同操作。

## 短按和长按分别配置

每个“左键 + 第二按键”规则可以分别设置：

- 单击操作：第二按键短按时执行；
- 长按操作：第二按键保持一段时间后执行；
- 规则说明和启用状态。

父级规则可以被当前场景完整覆盖。编辑器会明确显示两个操作区域，未设置其中一项时不会影响另一项。

## 拖放动作快速设置

在管理页中，可以把动作面板中的动作直接拖到已有规则上，替换短按或长按操作；也可以拖到列表空白处创建新规则。

列表支持双击编辑、添加按键、删除选择项，并独立显示每条规则的启用状态。动作以引用方式保存，原动作标题、图标或内容更新后，左键辅助可以继续使用最新内容。

## 目标窗口判断更一致

2.x 使用统一的鼠标目标和场景识别结果开始左键辅助会话。对桌面、任务栏、普通资源管理器、UWP、WPS 和浏览器网址，规则选择与其它场景触发功能保持一致。

设置窗口和动作编辑窗口等普通 Quicker 窗口也可以按场景规则触发左键辅助；主面板和明确不参与全局触发的悬浮窗口仍会排除。

删除用户已配置的全局规则后，2.x 不会在下一次运行时悄悄恢复同位置的系统预置动作。只有尚未初始化过规则的账号才会使用初始默认值。

## 从 1.x 升级时需要注意

- 原有左键辅助规则和兼容黑名单会继续保留；
- 新增禁用建议使用对应场景规则，不再继续扩大旧进程黑名单；
- 禁用本地按键规则会屏蔽上级同按键规则，删除本地项才恢复继承；
- 绘图、拖放、按住空格平移等软件可能大量使用“左键 + 键盘”，建议只启用明确需要的第二按键；
- 如果与扩展热键、高级鼠标或系统快捷键共用按键，请按真实按下顺序测试是否冲突。
