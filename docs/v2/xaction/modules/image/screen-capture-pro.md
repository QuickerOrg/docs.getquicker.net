## 参数说明

**操作**（2.2.17 起）：默认“截图”可调整选区、标注并确认；“框选即出图”直接返回图片；“立刻复制 / 立刻贴图”直接完成对应操作。还可选择“识别并复制”、文本 / 表格 / 公式识别、文本 / 图片翻译或“快速保存”。本参数不受全局“直接截图的完成操作”影响，各操作只显示适用的参数与输出。

**2.3.24 起，“操作”支持变量输入。** 可根据动作前面得到的结果，动态选择本次截图的完成方式；固定选择仍使用原来的下拉项。变量内容须是客户端支持的操作值，不要使用未定义的文字。分享给旧版本用户前，请验证旧客户端能否使用此种输入方式。（[#626](https://github.com/QuickerOrg/Quicker2-issues/issues/626)）

**加入截图历史**：默认开启，但仍遵循全局截图历史开关；取消勾选可排除本次截图，不能反向打开全局历史。

**截图前延迟时间**：等多少毫秒再进入截图。从面板或轮盘触发时，可垫一点延时，避免截到 Quicker 自己。

**预选截图区域**（2.2.19 起）：填写物理屏幕坐标 `left,top,right,bottom`，右、下边界不包含在区域内。在 2.2.19–2.2.24 中，仅“截图”和“快速保存”支持此参数；指定后跳过第一次手动框选，进入可调整和标注的截图状态。留空时仍正常手动选择。2.2.25 起对其他操作的支持见下文。

**确认后复制图片**：仅在默认确认出口（打勾、双击或 `Enter`）结束后，把结果写入剪贴板。复制出口本身会写剪贴板；保存、工具栏直接贴图以及自定义工具栏的 `post.confirm` / `post.pin` 不会再叠加此参数。默认关闭。

:::note 勾选后，工具栏中的复制入口会自动隐藏

勾选 **确认后复制图片** 后，确认按钮已经负责复制，截图工具栏会自动隐藏独立的 **复制到剪贴板** 入口，包括放入分组或“更多”菜单中的复制项。例如，“保存＋复制”组会只剩保存按钮，下拉箭头也会消失；布局配置中的复制项仍然保留。

若希望保留独立复制入口，请取消当前步骤的 **确认后复制图片**，再重新运行截图。这个步骤参数与 **设置 → 截图 → Quicker 截图 → 截图确认后执行 → 复制到剪贴板** 分别配置；只取消全局设置，不会取消动作步骤中的勾选。

:::

**确认后贴图**：仅在默认确认出口结束后，在选区位置弹出贴图窗口。保存、复制、工具栏直接贴图以及自定义工具栏的 `post.confirm` / `post.pin` 不会再叠加此参数。默认关闭。

**贴图后显示工具栏**：贴图窗口打开后是否自动显示标注工具栏。默认关闭；需要时可按空格再显示。

**自动吸附UI元素**：开启后悬停自动吸附到控件；关闭时只跟随窗口范围，用滚轮选择更细的控件。2.2.17 起新建步骤默认开启，已有步骤保留原参数；旧动作未保存该参数时仍按关闭处理。

**自定义工具栏**：给 Quicker 截图工具栏添加自定义按钮，或在进阶场景下重排工具栏。可内联填写 JSON / JS，也可外置为动作包内文件。完整写法见上面的 **JS 自定义工具栏**。

**失败后停止**：失败或取消是否中止动作。默认开启。

## 各操作的预选区域与完成后操作

以下行为需要 2.2.25 或更新版本；在 2.2.24 中，预选区域仍只适用于“截图”和“快速保存”。

“预选截图区域”扩展到所有操作。“截图”和“快速保存”仍先进入可调整、标注的状态；其他操作会直接在指定区域执行，不再等待手动框选。例如，选择“识别并复制”并填写 `100,100,500,300`，会识别该 400 × 200 物理像素区域，并在识别成功后复制文本。坐标格式无效会报错；留空仍走手动选区流程。

“确认后复制图片”和“确认后贴图”除普通“截图”外，也适用于“框选即出图”和“快速保存”。“框选即出图”在选区完成后应用这两个选项，“快速保存”在确认截图后应用；若改从工具栏的复制、保存、直接贴图或自定义出口结束，不会额外叠加这两个选项。具体可见参数以所选操作的模块定义为准。

## 2.3.13 · 单次截图参数与结束方式

以下参数只影响本次运行，不改全局截图偏好；默认继承设置，已有动作无需重新配置。

- **包含鼠标指针**：可选“跟随设置”“包含”“不包含”，决定本次初始值；进入截图界面后仍可临时切换。
- **确认快存目录**：留空使用全局目录。
- **文件名模板**：留空继承全局，支持 `{date}`、`{date:格式}`、`{time}`、`{width}`、`{height}`，重名自动加序号。
- **保存格式**：可选“跟随设置”“PNG”“JPEG”。

后三项用于“快速保存”操作的确认快存，不影响工具栏“另存为”中用户另行选择的路径。可见参数随“操作”变化。

原“写入剪贴板”和“截图后贴图”在界面中改名为 **确认后复制图片** 和 **确认后贴图**，触发范围不变，仍只在对应确认出口生效。

新增文本输出 **结束方式**，可据此决定后续步骤：

| 输出值 | 实际出口 |
|---|---|
| `confirmed` | 确认完成 |
| `saved` | 保存 |
| `copied` | 复制 |
| `pinned` | 贴图 |
| `ocr` | OCR |
| `qr_code` | 二维码识别 |
| `text_translation` | 文本翻译 |
| `recording` | 录屏 |
| `long_screenshot` | 长截图 |
| `toolbar_confirmed` | 自定义工具栏确认 |

失败或取消时为空。先判断 **是否成功**，再读取结束方式和相应结果；识别、录屏等出口不保证产生图片或保存路径。“确认后复制图片 / 贴图”不会把 `confirmed` 改为 `copied` / `pinned`。如果关闭“失败后停止”让动作在取消后继续，更应先检查成功状态。

## 输出

输出以所选“操作”的参数界面为准，下面列出常见截图输出。识别类操作按用途打开结果窗或复制文本；“识别并复制”在识别完成前取消时，不再写入剪贴板。

- **是否成功**：是否完成截图。
- **图片**：截到的图。
- **截图区域**：格式 `left,top,right,bottom`。
- **保存路径**：用户点保存并写入磁盘后的路径，或“快速保存”成功后的自动保存路径；普通截图只用确认按钮结束时为空。
