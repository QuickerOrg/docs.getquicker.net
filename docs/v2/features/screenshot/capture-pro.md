# 截图 Pro

截图 Pro 是 Quicker 的渐进式选区截图：进入后先出现全屏遮罩，光标附近会给出初始选区；你可以拖拽框选，也可以直接利用**自动选区**快速锁定窗口、面板和具体控件，再标注、复制、保存或贴图。同一界面也可进入长截图或录屏。

在组合动作中，对应步骤为 **截图 Pro**（步骤 Key：`sys:screenCapturePro`）。

## 快速开始

### 作为动作步骤

1. 在动作编辑器中添加 **截图 Pro** 步骤。
2. 按需设置延迟、是否写入剪贴板、是否截图后贴图、是否自动吸附等参数。
3. 运行动作。屏幕进入全屏选区界面。
4. 框选或确认高亮区域，必要时标注，然后复制、保存、贴图或确认结束。

步骤成功后可得到：

- **图片**：截取到的图像变量
- **截图区域**：屏幕坐标 `left,top,right,bottom`
- **保存路径**：若通过「保存」写入磁盘则返回文件路径，否则为空

### 基本操作流程

1. 进入截图后，移动鼠标查看高亮区域；或按住左键拖拽框选。
2. 如果当前高亮还太大，先滚动鼠标滚轮在父 / 子控件之间切换；满意后再单击或按 `Enter` 确认。
3. 按 `Space` 显示或隐藏标注工具栏，进行画框、箭头、文字、马赛克等标注。
4. 用复制、保存、贴图或确认按钮（或对应快捷键）结束；`Esc` 或右键可取消 / 重选。

## 选择区域

### 自动选区是核心能力

截图 Pro 最值得优先使用的能力，不是“先拖框”，而是**先悬停、再用滚轮切换层级**：

- 悬停到目标窗口附近，先得到一个稳定的大范围高亮。
- 如果高亮的是整个窗口、整个面板，而你只想截某个按钮或输入框，就滚动鼠标滚轮。
- 每滚动一档，选区会沿着 UI 层级在父 / 子元素之间切换，通常很快就能落到你真正想截的控件上。

把鼠标移入下方演示区可亲自体验：悬停自动吸附最细控件，滚轮向上扩大父级、向下缩小子级。

很多场景下，这比手动拖框更快，尤其适合截取菜单、设置页局部、按钮、列表项、输入框等标准界面元素。

### 悬停高亮与框选

进入截图后：

- **移动光标**：可用鼠标，也可用 `W` / `A` / `S` / `D` 微调位置。
- **框选**：按住左键拖拽画出矩形区域。
- **确认高亮区域**：单击或 `Enter`。
- **取消**：`Esc` 或右键。

确认选区后进入调整阶段：

- **移动选区**：`W` / `A` / `S` / `D`
- **缩放选区**：鼠标滚轮
- **确认**：双击或 `Enter`
- **重选 / 取消**：右键或 `Esc`

### 自动选区（控件吸附）

截图 Pro 支持按窗口 / UI 控件高亮选区，便于精确截取按钮、列表项、输入框等。默认建议先把它理解成“自动选区”：

- **悬停**：先锁定当前窗口或较大的控件范围；
- **滚轮**：在父 / 子控件之间切换；
- **确认**：单击或 `Enter` 固定当前范围。

动作步骤中的 **自动吸附**（默认关闭）：

| 设置 | 行为 |
| --- | --- |
| 关闭（默认） | 悬停时优先跟随窗口范围；需要更细的控件层时，用鼠标滚轮在父 / 子控件间切换，并按需触发精细探测 |
| 开启 | 悬停时持续尝试吸附到更细的控件元素；仍可用滚轮在父 / 子层级间切换 |

提示：

- 如果你想稳定地先看大范围，再自己滚轮缩到按钮或输入框，保持默认关闭通常更容易控制。
- 如果你经常直接截标准控件，可开启 **自动吸附**，让悬停时就更积极地下钻到细控件层。
- 部分自绘界面、游戏、远程桌面或特殊浏览器页面可能无法得到理想的控件矩形，此时请改用手动框选。
- 多显示器、混合 DPI 环境下仍可使用；若高亮略有偏差，可在确认后用滚轮或拖动手柄微调。

## 标注

确认选区后，按 `Space` 打开工具栏（再次按下可隐藏）。常用工具包括：

| 工具 | 说明 |
| --- | --- |
| 鼠标操控 | 移动、调整选区，不绘制 |
| 铅笔 | 自由手绘 |
| 矩形 / 椭圆 / 折线 | 形状标注；折线可单击加点，右键或 `Enter` 结束 |
| 箭头 | 指向说明 |
| 序列号 | 步骤编号 |
| 文本 | 添加文字说明 |
| 马赛克 / 智能马赛克 | 手动打码，或识别文字区域后自动打码（见下文） |
| 聚光灯 | 压暗周围，突出关注区域 |
| 橡皮擦 | 擦除标注 |
| 撤销 / 重做 | `Ctrl+Z` / `Ctrl+Y` |

工具栏上还可直接进行 OCR、**图片翻译**、保存、复制、贴图，以及进入长截图或录屏。

图片翻译会调用你在开放平台配置的百度 / 有道**图片翻译** API，得到译文贴合图后再复制或替换；配置步骤见 [图片翻译](./image-translate.md)。

需要加入「调用子程序处理图片」或「把图交给某个动作」等按钮时，可用 [JS 自定义工具栏](./toolbar-script.md) 只返回自定义按钮列表（默认工具栏保留，固定位置出下拉）。只有要改内置工具顺序时才整栏重排（后续由截图 Pro 步骤的输入参数传入脚本）。

### 马赛克与智能马赛克

马赛克工具是一个**分裂按钮**：左侧主键执行当前模式，右侧箭头在「手动马赛克 / 智能马赛克」之间切换，并记住上次选择。

**手动马赛克**：在图片上拖拽绘制打码区域。副工具条可选效果：

| 效果 | 说明 |
| --- | --- |
| 马赛克 | 像素化打码 |
| 模糊 | 高斯模糊 |
| 填充 | 按邻域取色硬填充，适合 UI 纯色块去字（非 AI 修复） |

**智能马赛克**：自动识别文字区域后再打码：

1. 进入工具后，对当前截图选区（截图界面）或整张图片（贴图）运行 OCR。
2. 悬停可高亮候选文字框；**单击**切换单个候选的打码 / 取消。
3. **拖框**可一次选中多个候选，批量应用为一个撤销步骤。
4. 仍在智能马赛克工具下时，若选区变化会防抖后自动重跑识别。

智能马赛克**不会**打开 OCR 结果窗，也**不会**写入贴图的文本选择层。

## 文字识别（OCR）

截图 Pro 与贴图共用一套本地 OCR 能力，但使用场景不同：

| 场景 | 行为 |
| --- | --- |
| 截图工具栏点 OCR | 结束当前截图会话，打开「文字识别」结果窗 |
| 贴图工具栏 / 右键「识别文字」 | 打开同一结果窗；成功后还会把文字写入贴图的不可见文本选择层 |
| 新建贴图后（自动） | 后台静默识别，不弹结果窗、默认不显示区域边框 |

### 识别引擎

- **优先本地 OCR**：首次使用需登录 Quicker，并按需下载依赖包（默认快速模型约 7MB，标准模型约 31MB）。
- **本地失败时**：若你在设置中配置了自有百度 OCR Key，会尝试在线识别。
- **不会**使用 Quicker 云端 OCR，也**不会**回退到 Windows 内置 OCR。

### 结果窗

打开后会先显示预览与进度，识别完成后再填入文字。你可以：

- 在左侧缩放查看原图（可隐藏预览区）。
- 在右侧编辑、复制识别文本。
- 切换 **快速 / 标准** 模型后重新识别（若该档模型尚未安装，会提示下载）。
- 使用「自动排版 / 恢复原始排版」整理段落。
- 点「复制并关闭」一次性复制并关闭窗口。

### 贴图上的选字复制

贴图在移动模式下，可直接在图片上拖选或双击选字，用 `Ctrl+C` 复制。文字层默认不可见；若需要对照识别区域，可在移动模式右键菜单中打开「显示文本区域边框」。

自动 OCR 在后台运行时，若你正在使用铅笔等标注工具，**不会**强制切回移动工具或抢占键盘焦点。关闭贴图会取消尚未完成的识别；从上次会话恢复的旧贴图不会批量重跑 OCR。

## 结束方式

确认选区（并可标注）后，常见结束方式：

| 操作 | 快捷键 / 入口 | 结果 |
| --- | --- | --- |
| 复制 | `Ctrl+C` 或工具栏「复制」 | 将当前图像（含标注）写入剪贴板，并结束截图 |
| 确认截图 | 双击、`Enter` 或工具栏确认 | 把图片返回给动作步骤，不强制写剪贴板 |
| 保存 | `Ctrl+S` 或工具栏「保存」 | 打开保存对话框写入文件；步骤可输出保存路径 |
| 贴图 | `Ctrl+T` 或工具栏「钉住」 | 在选区位置打开浮动贴图窗口 |
| OCR | 工具栏「文字识别」 | 结束截图并打开 OCR 结果窗（仍可能输出图片变量） |
| 长截图 | `L` 或工具栏「长截图」 | 进入长截图流程 |
| 录屏 | `G` 或工具栏「录屏」 | 进入区域录屏 |
| 取消 | `Esc` / 右键 | 取消本次截图或回到重选 |

说明：

- 若步骤勾选了 **写入剪贴板**，在标准确认 / 保存结束时，步骤侧也会把结果图写入剪贴板。
- 若步骤勾选了 **截图后贴图**，在标准确认结束（且不是「保存」结束）时，会再打开贴图窗口。工具栏里直接点「贴图」属于界面内出口，不依赖该参数。
- 长截图、录屏、OCR、界面内复制 / 贴图等「另类出口」会在截图界面内完成对应操作；步骤仍可能带上可用的图片、区域或路径输出。
- 成功确认、复制、保存、OCR、直接贴图等操作默认会写入本机**截图历史**（可在采集历史中心查看）；取消、仅选录屏范围、长截图过程中的中间帧不会收录。

## 贴图窗口（截图后）

贴图会把图片浮在屏幕上，方便对照、标注或临时展示。新建贴图后通常会在后台自动 OCR，可直接在图上选字复制（见上文）。

### 移动模式

- **右键短按**：打开菜单（识别文字、图片翻译、复制 / 另存为、图像处理、显示、锁定、历史记录、关闭等）
- **右键拖框**：进入非破坏性缩略图视口
- **`R`**：切换缩略图模式
- **`Shift + 左键双击`**：以双击点为中心进入正方形缩略视口
- **`Ctrl + 滚轮`**：调节窗口透明度
- **`Ctrl + 左键拖动`**：把当前合成图拖到其它程序
- **空格**：显示 / 隐藏标注工具栏
- **`L`**：锁定 / 解锁窗口
- **`T`**：切换置顶
- **`Ctrl+W` / `Esc`**：关闭贴图

### 图像处理与工具栏

- **工具栏隐藏时**：数字键 `1`–`8` 可快速旋转、翻转、灰度、反色、亮度等；`0` 重置滤镜、方向与不透明度。
- **工具栏显示时**：数字键优先选择标注工具（见「快捷键一览」），不再触发图像处理。

### 显示与缩略图

- 右键菜单「显示」可调缩放（25%–200%）、不透明度预设、窗口阴影、置顶等。
- 缩略图模式下，复制和另存为只输出当前可见部分；完整内容在退出缩略图后仍保留。
- 缩略图视口内可平移、拖拽边缘调整窗口大小；菜单中可用「重置缩略图范围」恢复，或用 **裁剪** 永久裁成当前视口。

### 锁定与历史

锁定窗口后，不能移动、缩放、改透明度或继续标注，但仍可复制、保存、OCR，以及开关置顶 / 阴影等。

右键菜单中的 **历史记录…** 可打开采集历史中心，查看当前贴图、已关闭贴图、截图历史与录屏历史，并做筛选、多选与批量操作。

## 动作步骤参数

| 参数 | 默认 | 说明 |
| --- | --- | --- |
| 截图前延迟时间 | `0` | 开始截图前等待的毫秒数，便于先打开菜单或隐藏 Quicker 面板 |
| 写入剪贴板 | 关 | 标准结束时是否把图片写入剪贴板 |
| 截图后贴图 | 关 | 标准确认结束时是否自动贴图；通过「保存」结束时不贴图 |
| 贴图后显示工具栏 | 关（高级） | 贴图窗口打开后是否自动显示标注工具栏；关闭时仍可按空格显示 |
| 自动吸附 | 关 | 是否在悬停时持续吸附到细控件；关闭时滚轮再触发精细选区 |
| 工具栏脚本（即将提供） | 空 | 可选的 JS 脚本，默认只加自定义按钮（原工具栏保留）；写法见 [JS 自定义工具栏](./toolbar-script.md)。未配置时使用默认工具栏 |
| 失败时中止动作 | 视步骤配置 | 用户取消或失败时是否中止后续步骤 |

输出：

| 输出 | 说明 |
| --- | --- |
| 是否成功 | 步骤是否成功 |
| 图片 | 截取图像 |
| 截图区域 | `left,top,right,bottom` |
| 保存路径 | 用户保存到磁盘时的路径，否则为空 |

同一时间只能进行一次截图 Pro；若已在截图中再次触发，会提示等待当前截图完成。

## 常见问题

### 控件高亮不准或不出现

先确认步骤是否开启 **自动吸附**；关闭时需要滚轮才会进入更细的控件层。若你已经滚轮切换但仍没有更准确的高亮，通常说明目标程序没有提供可靠的 UI 自动化信息，这时请改用手动拖拽框选。

### 截图后剪贴板没有图片

检查步骤是否勾选 **写入剪贴板**，或是否在截图界面内使用了 `Ctrl+C` / 工具栏复制。仅「确认」结束且未勾选写入剪贴板时，图片只进入动作变量。

### 保存后没有自动贴图

这是预期行为：通过「保存」结束时，步骤侧的 **截图后贴图** 不会再打开贴图窗口。需要贴图时可在保存前先贴图，或用单独的贴图步骤处理已有图片。

### OCR 提示需要登录或下载

本地 OCR 依赖按需下载的识别组件，需先登录 Quicker 账号。首次识别或切换更大模型时可能短暂下载；下载完成后同一模型不会重复下载。

### 贴图上看不到文字框，但似乎能选中

这是预期行为：自动 OCR 默认只填充不可见的文本选择层，不显示边框。需要对照区域时，在移动模式右键菜单打开「显示文本区域边框」；也可点 OCR 按钮打开结果窗查看全文。

### 智能马赛克识别不到文字

智能马赛克依赖 OCR 结果。若图片过小、文字过糊或背景复杂，请改用手动马赛克，或先用 OCR 结果窗确认能否识别。

### 图片翻译提示未配置或验证失败

图片翻译需要自备百度或有道的**图片翻译** API Key，在 **设置 → 截图 → 截图设置** 中填写，并与 OCR Key 分开。仅开通文本翻译、未开通图片翻译时会失败。详见 [图片翻译](./image-translate.md)。

### 想截下拉菜单或短暂弹出的内容

把 **截图前延迟时间** 设为几百到几千毫秒，先运行动作，再在倒计时内打开菜单，然后再框选。

### 与「屏幕截图」步骤有何不同

**截图 Pro** 面向交互式选区：控件吸附、标注、OCR、贴图、长截图和录屏入口更完整。传统屏幕截图步骤适合更简单的截取需求。新动作优先使用截图 Pro。
