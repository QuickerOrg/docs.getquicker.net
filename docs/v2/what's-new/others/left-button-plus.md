# 左键辅助（V2 变化）

:::info[完整功能说明已合并至功能目录]
左键辅助（左键＋第二按键/长按/拖放）日常配置请查看主文档 **[左键辅助](/v2/features/triggers/left-button-plus)**。本页仅保留相对 1.x 的变化与升级注意事项。
:::

## 相对 1.x 的主要变化

- **全局开关与场景规则分离**：2.2.11 引入功能级黑白名单及场景级禁用；支持短按、长按与拖放分开配置，以及单次按住连续触发。
- **目标窗口判断统一**：与新版场景识别一致。

## 从 1.x 升级时需要注意

- 原有规则与兼容黑名单保留；停用本地项仍回退上级；多设备混用旧版本可能丢失 2.2.11 新增设置，请先备份并升级全部编辑设备。
- 绘图或设计类软件常按住空格/快捷键配合左键拖放，建议仅开启明确需要的组合键并实测按下顺序。
