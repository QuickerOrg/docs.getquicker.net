# 贴图

在屏幕指定位置浮动贴图（与截图 Pro 贴图窗口一致）。按来源自动识别图片、HTML、公式、OCR 原始结果或文本。

## 使用说明

这是 Quicker 2.0 新增模块，当前页面已收录模块定义，详细用法与示例待补充。

2.1.27 起，HTML、公式或剪贴板贴图窗口已经显示后，不再因后续未生成位图提示而误弹“未产生位图”。

2.1.28 起，贴图右键菜单「图像处理」可用 **抠出主体（透明背景）**；2.1.29 起可手动选择 **通用抠图** 或 **人像抠图**，在本机完成抠图后继续保存或贴图。首次使用需要已登录 Quicker，并下载约 4.4 MB 的独立本地模型；它和 OCR 文字模型分开管理，不会重复下载已有 OCR 模型。
