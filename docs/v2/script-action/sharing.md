脚本动作可以发布到分享平台，多操作动作中内嵌脚本也适用。发布前先检查源码、运行关键路径，并在说明中写清用途、外部依赖、输入输出和实际修改的数据。

## 能力必须能够识别

直接使用 qk.域.方法(...)。把 qk 或其域赋给变量、传给其他方法，使用 qk?.，只引用 qk.域，或写了不存在的成员，都会影响识别；无法识别的源码会被拒绝分享，提示会指出位置和修改方法。

单纯使用某个公开成员不会因为内部兼容档位而被禁止分享。高风险能力仍需在动作说明中清楚解释，安装者运行时按[来源和能力](./security.md)确认。

## 版本要求

分享时记录作者使用的 Quicker 版本。比该版本旧的客户端打开动作会提示升级。不要据此认为每个 API 都有独立的最低版本标记；也不要手改动作数据来绕过版本提示。

qk API 会随产品演进，旧写法需要按编辑器“检查”的提示修复。修改动作后先验证再发布；新版本增加能力时，安装者可能需要确认新增能力。授权保存在本机，不随动作导出或账号同步。
