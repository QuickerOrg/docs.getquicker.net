# AI 与 Agent 现状

这页说明 AI 写动作、模型配置和外部助手连接的常用入口。AI 结果需要检查，不同功能的开放范围以当前界面为准。

## 现在可以用

- **统一 AI 设置**：设置里的「AI 服务」和「用途与模型」，用来管理连接、模型和用途优选。说明见 [统一 AI 服务与模型设置](/v2/what's-new/ai-services-and-models.md)。
- **AI 助手界面**：2.2.5 起，可查看本机 Token 用量统计，并按时间、对话和模型查看用量及缓存命中；对话可按工作区分组，后台任务可从输入框上方展开查看。未配置模型时，可从提示直接打开配置入口。
- **Quicker AI 写动作预览**：2.2.0 起，可在新版主窗口暂存区点击 **用 AI 写**，让 AI 生成或修改暂存动作；完成后暂存区会自动刷新。2.2.4 起，重复点击 **用 AI 写** 会复用没有草稿的空对话；还没有配置模型时，会沿用 AI 助手的配置入口。长对话压缩或重新打开后，已经生效的动作编辑规则仍会保留。生成结果先留在本机暂存区，确认可用后再执行「保留到场景」转为正式动作。功能仍在改进中，AI 可能写错步骤或逻辑，保存前请自行检查、试运行和调试。
- **五个组合动作模块**，共用上面的全局设置，不必在每个步骤里重填地址和 Key：
  - [AI 文本处理](/v2/xaction/modules/ai-text)
  - [AI 图片理解](/v2/xaction/modules/ai-vision)
  - [AI 文本分类](/v2/xaction/modules/ai-classify)
  - [AI 结构化提取](/v2/xaction/modules/ai-extract)
  - [AI 交互对话](/v2/xaction/modules/ai-chat)

首次使用 AI 能力前，需要在「配置 API」中添加服务商、模型和 API Key。多数服务需要自备账号和额度；API Key 只在本机加密保存，不随动作分享，也不随普通设置文件拷到另一台电脑。

## 连接外部助手

在设置中打开外部助手的 MCP 设置页，可按页面指引连接本机外部助手：

1. 启用 MCP，功能默认关闭。
2. 按所用助手的安装指引配置连接，首次连接时在 Quicker 中同意。
3. 需要编写动作时，另行开启“允许 MCP 写入”；仅连接不等于获得写入权限。
4. 2.2.11 起，可在“已同意的 MCP 客户端”中删除授权记录，该助手下次连接需要重新同意。

连接信息与令牌从自己的设置页获取，不要把令牌贴入公开动作或文档。

## 对话与图片输入

2.2.11 改进“用 AI 写”对当前空对话的复用；有草稿的空对话经确认关闭后保留归档。图片缺少本地文字识别组件时，可按提示安装再识别；需要直接理解图像内容时，还应选择支持图片输入的模型。

## 当前功能边界

Agent 对话与外部助手设置已有用户入口，但不代表所有开发中的浏览器、桌面操控能力都已开放。“选网页元素”等仍受发布限制的入口，以当前软件界面为准。

不要把 1.x 的手机遥控或 Android 局域网遥控当成 V2 已有能力。V2 已移除手机 App 遥控器，目前也没有承诺替代方案。见 [不再支持的功能](/v2/what's-new/not-supported.md)。

具体功能是否已经改用统一候选模型，以该功能自己的页面和软件界面为准。
