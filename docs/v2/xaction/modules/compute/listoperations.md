# 列表操作

对列表变量做添加、删除、排序、筛选等操作。要手工拖拽排序、给用户改列表，用 [管理和排序列表](/v2/xaction/modules/managelist)。

## 当前模块定义

<XActionModuleMeta moduleKey="sys:listOperations" />

## 概述

先选 **操作类型**，再按类型填写 **列表**、**序号**、**值** 等。名称带「（输出到结果）」的操作不改原列表，新列表写到 **结果**。

<ModuleParamPreview moduleKey="sys:listOperations" />

## 参数说明

**操作类型**：要对列表做哪一种。点开下拉看当前全部选项。下面按组说明，名称与下拉一致。

**列表**：要操作的列表变量。

**失败后停止**：操作失败是否中止动作。默认开启。旧稿未写。

### 读取与改项

| 操作类型 | 说明 |
| --- | --- |
| 无操作（仅用于获取列表信息） | 不改列表，只取是否为空、长度 |
| 读取某位置元素 | 按 **序号** 取出一项，写入 **结果** |
| 添加元素到末尾 | 把 **值** 加到末尾 |
| 插入元素 | 插到 **序号** 处，后面的项后移 |
| 设置/更新某序号元素 | 用 **值** 替换该位置 |
| 获取值的序号 | 按 **值** 找位置，从 0 计；没有则 **序号** 输出为 `-1` |

### 去除与清空

| 操作类型 | 说明 |
| --- | --- |
| 去除元素(指定值，有多个时去除第一个) | 按值删掉第一次出现 |
| 去除元素(指定值，有多个时去除全部) | 旧稿未写。按值删掉全部相同项 |
| 去除元素(指定位置) | 按 **序号** 删除 |
| 去除元素(匹配正则表达式的项) | 如 `1, 12, 1234, 0` 正则 `1` → 只剩 `0` |
| 去除元素(不匹配正则表达式的项) | 只留下匹配正则的项 |
| 清空列表 | 去掉全部元素 |

### 排序、截取、拼接

这些项多数把新列表写到 **结果**，不改原来的列表。

| 操作类型 | 说明 |
| --- | --- |
| 排序A-Z（输出到结果） / 排序Z-A（输出到结果） | 字母序 |
| 自然排序A-Z（输出到结果） | 类似资源管理器，避免 `2` 排在 `11` 后面 |
| 排序文件列表：文件大小 / 创建时间 / 最后访问时间 / 最后写入时间 | 旧稿未写。列表项应是文件路径 |
| 倒置 | 前后颠倒，改原列表 |
| 截取（输出到结果） | 从 **序号** 起取 **长度** 项 |
| 拼接（输出到结果） | **列表** 后面接上 **列表2** |
| 去除重复（输出到结果） | 去掉重复项 |

### 筛选

筛选后的新列表写入 **结果**；不符合条件的项可写入 **剩余项列表**。

| 操作类型 | 说明 |
| --- | --- |
| 筛选（正则,输出到结果） | 用 **正则表达式** |
| 筛选（模糊匹配,输出到结果） | 用 **值** 做字符/拼音等默认匹配 |
| 筛选（包含） / 筛选（开始） / 筛选（结束） | 旧稿未写。按 **值** 做包含、开头、结尾匹配 |

**列表2**：仅 **拼接（输出到结果）**。接到末尾的另一个列表。

**序号**：从 0 计；负值表示从后往前。适用于读取、插入、设置、按位置去除、截取。

**长度**：仅 **截取（输出到结果）**。要取的个数。

**值**：添加、插入、更新、按值去除、按值找序号，以及模糊/包含/开头/结尾筛选时的关键词。

**按匹配程度排序**：仅 **筛选（模糊匹配,输出到结果）**。开启后按匹配程度倒序。旧稿未写。

**正则表达式**：按正则去除或按正则筛选时填写。

## 输出

- **结果**：取出的元素，或排序、截取、拼接、筛选后的新列表。名称带「（输出到结果）」的操作写到这里。
- **是否为空**：列表（或结果列表）是否没有元素。
- **列表长度**：元素个数；截取或拼接后是新列表的长度。
- **序号**：仅 **获取值的序号**。找不到为 `-1`。
- **剩余项列表**：仅筛选类操作。不符合条件的项。旧稿未写。

## 限制与排障

改原列表的操作（添加、插入、删除、清空、倒置）要求 **列表** 是变量；只输出新列表的操作不会改输入。文件排序项必须是存在的路径，否则顺序可能不符合预期。
