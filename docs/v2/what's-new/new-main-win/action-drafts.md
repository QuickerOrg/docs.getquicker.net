# 本机动作暂存区（V2 变化）

:::info[完整功能说明已合并至功能目录]
日常使用暂存区、试运行、AI 创建、安装分享动作到暂存区以及正式化流程，请查看主文档 **[本机动作暂存区](/v2/features/action-panel/action-drafts)**。本页仅保留相对 Quicker 1.x 的变化与同步边界摘要。
:::

## 相对 1.x 的主要变化

- **无需先挂载到动作页**：1.x 中新动作通常需先放入动作页；V2 支持在左侧「暂存区」独立创建、粘贴、调试和保留本机版本历史。
- **支持分享链接直接落入暂存区**：剪贴板含有效分享链接时，点击暂存区右上角 **＋** 可安装到暂存区验证，确认可用后再通过「保留到场景」或拖入正式场景（复用原动作标识）。
- **顶部新建与用 AI 写（2.2.0 起）**：可直接由暂存区发起创建或 AI 生成草稿；30 天未活动仅提示清理，不会自动删除。

## 同步与恢复边界

- **仅限本机当前账号**：暂存动作、暂存分组与本机版本历史均不参与云同步；跨设备使用前须先正式保留到场景并完成同步。
- **未加入正式触发/回收站**：暂存动作不能直接绑定快捷键、轮盘或手势；执行「丢弃」或「全部删除」不会进入正式动作回收站。
