# 内容上下文菜单

这是针对文本、图片、文件等内容弹出的菜单，与动作本身的[自定义右键菜单](/v2/xaction/concepts/action-custom-context-menu/)不同。打开 **设置 → 上下文菜单** 配置；旧版分开的文本、图片和文件设置入口现在会定位到同一页的对应项目。

## 呼出方式

可启用“长按 Ctrl+C 呼出上下文菜单”。按住时间超过“长按触发间隔”后，针对复制的内容弹出菜单；短按仍是普通复制。间隔范围为 100–3000 毫秒，按 10 毫秒取整；设得过短更容易误触发。

## 文本搜索服务

“文本搜索或翻译网址”每行一个服务，格式为 `网站名称|搜索网址`，用 `%s` 表示要搜索的文本。例如：

```text
Bing|https://www.bing.com/search?q=%s
百度|https://www.baidu.com/s?wd=%s
```

只填写接受文本查询的网址。使用服务前，请确认该服务仍可访问，并考虑选中文本是否适合发送给该网站。

## 图片搜索服务

“图片搜索网址”同样每行一个，格式为 `网站名称|搜索网址`，但 `%s` 表示**图片 URL**，不是本机文件路径或图片二进制内容。

应从目标搜图服务的官方说明取得当前有效的“按图片 URL 搜索”地址，再把图片 URL 参数替换为 `%s`。不同服务的参数和访问限制会变化，不能把普通关键词搜索地址直接当作搜图地址。服务需要能访问该图片 URL；本机私有图片不一定可被外部服务读取。

## 文件移动目标

“移动到”的目标文件夹每行一个。可直接写文件夹路径，或使用 `[图标]标题|路径` 自定义显示名称。执行前确认路径存在、权限允许，避免误移动文件。

## 菜单中的动作

需要挑选菜单内的动作时，使用对应管理入口，详见[挑选上下文菜单的内容](./tools.md#挑选上下文菜单的内容)。搜索服务配置与动作内容配置是两项不同设置。
