# AI 助手提示词库、会话历史与工作区

本页介绍桌面 **AI 工作台** 与 **问问 AI** 中管理提示词模板、会话历史、独立工作目录、模型上下文和对话界面操作的方法。用 AI 编写、修改动作和权限控制见[AI 助手与动作编写](/v2/features/ai-and-agent)，外部 MCP 接入见[连接外部助手与 MCP](/v2/features/ai/mcp-and-external-agents)。

## 按场景管理提示词库 {/* #prompt-library-2340 */}

2.3.40 起，可在 **设置 → AI → 提示词库**，或从 **问问 AI** 的提示词管理入口建立常用模板：

1. 先选择 **图片提问、文本提问、通用提问、AI 工作台** 中的适用场景。
2. 新建模板，填写名称、命令和正文；命令不含空格，同一场景内不能重复。
3. 保存后，在相应输入框中输入 `/` 或 `/命令` 选择模板。问问 AI 浮窗下方的模板按钮会 **替换当前输入并立即发送**，点击前请确认正文与附件。

模板保存在当前账号数据库。云账号保存后进入正常同步流程；离线时先保存在本机，联网后再同步。本地账号的模板不上传。不同设备修改不同模板或不同字段时会尝试自动合并；同一字段冲突、删除与修改冲突等仍需人工处理。保存提示不等于云端已确认。

编辑时若其它窗口或同步已经修改同一模板，本次保存会保留草稿并提示冲突。可用 **重新合并草稿** 取回最新列表，核对内容和重复命令后再保存；选择 **放弃草稿并刷新** 则丢弃当前未保存修改。同步到达不会自动发送问题。

:::caution[旧模板不会自动导入]
2.3.40 改用账号数据库，不自动迁移旧本机提示词。升级前请另行保存重要模板正文，再在新版重新建立；回退后只能看到旧库，新版的模板修改不会回写旧库。多设备与回退边界见[升级与回退](/v2/migration/upgrade-and-rollback#prompts-and-ocr-2340)。
:::

## 集中管理会话历史 {/* #conversation-history-2340 */}

2.3.40 起，**设置 → AI → 会话历史** 集中列出 AI 工作台、组合动作／C# 脚本／公共子程序编辑助手、设置和场景管理助手，以及动作内 AI 对话、模型测试等本机已保存记录。

- 先选来源和归档状态，再按标题、关联名称或 ID 筛选；这里不是全文搜索。
- 选中记录只读预览正文，按需加载较早消息；图片可双击通过系统默认查看器打开原图。
- 多选后可归档、恢复或永久删除。**永久删除不可撤销**，需要保留的内容请事先另存；处理中的会话会按界面提示限制操作。
- 要继续处理，可使用页面提供的原助手定位入口；目标动作已删除或宿主不可用时，请按提示处理，不能把历史预览当作可直接发送的对话窗口。

这个页面不迁移原会话库，也不把聊天同步到云端；未落盘的临时会话和已永久删除的记录不保证可找回。恢复会话不会回退动作源码或设置内容。

## 桌面 AI 工作台会话整理与保留输入 {/* #2310--桌面-ai-工作台 */}

### 整理会话与保留输入 {/* #整理会话与保留输入 */}

侧栏支持 **按时间分组** 或 **按工作区分组**，可折叠分组及整个侧栏。已有会话中未发送的输入草稿只保存在本机；2.3.36 起可同时恢复草稿中的会话引用身份，但不保存附件、窗口上下文或动作引用身份。尚未发送过消息的新会话不跨重启保存草稿；重新打开后，发送前请检查引用和所需附件。

- 会话右键菜单提供 **永久删除**，会清除会话及附件；按住 `Shift` 点击可跳过确认。永久删除不能通过归档恢复，也不会回滚会话中已经执行的文件修改或动作操作。需要保留的内容请先导出或另存。
- 2.3.38 起，删除会话受阻时会按实际原因提示处理方式：等待回答或批准时，先停止对话；仍有 Shell 或 C# 后台任务时，到后台任务面板停止任务或等待结束；记录尚未保存完成时，等待保存后重试。`Shift` 跳过的只是删除确认，不会跳过这些保护。
- 回退旧版可能清除新增的分组偏好和输入草稿，详见[2.3.10 升级与回退](/v2/migration/upgrade-and-rollback#2310--ai-工作台与执行默认值)。

## 会话引用、标签与表格 {/* #conversation-reference-2336 */}

### 引用其它会话

在独立 **AI 工作台** 输入 `@`，按标题、拼音或完整会话 ID 查找其它未归档的普通会话。选中后补充问题，例如“参考这个会话里确认的步骤，继续整理操作说明”，再发送。也可在已有会话的侧栏右键菜单中选择 **复制会话引用**，粘贴到另一会话。

引用绑定具体会话，重命名不会改成另一个同名会话。助手按需检索、读取来源的可见对话内容，不会仅因插入引用就自动加入全部历史，也不会因此获得额外的执行或保存权限。设置、场景及动作编辑器等内部会话不作为这类来源；动作编辑器内的助手也不提供会话候选。

普通会话最近三轮用户消息中明确引用的来源可继续读取；如果后续提示引用已不可访问，请重新 `@` 选择。来源被删除、或经只支持纯文本的外部程序复制后丢失引用身份时，也应重新选择，不要只靠显示标题判断引用仍有效。

### 按标签和关联动作整理

在会话侧栏右键选择 **管理标签与关联动作**，为会话创建或选择彩色标签，并维护关联动作；可按标签或关联动作筛选会话。移除关联只改变整理关系，不会删除动作或会话。

标签与整理关系仅保存在本机，不随账号同步，也不作为模型上下文自动发送。回退旧版后再次保存本机状态可能清除这些信息，需保留时先备份，见[升级与回退](/v2/migration/upgrade-and-rollback#text-and-table-2336)。

### 复制表格与保存图片 {/* #save-reply-image-2329 */}

- 对话中的表格可局部选择文字；在已完成输出的表格上右键选择 **复制表格**，可复制整表并粘贴到 Excel 等表格软件。复制后仍应检查行列及数据内容。
- 回复输出完成后，可点击正文下方的 **下载图片** 按钮，选择位置保存原图；有多张图片时会按顺序提供对应按钮。也可在正文图片上右键选择 **另存为…**。下载期间按钮暂时不可用，取消保存窗口不会保存文件。
- 这里保存的是回复中已有的图片，不代表当前模型具备图片生成能力。遇到图片地址失效或下载失败时，请检查来源或重新获取图片，再重试保存。

## 工作区、独立目录与导出导入 {/* #2315--会话独立工作目录与文件操作 */}

<a id="ai-助手工作区和历史对话" />

### 为会话选择独立工作目录 {/* #workspace-recovery-2341 */}

在 AI 工作台的工作目录入口选择文件夹，只影响当前会话（2.3.15 起按会话独立保存）。重新打开历史对话时会恢复该会话的目录；可以在会话空闲时切换目录，保留原有消息和模型选择。

- 当前会话正在执行、等待批准或工具回复时，不能修改目录；其他会话正在运行不影响本会话选择目录。
- 修改目录不会搬迁文件、创建副本或清空聊天。已启动的后台任务继续使用启动时的目录，新任务使用新目录。
- 原目录失效时仍可查看历史并重新选择目录，但不能继续在失效目录执行，也不会自动切到别的目录；目录恢复不代表获得新的访问授权，也不会回退已保存的动作或文件内容。
- 不同会话选中同一个文件夹时，共享其中的实际文件；独立目录设置不等于隔离文件副本。

设置和动作编辑器内的助手仍使用各自的工作范围，不继承桌面会话的目录。工作区设置随对话保留，回退旧版限制见[升级与回退](/v2/migration/upgrade-and-rollback#2315--会话目录与截图-ai-历史)与[2.2.18 工作区回退](/v2/migration/upgrade-and-rollback#2218-远程文件账号与-ai-助手工作区)。

### 操作回复中的文件

点击 AI 回复中的本地文件链接，可在资源管理器中定位。右键菜单提供打开、复制路径或文件名、复制文件或文本内容、另存为，以及添加为附件。文件仍需存在于当前电脑，复制路径不等于复制文件内容。

### 导出与导入对话文件 {/* #导入后继续对话 */}

标题栏的「导入导出」菜单统一提供以下操作：

- **导出对话文件**：保存为 `.jsonl` 文件，包含消息、工具输入输出和事件记录（2.2.23 起可携带已保存的模型会话）。正式版会把文件复制到剪贴板，可直接粘贴发送；导出后也可打开所在文件夹。
- **导入对话文件…**：选择收到的对话文件，导入后会以带「[导入]」前缀的标题保存在本机对话列表中（兼容 2.2.20 完整会话 JSON）。
- **复制为 Markdown**：复制便于阅读的文本内容，不作为可重新导入的对话文件。

使用**同一种 Agent 入口**导入，并且文件中有可恢复的模型会话时，可以继续发送消息；缺少模型会话、来源入口不匹配或恢复失败时，仍按只读对话导入。可续聊对话使用**导入时当前选择的工作区**，不会自动复制发送方的工作区文件或附件；继续让助手处理文件前，请先核对本机目录和所需文件。导入本身不会重放历史工具操作。

新版对话文件请用 **2.2.22 或更高版本**导入；发送前请检查是否含私人内容、路径或工具返回的数据。

## 会话恢复、图片原图与模型选择 {/* #session-recovery-2326 */}

暂存动作转为正式动作后，原聊天不再因授权误失效而中断；单个动作访问受限时，助手仍可继续处理对话中的其它内容。真正只读或权限无法确认的动作仍受限制，重新打开和保存时也仍需检查版本与冲突。保留未保存修改的方法见[编辑副本恢复](/v2/features/action-panel/action-drafts#234--外部助手恢复编辑副本)。

旧会话保存的模型引用失效时，会尝试选择最近使用且仍可用的模型；多个连接提供同名模型、无法确认对应关系时，**不会猜测连接**。发送前请核对模型菜单；没有可恢复的模型时，仍需手动配置或选择。这与请求失败后自动换模型重试不同。

点击助手中的图片附件，可使用系统默认图片查看器打开原始 PNG / JPEG 图片，便于放大检查，不再只查看缩略图。这不会给导出的对话文件补上附件原文件。

<a id="开发中会话模型与恢复" />

### 会话独立模型与恢复 {/* #234--会话模型与恢复 */}

每个对话保存自己的具体模型和思考档位（2.3.4 起，适用于工作台、设计器、脚本、设置和场景助手），切回历史对话时沿用该对话的选择，不会因其他对话换模型而改变。新对话优先使用同账号已保存的最近一次明确模型选择，思考档位回到自动；尚无最近选择时，才用 AI 默认模型初始化。

- 选择时核对完整模型系列、版本和连接名称，避免把同名的不同连接选混。已选模型被删除、停用或无法调用时，会保留选择并提示原因，不会悄悄换到另一个模型。
- 新的选择用于后续请求，不会替换已经运行中的回合。模型不支持原思考档位时回到自动；“自动”和明确关闭思考是不同设置。历史包含图片时仍需核对目标模型的图片能力，不能靠换模型静默丢弃图片。切换可能使提示缓存失效，增加耗时和用量。
- 切到较小上下文窗口时，可能需要由目标模型分段压缩历史，这也会产生用量。压缩失败或取消会保留原历史；容量仍超限时不能继续正文请求，请按提示换模型、减少输入或手动压缩。恢复历史会话不会重新执行旧工具操作。

## 对话界面与操作细节 {/* #对话界面 */}

### 在对话中选择上下文窗口

在输入区域打开模型选择菜单，进入所选模型的「上下文」子菜单，选择界面提供的档位。只有存在至少两个可选窗口大小时才会出现此入口；看不到该项不一定是配置错误。

「默认」使用模型配置的工作窗口；其它档位以界面显示的模型容量为界。选择按模型记在本机，切换回该模型时会沿用；重新选择「默认」可恢复默认预算。上下文用量显示随选择更新，后续请求使用相应预算；这不会改变服务商实际允许的容量，也不会还原已经压缩掉的原始历史。

### 引用文字与引用块

在对话记录中选中需要追问的文字，点击浮出的「添加到对话」。选中文字会作为「所选文本」引用块加入输入区，原有草稿保留；点击引用块可展开检查，用旁边的移除按钮可删除单个引用。可以连续加入多段引用，再输入问题并发送；添加或移除引用不会立即发送消息，也不会删除原聊天记录。

### 手动压缩上下文

长对话中可单独发送 `/summarize`，把较旧的模型上下文整理成摘要后继续交谈。在空输入框键入 `/` 可打开命令补全，点击候选项或按 `Tab` / `Enter` 只补全命令，随后仍需发送。

发送时只保留该命令，不要附加问题、图片或引用块，否则会作为普通消息处理。压缩会保留界面中的聊天记录，并尽量保护最近消息和关键要求；生成摘要会调用所选模型，可能产生相应的用量。

### 调整字号与侧栏布局 {/* #assistant-font-2337 */}

- **调整并记忆字号**（2.3.37 起）：在助手 **输入框** 中按住 `Ctrl` 滚动鼠标滚轮可调整字号，已打开的其它助手输入框也会同步变化（支持 10–24）；**内容区** 的 `Ctrl+滚轮` 调整与输入框分别记忆。两种字号只保存在本机，不随账号同步；回退旧版后保存本机设置可能清除这两个偏好，需要保留时先按[升级与回退](/v2/migration/upgrade-and-rollback#capture-and-font-2337)备份。
- **收起与调整会话侧栏**：点击左侧会话栏顶部的「收起侧栏」可给对话留出更多空间；侧栏展开时拖动与对话区之间的分隔线可调整宽度，双击恢复默认，宽度和展开状态记在本机。标题较长时，将鼠标停在对话标题上可滚动查看完整标题。

### 新对话与输入草稿

输入区支持上下方向键浏览当前会话的输入历史；完全空白的新对话不再占据侧栏列表，输入文字、添加引用或附件、开始对话后才显示。点击「+」可在右侧标签栏打开动作选择页；关闭 Agent 窗口后，正在进行的任务会继续在后台执行，退出 Quicker 则会停止后台任务。
