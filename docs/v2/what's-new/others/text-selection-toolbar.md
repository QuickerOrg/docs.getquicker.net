# 选中文本工具条（V2 变化）

:::info[完整功能说明已合并至功能目录]
选中文本工具条的启用、按场景追加/替换/禁用与动作列表配置请查看主文档 **[选中文本工具条](/v2/features/triggers/text-selection-toolbar)**。本页仅保留与 1.x 旧文本悬浮窗的差异。
:::

## 相对 1.x 的主要变化

- **替代 1.x“文本悬浮窗”**：改为轻量化气泡/工具条，支持按程序记住弹出位置（本地习惯不云同步），并按场景追加工序、替换或完全禁用（如密码管理器）。
- **按选中内容过滤规则**：支持按长度、关键词或模式过滤显示项。

## 从 1.x 升级时需要注意

- 旧“文本悬浮窗”已停用；新工具条默认关闭，需到设置中主动开启，且需当前有效的专业版授权（权益失效时配置保留）。
- **不再自动复制选中文字**：若旧动作依赖悬浮窗预先写入文本，需改为在动作中主动读取选区；自绘控件/远程桌面可改用快捷键唤起。
