# 扩展热键（V2 变化）

:::info[完整功能说明已合并至功能目录]
扩展热键（引导键＋组合键）的日常规则配置与引导键设置请查看主文档 **[扩展热键](/v2/features/triggers/powerkeys)**。本页仅保留相对 1.x 的激活策略演进、升级映射与当前限制。
:::

## 相对 1.x 的主要变化

- **三种激活策略**：「仅作为引导键」「平衡模式」（接近 1.x 且保护快速打字）「输入优先（试验）」，支持全局默认、逐引导键设置与打字节奏校准及最近一次判定诊断。
- **与右键鼠标触发协同**：降低右键轮盘/手势与右键扩展热键之间的互抢。

## 从 1.x 升级与当前限制

- 原先“不保留单键功能”映射为「仅作为引导键」，“保留单键功能”映射为「平衡模式」，不会自动开启试验策略。
- 升级后建议重点测试：空格/字母/标点引导键、左侧修饰键规则、与鼠标触发共用的右键规则、`Win` 引导键系统快捷键兼容项。
- **当前限制**：「输入优先」为试验策略；Quicker 不将已开输入法直接视作正在组字；扩展热键的在线分享与在线安装暂未启用。
