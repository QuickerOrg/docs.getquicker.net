# 快速触发概览

动作是「做什么」，触发是「什么时候、用什么输入把它跑起来」。同一个动作可以挂在面板、快捷键、手势、轮盘等多种入口上；从某个入口移除规则，不会删除动作本身。

规则按**场景**生效：全局、当前程序、网址或子场景。更具体的场景可以覆盖或禁用上级规则。统一编辑入口在 **场景、动作与触发管理**。

```mermaid
flowchart LR
  input[按键或划动] --> scene[识别当前场景]
  scene --> rule[匹配触发规则]
  rule --> action[执行动作]
```

## 程序黑名单与全屏禁用

以下功能从 **2.3.2** 起可用。

在设置中搜索「禁用Quicker的应用程序」，配置不希望触发的进程；需要时启用全屏禁用，并设置全屏例外。黑名单页可分别选择将这些限制应用于 **扩展热键、动作快捷键、按键双击、热键联动**。

新增的后三个开关默认关闭，升级不会自动让现有键盘规则失效。只开启需要限制的类型：前台程序命中黑名单，或触发全屏禁用且不在例外中时，该类键盘触发暂停；离开后按当前规则恢复。

动作快捷键暂停时会释放对应的系统快捷键注册，避免继续占用组合键。按键双击和热键联动会取消尚未完成的按键序列；已经触发的动作不会因此中止。未被全局限制时，各功能自身的进程条件与场景规则继续生效。

这些开关不包含暂停、打开设置等 **Quicker 功能快捷键**，也不会统一禁止自动运行或其他触发方式。排查某个动作仍在运行时，先确认它实际使用的触发入口。

旧客户端保存并同步设置可能清除这三个新字段，重新升级后需要重新开启。建议所有维护同一账号设置的设备升级到 2.3.2 后再配置，见[升级与回退](/v2/migration/upgrade-and-rollback#232-键盘黑名单与悬浮分组)。

### 单击 Ctrl 弹出面板

以下入口调整从 **2.3.3** 起生效。

控制单击 Ctrl 是否遵循程序黑名单的开关，移到黑名单页并显示为 **单击Ctrl弹出面板**。开启后，在黑名单程序中单击 Ctrl 不再弹出面板；它不会开启“单击 Ctrl 键”这个面板触发方式，触发方式仍需在面板弹出设置中配置。

无论此开关是否开启，已生效的全屏禁用都会阻止单击 Ctrl 弹出面板。**面板全局快捷键不受此项影响**；不要用它判断动作快捷键或其他键盘触发是否已暂停。

## 统一管理与排障

1. 打开标题栏「更多」→「场景、动作与触发」（或设置里对应入口）。
2. 左侧选场景，右侧按 **键盘触发** / **鼠标触发** 等标签编辑规则。
3. 误触发或场景不对时：看 **「更多」→「工具」→「诊断与修复」→「动作运行与触发记录」→「触发记录」**（本次运行约 30 分钟内的记录），并可配合 **当前场景诊断**；2.1.23 起，切换窗口后高级鼠标、手势、轮盘等会更稳定地使用触发当时的程序和场景，历史记录中的规则、场景和操作摘要也更便于归因。
4. 快捷键冲突：2.2.25 起，在 **设置 → 功能快捷键** 页的相关功能中打开 **快捷键占用查询**，也可直接搜索此名称；较早版本的入口在「设置 → 快捷键查询」。

:::note[2.2.26 起的入口名称]
2.2.26 起，管理窗口更名为「场景、动作与触发管理」。设置中的规则管理入口会先打开全局场景；要修改特定程序或网址的规则，进入后再切换场景。此窗口与管理动作本体的「设置 → 动作 → 全部动作」是不同入口，名称变化不改变规则的继承和触发范围。
:::

场景继承与禁用语义见 [场景与触发方式（V2 变化）](/v2/what's-new/scenes-and-triggers)。

<a id="开发版搜索操作类型" />

## 选择操作类型

2.3.1 起，点击操作类型按钮后显示 **多级菜单**，按分类展开后选择目标操作。菜单只提供当前编辑场景可用的操作类型。

:::note[2.3.0 的搜索弹层]
2.3.0 中点击操作类型按钮会打开搜索弹层：可以输入名称或拼音搜索，也可选择分类；用上下方向键选择，`Enter` 确认，`Esc` 取消。候选同样受当前编辑场景限制。2.3.1 起恢复为上面的多级菜单，不再使用该弹层。
:::

2.3.0 起，还可在管理窗口内使用 [AI 助手配置设置和触发规则](/v2/features/ai-and-agent#设置与场景窗口中的-ai-助手)。
