# 更新记录

逐版本的新增、修复、校验值和注意事项写在官网，不在本站逐条转载：

**[https://getquicker.net/v2/versions](https://getquicker.net/v2/versions)**

请以官网记录为准（至少已更新到 2.1.23）。安装包也从 [https://getquicker.net/V2](https://getquicker.net/V2) 下载，不要使用仍提供 1.x 的 `/Download` 页。

本站补充的是安装、迁移、功能说明和相对 1.x 的结构变化，例如 [V2 重要变化](/v2/what's-new/)。文档会随版本抽查修订，但不会在每次发版时完整复述官网 changelog。

2.1.23 的用户可见补充已同步到相关功能页。需要特别检查的是：**后台屏幕录制**步骤的默认录制范围改为“主屏幕”。已明确保存录制范围的动作不受影响；其它旧动作升级后请打开动作确认录制范围，避免原本依赖旧默认值的动作录到不符合预期的屏幕区域。

体验、降级和回退风险见 [体验前必读](/important-notice)。
