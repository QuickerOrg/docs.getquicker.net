# AI 使用

Quicker 的 AI 能力需要先配置可用的服务与模型。之后可以在 AI 工作台提问、编写和修改动作，或在组合动作中调用 AI。

## 按任务查找

| 想做什么 | 阅读页面 |
| --- | --- |
| 填写服务地址、API Key，选择模型，设置超时 | [AI 服务与模型设置](/v2/what's-new/ai-services-and-models) |
| 用 AI 写动作、操作文件、继续历史对话或连接外部助手 | [AI 助手与动作编写](/v2/features/ai-and-agent) |
| 让助手长期记住偏好，管理共享与本机内容 | [AI 指令与记忆](./memory.md) |
| 在动作步骤中总结、翻译、识图或提取数据 | [AI 文本处理](/v2/xaction/modules/ai-text)、[AI 图片理解](/v2/xaction/modules/ai-vision)、[AI 结构化提取](/v2/xaction/modules/ai-extract) |

## 第一次使用

1. 在 **设置 → AI → AI 服务** 添加连接与模型，并测试需要的能力。
2. 在对话中选择模型；要为动作或特定用途指定候选模型，可进入 **模型分配**。
3. 从面板菜单或托盘打开 **AI 工作台**，用不含敏感信息的简单任务验证。
4. 需要长期使用的回答要求，可写入 **设置 → AI → AI 指令与记忆**；临时任务要求直接写在当前对话中。

模型服务可能产生费用，发送的文字、图片、文件和长期记忆也可能由服务商处理。助手生成或修改的动作需要检查、试运行，保存成功不等于已经验证正确。
