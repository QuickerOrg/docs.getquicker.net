# 账号、登录与数据同步

:::caution Preview · 仅专业版
免费版数据迁移仍在开发，免费账号目前无法登录 2.0。完整限制见 [体验前必读](/important-notice)。
:::

V2 为每个账号建立独立的本地数据目录。业务数据、本机状态、缓存和日志分开；切换账号时不再共用同一份账号业务库。

## 登录之后会发生什么

- 建议登录专业版账号，便于同步；也可以先用本机离线账号（离线账号固定使用新面板）。
- 从 1.x 过来时，**首次登录会分叉数据**：迁入当前账号的一份 V2 数据，之后与 1.x 不再双向镜像。
- 同步以独立数据项为单位（动作、动作页、场景配置、文本指令、公共子程序等可以分别更新）。
- 发生冲突时，不应假定一端会静默覆盖另一端。「用服务端数据重建」会以服务器数据重做本机账号库，不会自动合并尚未上传的本地修改。

## 完整说明

机制、目录边界、迁移时序和回退注意见 [数据存储与同步变化](/v2/what's-new/data-and-sync.md)。从 1.x 迁过来的操作顺序见 [从 V1 迁移](/v2/migration/from-v1.md)。

API Key 等本机凭据不会随普通设置 JSON 一起复制到另一台电脑，换设备后需要重填。见 [统一 AI 服务与模型设置](/v2/what's-new/ai-services-and-models.md)。
