# 动作回收站

从 **设置 → 动作 → 动作回收站** 打开。入口也可能出现在动作管理或面板菜单中。当前账号权益不足时会先显示版本限制说明。

## 本地恢复

本地列表来自当前账号的已删除动作备份。找到目标后点击“复制”，或双击该记录，再在合适的位置粘贴。请核对内容和依赖；复制不是撤销整次删除，也不会自动恢复原位置。

无法解析的备份会计入提示中的数量，但不会显示为可复制动作。换电脑、本机数据丢失或此前没有备份时，不能靠本地列表找回。

## 云端恢复

切换“云端”页签并刷新。云端仅列出曾同步到服务器且仍在保留期内的删除记录；离线账号与未上传动作不在此范围。复制并粘贴后得到新的动作副本，不恢复原标识、原位置和分享身份。详细限制见[云端动作回收站](./account-and-sync.md#云端动作回收站)。

## 删除与清空

本地列表可删除指定动作的备份记录；“清空动作回收站”会彻底清空本地已删除动作备份，包含无法解析的记录。确认后不能再通过本地回收站恢复。它不是清空 Windows 回收站，也不等于删除云端列表。

## 无法一并恢复的内容

- 暂存区的“丢弃”“全部删除”不进入正式动作回收站。
- 动作专属文件不在动作定义中；若删除时移入 Windows 回收站，需要单独还原。
- 动作依赖的程序、公共子程序、文件和本机配置需要另外检查。

修改前的定义应从[历史版本](./action-history.md)查找，误删动作才使用这里的回收站。
