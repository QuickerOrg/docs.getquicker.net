# 动作面板使用说明

新面板窗口是 Quicker 2.0 的主要动作入口。它不再要求把动作固定放在二维动作页中，而是按“场景 → 分组 → 动作”组织；同一个动作也可以出现在多个场景或其它触发入口中。

> **先了解一个重要区别**
>
> 在新面板中，**动作本体**和**动作的显示位置**是两回事。
>
> - “从此场景移除”只移除当前场景中的入口，不会删除动作本体。
> - “删除”会删除动作本体，并在确认后清理动作页、场景和触发规则等引用。
>
> 如果只是整理面板，请优先使用移动、分组或“从此场景移除”。

## 启用新面板窗口

已登录账号可以使用下面任一方法：

1. 打开旧面板右上角菜单，选择“切换至新版主窗口”；或
2. 打开“设置 → 基础设置 → 新版面板窗口”，开启“弹出面板时使用新版面板窗口”，然后保存设置。

此后，原来用于弹出动作面板的鼠标、快捷键等触发方式会打开新面板窗口。关闭上述设置即可临时切回旧面板；切换窗口不会删除动作或动作页。

本机离线账号固定使用新面板窗口，不能切回旧面板。

### 减少面板弹出闪烁

2.2.15 起，“设置 → 基础设置 → 弹出面板”提供 **减少面板弹出闪烁（软隐藏，仅新版面板）**。默认关闭，且仅本机生效，不会随账号同步。

个别电脑弹出新面板时若出现闪烁或延迟，可尝试开启。软隐藏会让面板在任务切换列表里短暂可见：若发现面板进入 Alt+Tab 或 Win+Tab，请关闭此项。

:::caution[跨版本编辑面板配置]

2.1.21 起，新版面板配置会执行一次性迁移。回退到 2.1.19 或 2.1.20 后，只适合紧急查看；不要在旧版中编辑或同步面板配置，否则可能丢失新版分组身份、适用主机等信息。多设备使用同一账号时，建议先全部升级并完成同步，再整理面板。

:::

## 认识面板结构

分区示意与配置入口见[概览：面板上的设置在哪](/v2/features/action-panel#面板上的设置在哪)（可点击布局图查看）。

### 全局区

全局区用于放置不依赖当前程序、希望随时使用的动作。你可以在这里添加全局场景、通用场景或自定义场景标签。

### 上下文区

上下文区随当前前台程序或网址变化。例如，在资源管理器中弹出面板时，会优先显示资源管理器场景；切换到浏览器后，可以同时出现浏览器程序场景和匹配的网址场景。

“通用”标签始终保留在上下文区末尾，适合放置所有程序都要使用的动作。

如果不希望上下文继续自动切换，点击上下文区右上角的锁定按钮。再次点击可恢复自动切换；右键该按钮还可以选择要加载并锁定的应用场景。

2.2.18 起，当前程序还没有配置场景时，面板会直接显示 **创建场景**、**禁止弹出** 和 **关闭提示** 等按钮。只是临时不想为这个程序建动作时，可关闭提示；不希望以后在该程序里弹出面板时，选择禁止弹出。

### 工具菜单

标题栏「更多」→「工具」集中放置与当前环境相关的入口。2.2.18 起，这里可打开本机已安装的软件列表、动作库，以及当前软件可用的桥接工具。桥接工具依赖 [软件连接](/v2/features/software-connections)；目标软件未安装 Bridge、未运行或没有在线实例时，先到软件连接页检查状态。

### 场景标签和分组

全局区和上下文区都可以包含多个场景标签。一个场景内还可以建立多个分组，用于替代 1.x 中“同一程序下的多个动作页”。

- 单击场景标签：切换场景。
- 双击场景标签：在“场景与动作管理”窗口中打开该场景。
- 右键场景标签：新建或导入动作、重新从旧动作页引入动作，以及打开场景管理。
- 拖动全局区的场景标签：调整标签顺序；“全局”标签也可以移动。松开后顺序会自动保存到当前账号的本机状态。
- 开启“显示分组”后：分组在同一滚动列表中连续显示；连续显示时，动作区**左侧**有一条很窄的圆点导航（约 16 DIP），悬停可看到分组名。存在置顶动作时，列表顶部还会显示带图钉标记的“置顶”分组。若改为「每次单个分组（上）」或把分组快速滚动区域放在上方，导航会移到标题行，圆点居中显示（2.2.15 起）。

上下文区的标签由当前程序、网址和场景规则动态生成，不支持拖动排序。

### 暂存区

新版主窗口左侧导航栏里，「动作」和「暂存区」是两个图标按钮（不是带文字的侧栏）。点「暂存区」后，右侧内容换成暂存列表。暂存区顶部可直接 **新建动作** 或 **用 AI 写**；暂存动作可以先在本机编辑、试运行和调试，确认后再放入正式场景。详细说明见[本机动作暂存区](./action-drafts.md)。

### 侧边栏快捷按钮

2.1.29 起，左侧导航**底部**的快捷按钮可以自定义。出厂默认只有 **截图 Pro**；还可放入 **设置**、**场景与动作管理**、**公共子程序管理**，也可以添加常用动作并调整顺序。入口在标题栏「更多」→「面板窗口」→「快捷按钮设置…」。常用动作本身的整理方式见[动作与入口](/v2/features/actions)。

::::caution[侧边栏快捷按钮的回退风险]

侧边栏快捷按钮会和动作面板偏好一起同步。若配置后仍在 2.1.28 或更早版本修改并同步动作面板偏好，旧客户端可能清除快捷按钮配置，恢复为仅默认「截图 Pro」。多设备使用同一账号时，建议先升级所有设备；回退旧版后也避免修改该项。配置丢失后，可在「快捷按钮设置」中重新配置。

::::

## 查找和运行动作

- 单击动作磁贴即可运行。
- 2.2.13 起，正在运行的动作会在磁贴上显示状态小点；旧面板和悬浮动作也使用同样的提示。
- 面板保持悬停显示时，可以直接键入名称或拼音，筛选当前动作区域中的动作；输入过程不会要求面板先取得前台焦点。
- 筛选时用 `↑`、`↓` 选择结果，按 `Enter` 运行，按 `Esc` 清除筛选。
- 点击标题栏的搜索入口，会打开全局搜索窗口；它适合跨场景和其它搜索来源查找。
- 鼠标位于全局区或上下文区时，按住 `Ctrl` 滚动滚轮，可以切换该区域的场景标签；横向滚轮也可以切换标签。
- 底部「最新动作」条可快速再次运行近期用过的动作；这一行只有图标，没有标题。


## 双击导航栏

导航栏在窗口**最左侧**：上端是 Quicker 标志，中间是「动作」「暂存区」，底部是快捷按钮。标准宽度约 50 DIP，紧凑约 38 DIP。也可以打开标题栏「更多」→「面板窗口」→「左侧导航栏」，在标准、紧凑和关闭之间选择。

2.2.10 起：

- 双击**面板内容空白处**，可显示或隐藏导航栏（给动作区域腾地方）。
- 双击**导航栏空白处**，可在标准导航与紧凑导航之间切换。

请点在空白区域；点到场景标签、动作磁贴或按钮上仍按原有单击 / 双击行为处理。

## 新建、粘贴和导入动作

先切换到目标场景或分组，然后使用以下入口之一：

- 点击「创建动作」磁贴；连续显示分组时，把指针移到分组标题旁也会出现 +。「每次单个分组（上）」时，加号固定在标题行；
- 在动作区域空白处右键，选择动作类型；
- 复制动作、文件或分享动作链接后，在空白处右键粘贴；
- 把文件或文件夹从资源管理器拖到目标场景或分组，直接创建“打开文件”或“打开文件夹”动作；
- 右键场景标签，选择“导入动作到此场景”，从本地 JSON 文件导入动作。

从本地文件导入时可识别 Quicker 1.x 和 2.0 动作 JSON。若导入动作的 ID 已存在，Quicker 会为导入副本生成新的 ID，避免覆盖现有动作。

### 复制后同时添加与删除关联

2.2.21 起，在面板中 **复制** 某个动作后，可到另一场景或分组的空白处右键，选择 **同时添加到这里**：目标位置会增加一个入口，并与来源共用同一个动作本体（不会生成内容互相独立的副本）。这和按住 `Ctrl` 拖动、「场景与动作管理」里的「同时添加到…」一样，都是增加入口而不是复制内容。

删除动作本体时，确认框会列出它在各场景中的关联位置，便于核对后再确认。若只想整理面板而不删本体，请继续使用「从此场景移除」、移动或「同时添加」。

## 整理动作和分组

### 自由格子布局

2.2.13 起，新版面板可在“视图选项 → 自由格子布局设置”中选择自由格子布局。每个真实分组都使用固定格位：

- 直接把动作拖到空格，可移动或交换位置；删除动作后，其他动作不会自动前移。2.2.18 起，把动作拖到格子边缘可在该位置插队，后续动作会自动顺移；想保留空位时仍拖到格子中间。2.2.15 起，跨分组拖放会落到正确目标格，不再因落点计算错误而偏到其它分组。
- 可分别设置全局区和上下文区的列数与最小行数；窗口较窄时可横向滚动，按住 Shift 滚轮可横滚。
- 分组菜单的“摆放动作 / 增减行”可在草稿中整理；取消、Esc 或关闭窗口不会写入。
- 搜索结果、置顶动作和最近动作仍紧凑排列，不占用独立格位。

首次切换时，Quicker 会询问使用自由格子还是原有的流式布局。从旧动作页导入时，自由布局会尽量按原固定四列保留行列和空隙。符合条件的首次升级会在联网同步完成后自动启用新版面板；原动作位置会保留，也可从面板更多菜单切回旧面板。

:::caution[旧版编辑可能清除布局]
自由格子布局随账号同步。回退到 2.2.12 或更旧版本后，如果再编辑或同步同一场景，旧客户端可能清除格子坐标和空位。多设备使用时请先全部升级。
:::

#### 触发键

2.2.14 起，自由格子布局可启用原有「触发键」（默认关闭；在触发键相关设置中启用）。启用期间会暂停悬停输入搜索，仍可主动进入搜索。

触发键复用已有的格子按键配置：按当前场景、当前分组的固定行列定位，并保留空位。「全部」使用第一个真实格子组；置顶投影不参与映射。

### 置顶常用动作

右键动作并选择“置顶”，可以把不同分组中的常用动作集中到列表顶部。再次右键并选择“取消置顶”即可移除置顶状态。

开启“显示分组”且当前场景存在置顶动作时，会出现一个带图钉标记的虚拟“置顶”分组。需要注意：

- 置顶动作会在“置顶”分组和原来的真实分组中各显示一次，但它们是同一个动作，不是两个副本；
- 置顶或取消置顶不会改变动作原来的分组；最后一个动作取消置顶后，“置顶”分组会自动消失；
- 排序方式为“手动”时，可以在“置顶”分组内向前或向后拖动动作，调整置顶动作的相对顺序；
- “置顶”分组不能重命名、合并或删除，也不能在其中新建动作或拖入未置顶动作；从该分组向外拖动也不会改变动作的真实分组。

关闭“显示分组”后不会显示虚拟分组，但置顶动作仍会优先排列。自动排序模式下也会优先显示置顶动作，但不能通过拖动调整顺序。

### 调整动作顺序

打开上下文区右上角的「视图选项」（滑块图标），把排序切换为「手动」，即可在同一场景中拖动动作调整顺序。其它排序方式包括最后使用、最多使用、综合、最近创建和最近编辑；这些自动排序模式下不能手动重排。

### 移动或复制动作

右键动作并选择“移动到其它场景…”，可以选择目标场景和分组。目标分组既可从已有分组中选择，也可直接输入一个新名称；留空表示放入“未分组”。

也可以直接拖动动作：

- 拖到同一场景的其它位置或分组：调整顺序或分组；
- 拖到其它场景：移动动作的场景位置；
- 按住 `Ctrl` 拖到其它场景：在目标场景增加一个位置，并保留来源场景的位置。

这些操作移动或复制的是动作入口，不会创建动作内容的独立副本。编辑动作后，引用同一动作的其它入口也会显示更新后的内容。

把动作拖出面板并放到悬浮目标区域，可以建立悬浮动作入口。悬浮入口仍引用同一个动作本体，不会复制动作内容。

需要一次处理多个动作时，打开“场景与动作管理”窗口并选择来源场景：

1. 单击动作可选择一个动作；按住 `Ctrl` 单击可逐个增减选择，按住 `Shift` 单击可连续选择；
2. 按 `Ctrl+A` 可选择当前场景中可见的全部动作；
3. 选择后，窗口底部会显示已选数量以及“移动到…”“同时添加到…”“剪切”等批量命令；在任一选中动作上右键也可打开批量菜单；
4. “移动到…”会在成功加入目标场景后移除来源场景中的入口；“同时添加到…”会保留来源入口；
5. 目标位置可以选择已有分组，也可以直接输入新的分组名称；留空表示放入“未分组”。

连续选择和全选都以当前界面可见的动作及显示顺序为准。搜索或筛选后，可以只处理筛选结果。

### 创建和管理分组

开启“显示分组”后，可从分组导航底部创建分组，也可把动作拖到“创建分组”入口，在新建分组的同时移入该动作。

右键具名分组可执行：

- 修改分组名称；
- 合并到另一个分组；
- 移动整个分组到其它场景；
- 同时把整个分组添加到其它场景，并保留来源分组；
- 设置 **适用主机**，让同一账号下的某个分组只在指定电脑显示；
- 单独设置该分组导航圆点的颜色（2.2.15 起）；
- 删除分组；
- 创建一个“加载此分组”的动作。

删除分组不会删除其中的动作，组内动作会转入“未分组”。合并分组会把来源分组的动作移到目标分组，然后删除来源分组。

整组移动会保留组内动作的相对顺序。目标场景已有同名分组时，动作会合并到该分组；移动完成且来源分组已空时，来源分组会被删除。“同时添加分组到其它场景”复用原动作，不会创建动作内容的独立副本。

适用主机适合把公司电脑、家用电脑或专用设备的动作分组分开显示。它只影响该分组在当前设备上的面板呈现，不会把组内动作复制成不同版本；编辑动作本体仍会影响所有引用位置。

## 调整显示方式

### 视图选项

点击上下文区右上角的「视图选项」（滑块图标）可以设置：

- 流式布局或自由格子布局；
- 同时显示「全局 + 上下文区」，或只显示其中一个区域；
- 是否显示底部最新动作（无标题，只显示图标）；
- 动作使用磁贴或紧凑列表，以及标题是否自动换行（最多两行）；
- 「每次单个分组（左）」「每次单个分组（上）」「连续显示分组」或不分组；
- 分组快速滚动区域在上方、左侧，或关闭；
- 是否显示创建动作磁贴；
- 动作排序方式。

默认「全局 + 上下文」时，视图选项只出现在上下文区右上角；仅显示全局区时，按钮改到全局区右上角。

「每次单个分组」适合较小窗口；「连续显示分组」适合拉大窗口浏览多个分组；「不分组」会隐藏标题和导航，平铺全部动作。

### 窗口尺寸

窗口支持拖动和缩放。标题栏「更多」→「面板窗口」→「窗口尺寸」可以保存和切换多个尺寸预设；双击标题栏也可以恢复或切换尺寸。

2.2.13 起，同时显示全局区和上下文区时，按住 `Ctrl` 拖动顶部或底部边框（两区之间的分界），可以分别调整某一侧的高度，而不是按比例一起变化。未按住 `Ctrl` 时，拖动边框仍会按比例调整两区。

动作磁贴会按当前可用宽度自动排列；2.1.28 起，动作名称会根据按钮空间自动缩小，较长名称不再被直接截断。面板外观仍使用 Quicker 的面板字体、磁贴尺寸、背景图片和透明度等设置。

背景可以选择普通透明、毛玻璃或亚克力，并调整背景色叠加浓度。亚克力需要 Windows 11 且开启系统“透明效果”；条件不满足时，Quicker 会按毛玻璃效果显示。背景色叠加浓度是 2.1.22 新增设置，回退到 2.1.21 或在未升级设备上保存设置时可能被清为 0，需要回到新版本重新设置。

## 管理多个场景和大量动作

需要跨场景整理时，使用标题栏“更多菜单 → 场景与动作”。在“场景与动作管理”窗口中，可以：

- 从左侧场景树选择全局、程序、网址或自定义场景；
- 管理新面板中的动作和分组；
- 查看及管理旧动作页；
- 在场景之间拖动动作；
- 管理该场景的快捷键、轮盘、手势和其它触发规则。

如果已经知道动作所在的来源场景，直接在这里使用多选、整组移动或批量剪切最方便。批量剪切后，切换到目标场景和分组，按 `Ctrl+V`；也可以在目标动作区域空白处右键，选择“粘贴已剪切的多个动作”。剪切时不会立即移除来源入口，只有目标写入成功后才会完成移动。

如果还不知道动作位于哪些旧动作页或场景，可使用标题栏“更多菜单 → 动作管理”，按程序、动作页等条件筛选后再批量处理。详细操作和剪切安全边界见[常见问题](./faq.md)。

2.1.23 起，动作管理页增加 **动作回收站** 和 **批量更新动作** 快捷入口，并提示可以把动作直接拖到面板。从动作管理列表拖到新面板目标场景或分组时，会建立该动作的面板入口；这和“移动到…”一样处理的是动作位置，不会复制动作内容本体。

排查最近运行失败的动作时，从标题栏「更多」→「工具」→「动作运行与触发记录」打开窗口，在「动作执行」中筛选「失败」。原「最近动作错误」入口已合并到这里。详细说明见[内置工具](/v2/features/tools#动作运行与触发记录)。
