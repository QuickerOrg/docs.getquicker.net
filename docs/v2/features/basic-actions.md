# 基础操作：输入、打开与运行

这些操作可用于快速操作编辑器，也会出现在旧动作的兼容编辑入口中。V2 中按实际用途选择操作类型；旧动作中的“运行程序或打开文件”等名称可能与新菜单不同。

<a id="keyboard-input" />

## 模拟按键

“发送快捷键”用于一个快捷键或组合键；“模拟按键B”按其自身语法解释字符串。不要把普通文本直接当作快捷键语法。多步输入可选“多步骤模拟输入”，把等待安排在需要的位置。

先在测试窗口确认焦点。Quicker 与目标程序权限不一致时，输入可能失败；快捷键也可能被其它软件截获。组合动作中的详细语法见[模拟按键](/v2/xaction/modules/sendkeys/)。

<a id="run-or-open" />

## 运行程序或打开文件

需要启动程序时选“启动程序/软件”，打开文档或目录时选“打开文件”或“打开文件夹”，需要命令及高级运行选项时选“运行命令”。程序路径和命令参数应分别填写，不要把带参数的整条命令当作一个文件路径。

文件与目录必须在执行的这台电脑上存在。关联程序由 Windows 决定；同步动作不会同时同步目标软件和本机文件。

<a id="open-url" />

## 打开网址

填写完整网址并确认协议，例如 `https://getquicker.net`。需要指定浏览器或传入选中文本时，按编辑器提供的字段配置；不要将用户输入直接拼入需要转义的网址。组合动作可使用[打开网址模块](/v2/xaction/modules/openurl/)。

<a id="send-text" />

## 发送文本

向目标窗口输入纯文本，可按编辑器选项选择模拟键入或剪贴板粘贴。目标程序可能限制粘贴；输入法、焦点与权限也会影响结果。HTML、图片和文件应使用“粘贴内容”，而不是把它们当作纯文本发送。

<a id="link-action" />

## 链接与运行其它动作

选择已有动作作为目标。链接不会复制目标动作的定义；目标被删除、未安装或不可运行时，链接无法替代它。需要参数时，填写目标动作认可的参数，详见[为动作传递参数](/v2/xaction/concepts/quicker_in_param/)。

<a id="switch-profile" />

## 切换动作页或场景

旧动作的“切换动作页”与 V2 的“打开动作页”“加载指定场景的动作”属于不同入口。选定目标后试运行，确认需要的是旧动作页还是新面板场景；切换入口不会复制或移动动作本体。新面板说明见[场景与动作管理](./scenes.md)。

<a id="run-script" />

## 运行脚本

“运行脚本”会把脚本内容写入临时文件后交给相应运行环境执行；它与在 Quicker 内运行 C# 的“Quicker脚本动作”不同。先确认本机已安装所需解释器，并检查脚本的文件、网络和程序调用行为。C# 脚本动作见[脚本动作指南](/v2/script-action/)。
