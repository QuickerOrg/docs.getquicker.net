# 高级鼠标触发

高级鼠标触发可以组合鼠标按键、控制键、触发类型和屏幕位置执行操作。常见方式包括单击、双击、长按、划动、滚轮、移动到角落和摩擦屏幕边界。

2.x 保留了 1.x 的触发类型，并重点改进了场景来源、规则管理和不同鼠标功能之间的协调。

## 使用统一场景识别

高级鼠标规则会按鼠标开始位置或当前前台目标解析程序、网址和子场景，并与轮盘、手势和动作面板使用同一套场景身份。

对资源管理器桌面与任务栏、UWP、WPS 内部文档、浏览器网址和 WebView 宿主，2.x 会使用统一的逻辑目标和回退规则，减少不同触发功能各自判断程序导致的结果差异。

全局、父场景和当前场景中所有启用且条件匹配的高级鼠标规则都会参与匹配。停用一条本地规则只会排除该条规则，不会自动屏蔽上级其它鼠标规则。如果需要在某个场景完全关闭高级鼠标触发，应使用场景级禁用开关。

## 规则列表更容易筛选

“场景与动作管理 → 鼠标触发 → 高级鼠标触发”使用单一规则列表，不再把“常用按键”做成另一套并行编辑入口。

列表顶部可以组合筛选：

- 鼠标按键：无按键、左键、右键、中键、X1、X2；
- 触发类型：短按、按下、长按、双击、划动、四向滚轮、屏幕角落、摩擦边界；
- 说明文字。

筛选期间会禁用拖动排序，避免把过滤后的局部顺序误写成完整规则顺序。清除筛选后可以继续正常排序。

规则支持多选删除、复制和粘贴。新增或粘贴的条目会放在当前选中项之后，便于保持相关规则相邻。

## 操作选择与触发方式一致

2.x 统一了触发器使用的操作编辑器。普通单击、双击和滚轮只显示适合直接执行的操作；划动或长按规则还可以选择：

- 显示轮盘菜单；
- 开始鼠标手势；
- 快速截图。

切换触发方式时，编辑器会继续校验当前操作是否仍适用于新方式，避免保存“界面上存在但运行时不能执行”的组合。

只填写触发后提示而不设置具体操作也是合法配置，适合先验证规则是否命中。

## 引导键选择更直接

高级鼠标规则需要配合键盘引导键时，可以直接选择任意普通引导键。该键尚未定义扩展热键时，保存规则会自动创建对应的引导键设置；如果引导键已存在但处于停用状态，Quicker 会明确提示并让你确认是否启用。

这减少了在“高级鼠标触发”和“扩展热键”设置之间来回切换的步骤。仍然建议检查同一引导键是否已经用于面板、轮盘、手势或扩展热键，避免一个按键承担过多入口。

## 触发目标和延迟执行更稳定

鼠标按下、移动、释放以及延迟执行可能跨越多个窗口。2.x 会在会话开始时固定必要的鼠标目标和规则内容，执行时仍使用这次操作的原始目标，不会因为鼠标经过 Quicker 辅助窗口或前台窗口变化而改用另一场景。

设置窗口、动作编辑窗口等普通 Quicker 窗口可以按正常场景规则使用鼠标触发；主面板和明确标记为不参与触发的悬浮窗口仍会排除，避免在操作 Quicker 面板时意外递归触发。

## 轮盘和手势的角落快捷入口

如果高级鼠标规则启动了轮盘或手势，可以在结束会话前把鼠标移动到当前屏幕顶部角落：

- 左上角：打开本次场景的轮盘或手势动作管理；
- 右上角：打开对应功能的全局参数设置。

该入口只在已经开始的轮盘或手势会话中生效。普通“移动到屏幕角落”规则仍按高级鼠标触发自己的设置运行。

## 从 1.x 升级时需要注意

- 原有规则、顺序、进程范围和触发位置会继续保留；
- 全局规则仍保存在账号级列表，程序和网址规则进入对应场景；
- 停用本地单条规则不会屏蔽父场景规则；需要完全关闭时使用场景级禁用；
- 同一个按键组合如果同时用于面板、轮盘、手势、扩展热键或左键辅助，应重新检查冲突；
- 对屏幕角落、全屏禁用、任务栏、多显示器和 WPS 等特殊目标，建议按实际使用路径各测试一次。
