# 升级到 2.x 的理由

Quicker 2.x 不是 1.x 的简单换皮。1.x 长期受限于 .NET Framework、按整张动作页保存 JSON 以及动作与二维面板格子绑定，很多新功能很难继续演进。2.x 重建了运行底座、数据存储和面板模型，同时也带来了不少 1.x 没有的新能力。

如果你正在犹豫值不值得从 1.x 升到 2.x，下面按日常使用最能感知到的变化整理核心理由，并在文末列出仍建议先观望的情况。

## 1. 新面板更顺手，整理动作不怕误删

- **场景 → 分组 → 动作，一眼少翻页**：新版面板同时展示全局区与上下文区，同一程序在 1.x 中的多张二维动作页会组织成同一场景下的多个分组，切换更连贯。见 [动作面板（新面板）](/v2/features/action-panel/)。
- **动作本体和显示位置分开**：同一个动作可以同时出现在多个场景、轮盘、手势或快捷键里。改一次动作内容，所有入口一起生效；「从此场景移除」或「删除分组」只去掉位置，不会误删动作本体；删除前还能先查看完整引用范围。
- **新增本机动作暂存区**：写草稿、试运行、用 AI 生成或把剪贴板里的分享动作装进暂存区验证，确认好用了再「保留到场景」，不用一开始就硬塞进正式面板。见 [本机动作暂存区](/v2/features/action-panel/action-drafts)。
- **找动作和整理更快**：面板悬停直接输入名称或拼音筛选当前区域，标题栏搜索可跨场景查找；支持批量移动、同时添加到多个场景，以及“粘贴写入成功后再清理来源”的安全剪切。

## 2. 运行底座全面换代，原生支持 Windows ARM64

- **升级到 .NET 10**：摆脱已进入维护阶段的 .NET Framework 4.7.2，除 **x64** 外，2.3.31 起还提供原生 **Windows ARM64** 安装包。见 [运行平台、系统要求与 64 位迁移](/v2/what's-new/platform-and-compatibility)。
- **自研 QkEval 表达式引擎**：在常见算术、变量读取、成员访问与循环/LINQ 场景下速度明显更快、内存分配显著减少，报错能指出具体出错片段与行列号，并支持更多现代 C# 语法。见 [全新表达式引擎](/v2/what's-new/actions/new-expression-engine)。
- **设置更好找、窗口不互锁**：设置窗口改为左侧树形导航与关键词/拼音首字母搜索，多数页面支持修改后自动保存；独立确认框不再冻住所有 Quicker 窗口，新版主面板也默认不抢占前台焦点。

## 3. 写动作与调动作能力跨代提升

- **组合动作支持断点与单步调试**：新增统一执行管道和结构化调试记录，清晰记录步骤层级、变量变化和并行分支；可编辑动作支持断点、单步进入/跳过/跳出，并强化 `WaitAny` 并行分支取消。见 [组合动作执行与调试变化](/v2/what's-new/actions/xaction-steps)。
- **新增独立的脚本动作**：2.3.0 起可直接用受控 C# 语法与 `qk` API 编写动作，基于 `Main` 参数自动生成设置表单，同样支持菜单入口、AI 助手、断点调试与版本恢复。见 [Quicker 脚本动作](/v2/script-action)。
- **更多开箱即用的新能力与自动化**：组合动作新增 **PDF 文件处理**、**截图 Pro**、**长截图**、**屏幕录制**、**运行 C# 文件应用** 等步骤；浏览器控制配合 Quicker Connector 1.2.0 还支持可视化生成 **网页列表提取** 与 **表单批量填写** 模板。见 [组合动作模块新增与改进](/v2/what's-new/actions/xaction-steps) 与 [网页列表提取与表单填写](/v2/xaction/guides/web-data-and-form-automation)。

## 4. 原生 AI 能力与外部助手协作

- **一站管理 AI 服务与模型**：集中配置多家服务商、可用模型与用途分配，API Key 默认在本机加密保存，也可按需开启跨设备同步。见 [统一 AI 服务与模型设置](/v2/what's-new/ai-services-and-models)。
- **桌面 AI 工作台与助手写入**：可在桌面窗口或动作编辑器内提问、看图对话、让助手生成或修改动作，并按场景管理提示词库与长期指令记忆；组合动作也能直接调用 AI 文本、图片理解、结构化提取和问问 AI 步骤。
- **接入外部 AI 工具**：支持通过 MCP 让外部 AI 客户端在受控授权与预览下协作编写动作。详情见 [AI 使用](/v2/features/ai)。

## 5. 截图录屏工具链、触发管理与软件连接更完整

- **截图 Pro + 贴图 + 录屏一体化**：集成了控件吸附、套索裁切、标注与智能马赛克、本地/在线 OCR 与表格识别、翻译、本机抠图、鼠标穿透贴图、自定义 JS 工具栏以及统一采集历史中心。见 [截图与贴图概览](/v2/features/screenshot/)。
- **Bridge 软件连接**：安装对应宿主插件即可直接查询状态与调用设计、建模或办公软件原生命令，减少易受界面位置变化影响的键鼠模拟。见 [软件连接](/v2/features/software-connections)。
- **触发集中管理与可诊断**：快捷键、手势、轮盘、扩展热键和文本指令统一收进「场景、动作与触发管理」，支持按场景继承或明确禁用；并新增「当前场景诊断」「触发记录」「快捷键占用查询」方便排障。同时用轻量的 **选中文本工具条** 替代旧文本悬浮窗。见 [快速触发概览](/v2/features/triggers)。

## 6. 按单个动作同步，多设备冲突大幅减少

- **账号目录隔离 + 细粒度同步**：每个账号使用独立本地数据目录，动作、动作页、场景配置和子程序拆成独立项目同步；两台设备改同一动作页里的不同动作，不再因为整页合并而冲突。见 [数据存储与同步变化](/v2/what's-new/data-and-sync)。
- **作者分享可同时兼顾 V1 与 V2**：同一个动作分享链接可在同一修订内同时提供 1.x 兼容内容与 2.x 原生内容。见 [动作作者迁移指南](/v2/migration/action-authors.md)。

## 什么情况下可以先观望？

2.x 并非适合所有人立刻全量切换。下面几类情况建议先评估或先用备用电脑试跑：

1. **当前为 Preview 体验版（仅专业版可登录）**：免费版数据迁移仍在开发中，免费账号暂时无法登录 2.0。
2. **工作电脑依赖不能中断的生产流程**：两代不能同时安装，且首次登录分叉后数据各自独立，不建议直接在主力环境仓促替换。
3. **强依赖已移除或 32 位专属环境**：例如 Windows 7/8/8.1、32 位系统、进程内 32 位 DLL/COM/ODBC、**手机 App 遥控器**、需要直接修改的旧版组合动作等。

升级前的兼容红线见 [不再支持或不再推荐的功能](/v2/what's-new/not-supported)；想按完整清单安全过渡见 [从 1.x 迁移到 V2](/v2/migration/from-v1)。
