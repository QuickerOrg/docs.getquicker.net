## 动作运行与触发记录

2.2.11 起，从标题栏「更多」→「工具」→「动作运行与触发记录」打开该窗口，在「动作执行」和「触发记录」间切换。原「最近动作错误」入口已合并，在动作执行中选择「失败」即可。

可查看结果、错误及可关联的触发来源，复制或导出记录；动作仍存在时可打开当前动作。可诊断的组合动作失败时自动保留最近步骤，不要求先修改动作。只读动作或不支持的操作类型可能只有摘要。

选中动作后可开启“临时保留每次运行步骤”，在未来 15 分钟或 20 次运行内保留步骤，先到即止，包含成功与取消；不会自动重新运行，也不采集变量值、参数值或手动日志。

普通成功、取消的运行摘要只保留在当前进程。失败和临时诊断记录保存在本机，按三天、最多 100 份等限额清理，不参与账号同步。触发记录仅保留本次进程最近 30 分钟、最多 200 条，不保证每种触发都能关联到动作执行。

自动记录不同于 [调试运行](/v2/xaction/concepts/debug) 的输入输出日志。记录中的错误文本可能含路径或地址，分享前请检查。清理时留意是否勾选“同时清理已保存记录”。

2.2.17 起，原主菜单中独立的“动作日志”入口并入这个窗口的 **动作日志** 页签，已有日志继续保留。可以按动作、调用链、级别和关键字筛选，用“较早 / 较新”翻页，并导出所选调用链的日志。也可从“动作执行”页签跳转查看所选动作的日志。

排查“主动作调用子程序后失败”时，先选择主动作，再选择对应调用链，查看其中子动作输出的日志。这里查询的是动作输出的日志，不会因为打开页签而自动采集完整变量或步骤输入输出；需要这些信息时请使用调试运行。导出前检查日志中是否含本机路径、网址或其它私密内容。

## 查看控件树与取消选择

以下改进从 **2.3.1** 起可用。

在窗口检查器或界面检查器中查看控件树时，可以使用「展开全部」，也可以右键节点选择「展开此分支」。展开按批次进行；达到深度或节点数量上限时会显示提示，可从需要的子分支继续展开。

目标软件的界面已经变化，或节点读取失败时，右键选择「刷新此节点」重新获取。刷新会中止当前展开过程，避免继续查看已过时的分支。

使用「控件选择器」点选目标控件时，尚未点击确认前可按 `Esc` 取消。已经点击、正在确认中的选择不会被该取消打断。

<a id="开发版搜索并定位设置" />

## 搜索并定位设置

以下设置搜索改进从 **2.3.1** 起可用。

在设置窗口顶部输入页面名、选项名或拼音，结果按所属页面组织。页面入口、功能分组和具体选项会分别显示；同名的浅色 / 深色配色项用标签区分，完整路径可从悬停提示查看。

用方向键选择结果，按 `Enter` 打开；没有选中项时，回车会打开最匹配的实际目标。页面结果打开页面，功能分组或选项结果会滚动到对应位置并高亮，必要时切换到对应配色页签。搜索和定位本身不会修改设置。

搜索「深色」等分类词不会只因归属关系列出其中每个选项。想调整某项时，优先输入它的名称；通过说明找到的结果会标注 **根据说明匹配**。部分旧设置页只有页面入口，没有逐项索引。按 `Esc` 可收起结果。

<a id="开发版按路径组合搜索词" />

### 2.3.2 · 按路径组合搜索词

以下功能从 **2.3.2** 起可用。

可用空格组合分类和选项名称来缩小范围，例如输入 **黑名单 快捷键**，定位黑名单页中的「动作快捷键」开关。前面的词可匹配选项所在的完整路径，**最后一个词必须匹配选项标题**；也可输入对应拼音，例如 `hmd kjj`。

因此交换词序可能得到不同结果：`快捷键 黑名单` 不会按同一规则找到「动作快捷键」。仅在说明或关键词中出现的词不会补齐路径条件。找到结果后仍需打开并自行修改，搜索本身不会改变设置。

2.2.17 起，配置操作时的“常用功能”选择框支持输入名称或拼音筛选；输入法组字期间不会提前改变筛选结果。

2.2.17 起，主菜单原「动作日志」入口已移到本窗口的「动作日志」页签；已有日志继续保留。排查运行问题时，可在同一窗口切换「动作执行」「触发记录」和「动作日志」。

## 挑选上下文菜单的内容

以下功能从 2.2.26 起可用，用于处理文本、图片或文件内容的上下文菜单。

在设置中搜索「上下文菜单」，选择「菜单内容」下的文本、图片或文件页签。每类可分别控制内置功能组，并从「管理关联动作…」调整该类菜单的动作：

| 模式 | 显示方式 |
| --- | --- |
| 自动显示 | 显示符合关联条件的动作，可隐藏个别动作并调整顺序；未排序的动作按标题排列，新安装且符合条件的动作可自动加入 |
| 手动挑选 | 只显示已挑选且符合本次内容条件的动作，按挑选顺序排列；新安装的动作不会自动出现 |

列表支持拖动或用上下按钮排序，修改即时保存。隐藏或从挑选列表移除，只影响该类菜单中的显示，不会删除动作，也不会取消动作本身的关联。管理页列出的是候选动作，实际弹出时仍检查内容匹配条件；挑选了一个动作不代表它会对任意文字、图片或文件显示。

菜单底部的「设置…」入口由三类菜单共用开关控制；即使隐藏该入口，仍可从 Quicker 主设置页进入。若页面显示保存失败或只读原因，应先处理提示，不能把列表上的临时显示当成保存成功。

### 自定义搜索引擎的导入导出

2.2.16 起，设置中的搜索引擎列表支持 **批量导出** 与 **批量导入** JSON，便于备份和迁移自定义搜索引擎。

- **批量导出**：把当前列表中的全部搜索引擎写入 JSON 文件。
- **批量导入**：从 JSON 文件**追加**到当前列表；导入结果先留在编辑草稿中，需在设置页保存后才会写入正式配置。重新打开设置且未保存时，未保存的导入会被丢弃。
- 每条至少需要名称、查询网址和触发词；格式不符时整份文件不会导入任何条目。
