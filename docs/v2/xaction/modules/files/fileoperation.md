# 文件和目录操作

复制、移动、删除、创建文件或文件夹，以及列举目录里的文件。路径必须合法。移动或删除前请先备份重要数据。

## 当前模块定义

<XActionModuleMeta moduleKey="sys:fileOperation" />

## 概述

先选操作类型，再填路径；复制或移动时再填目标路径/名称。

<ModuleParamPreview moduleKey="sys:fileOperation" />

## 参数说明

**操作类型**：见下表。名称与下拉一致。

**路径**：要操作的文件或文件夹。

**目标路径/名称**：复制/移动时的目标目录、结果路径或新文件名。仅部分操作显示。

**覆盖已有**：目标已存在时是否覆盖。仅部分复制/移动操作显示。默认关闭。

**搜索内容** / **包含子目录**：仅「获取文件夹内的文件 / 子文件夹」。见后文。

**失败后中止动作**：操作异常是否终止动作。默认开启。

| 操作类型 | 说明 |
| --- | --- |
| 复制到指定目录下 | 复制单个文件或文件夹到目标目录。路径是源，目标路径/名称是目标文件夹。 |
| 复制到指定目录下(Windows) | 用资源管理器同款方式复制。**路径** 可用列表或多行文本传入多个项，文件名可用 `*` 匹配。 |
| 复制为（指定结果名称或路径） | **目标路径/名称** 写复制结果的完整路径或新名称。 |
| 移动到指定目录下 | 移动单个文件或文件夹到目标目录。 |
| 移动到指定目录下(Windows) | 用资源管理器同款方式移动。同样支持多路径和 `*`。 |
| 移动/重命名为（指定结果名称或完整路径） | **目标路径/名称** 写移动或重命名后的完整路径或新名称。 |
| 删除文件（不支持文件夹） | **路径** 必须是文件。 |
| 删除空文件夹 | 只删空目录。1.39.11 起提供。 |
| 移入回收站 | 把文件或文件夹放进回收站。很大的项可能被直接删除。 |
| 移入回收站（安静模式，自动确认操作） | 不弹界面；无法回收的大项会直接删除。 |
| 创建文件夹 | 目录已存在则跳过。 |
| 创建空文件 | **路径** 必须包含文件名和扩展名。 |
| 获取文件夹内的文件 | 返回匹配的文件路径列表。 |
| 获取文件夹内的子文件夹 | 返回匹配的子文件夹路径列表。 |
| 复制文件/文件夹（自动）【不建议使用】 | 旧操作。文件按文件复制，否则按文件夹。目标可以是完整路径或目标目录。 |
| 移动/重命名文件(夹)（自动）【不建议使用】 | 旧操作。目标可以是完整路径、目标目录，或仅新文件名。 |

### 搜索内容

获取文件时：

- 通配符：`*` 任意多个字符，`?` 一个字符，如 `202*年*月报表.xlsx`（只能一种模式）
- `regex:正则表达式`（1.35.38+），如 `regex:emp.*\.png`。会先取出全部文件再逐个匹配，文件多时较慢
- 多个后缀，用 `;` 分隔（1.35.38+），如 `.jpg;.png;.bmp;.gif`

获取子文件夹时：

- 同样支持 `*` / `?`，如 `202*年*月`
- `regex:正则表达式`（1.38.23+），对每个文件夹名做匹配

**包含子目录**：是否连同下层目录一起搜。默认关闭。

## 输出

- **是否成功**：操作是否成功。
- **路径列表**：仅获取文件 / 子文件夹。
- **结果路径**：仅「复制为」「复制到指定目录下」「移动/重命名为」。

## 限制与排障

- 删除、移动、回收站都不可逆或难以恢复，先在测试目录试。
- 「删除文件」不能删文件夹；空目录用「删除空文件夹」或回收站。
- Windows 方式复制/移动才支持一次传多个路径。
- 大文件或大目录移入回收站时，系统可能直接删除。
