# 轮盘菜单

轮盘菜单把一组常用操作放在指针周围，通过方向和距离选择。适合鼠标不离开当前窗口、又希望「往某个方向一滑就执行」的场景。

通常先通过 [高级鼠标触发](/v2/features/triggers/advanced-mouse-triggers) 进入轮盘会话（例如按住右键并移动，操作选 **显示轮盘菜单**）。圈层容量、可视子动作和场景来源在 **场景与动作管理** 里配置。

## 快速开始

1. 确认 Quicker 在后台运行，并能弹出动作面板或其它触发入口。
2. 打开 **场景与动作管理**，在当前场景中编辑轮盘槽位：可把动作面板中的动作拖入空槽，或在轮盘打开时按下面的 `Ctrl+Shift` 快速添加。
3. 如需从鼠标进入轮盘：打开 **场景与动作管理 → 鼠标触发 → 高级鼠标触发**，新增一条划动或长按规则，操作选 **显示轮盘菜单**（按键以你本机设置为准，常见是右键）。
4. 保存后，在目标程序中按配置的方式打开轮盘，把指针移向目标槽位并提交（滑动模式松开鼠标键，点击模式再点一次）。
5. 需要改圈层容量、指针放大或外观时，打开轮盘功能设置。

一次轮盘会话开始后，目标程序、场景和动作内容会保持稳定，不会因为显示期间前台窗口变化而改用另一套配置。

## 圈层容量与版式

常驻圈可以配置：

- 第二圈：`0`、`8` 或 `16` 格；
- 第三圈：`0`、`8`、`16` 或 `24` 格。

第三圈与传统扩展圈不是同一个功能：

- **第三圈**是始终参与正常布局和指向选择的常驻圈；
- **扩展圈**仍是常驻圈外侧的 8 个方向位置。

启用「自动隐藏连续为空的外圈」后，轮盘会按当前来源中实际存在的动作收起最外侧空圈。它只隐藏连续为空的尾部圈，不会改变每圈格子数，也不会把中间的空圈压缩掉，因此同一动作的方向和位置不会因为临时空了几个槽位而改变。

在轮盘编辑器中，「查看全部位置」可以临时显示第二圈 16 格和第三圈 24 格，方便检查暂时超出当前版式的动作。它只改变编辑器显示，不会修改版式或删除动作。缩小版式可能影响已有动作时，Quicker 会先统计影响范围并要求确认。

第三个常驻圈、可视子动作，以及第二圈第 9～16 格，需要当前有效的专业版授权。当前设备暂时不能使用某个圈层时，配置和动作仍会保留。

## 可视子动作

可以给一个轮盘项添加一组「可视子动作」。指针指向父项后，子动作会在轮盘外侧展开，继续移动即可选择，不需要记住额外按键。

适合把相关命令收在一个父项下、为同一动作提供几种常用参数，或在不长期占用主槽位的情况下扩充一组低频操作。

在轮盘项编辑窗口的「可视子动作」标签页中可以添加、编辑、复制、删除和拖动排序，也可以从父动作的自定义右键菜单导入。每个子动作都可以单独设置标题、图标、说明、延迟时间和临时禁用状态。

可选择三种展开样式：

| 样式 | 特点 |
| --- | --- |
| 扇环式 | 子动作沿轮盘外缘排成一段扇环，适合保持传统轮盘的方向感 |
| 串珠式 | 子动作沿父项方向排成一串圆形按钮，适合直线移动选择 |
| 折扇式 | 子动作在父扇区范围内分层展开，适合项目较多的情况 |

目前只支持一层可视子动作。数量不限制为 8 项，但项目过多时会自动缩小，实际使用时仍建议把一组控制在容易辨认和命中的范围内。

:::note[父项可以只作为分组]

父项可以不设置直接触发动作，只保留可视子动作。此时在父项上释放会取消并关闭轮盘，不会自动执行第一个子动作。

:::

## 按场景覆盖与来源切换

「当前显示哪些动作」和「使用哪一种轮盘版式」是分开处理的。普通程序或子场景可以选择：

- **合并并复用上级轮盘**：保留上级动作，在当前场景中覆盖或增加少量专用动作，并沿用上级版式；
- **独立轮盘模式**：使用当前场景自己的动作和圈层容量，不在初始视图中混入上级动作。

例如：全局轮盘放通用操作，浏览器程序轮盘增加浏览器命令，某个网址再使用自己的独立轮盘。网址轮盘的版式不依赖当前使用 Chrome 还是 Edge，切换浏览器后仍保持相同的动作方向。

轮盘打开后，可以用滚轮在当前场景、宿主程序和全局轮盘等可用来源之间切换。中心位置点会显示有多少个可切换来源以及当前所在位置；没有有效动作的来源会自动跳过。切换来源时，轮盘会使用对应来源的版式重新显示，但保持指针的屏幕位置不变。

## 在轮盘中直接添加和编辑

轮盘打开后，保持 `Ctrl+Shift`：

- 指向空槽并提交，可以直接打开创建窗口；
- 指向已有动作并提交，可以编辑当前实际显示的动作；
- 编辑已有动作时，可以使用「删除此位置动作」移除该槽位内容。

「提交」在滑动模式下是松开触发鼠标键，在点击模式下是点击目标槽位。组合键生效时，空槽会显示「＋」，已有动作会显示编辑提示，轮盘中心同时说明将要修改的场景，例如「添加到当前网址」或「编辑全局轮盘」。

新动作会保存到当前正在查看的来源：当前场景、网址、宿主程序或全局轮盘。编辑继承而来的动作时，则会修改该动作真正所属的来源，不会悄悄复制一份到当前场景。

:::tip[避免误进入编辑]

普通方式在空槽上松手仍然只是取消。只有在本次轮盘操作中明确按下 `Ctrl+Shift`，并在提交时继续按住，才会进入槽位管理。

:::

快速编辑适用于当前可见的常驻圈槽位。轮盘中心、圈间空白、传统扩展圈的空位置和可视子动作区域不会通过此方式创建动作。

在轮盘设置界面中，也可以通过右键菜单直接进入引用动作的编辑。

## 覆盖粘贴与跨场景剪切

2.2.10 起，轮盘动作支持：

- **覆盖粘贴**：把剪贴板中的动作粘贴到已有槽位时可以直接覆盖，不必先清空。
- **跨场景剪切**：可以把轮盘槽位动作剪切到另一场景的轮盘，再粘贴到位；目标写入成功后才会从原场景移除。

整理多个场景的轮盘时，优先用剪切而不是先复制再手动删除，以免留下重复入口。

## 用更短的移动距离够到外圈

第三圈和可视子动作增加了可用空间，也可能让滑动距离变长。可在轮盘功能设置中把「指针放大倍率」设为 `1` 到 `4` 倍，只在按住鼠标键滑动触发时生效。

例如设置为 `2` 倍时，指针从轮盘中心实际移动一段距离，Quicker 会按两倍距离计算轮盘上的指向位置。这样可以用更短的手部移动到达外圈，同时保持原来的方向判断。

- `1` 倍以及 `1.1` 倍以内视为关闭；
- 倍率越大，够到外圈需要的移动越短；
- 放大后，真实指针位置和计算出的指向位置不再重合，轮盘会用小圆点标出当前指向位置；
- 点击方式显示轮盘时不使用指针放大。

建议从较小倍率开始逐步调整。倍率过大虽然移动更短，但也会放大手部的细小偏移。默认是 `1`，不会自动改变原来的滑动距离。

## 运行时快速进设置

通过「按键 + 移动」等高级鼠标规则启动轮盘后，可在结束会话前把指针移到**当前屏幕顶部角落**（识别范围很小）：

- **左上角**：打开本次场景的轮盘动作管理
- **右上角**：打开轮盘功能设置

这不会替代普通的「移到屏幕角落」高级鼠标规则。

## 与手势、扩展热键共用右键时

若右键同时用于轮盘、手势、长按面板和右键扩展热键，Quicker 会按本次操作意图协调：

- 按住右键再按字母 → 倾向扩展热键
- 按住右键并移动 → 可进入轮盘或手势
- 长按右键打开面板后，只要右键仍未松开，还可以继续使用右键组合
- 扩展热键一旦确定触发，同一次按住不会再误转成轮盘或手势

日常配置见 [鼠标手势](/v2/features/triggers/mouse-gestures) 与 [扩展热键](/v2/features/triggers/powerkeys)。

## 限制与排障

- **专业版圈层**：第三个常驻圈、可视子动作，以及第二圈第 9～16 格需要当前有效的专业版授权；不提供传统扩展圈的 90 天试用。当前设备暂时不能使用某个圈层时，配置仍保留。
- **总是进手势而不是轮盘**：检查同一按键上是否同时配置了「显示轮盘菜单」与「开始鼠标手势」，以及移动距离、触发类型是否满足轮盘条件。
- **滑不到外圈**：先看圈层容量和「自动隐藏连续为空的外圈」是否符合预期，再按屏幕边缘、多显示器或高 DPI 情况微调指针放大倍率。
- **Ctrl+Shift 进不了编辑**：确认本次会话中已按下并在提交时仍按住；快速编辑只作用于当前可见的常驻圈槽位。
- **缩小版式后动作不见了**：先用「查看全部位置」检查越界槽位，缩小前留意影响提示。
- **相对 1.x 的圈层、版式和外观变化**：见 [轮盘菜单（2.x 变化）](/v2/what's-new/others/circle-menu)。
