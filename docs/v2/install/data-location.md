# 数据目录与迁移

Quicker 的**安装目录**用于存放程序，**数据目录**用于存放本机账号数据、配置、缓存和日志等。把软件安装到 D 盘，不会自动把数据目录一起移到 D 盘。

## 数据保存在哪里

默认数据目录为：

```text
%LOCALAPPDATA%\Quicker
```

按 `Win+R`，粘贴上述路径并按回车即可打开。它通常对应 `C:\Users\用户名\AppData\Local\Quicker`，实际位置以当前 Windows 用户的本地应用数据目录为准。

其中一些常见子目录如下：

| 目录（相对于数据目录） | 内容 |
| --- | --- |
| `ScreenCapture` | 截图、贴图和采集历史相关数据及设置；原图在 `assets`，缩略图在 `thumbnails` |
| `action-data` | [动作专属的本机数据文件夹](/v2/xaction/concepts/standard#动作数据文件夹) |
| `browser-data` | 内置浏览器的本机用户数据 |

截图历史和贴图图片目前不能在截图设置中单独指定存储目录。如果担心占用 C 盘，可以调整[采集历史的保留设置](/v2/features/screenshot/capture-pro#图片与录屏历史管理)，也可以按下文整体迁移数据目录。自行另存的图片，以及保存在自定义文件夹中的录屏成品，仍在各自选择的位置，不会因整体迁移而自动搬动。

## 将数据迁移到其他磁盘

使用 **Quicker 安装器（QuickerInstaller）→ 工具与诊断 → 迁移 Quicker 数据位置**。这是移动当前电脑上的数据位置，与[从 V1 迁移到 V2](/v2/migration/from-v1)是两件不同的事。

1. 退出 Quicker，并关闭 Chrome / Edge 浏览器；若工具仍提示占用，按提示关闭相关进程。
2. 打开安装器，在 **工具与诊断** 中找到 **迁移 Quicker 数据位置**。
3. 点击 **选择目标并迁移**，选择其他本机固定磁盘上的空文件夹，例如 `D:\QuickerData`。目标磁盘需为 NTFS 或 ReFS，并有足够空间；不能选择磁盘根目录、网络盘、U 盘、系统目录或与原数据目录互相包含的位置。工具会检查目标是否可用。
4. 等待复制、校验和切换完成，再启动 Quicker，检查账号、动作和截图历史是否正常。

迁移覆盖整个 `%LOCALAPPDATA%\Quicker`，包括 `ScreenCapture` 中的截图历史和贴图图片。原目录会改名为 `Quicker.bak-时间戳` 备份，原位置则建立指向目标文件夹的**目录链接（Junction）**。

例如迁移到 `D:\QuickerData` 后，程序仍可通过 `%LOCALAPPDATA%\Quicker\ScreenCapture` 访问截图，但实际数据已存放在 `D:\QuickerData\ScreenCapture`，无需在 Quicker 内修改路径。请保留这个目录链接，也不要自行移动或删除目标文件夹。

### 确认正常后释放原磁盘空间

迁移完成后，原磁盘仍保留一份备份，因此占用不会立即全部释放。确认 Quicker 和重要数据正常后，可在同一工具的 **原数据备份** 列表中使用 **删除备份**，释放这部分空间。

原备份是迁移时的副本，之后的新数据写入迁移目标，不会继续更新这份备份。删除前请确认不再需要它；不要把删除备份当作删除正在使用的数据目录。

### 迁回原位置

需要恢复默认存储位置时，先退出 Quicker 并关闭 Chrome / Edge，再在同一工具中点击 **迁回原位置**。工具会将当前目标中的数据复制、校验并迁回原位置，因此原磁盘需要有足够空间。不要用迁移时的旧备份直接覆盖当前数据。

数据位置迁移不等于云同步或额外备份，也不会把数据目录以外的文件一并迁移。重要文件仍应单独备份；同步范围见[账号、登录与数据同步](/v2/features/account-and-sync)。
