# 组合动作

组合动作把多个步骤按顺序执行，用来完成打开网页、处理文本、操作窗口这类自动化。Quicker 2.0 沿用 1.x 的主要模块，并补充了参数、执行和调试能力。

第一次编写请从 [怎样学会组合动作](/v2/xaction/guides/how-to-learn) 开始。
