# 新增：截图 Pro 模块

“截图 Pro”是 2.x 新增的组合动作模块。它会打开新版全屏选区界面，从光标所在窗口开始选择，并可进一步定位到窗口内的控件。

选择过程中可以使用滚轮切换父级或子级区域，也可以启用自动吸附，让悬停时直接跟踪控件。确认前可以调整选区和使用标注工具；结束时可按参数写入剪贴板或显示为贴图，并返回图片、实际截图区域和用户保存的文件路径。

它适合需要人工确认和标注的截图流程。只需要按固定坐标或窗口句柄在后台取图时，原有“屏幕截图”模块仍然更直接。

参数说明见[截图 Pro](/v2/xaction/modules/screen-capture-pro)。
