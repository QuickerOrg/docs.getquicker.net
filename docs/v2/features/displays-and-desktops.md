# 显示器与虚拟桌面

2.2.20 起，动作设计器的「系统」分类提供 **显示器** 和 **虚拟桌面** 两个步骤。可以先查询设备或桌面列表，再把得到的标识交给后续步骤使用。

## 显示器

「显示器」可获取显示器列表与坐标、工作区、DPI，也可读取、设置、增加或降低硬件亮度。目标可选鼠标所在显示器、主显示器、指定显示器或所有显示器；指定显示器时，可从选择器选设备，或使用上一步输出的显示器标识。

完整参数见[显示器步骤](/v2/xaction/modules/monitor)。

调整亮度时可显示可拖动的亮度浮层。目标亮度按 0–100% 输入；0% 不等于关闭显示器。实际支持的亮度档位取决于设备；部分外接显示器可能不支持硬件亮度读写。对所有显示器执行时，各设备逐一处理；若其中一块失败，已经完成的调整不会回滚。

## 虚拟桌面

「虚拟桌面」可查询列表和当前桌面、切换到指定或相邻桌面、创建、删除、重命名与排序桌面，也可查询或移动窗口、设置窗口固定状态。可用桌面标识、从 1 开始的编号或名称定位；名称重复时请改用编号或标识。

完整参数见[虚拟桌面步骤](/v2/xaction/modules/virtualdesktop)。

删除桌面前，必须指定另一个现存桌面作为窗口迁移目标；不能删除最后一个桌面。创建桌面或移动窗口后若继续切换失败，前一步操作不会自动撤销，运行前请检查是否成功及输出标识。桌面标识在桌面删除或换电脑后可能失效，跨设备动作宜先查询目标。各项操作能否使用取决于 Windows 的完整版本。
