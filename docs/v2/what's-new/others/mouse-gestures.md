# 鼠标手势（V2 变化）

:::info[完整功能说明已合并至功能目录]
鼠标手势轨迹绘制、延迟设置与手势管理请查看主文档 **[鼠标手势](/v2/features/triggers/mouse-gestures)**。本页仅保留相对 1.x 的变化与升级核对项。
:::

## 相对 1.x 的主要变化

- **收笔与长轨迹改进**：改善收笔抖动识别及长轨迹绘制流畅度，支持单条手势独立延迟与场景级覆盖/禁用。
- **快捷设置入口**：手势绘制后可移动到屏幕顶部角落快速进入手势管理或设置。

## 从 1.x 升级时需要注意

- 原有手势图形、程序动作、按键子动作与外观设置全部保留；旧匹配阈值按兼容方式换算，升级后手感保持连贯。
- 旧程序覆盖规则进入场景继承链；本地禁用会屏蔽上级同轨迹规则（删除本地规则才恢复继承）。
