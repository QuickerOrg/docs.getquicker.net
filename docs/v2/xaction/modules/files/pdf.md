# PDF 文件处理

创建、合并、拆分、调整、保护或在 PDF 页面上叠加内容。

## 当前模块定义

<XActionModuleMeta moduleKey="sys:pdf" />

## 支持的操作

模块可以创建空白 PDF、将图片转换为 PDF，或对已有文件执行合并、拆分、提取、复制、重排、删除和旋转页面。还可以读取或修改文档信息、设置或移除密码，以及叠加文字、水印、页码、图片和图形。

选择“操作”后，编辑器只显示该操作需要的参数。处理结果通过“结果路径”“结果路径列表”“页数”或“文档信息”输出。

## 页面选择

需要指定页面的操作使用“页面”参数。可以填写 `all` 处理全部页面，也可以按模块编辑器中的说明填写页码或页码范围。提取、复制和重排时，页面顺序会影响输出文件中的顺序。

## 文件与安全

- 默认不覆盖已有文件；确需覆盖时显式启用“覆盖已有”。
- 处理加密 PDF 时，在“输入密码”中提供打开文件所需的密码。
- 如果输入文件受密码保护，而操作会生成未加密输出，需要显式启用“允许生成未加密输出”。
- 设置密码时可分别填写用户密码和 owner 密码，并配置打印、复制、修改和注释等权限。
- 建议先用副本验证页面范围、覆盖规则和叠加位置，再处理重要文件。
