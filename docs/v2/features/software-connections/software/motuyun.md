模兔云是 SketchUp 中的插件工具。Quicker 通过它提供的本机服务搜索并执行插件命令，让你把常用命令放到 Quicker 面板、快捷键或组合动作中。

**不需要另外安装 Quicker Bridge。** 模兔云与 [SketchUp Bridge](./sketchup.md) 是两个独立入口：前者调用模兔云提供的命令，后者使用 Quicker 自己的 SketchUp 连接插件。使用模兔云命令不要求同时安装 SketchUp Bridge。

## 使用前准备

1. 使用包含“模兔云控制”和“模兔云命令工具”的 Quicker 版本。如果设置页没有模兔云卡片，请先更新 Quicker。
2. 在 SketchUp 中安装并启用支持本机命令接口的模兔云版本。
3. 启动 SketchUp，确认模兔云已加载，再打开 Quicker。
4. 进入 **Quicker 设置 → 软件连接**，找到 **模兔云** 卡片。点击命令工具图标打开命令列表；书本图标打开本页。

Quicker 连接的地址固定为 `http://127.0.0.1:57579`，不经过代理。模兔云卡片没有“安装 / 管理 Bridge”按钮，插件的安装和更新仍在模兔云一侧处理。

卡片的“1 个连接”表示本机模兔云服务可用，不表示只有一个 SketchUp 窗口，也不保证每条命令在当前模型状态下都能执行。

## 搜索和筛选命令

打开命令工具后会自动读取命令目录。输入搜索文字，稍作停顿即可筛选，不需要再点击搜索按钮；也可按 Enter 立即筛选。

- 支持命令名称、说明及插件名搜索，也支持中文拼音和拼音首字母。
- 下拉框按**命令所属插件名**筛选，选择“全部插件”恢复全部结果。
- 列表按插件分组。没有返回插件名的命令归入“未知插件”。
- 选中命令可在下方查看说明。命令 ID 和插件 ID 由程序保存，通常无需手工输入。

当前工具最多请求 500 条命令，搜索是在已读取的列表中进行，并非每次输入都重新请求厂商服务。加载新插件或更新模兔云后，请关闭并重新打开命令工具以重新读取目录。

## 生成动作

1. 选中需要的命令，点击 **生成动作**，或双击该命令。
2. 程序将动作复制到剪贴板。
3. 回到 Quicker 面板，在需要的位置粘贴动作。
4. 切换到希望操作的 SketchUp 窗口，再触发动作。

动作保存命令 ID 和插件 ID，而不是命令工具中的临时连接。名称相同但属于不同插件的命令可能不同，请按所属插件选择。

### 动作图标

生成动作时，Quicker 会读取模兔云返回的本地图标文件：

- **在线账号**：通过 Quicker 图标上传服务转换为网络图标地址，便于同步和分享动作。
- **本地账号**：保存为 Quicker 离线图标，可能显示为 `local-icon:…`，不依赖模兔云原来的文件路径。
- 图标缺失或处理失败时，仍可生成动作，但使用默认图标。

已生成的旧动作不会自动转换图标。如需改成网络图标，请登录在线账号后重新生成动作。分享动作只分享调用方式和图标，不会替对方安装模兔云及其插件。

## 立即执行与目标窗口

点击 **立即执行** 会实际调用选中的命令，不是预览。请先准备好模型及所需选择对象；涉及删除、保存或修改模型的命令，建议先在副本中测试。

**目标 SketchUp 由模兔云判断和分派，Quicker 不选择或保存具体实例。** 多个 SketchUp 同时运行时，请按模兔云的前台窗口规则确认操作目标。Quicker 不负责将请求改投某个指定实例。

模兔云负责串行处理命令，其接口成功响应表示执行完成。部分 SketchUp 工具仍可能需要后续鼠标交互，以具体命令行为为准。

## 在组合动作中使用

添加 **模兔云控制** 模块，可以选择：

| 操作 | 用途 |
| --- | --- |
| 搜索命令 | 按搜索词请求命令列表，可设置最大数量及是否返回图标。 |
| 执行命令 | 提供命令 ID 和插件 ID，执行指定插件命令。建议先用命令工具生成动作，避免手工填错。 |
| 读取工具列表 | 获取模兔云公开的工具目录 JSON，供排查或进一步处理；不是任意工具调用入口。 |

模块可输出“是否成功”和“返回结果”，并支持设置最长等待时间。超时或取消等待不等于撤销宿主已经执行的操作；不要对修改模型的命令盲目重试。

## 常见问题

### 没有连接，或搜索失败

先确认 Quicker、SketchUp 和模兔云都已启动，模兔云在 SketchUp 中已加载且支持本机接口。更新插件后需重启 SketchUp。设置页刷新状态后，再重新打开命令工具。

如果仍失败，记录工具下方的错误，以及 Quicker、SketchUp 和模兔云版本。不要通过安装 SketchUp Bridge 来修复模兔云接口连接，它们不是同一个服务。

### 找不到命令或插件分组

先清空搜索词并选择“全部插件”。确认目标插件已在模兔云中启用，再重新打开命令工具。命令是否出现在目录中取决于模兔云返回的列表；超过当前请求数量的命令可能不在工具列表中，可尝试组合动作模块的“搜索命令”按关键词查询。

### 能找到命令，但执行失败

检查所需插件是否启用、许可证是否有效，以及模型、选择对象和交互状态是否满足命令要求。查看返回的错误信息；Quicker 不会绕过插件授权或 SketchUp 的操作限制。
