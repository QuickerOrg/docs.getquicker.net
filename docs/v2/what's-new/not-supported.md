# 不再支持或不再推荐的功能

V2 会尽量迁移 1.x 数据，但不会永久保留每一种旧运行环境、界面和数据格式。

本页区分“完全移除”“仅保留兼容运行”和“不再建议继续使用”。如果某项仍有替代方式，会在对应章节说明。

## .NET 10 不支持的 Windows 系统

V2 基于 .NET 10，只支持 [.NET 10 官方支持列表](https://github.com/dotnet/core/blob/main/release-notes/10.0/supported-os.md)中的 Windows 系统。

Windows 7、Windows 8 和 Windows 8.1 不在支持范围内，无法安装或运行 V2。Windows 10 是否受支持还取决于具体版本、版本类型及其生命周期，不能仅根据系统名称判断。

仍在这些系统上使用 Quicker 时，应先升级到受支持的 64 位 Windows。暂时不能升级系统的电脑只能继续使用兼容的 1.x 版本，但旧版 Quicker 不会改变 Windows 本身已经停止安全维护的状态。

详细说明见[运行平台、系统要求与 64 位迁移](./platform-and-compatibility.md)。

## x86 和 32 位 Windows

V2 正式版本只提供 x64 安装包，不再提供 x86 正式版本。32 位 Windows 无法安装和运行 V2。

只能加载到 32 位进程中的 DLL、COM、ODBC、OLE DB 或硬件组件，也不能直接加载到 V2 的 x64 进程中。

可以安装对应的 x64 组件，或把只能以 x86 运行的逻辑放到独立辅助程序中。详细说明见[运行平台、系统要求与 64 位迁移](./platform-and-compatibility.md)。

## 手机 App 遥控器

1.x 的手机 App 可以在安卓手机上显示并触发面板按钮。V2 不再提供这套手机遥控功能。

原手机端布局和连接设置不会迁移为 V2 面板场景。目前没有完全等价的内置替代方式。

## 文本悬浮窗

1.x 的文本悬浮窗会在选中文字后显示悬浮按钮，鼠标移入后展开全局动作页和手动添加的动作页。

V2 不再提供旧文本悬浮窗，也不会继续执行“显示文本悬浮窗”操作。

替代功能是[选中文本工具条](../features/triggers/text-selection-toolbar.md)。它更轻量，并支持按场景追加、替换或禁用候选操作。

旧文本悬浮窗配置不会自动等价转换为工具条清单。升级后需要重新选择希望直接显示的操作。

## 旧版组合动作

早期 Quicker 使用“旧版组合动作”，其内部保存一组旧基础动作。它不同于目前使用步骤和变量的新版组合动作。

V2 保留旧版组合动作的运行和查看能力，但不再支持编辑或创建。旧数据会以兼容格式保留。

仍需维护的动作应迁移为新版组合动作。迁移前建议保留旧动作副本，并逐项验证条件、变量、延迟和异常处理结果。

## 依赖 .NET Framework 专有能力的脚本和组件

V2 基于 .NET 10，不再运行在 .NET Framework 4.7.2 进程中。

仅支持 .NET Framework 的程序集、旧应用域隔离、`Thread.Abort`、`BinaryFormatter` 或旧 CodeDOM 行为，不属于 V2 可保证的兼容范围。

Quicker 会为常见旧动作提供兼容处理，但用户脚本和第三方组件仍需自行验证。详情见[运行平台、系统要求与 64 位迁移](./platform-and-compatibility.md)。

## 把 1.x 数据库直接作为 V2 数据库

V2 不支持继续把 1.x 的 `quicker.db` 当作 V2 日常存储直接写入，也不支持用文件覆盖的方式在两代数据库之间来回切换。

应通过正式迁移、同步、动作导入导出和恢复入口转移数据。详细说明见[数据存储与同步变化](./data-and-sync.md)。

## 1.x 与 V2 持续双向编辑

V2 完成迁移后，1.x 和 V2 不会长期双向同步同一份动作和设置。

短期保留两个版本时，应指定一个主要编辑端。不要在两边同时修改同一动作，再期待系统自动合并。

## 尚未迁移的旧操作或步骤

个别旧操作、第三方步骤或异常历史数据可能暂时没有完整的 V2 编辑器。

V2 会尽量保留原始数据，并以兼容运行、只读查看或不可编辑占位的方式打开。不要通过删除未知字段、反复保存或手工改 JSON 强行“修复”。

遇到这种情况时，请先导出动作并保留副本，再附上动作类型、错误提示和来源版本反馈。

## 升级前检查清单

- Windows 版本是否在 .NET 10 官方支持范围内；
- Windows 是否为 64 位；
- 是否使用手机 App 遥控器；
- 是否依赖旧文本悬浮窗；
- 是否仍有需要编辑的旧版组合动作；
- 是否加载 x86 DLL、COM 或数据库驱动；
- 是否有依赖 .NET Framework 专有 API 的 C# 动作；
- 是否准备在 1.x 与 V2 中同时编辑数据。

如果以上任一项是“是”，请先完成备份和替代方案验证，再把 V2 作为主要工作版本。
