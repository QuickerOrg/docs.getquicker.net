# 动作快捷键（V2 变化）

:::info[完整功能说明已合并至功能目录]
动作快捷键的配置、同键继承与冲突排查请查看主文档 **[动作快捷键](/v2/features/triggers/action-hotkeys)**。本页仅保留相对 1.x 的架构变化与升级注意点。
:::

## 相对 1.x 的主要变化

- **进入场景继承链**：由 1.x 全局列表 + 进程白黑名单，升级为按场景（全局、程序、网址等）配置与继承。
- **切换更稳定**：前台切换时保持新旧场景共用按键的系统注册不断开，优先注册新键再释放旧键。
- **批量整理**：支持多选与批量删除；免费版数量配额按全部场景总数计算，超限同步规则保留但限制继续主动新增。

## 从 1.x 升级时需要注意

- 原有全局快捷键与进程白黑名单、等待抬键设置继续保留，不会强制拆散到各程序场景；普通场景编辑器隐藏进程过滤字段。
- 本地禁用同键规则会屏蔽上级规则（彻底停用）；恢复继承请删除本地同键规则。
- 桌面、任务栏和普通资源管理器在 2.x 中属于不同逻辑场景，升级后建议分别确认规则；浏览器网址按「网址 → 当前浏览器 → 浏览器通用 → 全局」继承。
