# 提示消息模块

2.x 重写了应用内提示消息。相比 1.x 的默认样式和全局位置设置，现在每个步骤都可以选择屏幕的六个位置，并可以设置标题、显示时间和保持时长；填写 `-1` 可以让提示持续显示。

重复通知可以按标识替换内容、累计次数或忽略后续消息，适合下载进度、循环计数和状态监控。点击操作除了执行整卡命令，还可以定义一到两个按钮；没有配置点击操作时，点击消息会复制正文。

这些改进适用于应用内的成功、信息、警告和错误提示；“Windows 通知”仍由系统通知中心处理。

参数说明见[提示消息](/v2/xaction/modules/notify)。
