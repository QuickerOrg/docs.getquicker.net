# 分享动作与公共子程序

Quicker 2.2.1 起，动作和公共子程序使用统一的分享与版本体系。同一个分享只有一个网址和一组修订版本，但每个修订可以同时包含供 Quicker 1.x 和 Quicker 2.0 使用的内容。

这意味着作者不必维护两条互不关联的分享记录，使用者也可以从同一个网页查看版本历史、安装适合当前 Quicker 的内容。

:::note 版本要求
请使用 Quicker 2.2.1 或更高版本发布、更新和安装新版 Quicker 2.0 原生分享。若要安装只有 V2 制品的动作，或在动作设计器中下载网络共享子程序，建议升级到 Quicker 2.2.3 或更高版本，避开 2.2.1–2.2.2 中已修复的格式读取和下载问题。较早的 V2 客户端使用过一套独立分享方式，只保留有限的读取兼容能力。
:::

## 一个分享如何保存多个格式

新版分享中的几个概念分别表示：

- **分享 ID**：分享的网址身份。以后更新仍沿用同一个 ID。
- **修订版本（revision）**：每次发布正文更新都会增加一个修订版本，旧修订不会被新正文覆盖。
- **V1**：界面中的“Quicker 1.x（兼容制品）”，供 1.x 客户端使用。
- **V2**：界面中的“Quicker 2.0（原生制品）”，完整保存 Quicker 2.0 动作或子程序。

V1 和 V2 只是同一修订中的两种可安装内容，不是两条独立分享。网页版本历史会在每个修订旁显示 `V1`、`V2` 或两者。

## 分享或更新动作

在动作的右键菜单中选择分享命令，打开分享窗口后：

1. 检查名称、说明、适用软件和关键词。
2. 选择用户许可。
3. 更新已有分享时填写本次更新说明。
4. 在“本次发布格式”中至少选择一种格式。
5. 选择公开分享或不公开分享。
6. 点击“分享”，或使用“分享并打开网页”继续编辑网页信息。

公开分享需要填写动作说明，并为动作设置合适的图标，不能使用默认图标。标签、分类和更详细的图文介绍可以在分享后的网页中继续编辑。

:::warning 分享前检查内容
无论公开还是不公开，都不要在动作或子程序中保存密码、Token、账号凭据、私人文件内容等敏感信息。不公开分享不会出现在动作库中，但持有网址的已登录用户仍可安装。
:::

### 如何选择发布格式

| 本次选择 | Quicker 1.x | Quicker 2.0 | 适用情况 |
| --- | --- | --- | --- |
| V1 + V2 | 安装 V1 | 优先安装同修订的 V2 | 推荐，兼顾两代客户端 |
| 仅 V2 | 无法安装该修订 | 安装 V2 | 使用了 2.0 专属能力，或无法无损生成 V1 |
| 仅 V1 | 安装 V1 | 仍可安装并转换 V1 | 只需要发布兼容内容的特殊情况 |

通常建议同时选择 V1 和 V2。Quicker 2.0 会优先使用同一修订中的原生 V2 内容；该修订没有 V2 时，仍可安装 V1 兼容内容。

某些 Quicker 2.0 动作使用了 1.x 不支持的模块或结构，客户端会说明为什么无法生成 V1。此时可以取消 V1，只发布 V2，不要为了兼容而删除动作必需的步骤。

2.2.2 起继续完善统一分享：Quicker 2.0 可以从统一分享中安装只有 V2 制品的动作，不应再因为缺少 V1 制品而无法安装。若旧客户端仍提示格式不支持或安装失败，请先升级 Quicker，再重新从分享链接安装。

快速更新会沿用当前分享已有的格式。如果动作后来已经无法生成原有的 V1 内容，快速更新会停止并提示打开完整分享窗口，由作者决定是否改为仅发布 V2。

## 公开、审核和不公开分享

- **公开分享**会提交到动作库或子程序库。普通动作通常需要审核；部分账号或资源可能按当前规则直接通过。
- **不公开分享**不会进入公共列表和搜索，但持有网址的已登录用户仍可以安装。
- 将原来的不公开分享改成公开分享后，如果不符合免审核条件，新修订会显示为待审核。

公开动作更新进入审核时，之前已经审核通过的版本会继续公开，不会被待审核正文立即替换。审核通过后，新修订才成为对应格式的最新公开版本；审核未通过也不会破坏此前已经公开的修订。

如果新修订只包含 V2，审核通过后 Quicker 2.0 可以使用新修订，而 Quicker 1.x 继续停留在此前最后一个包含 V1 的公开修订。网页会将没有 V1 内容的分享标记为“仅 V2”。

## 安装和检查更新

Quicker 2.0 检查更新时，会先找到该分享当前最高的可分发修订，再下载这个修订中适合 V2 客户端的内容：有 V2 时使用 V2，否则使用 V1。

2.2.3 修复了从分享链接安装动作时可能读错格式的问题。动作设计器中下载网络共享子程序时，也修复了因格式判断或下载过程异常导致失败的情况。遇到这类问题时，先确认本机 Quicker 版本，再重新打开分享链接或重新下载子程序。

如果新修订要求更高版本的 Quicker，客户端会提示需要升级，而不是悄悄退回到更早的历史修订。升级 Quicker 后，可以再次安装或更新该动作。

Quicker 1.x 只能识别包含 V1 的修订。仅 V2 分享在 1.x 中不会伪装成“动作已删除”；客户端应提示该分享需要 Quicker 2.0 或更高版本。

自动更新是否执行还取决于本地动作的更新设置。未启用自动更新时，客户端可以显示有新版本，由用户手动决定是否更新。

## 版本历史怎么看

每次正文更新都会创建新的 revision。网页的版本历史中：

- `V1` 表示该修订包含 Quicker 1.x 兼容内容；
- `V2` 表示该修订包含 Quicker 2.0 原生内容；
- 同时显示两个标记表示两代客户端都能使用这个修订中的对应内容。

历史记录还会显示更新时间和更新说明。能否安装某个历史修订，仍取决于该分享的公开状态、登录状态、客户端版本以及该修订是否包含当前客户端可用的格式。

2.2.3 起，预览动作窗口标题会显示当前制品与 revision 版本号。对照用户反馈或旧修订时，可先看标题确认自己正在预览的是哪一种制品和哪一个修订。

## 分享公共子程序

公共子程序与普通动作共用分享 ID、revision、公开状态和版本历史。当前客户端发布公共子程序时，会自动同时生成 V1 和 V2 内容，不需要在子程序分享窗口中单独选择格式。

公开子程序会进入子程序库。动作设计器可以从“网络共享子程序”中搜索并添加它；新建引用使用统一分享身份，以后可以按 revision 获取和缓存对应正文。

分享包含公共子程序的 Quicker 2.0 组合动作时，2.2.3 起会把这些子程序完整内嵌到分享制品中。若旧版组合动作无法安全转换为可用制品，发布会被明确阻止；这比生成一个安装后缺少子程序或无法运行的分享更安全。遇到阻止发布提示时，请先把旧版组合动作迁移或拆分成可转换的内容。

只有能够解决通用需求、没有敏感数据的子程序才适合公开。仅供自己或少数人使用时，可以保持不公开并通过网址传递。

## 用户许可和大小限制

动作分享窗口提供三种许可：

- **允许修改和再分享**；
- **可修改，不可再分享**；
- **只读，不可再分享**。

“只读”会限制标准客户端中的编辑、复制、导出和再次分享，但不能防止修改版客户端或调试工具绕过。不要把它当作加密或秘密保护措施。

使用普通许可时，每种发布格式的内容上限为 500 KB。动作超过 500 KB 时，可以在动作分享窗口选择“只读”，上限提高到 2 MB。新分享的公共子程序使用普通许可，超过 500 KB 时需要精简内容；更新已有子程序则沿用该分享原来的许可。

客户端按 UTF-8 实际字节数计算并显示大小，不使用网页列表中的历史显示值判断是否允许发布。

## 旧版 V2 分享

Quicker 2.1.20～2.2.0 曾使用独立的 V2 分享通道。新版客户端不会再通过该通道新建或更新分享，也不会把旧 V2 内容加入新的公共目录。

为了让已经安装的动作和旧网络子程序继续运行，旧分享在过渡期内仍可按原网址或 ID 读取。作者需要继续维护旧分享时，应使用 Quicker 2.2.1 或更高版本重新分享，使它进入新的统一版本体系。

## 常见问题

### 为什么 Quicker 1.x 找不到这个分享？

该分享可能只有 V2 内容。请使用 Quicker 2.2.1 或更高版本安装，或请作者重新发布包含 V1 的修订。

### 为什么 Quicker 2.0 也安装不了仅 V2 分享？

先确认本机版本。2.2.2 起已修复只有 V2 制品的动作无法安装的问题，2.2.3 还修复了从分享链接安装时可能读错格式的情况。升级后重新打开分享链接，通常比反复下载旧文件更可靠。

### 为什么改成公开后显示待审核？

不公开分享本身不进入公共审核。改成公开后，如果作者或动作不符合免审核条件，当前修订需要先通过审核。

### 为什么作者已经更新，动作库里仍是旧版本？

新修订可能仍在审核中。审核期间，动作库继续分发此前已经通过的版本。

### 为什么提示升级 Quicker，而不是安装旧版本？

更新目录以最新可分发 revision 为准，不会为了兼容旧客户端而回退历史版本。这样可以避免客户端长期停留在作者已经替换的旧正文。

### 为什么快速更新要求打开完整分享窗口？

常见原因是当前动作已经无法生成原分享包含的 V1 格式。完整窗口允许作者重新检查格式，并明确决定是否改为仅发布 V2。

### 不公开分享等于只有作者能下载吗？

不是。不公开只表示不进入动作库或搜索；持有网址的已登录用户仍可安装。不要在其中保存需要保密的数据。
