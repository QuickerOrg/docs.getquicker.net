# 工具与使用体验

除底层架构和动作系统外，V2 还更新了多项日常可见功能。本页只列出相对于 1.x 较重要的变化。

## 截图 Pro、贴图与录屏

V2 将截图、贴图、长截图和录屏整理为更完整的工作流。

截图 Pro 支持窗口与 UI 元素选区、手动框选、标注、OCR、智能马赛克、斜铺文字水印、贴图、长截图和录屏入口。动作步骤也能返回图片、截图区域和保存路径。

选区阶段可用 `Ctrl+A` 在鼠标所在显示器与全部屏幕之间切换。截图 Pro、长截图和录屏的工具栏可以拖动并吸附到选区附近，双击手柄可恢复自动定位；吸附窗口时也会尽量排除窗口阴影。

步骤工具栏既可用可视化方式拖放内置工具、分组和自定义命令，也可配置 **自定义工具栏脚本**（JavaScript）：用压缩写法 `sp` / `act` 给默认工具栏加「调子程序 / 开动作」按钮，需要分支时再写完整 `run`。说明见 [JS 自定义工具栏](../features/screenshot/toolbar-script.md)。

贴图支持缩略图视口、图像处理、标注、透明度和拖出图片。重启后恢复贴图时，原显示器仍在则尽量保留上次屏幕位置；HTML 和公式贴图使用隔离渲染后以普通图片窗口显示，可继续拖移、显示阴影并选字复制。Quicker 或 PixPin 复制的图片位置可随剪贴板保留，配合贴图步骤的「截图原位置」把图片贴回原处。

截图、贴图与录屏历史使用统一的采集历史中心。录屏成品可页内预览、复制、另存和切换播放速度；进行中的录屏也可以在这里管理。交互式和后台录屏步骤支持选择保存文件夹，写到自定义目录的成品只建立历史索引，不再为了入库额外复制一份。

详情见[截图与贴图概览](../features/screenshot/index.md)和[截图 Pro](../features/screenshot/capture-pro.md)。

## 选中文本工具条

1.x 的“文本悬浮窗”会展开动作页，界面较大，也把文本选择与旧动作页结构绑定在一起。

V2 改为轻量的“选中文本工具条”。它可以在选中文字后显示少量常用操作，并把更多操作收纳到展开菜单中。

工具条支持全局默认清单和按场景追加、替换或禁用。也可以关闭自动显示，仅通过快捷键主动呼出。

详情见[选中文本工具条](../features/triggers/text-selection-toolbar.md)。

## 动作与文件搜索

新版主窗口支持两种搜索范围。面板悬停显示时直接键入名称或拼音，会筛选当前动作区域；点击标题栏搜索入口，则打开跨场景的全局搜索窗口。

动作搜索会显示动作所在的新面板场景和分组，也可以从结果打开实际位置。搜索框为空时，历史动作按使用时间排列，便于再次运行近期内容。

文件搜索改用新版 Everything 接口并复用连接。Windows 应用搜索、图标加载和结果刷新也进行了调整。

“打开所在位置”会尽量复用已有资源管理器窗口。对部分支持的第三方文件管理器，也可以复用已有标签页，而不是重复打开窗口。

这些改进不会改变已有动作数据，但能减少在大量动作和文件之间查找、定位和重复开窗的成本。

## 应用更新

V2 的更新窗口可以直接选择“下载并静默更新”，也可以跳过当前版本或暂不更新。

自动安装要求服务端提供 HTTPS 下载地址和完整 SHA-256 校验值。下载完成后，Quicker 会再次核对文件哈希；独立更新程序还会验证安装包的 Windows 签名，并要求发布者与更新程序一致。

确认更新后，Windows 会在安装阶段请求一次管理员权限。Quicker 随后退出，使用 Windows Installer 静默安装，并在完成后尝试以普通用户身份重新启动。

如果签名、发布者、文件位置或哈希验证失败，Quicker 不会继续静默安装。安装成功但 Windows 要求重启时，更新程序会提示保存工作并重启电脑。

## 统一的窗口和提示交互

V2 对设置、动作管理、确认框和通知窗口的生命周期进行了统一处理。

多数确认窗口只阻止发起操作的窗口，不再因为一个对话框而冻结同一线程上的所有 Quicker 窗口。提示按钮、禁用状态和关闭顺序也更加一致。

新版主窗口默认采用不抢占前台焦点的面板行为。进入搜索输入状态后才允许正常输入，结束搜索后恢复面板的被动显示方式。

## 场景动作的批量整理

“场景与动作管理”支持多选、连续选择、全选、批量移动、同时添加和安全剪切。

剪切不会立即从来源移除动作。只有成功写入目标场景后，Quicker 才会清理来源位置，减少未粘贴或粘贴失败导致的数据风险。

详情见[新面板窗口的使用](./new-main-win/usage.md)。
