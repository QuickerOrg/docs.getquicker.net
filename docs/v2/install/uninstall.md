# 卸载 Quicker V2

## 从 Windows 卸载

1. 保存正在进行的工作，退出 Quicker。
2. 打开 Windows **设置 → 应用 → 已安装的应用**（Windows 10 中为“应用和功能”），搜索 **Quicker**。
3. 选择 **卸载**，按 Windows Installer 的提示完成操作；请求管理员权限时按提示确认。

也可以从 **控制面板 → 程序和功能** 中找到 Quicker 并卸载。若提示文件被占用或其他安装正在进行，先关闭相关程序或等待安装任务结束，再重试。不要直接删除安装目录来代替卸载。

## 卸载后，本机数据还在吗

卸载程序不会主动清空 `%LOCALAPPDATA%\Quicker` 中的本机数据。配置、动作和截图历史等数据可能继续占用磁盘空间；重新安装后也可能继续使用这些数据。卸载软件不等于删除账号或清空云端数据。

如果只是重新安装以修复程序，通常保留本机数据即可。先备份重要数据，再从[官网 V2 页面](https://getquicker.net/V2)下载安装；需要安装旧版时，先阅读[升级与回退](/v2/migration/upgrade-and-rollback)，不要把重装当作无风险降级。

## 需要清理本机数据时

只有确认不再需要本机配置、动作、截图历史及其他本机文件时，才考虑清理。云同步不覆盖全部本机文件，不能替代备份，参见[账号、登录与数据同步](/v2/features/account-and-sync)。

1. 卸载前确认重要数据已备份，并记下实际数据位置。
2. 完成卸载后，按 `Win+R`，输入 `%LOCALAPPDATA%\Quicker` 查看数据目录。
3. 确认其中的内容不再需要后，再手动清理；不确定时先保留。

如果曾通过安装器迁移数据，默认路径可能是指向其他磁盘的目录链接。清理前先核对[数据目录与迁移](./data-location.md)中的实际目标和备份位置，避免误删正在使用的数据或只处理了链接却遗漏实际数据。自行另存的图片、录屏和其他文件仍需到各自保存位置处理。

## 更新出错时的安装日志

如果此次卸载是为了处理更新失败，先保留错误提示和对应安装日志。由 **2.3.28 或更高版本发起的内置升级**，默认日志目录为：

```text
%TEMP%\QuickerInstallerLogs
```

按 `Win+R` 打开目录，按修改时间查找 `Quicker-install-<目标版本>-<时间>-<随机标识>.log`。默认尝试保留最近 10 份非空日志，详情见[安装日志](./update.md#2328--安装日志)。此目录用于内置升级日志，不保证包含手动安装或卸载日志。
